## Overview

The `AnonymizeText` command transforms text using PII detections supplied in `analyzer_results`. Operators can be configured per entity type or through the `DEFAULT` key.

Analyzer and Anonymizer may be deployed at separate endpoints. Use the configured Anonymizer address rather than assuming a shared service URL.

<NodeGraph />

## Request and response

Send `application/json` with the original `text` and an `analyzer_results` array. The optional `anonymizers` map selects operators such as replace, redact, mask, hash, and encrypt. A `200 OK` response returns the transformed text and the applied operations. `400` and `422` responses report invalid requests or input.
