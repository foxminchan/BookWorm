The `AnonymizeText` command (`POST /anonymize`) requests PII transformation from the internal **Presidio** Anonymizer sidecar (`presidio-anonymizer`) using entity spans produced by [[command|AnalyzeText]]. In BookWorm, **Chat API** and **Rating API** call this endpoint through `BookWorm.Chassis` to replace detected PII spans with `<PII>`.

## Overview

| Property                  | Value                                                                                                                                                                                                                                       |
| :------------------------ | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Owner**                 | Data privacy sidecar (`presidio-anonymizer`, image `ghcr.io/data-privacy-stack/presidio-anonymizer:latest`)                                                                                                                                 |
| **Source**                | `src/BuildingBlocks/BookWorm.Chassis/AI/Presidio/Clients/IPresidioAnonymizer.cs`, `src/BuildingBlocks/BookWorm.Chassis/AI/Presidio/PresidioContracts.cs`, `src/Integrations/BookWorm.Hosting.Presidio/PresidioResourceBuilderExtensions.cs` |
| **Protocol / format**     | HTTP `POST /anonymize`, `application/json` (container port `3000`; HTTPS with developer certificate locally, HTTP in publish mode)                                                                                                          |
| **Authentication**        | Internal sidecar only (no Microsoft Entra ID token; not routed through the YARP API Gateway)                                                                                                                                                |
| **Consumers in BookWorm** | **Chat API** (`chatting`), **Rating API** (`rating`) via `AddPresidio()` and `IPresidioService`                                                                                                                                             |
| **Health check**          | `GET /health` on the `presidio-anonymizer` endpoint                                                                                                                                                                                         |

:::warning
Pass `analyzer_results` computed against the exact same `text` string. Stale character offsets cause Presidio Anonymizer to corrupt unrelated substrings or reject the request.
:::

## Parameters and fields

### Request body (`application/json`)

| Name               | Type                  | Required | Default           | Constraints                                                  | Description                                        |
| :----------------- | :-------------------- | :------- | :---------------- | :----------------------------------------------------------- | :------------------------------------------------- |
| `text`             | `string`              | Yes      | —                 | Exact string analyzed by `AnalyzeText`                       | Original text containing PII spans to transform.   |
| `analyzer_results` | `object[]`            | Yes      | —                 | Each item requires `start`, `end`, `score`, `entity_type`    | PII detections returned by `POST /analyze`.        |
| `anonymizers`      | `map<string, object>` | No       | `DEFAULT` replace | Keys are `DEFAULT` or an entity type (for example, `PERSON`) | Per-entity or fallback operator configuration map. |

### `analyzer_results` item fields

| Name          | Type      | Required | Default | Constraints                     | Description                                                          |
| :------------ | :-------- | :------- | :------ | :------------------------------ | :------------------------------------------------------------------- |
| `start`       | `integer` | Yes      | —       | `>= 0`                          | Zero-based inclusive start character offset in `text`.               |
| `end`         | `integer` | Yes      | —       | `> start`                       | Zero-based exclusive end character offset in `text`.                 |
| `score`       | `number`  | Yes      | —       | `0.0`–`1.0`                     | Confidence score returned by Presidio Analyzer.                      |
| `entity_type` | `string`  | Yes      | —       | Non-empty Presidio entity label | Entity type used to select the matching operator from `anonymizers`. |

### Supported `anonymizers` operator schemas

| `type` value | Required fields                                                | Optional fields                                            | Description                                                                                                                             |
| :----------- | :------------------------------------------------------------- | :--------------------------------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------- |
| `"replace"`  | `type`, `new_value` (`string`)                                 | —                                                          | Replaces the detected span with `new_value`. BookWorm's `PresidioService` sends `DEFAULT: { "type": "replace", "new_value": "<PII>" }`. |
| `"redact"`   | `type`                                                         | —                                                          | Removes the detected span completely.                                                                                                   |
| `"mask"`     | `type`, `masking_char` (`string`), `chars_to_mask` (`integer`) | `from_end` (`boolean`)                                     | Replaces `chars_to_mask` characters with `masking_char`, starting from the beginning or from the end when `from_end` is `true`.         |
| `"hash"`     | `type`                                                         | `hash_type` (`"sha256"` or `"sha512"`; default `"sha256"`) | Replaces the detected span with its cryptographic digest.                                                                               |
| `"encrypt"`  | `type`, `key` (`string`)                                       | —                                                          | Encrypts the detected span with the supplied cryptographic key.                                                                         |

### Response body (`200 OK`, `application/json`)

| Name    | Type       | Required | Default | Constraints                                                                              | Description                                                                                                     |
| :------ | :--------- | :------- | :------ | :--------------------------------------------------------------------------------------- | :-------------------------------------------------------------------------------------------------------------- |
| `text`  | `string`   | Yes      | —       | —                                                                                        | Transformed text after applying configured operators. Deserialized by BookWorm's `AnonymizerResponse`.          |
| `items` | `object[]` | No       | —       | Each item requires `start`, `end`, and `entity_type`; `operator` and `text` are optional | Applied operator metadata returned by Presidio Anonymizer; not deserialized by BookWorm's `AnonymizerResponse`. |

The [upstream Presidio OpenAPI schema](https://raw.githubusercontent.com/data-privacy-stack/presidio/refs/heads/main/docs/api-docs/api-docs.yml) defines the `items` fields and declares `sha256` as the default `hash_type`. This is the published upstream contract; BookWorm's `latest` image tag is mutable and is not pinned to a specific Presidio release.

## Behavior and side effects

- **Stateless transformation:** `POST /anonymize` transforms the supplied string in memory and stores no data.
- **BookWorm default operator:** `PresidioService` (`src/BuildingBlocks/BookWorm.Chassis/AI/Presidio/PresidioService.cs`) defines a frozen dictionary containing `"DEFAULT": { "type": "replace", "new_value": "<PII>" }` (`ReplaceAnonymizer`) and sends all `analyzer_results` returned by `IPresidioAnalyzer.AnalyzeAsync`. If the deserialized response is null, `PresidioService` throws `JsonException`.
- **PII logging restriction:** Do not log raw `text` request bodies when they may contain customer PII.

## Error responses

| Code / status              | Condition                                                   | Recovery behavior                                                                            |
| :------------------------- | :---------------------------------------------------------- | :------------------------------------------------------------------------------------------- |
| `400 Bad Request`          | Upstream OpenAPI example: invalid request JSON              | Correct the request body; the specification does not define an exhaustive condition mapping. |
| `422 Unprocessable Entity` | Upstream OpenAPI example: invalid input, such as empty text | Correct the input; the specification does not define an exhaustive condition mapping.        |

The [upstream Presidio OpenAPI contract](https://raw.githubusercontent.com/data-privacy-stack/presidio/refs/heads/main/docs/api-docs/api-docs.yml) explicitly declares both `400` and `422` for `POST /anonymize`, with examples of invalid JSON and invalid input respectively. It does not specify every condition-to-status mapping or a stable contract for the mutable `latest` image.
