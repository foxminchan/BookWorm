## Single-string JSON request

<CodeGroup>

```json
{
	"text": "Contact Jane Example at jane@example.test.",
	"language": "en",
	"entities": ["PERSON", "EMAIL_ADDRESS"],
	"score_threshold": 0.6
}
```

</CodeGroup>

Expected response (`200 OK`):

<CodeGroup>

```json
[
	{
		"entity_type": "PERSON",
		"start": 8,
		"end": 20,
		"score": 0.85
	},
	{
		"entity_type": "EMAIL_ADDRESS",
		"start": 24,
		"end": 41,
		"score": 0.99
	}
]
```

</CodeGroup>

## Call from C# (`HttpClient`)

<CodeGroup>

```csharp
using System.Net.Http.Json;
using System.Text.Json;

var analyzerUrl = Environment.GetEnvironmentVariable("ANALYZER_URL")
    ?? throw new InvalidOperationException("Set ANALYZER_URL to the Presidio Analyzer base URL.");

using var httpClient = new HttpClient { BaseAddress = new Uri(analyzerUrl) };
using var response = await httpClient.PostAsJsonAsync("/analyze", new
{
    text = "Contact Jane Example at jane@example.test.",
    language = "en",
    entities = new[] { "PERSON", "EMAIL_ADDRESS" },
    score_threshold = 0.6
});

response.EnsureSuccessStatusCode();

using var results = await JsonDocument.ParseAsync(await response.Content.ReadAsStreamAsync());
foreach (var item in results.RootElement.EnumerateArray())
{
    Console.WriteLine(
        $"{item.GetProperty("entity_type").GetString()}: " +
        $"{item.GetProperty("start").GetInt32()}-{item.GetProperty("end").GetInt32()} " +
        $"(score {item.GetProperty("score").GetDouble():F2})");
}
```

</CodeGroup>

Expected output:

<CodeGroup>

```text
PERSON: 8-20 (score 0.85)
EMAIL_ADDRESS: 24-41 (score 0.99)
```

</CodeGroup>
