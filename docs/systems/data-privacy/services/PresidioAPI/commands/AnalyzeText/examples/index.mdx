## Analyze text with `HttpClient`

Send a text string and language to the Analyzer. The response is an array of
detections containing the entity type, offsets, and confidence score. When
analyzing a batch, Presidio returns one array of detections per input string.

<CodeGroup dropdown>

```csharp AnalyzeText.cs
using System.Net.Http.Json;
using System.Text.Json;

var analyzerUrl = Environment.GetEnvironmentVariable("ANALYZER_URL")
    ?? throw new InvalidOperationException("Set ANALYZER_URL to the Presidio Analyzer base URL.");

using var httpClient = new HttpClient { BaseAddress = new Uri(analyzerUrl) };
using var response = await httpClient.PostAsJsonAsync("/analyze", new
{
    text = "Contact Jane Example at jane@example.test.",
    language = "en",
    entities = new[] { "PERSON", "EMAIL_ADDRESS" },
    score_threshold = 0.6
});

response.EnsureSuccessStatusCode();

using var results = await JsonDocument.ParseAsync(await response.Content.ReadAsStreamAsync());
PrintDetections(results.RootElement);

static void PrintDetections(JsonElement element)
{
    if (element.ValueKind == JsonValueKind.Array)
    {
        foreach (var item in element.EnumerateArray())
        {
            PrintDetections(item);
        }

        return;
    }

    if (element.ValueKind == JsonValueKind.Object
        && element.TryGetProperty("entity_type", out var entityType))
    {
        Console.WriteLine(
            $"{entityType.GetString()}: {element.GetProperty("start").GetInt32()}-" +
            $"{element.GetProperty("end").GetInt32()} " +
            $"(score {element.GetProperty("score").GetDouble():F2})");
    }
}
```

</CodeGroup>

The sample prints entity labels and offsets rather than the submitted text.
Avoid logging raw text or full response bodies when processing real PII.
