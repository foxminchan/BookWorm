## Overview

The `AnalyzeText` command asks [[service|PresidioAPI]] Analyzer to detect PII in text. The request accepts either a single string or an array of strings and can restrict entity types, configure a score threshold, or request decision explanations.

Analyzer and Anonymizer may be deployed at separate endpoints. Use the configured Analyzer address rather than assuming a shared service URL.

<NodeGraph />

## Request and response

Send `application/json` with the required `text` and ISO 639-1 `language`. A `200 OK` response contains detected entity types, start and end offsets, and confidence scores. For a batch request, the response contains one result array per input string.
