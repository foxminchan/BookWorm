`GetRecognizers` queries the internal [[service|presidio-api]] Analyzer sidecar (`GET /recognizers`) to list the PII recognizers available for a language. This endpoint is an upstream capability discovery query; BookWorm's runtime PII middleware calls only `POST /analyze` (defaulting to `language: "en"`).

## Overview

| Property                           | Value                                                             |
| :--------------------------------- | :---------------------------------------------------------------- |
| **Bounded Context**                | Data Privacy (External Integration)                               |
| **Owner Service**                  | [[service\|presidio-api]] (`presidio-analyzer`)                   |
| **Protocol / Format**              | HTTP `GET /recognizers`, `application/json` response              |
| **Gateway Endpoint**               | Internal sidecar `GET /recognizers` (not exposed via API Gateway) |
| **Authentication & Authorization** | None (internal service-to-service network boundary)               |
| **Idempotency / Concurrency**      | Read-only and naturally idempotent                                |
| **Rate Limit / Caching**           | None (sidecar)                                                    |
| **Contract Version**               | `1.0.0`                                                           |

:::note
**Capability discovery only:** BookWorm's runtime privacy middleware does not call `GET /recognizers`; it calls [[command|AnalyzeText]] with `language: "en"`.
:::

## Request & Response Contract

### Query Parameters

| Name       | Type     | Required | Constraints                               | Description                                                             |
| :--------- | :------- | :------- | :---------------------------------------- | :---------------------------------------------------------------------- |
| `language` | `string` | No       | Two-character ISO 639-1 code (e.g., `en`) | Filters returned recognizers to those loaded for the specified language |

### Success Response (`200 OK`)

| Name       | Type       | Required | Constraints               | Description                                                |
| :--------- | :--------- | :------- | :------------------------ | :--------------------------------------------------------- |
| Root value | `string[]` | Yes      | Array of recognizer names | Names of PII recognizers loaded for the requested language |

## Behavior & Side Effects

- **Read-only discovery:** Returns loaded recognizer names from the sidecar without mutating state.

## Error Responses

| Status / Code               | Condition                                                                                              | Client Recovery Action                                  |
| :-------------------------- | :----------------------------------------------------------------------------------------------------- | :------------------------------------------------------ |
| `500 Internal Server Error` | Unsupported `language` (`"No matching recognizers were found to serve the request."`) or sidecar error | Supply a supported ISO 639-1 language code (e.g., `en`) |
