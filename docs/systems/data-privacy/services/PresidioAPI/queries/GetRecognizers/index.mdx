## Overview

The `GetRecognizers` query lists the recognizers available from [[service|PresidioAPI]] Analyzer. Use the optional `language` query parameter to select a language using its two-character ISO 639-1 code.

<NodeGraph />

## Query parameters and response

`language` is optional. A `200 OK` response returns an array of recognizer names.

### Query using cURL

<CodeGroup dropdown>

```sh GetRecognizers.sh
curl --get --data-urlencode "language=en" "$ANALYZER_URL/recognizers"
```

</CodeGroup>
