## Query supported English entities with curl

<CodeGroup>

```bash
curl --fail --get --data-urlencode "language=en" "<presidio-analyzer-url>/supportedentities"
```

</CodeGroup>

Where:

- `<presidio-analyzer-url>`: Base URL of the `presidio-analyzer` container (resolved from the Aspire Dashboard or `ConnectionStrings__presidio-analyzer`).

Illustrative response (`200 OK`, from the upstream OpenAPI example; the installed image may expose a different list):

<CodeGroup>

```json
[
	"PHONE_NUMBER",
	"US_DRIVER_LICENSE",
	"US_PASSPORT",
	"LOCATION",
	"CREDIT_CARD",
	"CRYPTO",
	"UK_NHS",
	"US_SSN",

	"IP_ADDRESS",
	"PERSON",
	"IBAN_CODE",

	"US_ITIN",
	"MEDICAL_LICENSE",
	"URL"
]
```

</CodeGroup>

## Query supported entities with C# `HttpClient`

<CodeGroup>

```csharp
using System.Net.Http.Json;

var analyzerUrl = Environment.GetEnvironmentVariable("ANALYZER_URL")
    ?? throw new InvalidOperationException("Set ANALYZER_URL to the Presidio Analyzer base URL.");

using var httpClient = new HttpClient { BaseAddress = new Uri(analyzerUrl) };
using var response = await httpClient.GetAsync("/supportedentities?language=en");
response.EnsureSuccessStatusCode();

var entities = await response.Content.ReadFromJsonAsync<string[]>()
    ?? throw new InvalidOperationException("Presidio returned an empty supported-entities response.");

foreach (var entity in entities)
{
    Console.WriteLine(entity);
}
```

</CodeGroup>
