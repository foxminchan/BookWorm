## Query built-in anonymizers with curl

<CodeGroup>

```bash
curl --fail "<presidio-anonymizer-url>/anonymizers"
```

</CodeGroup>

Where:

- `<presidio-anonymizer-url>`: Base URL of the `presidio-anonymizer` container (resolved from the Aspire Dashboard or `ConnectionStrings__presidio-anonymizer`).

The upstream OpenAPI example for `200 OK` lists these operators; it is not asserted as the complete response from the mutable `latest` image. The upstream [Anonymizer API tests](https://github.com/data-privacy-stack/presidio/blob/main/e2e-tests/tests/test_api_anonymizer.py) currently expect an additional `custom` entry. Treat either list as upstream reference data, not a guarantee about BookWorm's deployed image.

<CodeGroup>

```json
["hash", "mask", "redact", "replace", "encrypt"]
```

</CodeGroup>

## Query built-in anonymizers with C# `HttpClient`

<CodeGroup>

```csharp
using System.Net.Http.Json;

var anonymizerUrl = Environment.GetEnvironmentVariable("ANONYMIZER_URL")
    ?? throw new InvalidOperationException("Set ANONYMIZER_URL to the Presidio Anonymizer base URL.");

using var httpClient = new HttpClient { BaseAddress = new Uri(anonymizerUrl) };
using var response = await httpClient.GetAsync("/anonymizers");
response.EnsureSuccessStatusCode();

var anonymizers = await response.Content.ReadFromJsonAsync<string[]>()
    ?? throw new InvalidOperationException("Presidio returned an empty anonymizers response.");

foreach (var anonymizer in anonymizers)
{
    Console.WriteLine(anonymizer);
}
```

</CodeGroup>
