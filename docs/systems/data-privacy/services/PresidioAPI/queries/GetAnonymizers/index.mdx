## Overview

The `GetAnonymizers` query lists the built-in operators available from [[service|PresidioAPI]] Anonymizer.

<NodeGraph />

## Response

A `200 OK` response returns an array of supported operator names, such as `hash`, `mask`, `redact`, `replace`, and `encrypt`.

### Query using cURL

<CodeGroup dropdown>

```sh GetAnonymizers.sh
curl "$ANONYMIZER_URL/anonymizers"
```

</CodeGroup>
