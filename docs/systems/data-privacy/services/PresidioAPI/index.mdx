## Overview

The Presidio API is the integration surface of [[system|data-privacy]].
The [[system|rating-system]] uses it through the
[[agent|rating-agent]] PII middleware for privacy processing in feedback
summarization. The Chat service also uses it for [[agent|router-agent]],
[[agent|qa-agent]], [[agent|book-agent]], [[agent|book-catalog-researcher]], and
[[agent|book-recommendation-researcher]]. The researchers reuse Book Agent's
middleware-wrapped chat client.

The agents' middleware sends [[command|AnalyzeText]] for non-empty text to detect
sensitive entities, then [[command|AnonymizeText]] with the analysis results
when PII is detected. Both commands connect these agents to this service in
the catalog graph and represent middleware HTTP requests, not model-selected
tools or brokered messages.

## API capabilities

| Operation                | Purpose                                                                                             |
| ------------------------ | --------------------------------------------------------------------------------------------------- |
| `POST /analyze`          | [[command\|AnalyzeText]] detects PII and returns entity types, text offsets, and confidence scores. |
| `POST /anonymize`        | [[command\|AnonymizeText]] transforms text using detected entities and configured anonymizers.      |
| `GET /recognizers`       | [[query\|GetRecognizers]] lists available recognizers for a language.                               |
| `GET /supportedentities` | [[query\|GetSupportedEntities]] lists PII entity types detectable for a language.                   |
| `GET /anonymizers`       | [[query\|GetAnonymizers]] lists supported anonymization operators.                                  |

The upstream contract also describes deanonymization and health endpoints.
Those capabilities are not documented as part of the Reviews or Chat integrations.
Analyzer and Anonymizer may use separate deployed endpoints; consult the
operation-level server definitions and runtime configuration.
