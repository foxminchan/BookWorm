## System Purpose & Boundary

The Identity Provider system is BookWorm's external authentication and OAuth 2.0 / OpenID Connect (OIDC) boundary, backed by Microsoft Entra ID. It authenticates **Customers**, **Business Users**, and **Administrators**, issues JWT access tokens, and supports On-Behalf-Of (OBO) agent identity delegation across BookWorm services. Owning domain business data and making fine-grained resource authorization decisions are explicitly out of scope—each consuming BookWorm service enforces its own policies and ownership checks.

:::warning
Authentication is a prerequisite for protected operations, not a substitute for service-level authorization. Protected BookWorm APIs must **fail closed** when token validation or provider metadata fails, never falling back to anonymous access.
:::

## External Interactions & Trust Boundaries

- **Human sign-in:** Customers, Business Users, and Administrators authenticate through Storefront and Backoffice sessions and present bearer tokens to protected BookWorm APIs.
- **Service token validation:** [[system|product-catalog-system]], [[system|cart-system]], [[system|order-system]], [[system|rating-system]], [[system|chat-system]], [[system|mcp-tools]], and [[system|scheduler-system]] validate issuer, audience, signing keys, expiry, roles, and scopes before executing protected operations.
- **Agent delegation:** Supports delegated OBO token exchange between [[system|chat-system]], [[system|rating-system]], and [[system|mcp-tools]].
