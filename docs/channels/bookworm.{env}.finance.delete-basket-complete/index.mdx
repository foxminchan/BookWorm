## Overview

Finance publishes [[command|DeleteBasketCompleteCommand]] after successful
basket cleanup. [[service|order-api]] logs the outcome without changing the
Order's business status. This is separate from Basket's own deletion event.

The camelCase JSON payload contains `id`, `creationDate`, `orderId`, and
`totalMoney` inside the BookWorm CloudEvents-compatible envelope.
