Rating publishes this event when a customer deletes feedback. Catalog consumes it to remove that rating from the book's displayed summary.

**Producer:** Rating service. **Consumer:** Catalog service.

If Catalog no longer has the book, it treats the event as a no-op; no compensation is sent.

## Channel information

<ChannelInformation />

## Topic and message

The topic is `bookworm.{env}.rating.feedback-delete`. Replace `{env}` with `development`, `staging`, or `production`. Messages are CloudEvents JSON keyed by `bookId` and include the deleted feedback ID and rating. Failed Catalog processing goes to [[channel|bookworm.&#123;env&#125;.catalog.dead-letter-queue]].

## Operations and recovery

Check that the feedback deletion was committed and inspect the book's rating summary before replaying. An already-missing book is an expected no-op. Restore Catalog service or database health before replay; avoid manually adjusting the summary unless the source feedback data has been reconciled.
