Catalog publishes this compensation signal when a new feedback submission refers to a book it cannot find. Rating uses it to remove the orphaned feedback record.

**Producer:** Catalog service. **Consumer:** Rating service.

A feedback deletion for an unknown book is ignored and does not produce this signal.

## Channel information

<ChannelInformation />

## Topic and message

The topic is `bookworm.{env}.catalog.book-update-rating-failed`. Replace `{env}` with `development`, `staging`, or `production`. Messages are CloudEvents JSON keyed by `feedbackId`. The example identifies the feedback whose rating could not be applied.

## Operations and recovery

Before replaying, verify that the book is still absent and that Rating storage is available. If the feedback record has already been removed, processing is a safe no-op. If the book exists, investigate the projection or message mismatch rather than replaying repeatedly. Failed messages are sent to the Rating dead-letter topic.
