`bookworm.{env}.finance.delete-basket-failed` (v1.0.0) is the Kafka topic owned by Finance that instructs Ordering API to recover from a failed basket cleanup by soft-deleting the order. Finance publishes `DeleteBasketFailedCommand` either when Basket API reports deletion failure or during LIFO saga compensation if a downstream orchestration step fails. This channel is separate from Basket API's upstream `bookworm.{env}.basket.delete-failed` integration event.

## Delivery, partitioning, and consumer behavior

- **Finance publication triggers:** Finance invokes `PublishDeleteBasketFailedActivity` (Durable Task activity retry policy: `3` attempts, `5s` initial delay, `2.0x` backoff) in two scenarios:
  1. **Direct basket failure:** `BasketDeletedFailedStep` transitions the saga to terminal `OrderStatus.BasketDeletionFailed` and publishes `DeleteBasketFailedCommand`.
  2. **Saga compensation:** `BasketDeletedCompleteStep` registers `PublishDeleteBasketFailedActivity` on `OrderSagaCompensations` so a later `TaskFailedException` or `FinanceDomainException` triggers LIFO rollback.
- **Partitioning:** Finance keys Kafka messages by `OrderId` so recovery commands for the same order stay on one partition within this topic.
- **Ordering API consumption and idempotency:** Ordering API listens with Wolverine's PostgreSQL durable inbox (`orderingdb`, `wolverine` schema, 1-hour `KeepAfterMessageHandling`, 7-day `DeadLetterQueueExpiration`). `DeleteBasketFailedCommandHandler` guards execution with `IIntegrationEventIdempotencyGuard` (24-hour Redis/FusionCache key `idempotency:DeleteBasketFailedCommandHandler:{id:N}`), fetches the `Order` by `orderId`, calls `order.Delete()` to soft-delete it if found, and commits through EF Core without changing business `Status` (`New`, `Cancelled`, or `Completed`).

## Error responses and dead-letter behavior

| Condition                                                                                                                                              | Handling behavior                                                                                                                                                         | Recovery behavior                                                                                                        |
| :----------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | :----------------------------------------------------------------------------------------------------------------------- |
| Matching `Order` not found in `orderingdb`                                                                                                             | `DeleteBasketFailedCommandHandler` returns cleanly as an idempotent no-op.                                                                                                | Expected when the order was already deleted or never persisted; no retry or DLQ routing occurs.                          |
| Transient database or infrastructure failure (`TimeoutException`, `HttpRequestException`, `DbUpdateConcurrencyException`, transient `NpgsqlException`) | `IIntegrationEventIdempotencyGuard.ExecuteAsync` releases the Redis key on failure; Wolverine retries with `50ms`, `250ms`, and `1s` cooldown intervals plus full jitter. | After retries exhaust, Wolverine moves the envelope to [[channel\|bookworm.&#123;env&#125;.ordering.dead-letter-queue]]. |
| `JsonException` or `FormatException`                                                                                                                   | Immediately moved to [[channel\|bookworm.&#123;env&#125;.ordering.dead-letter-queue]] with zero retries.                                                                  | Inspect contract compatibility between Finance and Ordering API before replaying.                                        |
