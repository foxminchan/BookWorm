## Overview

Finance publishes [[command|DeleteBasketFailedCommand]] when basket cleanup
fails. [[service|order-api]] soft-deletes the matching Order if it still
exists, without changing its business status. This is separate from Basket's
own deletion failure event.

The camelCase JSON payload contains `id`, `creationDate`, `basketId`, nullable
`email`, `orderId`, and `totalMoney` inside the BookWorm CloudEvents-compatible
envelope. Messages exhausting Wolverine's retry policy in [[service|order-api]]
route to [[channel|bookworm.&#123;env&#125;.ordering.dead-letter-queue]].
