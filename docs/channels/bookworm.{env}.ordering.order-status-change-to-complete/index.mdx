## Overview

[[service|order-api]] publishes
[[event|OrderStatusChangedToCompleteIntegrationEvent]] after completing an
Order. This reports the Order's business status to Finance; it is not Finance's
separate completion command or confirmation of email delivery.

The camelCase JSON payload is carried inside the BookWorm CloudEvents-compatible
envelope. Its `basketId` currently contains the Order's Buyer ID.
