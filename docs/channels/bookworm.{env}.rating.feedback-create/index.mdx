Rating publishes this event when a customer submits feedback. Catalog consumes it to update the book's displayed rating summary.

**Producer:** Rating service. **Consumer:** Catalog service.

If Catalog cannot find the book, it sends a compensation signal so Rating can remove the feedback rather than leaving an orphaned review.

## Channel information

<ChannelInformation />

## Topic and message

The topic is `bookworm.{env}.rating.feedback-create`. Replace `{env}` with `development`, `staging`, or `production`. Messages are CloudEvents JSON keyed by `bookId` and include the rating and feedback ID. Failed Catalog processing goes to [[channel|bookworm.&#123;env&#125;.catalog.dead-letter-queue]]. A missing book follows [[channel|bookworm.&#123;env&#125;.catalog.book-update-rating-failed]] instead.

## Operations and recovery

Before replaying, check whether Catalog already applied the rating and whether the referenced book still exists. Resolve any service or data-store outage first. If the book is missing, use the compensation path rather than repeatedly replaying the create event. Duplicate deliveries are guarded, but verify the current summary before manual intervention.
