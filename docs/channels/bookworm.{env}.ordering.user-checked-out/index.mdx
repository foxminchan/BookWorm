## Overview

[[service|order-api]] publishes [[event|UserCheckedOutIntegrationEvent]] after
placing an Order. Finance uses the checkout details to coordinate subsequent
work; publication does not indicate payment settlement or Order completion.

The camelCase JSON payload is carried inside the BookWorm CloudEvents-compatible
envelope. Its `basketId` currently contains the Order's Buyer ID, as documented
in the Order API AsyncAPI contract.
