This topic holds Catalog compensation messages that Rating could not process. These messages ask Rating to remove feedback that could not be applied to a book's rating summary.

**Writer:** Rating service. **Reader:** Operators investigating or recovering failed messages. Records preserve the original message and feedback key.

## Channel information

<ChannelInformation />

## Topic and message

The topic is `bookworm.{env}.rating.dead-letter-queue`. Replace `{env}` with `development`, `staging`, or `production`. The source is [[channel|bookworm.&#123;env&#125;.catalog.book-update-rating-failed]]. Kafka retention is set by the broker.

## Operations and recovery

Confirm the referenced book is absent and that Rating's feedback store is healthy before replaying. If the feedback record is already gone, replay is a safe no-op. If the book now exists, investigate why the compensation was requested instead of replaying automatically. Restore service health before recovery.
