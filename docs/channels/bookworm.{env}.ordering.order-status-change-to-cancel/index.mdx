## Overview

[[service|order-api]] publishes
[[event|OrderStatusChangedToCancelIntegrationEvent]] after cancelling an
Order. This reports the Order's business status to Finance; it is distinct
from soft deletion and Finance's separate cancellation command.

The camelCase JSON payload is carried inside the BookWorm CloudEvents-compatible
envelope. Its `basketId` currently contains the Order's Buyer ID.
