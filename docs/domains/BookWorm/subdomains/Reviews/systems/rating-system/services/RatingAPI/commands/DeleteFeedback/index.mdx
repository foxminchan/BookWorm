## Overview

Deletes a [[entity|feedback]] record when it exists. This administrator-only operation
publishes a [[event|FeedbackDeletedIntegrationEvent]] after the record is removed.

<NodeGraph />

## Request and response

Provide the feedback UUID in the `id` path parameter. The successful `204`
response has no body. A missing feedback record returns `404` with
`application/problem+json` and `ProblemDetails`.
