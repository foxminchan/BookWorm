`DeleteFeedback` (`DELETE /api/v1/feedbacks/{id}`) is an administrator-only command in **Rating API** that deletes an existing **Feedback** record from **Azure Cosmos DB** (`ratingdb`/`feedbacks`), publishes `FeedbackDeletedIntegrationEvent` to Kafka, invalidates Redis/FusionCache entries, and returns `204 No Content`.

## Overview

| Property                 | Value                                                                                                                                                                                                |
| :----------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Owner**                | Reviews bounded context (**Rating API**, Aspire resource `rating`)                                                                                                                                   |
| **Source**               | `src/Services/Rating/BookWorm.Rating/Features/Delete/DeleteFeedbackEndpoint.cs`, `DeleteFeedbackCommand.cs`, `src/Services/Rating/BookWorm.Rating/Infrastructure/Repositories/FeedbackRepository.cs` |
| **Protocol / format**    | HTTP `DELETE`, UUID path parameter, empty request and `204` response bodies                                                                                                                          |
| **Direct endpoint**      | `DELETE /api/v1/feedbacks/{id}` (local ports: HTTP `5278`, HTTPS `7003`)                                                                                                                             |
| **API Gateway endpoint** | `DELETE /rating/api/v1/feedbacks/{id}` (YARP strips `/rating`)                                                                                                                                       |
| **Authentication**       | Microsoft Entra ID JWT bearer token; `admin` authorization policy requires role `admin` and scopes `rating_read` and `rating_write`                                                                  |
| **Rate limit**           | `PerUserRateLimit` token bucket (30 tokens, +20 per 10 s, queue 5) plus global concurrency (100) and per-IP fixed-window (30 req/min) limiters                                                       |
| **Contract version**     | `1.0.0` (`ApiVersions.V1`)                                                                                                                                                                           |

## Behavior and side effects

- **Azure Cosmos DB lookup and deletion (not PostgreSQL):** `DeleteFeedbackHandler` queries Azure Cosmos DB (`ratingdb`/`feedbacks`, partition key `/bookId`) by `Id` with EF Core change tracking enabled (`FeedbackRepository.GetByIdAsync`), verifies existence via `Guard.Against.NotFound`, calls `feedback.Remove()` to register `FeedbackDeletedEvent`, deletes the entity, and commits via `SaveEntitiesAsync` (with ETag optimistic concurrency).
- **Kafka integration event:** After `SaveChangesAsync` succeeds, `EventDispatchInterceptor` dispatches `FeedbackDeletedEvent`. `FeedbackDeletedEventHandler` maps it to `FeedbackDeletedIntegrationEvent` (`BookId`, `Rating`, `FeedbackId`) and publishes it via **Wolverine** (with `WolverineFx.CosmosDb` persistence) to Kafka topic `bookworm.{env}.rating.feedback-delete`, partitioned by `BookId` and `FeedbackId`. **Catalog API** consumes this event to recalculate the book's derived rating summary.
- **Redis / FusionCache invalidation:** `FeedbackCacheInvalidationHandler` removes both the cached feedback list entries tagged for `bookId` and the cached AI rating summary key for that book.

:::note
OpenAPI metadata (`ProducesDelete()`) declares `404 Not Found` as `application/problem+json` (`ProblemDetails`), but at runtime `NotFoundExceptionHandler` (`src/BuildingBlocks/BookWorm.Chassis/Exceptions/NotFoundExceptionHandler.cs`) returns `application/json` with `{ "detail": "The requested resource was not found." }`.
:::

## Error responses

| Code / status               | Condition                                                                                                                                                                     | Recovery behavior                                                       |
| :-------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :---------------------------------------------------------------------- |
| `400 Bad Request`           | `id` path segment is not a valid UUID (`FeedbackId` binding failure)                                                                                                          | Provide a valid feedback UUID in the path and retry                     |
| `401 Unauthorized`          | Missing, expired, or invalid Entra ID bearer token                                                                                                                            | Acquire a valid Entra ID access token and retry                         |
| `403 Forbidden`             | Valid token missing the `admin` role or the `rating_read`/`rating_write` scopes                                                                                               | Authenticate as a store administrator with the required scopes          |
| `404 Not Found`             | No feedback record exists with the specified `id` (`NotFoundExceptionHandler` returns `application/json` `{ "detail": "The requested resource was not found." }`)             | Refresh the moderation list; do not retry unchanged                     |
| `409 Conflict`              | Cosmos DB ETag concurrency conflict wrapped in `InvalidOperationException` (`RatingDbContext.SaveEntitiesAsync` -> `GlobalExceptionHandler`, `ProblemDetails` with `traceId`) | Re-fetch the feedback state and retry if still present                  |
| `429 Too Many Requests`     | `PerUserRateLimit` or global rate limiter exceeded (`ProblemDetails` with `Retry-After` header in seconds)                                                                    | Wait for the `Retry-After` interval before retrying                     |
| `500 Internal Server Error` | Unexpected Cosmos DB, Kafka, or server failure (`GlobalExceptionHandler`, `ProblemDetails` with `traceId`)                                                                    | Retry with exponential backoff; inspect Rating API logs using `traceId` |
