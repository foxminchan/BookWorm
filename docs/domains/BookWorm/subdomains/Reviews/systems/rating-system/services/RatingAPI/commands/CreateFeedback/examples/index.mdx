## Create feedback with curl

<CodeGroup>

```bash
curl --request POST "<gateway-url>/rating/api/v1/feedbacks" \
  --header "Content-Type: application/json" \
  --data '{
    "bookId": "0193f1a2-7b4c-7d8e-9f01-23456789abcd",
    "firstName": "Avery",
    "lastName": "Nguyen",
    "comment": "A thoughtful and engaging read.",
    "rating": 5
  }'
```

</CodeGroup>

Where:

- `<gateway-url>`: Base URL of the BookWorm API Gateway (or use the direct Rating API URL without the `/rating` prefix).

Expected response (`200 OK`):

<CodeGroup>

```json
"0193f1a3-2c9d-7a4b-8e12-3456789abcde"
```

</CodeGroup>

## Validation error response (`400 Bad Request`)

<CodeGroup>

```json
{
	"title": "One or more validation errors occurred.",
	"status": 400,
	"errors": {
		"Rating": ["'Rating' must be between 0 and 5. You entered 6."]
	}
}
```

</CodeGroup>
