## Delete feedback with curl

<CodeGroup>

```bash
curl --request DELETE "<gateway-url>/rating/api/v1/feedbacks/<feedback-id>" \
  --header "Authorization: Bearer <admin-access-token>"
```

</CodeGroup>

Where:

- `<gateway-url>`: Base URL of the BookWorm API Gateway (or use the direct Rating API URL without the `/rating` prefix).
- `<feedback-id>`: UUID of an existing feedback record (for example, `0193f1a3-2c9d-7a4b-8e12-3456789abcde`).
- `<admin-access-token>`: Entra ID JWT bearer token with role `admin` and scopes `rating_read` and `rating_write`.

Expected response (`204 No Content`):

<CodeGroup>

```text
HTTP/1.1 204 No Content
```

</CodeGroup>

## Missing feedback response (`404 Not Found`)

<CodeGroup>

```json
{
	"detail": "The requested resource was not found."
}
```

</CodeGroup>
