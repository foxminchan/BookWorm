## Service Responsibility & Boundary

Rating API is the system of record within the [[domain|reviews]] domain for individual customer [[entity|feedback]] records on Catalog books. It exposes versioned HTTP endpoints for feedback management and read-time AI summarization, hosts BookWorm's Agent-to-Agent (A2A) gRPC server for [[agent|rating-agent]], and synchronizes rating deltas with [[service|catalog-api]] over Kafka. Book metadata and derived rating totals remain owned by [[service|catalog-api]].

## Service Profile

| Property                                  | Value                                                                                                                                                                                  |
| :---------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Bounded Context / Domain**              | [[domain\|reviews]]                                                                                                                                                                    |
| **Owner Team**                            | [[team\|catalog-experience-team]]                                                                                                                                                      |
| **Runtime Style**                         | REST API, A2A gRPC Server, and Async Kafka Producer/Consumer                                                                                                                           |
| **Public / Gateway Exposure**             | Yes via API Gateway (HTTP) and Internal Only (A2A gRPC)                                                                                                                                |
| **Authentication & Authorization Policy** | Microsoft Entra ID JWT and Entra Agent Identity via [[system\|identity-provider]]; `admin` policy for deletion, `rating_read` scope for A2A gRPC                                       |
| **Owned Data Store(s)**                   | [[container\|rating-database]] (Azure Cosmos DB partitioned by book ID), [[container\|rating-cache]] (Redis read cache & idempotency)                                                  |
| **Key Resilience / Idempotency Pattern**  | Compensating delete on Catalog rejection, fail-closed PII screening, per-user rate limiting, and dead-letter routing on [[channel\|bookworm.&#123;env&#125;.rating.dead-letter-queue]] |

## Contracts & Data Ownership

Rating API owns the [[entity|feedback]] aggregate in [[container|rating-database]] and enforces uniqueness per `(bookId, firstName, lastName)`.

:::note
Read-time summarization via [[agent|rating-agent]] retrieves book metadata and analysis prompts from [[service|mcp-server]], reads raw reviews in-process under a rate cap, and screens inputs and outputs fail-closed through [[service|presidio-api]] without mutating stored feedback.
:::

:::warning
If [[service|catalog-api]] emits [[event|BookUpdatedRatingFailedIntegrationEvent]] because a reviewed book does not exist, Rating API executes an idempotent compensating delete on the orphaned feedback record.
:::
