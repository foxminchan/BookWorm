## List feedback for a book with curl

<CodeGroup>

```bash
curl --request GET \
  "<gateway-url>/rating/api/v1/feedbacks?BookId=11111111-1111-1111-1111-111111111111&PageIndex=1&PageSize=20&OrderBy=Rating&IsDescending=true" \
  --header "Accept: application/json"
```

</CodeGroup>

Where:

- `<gateway-url>`: Base URL of the BookWorm API Gateway (or direct Rating API URL `https://localhost:7003` without the `/rating` prefix).

Expected response (`200 OK` with `Pagination-Count` and `Link` headers):

<CodeGroup>

```json
[
	{
		"id": "22222222-2222-2222-2222-222222222222",
		"firstName": "Avery",
		"lastName": "Nguyen",
		"comment": "A thoughtful and engaging read.",
		"rating": 5,
		"bookId": "11111111-1111-1111-1111-111111111111"
	}
]
```

</CodeGroup>

Expected validation error (`400 Bad Request`):

<CodeGroup>

```json
{
	"title": "One or more validation errors occurred.",
	"status": 400,
	"errors": {
		"BookId": ["The value is not a valid UUID."]
	}
}
```

</CodeGroup>

## List feedback with TypeScript

<CodeGroup>

```typescript
type FeedbackDto = {
	id: string;
	firstName: string | null;
	lastName: string | null;
	comment: string | null;
	rating: number | string;
	bookId: string;
};

const params = new URLSearchParams({
	BookId: "11111111-1111-1111-1111-111111111111",
	PageIndex: "1",
	PageSize: "20",
	OrderBy: "Rating",
	IsDescending: "true",
});

const gatewayUrl = "<gateway-url>";
const response = await fetch(`${gatewayUrl}/rating/api/v1/feedbacks?${params}`);

if (response.status === 400) {
	throw new Error("ListFeedbacks validation failed");
}
if (!response.ok) {
	throw new Error(`ListFeedbacks failed with ${response.status}`);
}

const totalItems = Number(response.headers.get("Pagination-Count") ?? "0");
const feedbacks = (await response.json()) as FeedbackDto[];
console.log(`Received ${feedbacks.length} of ${totalItems} feedback record(s)`);
```

</CodeGroup>
