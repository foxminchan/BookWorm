## Summarize feedback with curl

<CodeGroup>

```bash
curl --request GET \
  "<gateway-url>/rating/api/v1/feedbacks/11111111-1111-1111-1111-111111111111/summarize" \
  --header "Authorization: Bearer <access-token>" \
  --header "Accept: application/json"
```

</CodeGroup>

Where:

- `<gateway-url>`: Base URL of the BookWorm API Gateway (or direct Rating API URL `https://localhost:7003` without the `/rating` prefix).
- `<access-token>`: Entra ID bearer token authorized for Rating API.

Expected response when feedback exists (`200 OK`):

<CodeGroup>

```json
{
	"summary": "Readers consistently praise the book's engaging story and clear writing.",
	"classification": "Good",
	"averageRating": 4.6,
	"reviewCount": 10,
	"evidence": "Readers repeatedly praise the engaging story and clear writing.",
	"confidence": "High"
}
```

</CodeGroup>

Expected response when no feedback exists (`200 OK`):

<CodeGroup>

```json
{
	"summary": "No feedback found for this book.",
	"classification": "NoData",
	"averageRating": null,
	"reviewCount": 0,
	"evidence": "",
	"confidence": ""
}
```

</CodeGroup>

Expected response when not found (`404 Not Found`):

<CodeGroup>

```json
{
	"title": "Not Found",
	"status": 404
}
```

</CodeGroup>

## Summarize feedback with TypeScript

<CodeGroup>

```typescript
type SummarizeResult = {
	summary: string;
	classification?: "NoData" | "Bad" | "Good" | "TopRated";
	averageRating?: number | null;
	reviewCount?: number;
	evidence?: string;
	confidence?: string;
};

const gatewayUrl = "<gateway-url>";
const accessToken = "<access-token>";
const bookId = "11111111-1111-1111-1111-111111111111";

const response = await fetch(`${gatewayUrl}/rating/api/v1/feedbacks/${bookId}/summarize`, {
	headers: {
		Authorization: `Bearer ${accessToken}`,
		Accept: "application/json",
	},
});

if (response.status === 404) {
	throw new Error("Book or feedback summary was not found");
}
if (!response.ok) {
	throw new Error(`SummarizeFeedback failed with ${response.status}`);
}

const result = (await response.json()) as SummarizeResult;
console.log(result.summary);
```

</CodeGroup>
