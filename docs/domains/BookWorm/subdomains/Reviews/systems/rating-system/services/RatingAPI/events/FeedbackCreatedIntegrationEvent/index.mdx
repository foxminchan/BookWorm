`FeedbackCreatedIntegrationEvent` (v1.0.0) signals that Rating API persisted a new customer `Feedback` document in Azure Cosmos DB (`ratingdb` / `feedbacks`). Catalog API consumes this event to increment the target book's denormalized rating summary in PostgreSQL (`catalogdb`).

## Overview

| Property                 | Value                                                                                                                                                      |
| :----------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Owner**                | Reviews bounded context (`Rating API`)                                                                                                                     |
| **Producer**             | [[service\|rating-api]]                                                                                                                                    |
| **Consumer**             | [[service\|catalog-api]] (`FeedbackCreatedIntegrationEventHandler`)                                                                                        |
| **Source**               | `src/Services/Rating/BookWorm.Rating/IntegrationEvents/Events/FeedbackCreatedIntegrationEvent.cs`                                                          |
| **Protocol / format**    | Kafka + CloudEvents JSON (Wolverine)                                                                                                                       |
| **Kafka topic**          | `bookworm.{env}.rating.feedback-create` (where `{env}` is the kebab-case environment name)                                                                 |
| **Message identity**     | `BookWorm.Contracts.FeedbackCreatedIntegrationEvent`                                                                                                       |
| **Partition key**        | `BookId` (configured via `opts.MessagePartitioning.ByPropertyNamed("BookId", "FeedbackId")` so concurrent updates for one book land on the same partition) |
| **Outbox / idempotency** | Published via Wolverine Cosmos DB persistence (`WolverineFx.CosmosDb`, `ratingdb`); consumed in Catalog API with 24-hour Redis idempotency keyed by `id`   |

## Parameters and fields

The table below reflects the runtime C# contract (`FeedbackCreatedIntegrationEvent : IntegrationEvent`) serialized as camelCase JSON inside the CloudEvents envelope.

| Name           | Type                 | Required | Default                 | Constraints                                              | Description                                                                                        |
| :------------- | :------------------- | :------- | :---------------------- | :------------------------------------------------------- | :------------------------------------------------------------------------------------------------- |
| `id`           | `string` (UUID)      | Yes      | `Guid.CreateVersion7()` | UUID v7 inherited from `IntegrationEvent`                | Unique event identifier; used by Catalog API as the Redis idempotency key.                         |
| `creationDate` | `string` (date-time) | Yes      | `DateTime.UtcNow`       | ISO 8601 UTC timestamp inherited from `IntegrationEvent` | UTC timestamp when Rating API created the event.                                                   |
| `bookId`       | `string` (UUID)      | Yes      | —                       | Valid UUID; also used as Kafka partition key             | Identifier of the book whose rating summary must be updated.                                       |
| `rating`       | `integer`            | Yes      | —                       | `0`-`5` (`int`)                                          | Rating score to add to the book's denormalized rating summary.                                     |
| `feedbackId`   | `string` (UUID)      | Yes      | —                       | Valid UUID                                               | Identifier of the newly created `Feedback` document, used for compensation if the book is missing. |

:::warning
**Schema drift notice:** The legacy EventCatalog file `schema.json` sets `"additionalProperties": false` and omits `id` and `creationDate` inherited from `IntegrationEvent`. Catalog API actively reads `id` for Redis idempotency; consumers must accept all five fields.
:::

### CloudEvents envelope headers

## Error handling and delivery guarantees

| Condition                                                     | Behavior                                                                                                                        | Recovery behavior                                                           |
| :------------------------------------------------------------ | :------------------------------------------------------------------------------------------------------------------------------ | :-------------------------------------------------------------------------- |
| Target book not found in `catalogdb`                          | `FeedbackCreatedIntegrationEventHandler` emits [[event\|BookUpdatedRatingFailedIntegrationEvent]] with `feedbackId`.            | Rating API reverts and deletes the orphaned `Feedback` record in Cosmos DB. |
| Duplicate delivery within 24 hours                            | `IIntegrationEventIdempotencyGuard` skips duplicate processing using `idempotency:FeedbackCreatedIntegrationEventHandler:{id}`. | Prevents double-counting a rating on retries.                               |
| Transient PostgreSQL or concurrency error                     | Wolverine retries with cooldown (`50ms`, `250ms`, `1s`) and full jitter.                                                        | Exhausted messages route to `bookworm.{env}.catalog.dead-letter-queue`.     |
| Deserialization failure (`JsonException` / `FormatException`) | Routed directly to `bookworm.{env}.catalog.dead-letter-queue`.                                                                  | Validate payloads against `tests/pacts/Catalog-Rating.json`.                |
