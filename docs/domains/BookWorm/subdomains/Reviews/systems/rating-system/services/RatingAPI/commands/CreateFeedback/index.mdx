## Overview

Creates a [[entity|feedback]] record for a [[entity|book]]. The request includes the book UUID,
reviewer name, optional comment, and an integer rating from 0 through 5.

<NodeGraph />

## Request and response

Send `application/json` with the required fields from the
`CreateFeedbackCommand` contract. A successful `200` response returns the
generated feedback UUID as a JSON string.

`400` returns `application/problem+json` with
`HttpValidationProblemDetails`.
