`CreateFeedback` (`POST /api/v1/feedbacks`) creates an individual **Feedback** record for a Catalog book in **Rating API**, persists it to **Azure Cosmos DB** (`ratingdb`/`feedbacks`), publishes `FeedbackCreatedIntegrationEvent` to Kafka, and returns the generated UUIDv7 feedback identifier (`200 OK`).

## Behavior and side effects

- **Azure Cosmos DB persistence (not PostgreSQL):** `CreateFeedbackHandler` creates a `Feedback` entity with a UUIDv7 ID and saves it through `RatingDbContext` (EF Core Cosmos provider) to Azure Cosmos DB database `ratingdb`, container `feedbacks`, partitioned by `/bookId`, using ETag optimistic concurrency.
- **Kafka integration event:** After `SaveChangesAsync` completes, `EventDispatchInterceptor` dispatches `FeedbackCreatedEvent`. `FeedbackCreatedEventHandler` maps it via `EventMapper` to `FeedbackCreatedIntegrationEvent` (`BookId`, `Rating`, `FeedbackId`) and publishes it through **Wolverine** (with `WolverineFx.CosmosDb` persistence) to Kafka topic `bookworm.{env}.rating.feedback-create`, partitioned by `BookId` and `FeedbackId`. **Catalog API** consumes this event to update the book's derived rating summary.
- **Compensating rollback:** If **Catalog API** fails to update the book's rating summary and publishes `BookUpdatedRatingFailedIntegrationEvent`, `BookUpdatedRatingFailedIntegrationEventHandler` in **Rating API** deletes the newly created feedback record and invalidates caches.
- **Redis / FusionCache invalidation:** `FeedbackCacheInvalidationHandler` removes cached feedback list entries tagged for `bookId` and clears the cached AI rating summary if its cached `ReviewCount` is `0`.
- **PII log redaction:** `FirstName` and `LastName` carry `[PIIData]` so structured logging redacts reviewer names.

## Error responses

| Code / status               | Condition                                                                                                                                                                                                               | Recovery behavior                                                       |
| :-------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :---------------------------------------------------------------------- |
| `400 Bad Request`           | Empty `bookId`, empty or >50-char `firstName`/`lastName`, >1000-char `comment`, `rating` outside `0`–`5`, or malformed JSON (`ValidationExceptionHandler`, `application/problem+json` `HttpValidationProblemDetails`)   | Fix the failing fields in `errors` and resubmit                         |
| `409 Conflict`              | Azure Cosmos DB conflict (`HttpStatusCode.Conflict`) or concurrency exception wrapped in `InvalidOperationException` (`RatingDbContext.SaveEntitiesAsync` -> `GlobalExceptionHandler`, `ProblemDetails` with `traceId`) | Refresh state or verify whether feedback already exists before retrying |
| `429 Too Many Requests`     | `PerUserRateLimit` or global rate limiter exceeded (`ProblemDetails` with `Retry-After` header in seconds)                                                                                                              | Wait for the `Retry-After` interval before retrying                     |
| `500 Internal Server Error` | Unexpected Cosmos DB, Kafka, or server failure (`GlobalExceptionHandler`, `ProblemDetails` with `traceId`)                                                                                                              | Retry with exponential backoff; inspect Rating API logs using `traceId` |
