`FeedbackDeletedIntegrationEvent` (v1.0.0) signals that [[service|rating-api]] deleted an existing customer [[entity|feedback]] document from Azure Cosmos DB. [[service|catalog-api]] consumes this event to subtract the removed score from the target book's denormalized rating summary in PostgreSQL.

## Overview

| Property                             | Value                                                                                            |
| :----------------------------------- | :----------------------------------------------------------------------------------------------- |
| **Bounded Context**                  | Reviews                                                                                          |
| **Producer**                         | [[service\|rating-api]]                                                                          |
| **Consumer(s)**                      | [[service\|catalog-api]]                                                                         |
| **Protocol / Format**                | Kafka + CloudEvents JSON (camelCase payload)                                                     |
| **Channel / Topic**                  | [[channel\|bookworm.&#123;env&#125;.rating.feedback-delete]]                                     |
| **Dead-Letter Channel**              | [[channel\|bookworm.&#123;env&#125;.catalog.dead-letter-queue]]                                  |
| **Partition Key**                    | `BookId`                                                                                         |
| **Delivery / Idempotency Guarantee** | Published via transactional outbox; consumed with Redis-backed 24-hour idempotency keyed by `id` |

## Payload Fields & Envelope

### Event Payload

| Name           | Type                   | Required | Constraints                     | Description                                                                           |
| :------------- | :--------------------- | :------- | :------------------------------ | :------------------------------------------------------------------------------------ |
| `id`           | `string` (`uuid`)      | Yes      | UUIDv7                          | Unique event identifier used by [[service\|catalog-api]] as the Redis idempotency key |
| `creationDate` | `string` (`date-time`) | Yes      | ISO 8601 UTC timestamp          | UTC timestamp when the event was created                                              |
| `bookId`       | `string` (`uuid`)      | Yes      | Valid UUID; Kafka partition key | Identifier of the book whose rating summary must be decremented                       |
| `rating`       | `integer`              | Yes      | `0`-`5`                         | Rating score removed from the book's denormalized rating summary                      |
| `feedbackId`   | `string` (`uuid`)      | Yes      | Valid UUID                      | Identifier of the deleted feedback record                                             |

### CloudEvents Envelope Headers

| Header        | Value / Source                                         | Purpose                                                      |
| :------------ | :----------------------------------------------------- | :----------------------------------------------------------- |
| `messagetype` | `BookWorm.Contracts.FeedbackDeletedIntegrationEvent`   | Explicit message identity for cross-service deserialization  |
| `source`      | `urn:bookworm:bookworm-rating`                         | Identifies the producing service                             |
| `requestid`   | Propagated from `DELETE /rating/api/v1/feedbacks/{id}` | Correlates feedback deletion with catalog projection updates |

## Delivery Guarantees & Error Handling

| Condition                                         | System Behavior                                                                    | Recovery / Compensation                                                                     |
| :------------------------------------------------ | :--------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------ |
| Duplicate delivery within 24 hours                | Consumer skips reprocessing via Redis-backed 24-hour idempotency keyed by `id`     | Prevents double-subtracting a rating on retries                                             |
| Target book not found in [[service\|catalog-api]] | Consumer returns without modifying state or emitting a compensating event          | No action required; no local rating summary exists to adjust                                |
| Transient database or concurrency error           | Retried with cooldown (`50ms`, `250ms`, `1s`) and full jitter                      | Exhausted messages route to [[channel\|bookworm.&#123;env&#125;.catalog.dead-letter-queue]] |
| Deserialization failure                           | Routed directly to [[channel\|bookworm.&#123;env&#125;.catalog.dead-letter-queue]] | Inspect dead-letter payload against contract schema                                         |
