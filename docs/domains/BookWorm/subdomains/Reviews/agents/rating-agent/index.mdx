Rating Agent (`rating`) is the read-only review analysis and quality-signal specialist hosted inside [[service|rating-api]] in the Reviews bounded context. It serves two runtime paths: remote Agent-to-Agent (A2A) gRPC handoffs from [[service|chat-api]] and Rating API's local `RatingSummarizer` Map-Reduce workflow backing `SummarizeFeedback`. Rating Agent never writes to [[container|rating-database]] or [[container|catalog-database]], and final quality classifications are computed deterministically in C# code rather than by the language model.

## Architecture and runtime paths

Rating Agent runs in-process inside Rating API. It does **not** call Chat API; instead, Chat API connects to Rating Agent over A2A gRPC (`RatingAgentRegistration.cs`, 2-minute HTTP timeout, agent token exchange).

### `RatingSummarizer` workflow stages

For the `SummarizeFeedback` endpoint, `RatingSummarizerWorkflowFactory.Create(int reviewCount)` constructs a per-invocation Microsoft Agent Framework workflow:

1. **`PartitionExecutor`:** Splits reviews into batches (`options.BatchSize`, bounded by `options.MaxConcurrency`).
2. **`MapExecutor` (fan-out) → `MapResultsJoinExecutor` (fan-in barrier):** Summarizes review batches in parallel via `StructuredRatingResponseRunner` using MCP prompts (`McpRatingPromptProvider`).
3. **`ReduceExecutor`:** Merges batch summaries into a unified structured summary (`OverallSentiment`, `RecurringThemes`, `ReportedStrengths`, `ReportedWeaknesses`, `ReviewBasedQualitySignals`, `DataLimitations`).
4. **`QualityAssessExecutor`:** Produces `QualityAssessmentOutput` (`DominantNegativePattern`, `Evidence`, `Confidence`).
5. **`RefineReductionExecutor` (conditional loop):** Re-runs reduction when `Iteration < options.MaxIterations` and parsed confidence is below `options.MinimumConfidence`.
6. **`ClassifyExecutor`:** Applies deterministic C# thresholds (`RatingClassifier.Classify`) to produce the final `SummarizeResult`.

## Deterministic classification rules

`rating-agent.yaml` explicitly instructs the model **not** to return a classification and states that review counts and ratings are not evidence of sales volume. `RatingClassifier.Classify` (`src/Services/Rating/BookWorm.Rating/Infrastructure/Summarizer/Models/RatingClassification.cs`) assigns the final tier in order:

| Classification (`RatingClassification`) | Display label | Deterministic rule                                                                                         |
| :-------------------------------------- | :------------ | :--------------------------------------------------------------------------------------------------------- |
| `NoData` (`0`)                          | **No Data**   | `reviewCount < 3`, or `averageRating` is non-finite, or `averageRating < 0` or `> 5`                       |
| `Bad` (`1`)                             | **Bad**       | `averageRating < 3.5`, OR `dominantNegativePattern == true`                                                |
| `TopRated` (`3`)                        | **Top Rated** | (`averageRating >= 4.5` AND `reviewCount >= 50`) OR (`averageRating >= 4.0` AND `reviewCount >= 200`)      |
| `Good` (`2`)                            | **Good**      | All remaining books with `reviewCount >= 3` and `averageRating >= 3.5` without a dominant negative pattern |

## Middleware, context compaction, and governance

`BookWorm.Rating/Infrastructure/AI/Extensions.cs` wraps `IChatClient` and applies `Policies/rating-agent.yaml`:

| Layer                                   | Component / rule                              | Behavior                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| :-------------------------------------- | :-------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Middleware 1**                        | `UsePIIMiddleware(sp)`                        | Calls [[service\|PresidioAPI]] (`AnalyzeText` then `AnonymizeText`) on input and output text; stored reviews in Cosmos DB remain unmodified                                                                                                                                                                                                                                                                                                    |
| **Middleware 2**                        | `UseGuardrailMiddleware()`                    | Enforces shared prompt/response guardrails                                                                                                                                                                                                                                                                                                                                                                                                     |
| **Middleware 3**                        | `RatingOutputGuardrailMiddleware`             | Enforces Rating-specific output checks on both buffered and streaming responses                                                                                                                                                                                                                                                                                                                                                                |
| **Middleware 4**                        | `RatingCompactionPipelineFactory.Create(...)` | Four-stage compaction pipeline: tool-result compaction (`> 20` messages), LLM summarization (`> 3,000` tokens), sliding window (`> 12` turns), and hard truncation (`> 24,000` tokens)                                                                                                                                                                                                                                                         |
| **Governance (`default_action: deny`)** | `Policies/rating-agent.yaml`                  | Priority `100`: `block-write-operations`; Priority `95`: `block-destructive-sql`; Priority `50`: `allow-read-tools`; Priority `30`: `rate-limit-review-reads` capping `GetCustomerReviews` at `30/minute`. Includes `sql_policy` (blocks `DROP`, `TRUNCATE`, `ALTER`, `GRANT`, `REVOKE`, `MERGE`, `INSERT`, `UPDATE`, `DELETE`, and execution/file patterns; allows `SELECT` only) and regex `pii_patterns` (`email`, `phone`, `credit_card`). |
