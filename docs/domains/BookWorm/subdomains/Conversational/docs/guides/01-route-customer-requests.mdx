## Start with the request outcome

Requests enter the composed workflow through `/ag-ui`. Input validation runs
before agent routing. Empty or detected suspicious input can be rejected, and
accepted messages over the configured length limit are shortened before
processing.

After validation, `DecisionRouterExecutor` (`ChatRoutingDecisionService` backed by
`Microsoft-Decision-1`) checks whether the request is in English (`is_english`)
and within BookWorm's scope (`is_in_scope`). These are decision-model routing
checks, separate from input validation.

## Choose the specialist

| Customer intent                                                                    | Route                                    |
| ---------------------------------------------------------------------------------- | ---------------------------------------- |
| Book search, recommendations, book information, feedback, or reviews without an ID | [[agent\|book-agent]]                    |
| Store policies, services, accounts, orders, or billing                             | [[agent\|qa-agent]]                      |
| Review summaries or rating analysis when a book catalog ID (UUID/GUID) is present  | [[agent\|rating-agent]]                  |
| Request unrelated to BookWorm                                                      | Return a brief boundary response         |
| Request is not in English                                                          | Ask the customer to resend it in English |

The QA Agent can hand book-specific follow-up work to Book Agent. Book Agent
can hand off review or rating requests to Rating Agent once it resolves the
book's catalog ID.

## Handle mixed or unsupported questions

For a mixed request, route based on the work that can be handled. QA can answer
the supported policy portion and hand off book-specific questions. Do not imply
that Conversational has performed a live account, Basket, or Order lookup.
When supplied information is insufficient, make that limitation clear and
direct the customer to support.

See the [[flow\|agent-orchestration]] for the full request path.
