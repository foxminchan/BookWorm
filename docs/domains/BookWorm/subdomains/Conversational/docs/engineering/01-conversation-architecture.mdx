## Request path

The Chat API accepts interactive requests through `/ag-ui`. The composed
workflow validates the request, hands accepted messages to the Router, and
formats the final assistant response. Rejected input returns without entering
the agent handoff.

The Router selects the [[agent|book-agent]] for book discovery and feedback,
or the [[agent|qa-agent]] for store and customer-support questions. The QA
Agent can hand book-specific work to the Book Agent. For complex requests,
Book Agent can delegate independent book research to
[[agent|book-catalog-researcher]] and
[[agent|book-recommendation-researcher]] before composing a response.

## Domain boundaries

- Conversational provides assistance; it does not own Catalog, Basket, Order,
  or persisted feedback records.
- Book details and availability must be grounded in Catalog information.
- The QA Agent uses supplied policy context. It does not retrieve or modify
  live account, Basket, or Order data.
- Discussing book feedback in a conversation does not create a persisted
  Reviews feedback record.
- Chat sessions use in-memory state and are not durable conversation history.

## Workflow responsibilities

| Stage              | Responsibility                                                                                 |
| ------------------ | ---------------------------------------------------------------------------------------------- |
| Input validation   | Reject empty or detected suspicious input and constrain message length.                        |
| Router             | Check language and request scope, then choose a specialist or respond with a boundary message. |
| Book Agent         | Handle book requests directly or coordinate independent research.                              |
| QA Agent           | Answer from supplied store-policy context and identify when information is unavailable.        |
| Response formatter | Select and normalize the final assistant message.                                              |

The [[flow|agent-orchestration]] documents the customer-facing workflow.
System and agent resources describe their own responsibilities in more detail.
