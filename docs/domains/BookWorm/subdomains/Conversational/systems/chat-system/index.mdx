## System Purpose & Boundary

The Chat System delivers BookWorm's interactive conversational assistant and multi-agent orchestration within the [[domain|conversational]] domain. It serves **Customers** seeking store-policy answers, catalog-backed book discovery, personalized recommendations, and review insights. Modifying shopping baskets ([[domain|shopping]]), placing or mutating orders ([[domain|ordering]]), and persisting customer reviews ([[domain|reviews]]) are explicitly out of scope—the system operates strictly as a read-only advisor.

:::warning
All conversational inputs and outputs pass through fail-closed PII detection and anonymization in [[system|data-privacy]]. Streaming replies are buffered until privacy screening succeeds; if privacy screening is unavailable, the turn fails rather than bypassing redaction.
:::

## External Interactions & Trust Boundaries

- **Customer entry point:** Customers interact over the authenticated AG-UI streaming surface via the API Gateway, backed by [[system|identity-provider]] token validation and per-user rate limiting.
- **Catalog tooling:** Book specialists connect to [[system|mcp-tools]] using delegated On-Behalf-Of (OBO) tokens to invoke read-only catalog lookup tools; [[agent|qa-agent]] has no catalog tool access.
- **Review insights:** [[agent|book-agent]] or the conversational router delegates book-specific review analysis to [[agent|rating-agent]] in [[system|rating-system]] over Agent-to-Agent (A2A) gRPC.
- **Privacy boundary:** [[system|data-privacy]] screens and redacts personal information on every turn before model invocation and before responses reach the customer.

<Accordion title="Governance & Session Persistence Notes">
	- **Prompt safety & scope routing:** Empty inputs and prompt-injection attempts are rejected
	upfront; non-English or out-of-scope requests receive a boundary response without invoking
	specialist agents. - **Session memory:** Conversation transcripts and agent memory are persisted
	in [[container|chat-session-blob]] across turns.
</Accordion>
