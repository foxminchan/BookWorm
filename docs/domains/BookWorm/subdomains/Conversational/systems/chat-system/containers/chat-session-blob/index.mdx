## Overview

Chat Session Blob Storage holds conversational session state and Microsoft
Foundry memory for [[system|chat-system]]. The Aspire AppHost provisions this
container (`chatSessionContainer`) on the shared Azure Storage account and
grants [[service|chat-api]] `StorageBlobDataContributor` access.

## Access and ownership

- [[service|chat-api]] is the sole reader and writer of this container.
- Stored conversation session data is classified as confidential and must not be
  shared directly across domain boundaries.
- Chat does not own Catalog, Basket, Ordering, or Reviews business state; only
  conversational session history and memory are persisted here.
