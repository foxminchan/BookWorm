## Service Responsibility & Boundary

Chat API is the interactive conversational host within the [[domain|conversational]] domain, orchestrating BookWorm's multi-agent chat workflow, prompt safety validation, and session persistence in [[container|chat-session-blob]]. It delegates catalog lookups to [[service|mcp-server]], review summarization to [[agent|rating-agent]] in [[service|rating-api]] over Agent-to-Agent (A2A) gRPC, and PII redaction to [[service|presidio-api]]. Chat API never places orders, modifies baskets, writes reviews, or publishes Kafka integration events.

## Contracts & Data Ownership

Chat API persists conversation session state and model memory in [[container|chat-session-blob]] and exposes the interactive streaming chat endpoint alongside agent discovery metadata.

:::warning
Chat API operates exclusively as an A2A **client** communicating with [[service|rating-api]]. All specialist agent inputs and outputs pass through fail-closed PII screening via [[service|presidio-api]]; streaming responses are buffered until privacy filtering succeeds, and any screening failure aborts the turn.
:::

<Accordion title="Multi-Agent Routing & Governance Notes">
	- **Validation & scope routing:** Empty or suspected prompt-injection inputs are rejected
	immediately, oversized inputs are truncated safely, and non-English or out-of-scope requests
	short-circuit before reaching specialist agents. - **Scoped specialists:** [[agent|qa-agent]]
	answers store-policy questions without catalog tools; [[agent|book-agent]] coordinates
	[[agent|book-catalog-researcher]] and [[agent|book-recommendation-researcher]] using read-only
	catalog tools on [[service|mcp-server]]; review insights delegate to [[agent|rating-agent]].
</Accordion>
