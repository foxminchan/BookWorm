## Service Responsibility & Boundary

MCP Server is a stateless Model Context Protocol (MCP) adapter within the [[domain|conversational]] domain that exposes read-only catalog lookup tools and reusable AI prompt templates over Streamable HTTP to [[service|chat-api]] and [[service|rating-api]]. It delegates all product queries to [[service|catalog-api]] over gRPC and owns no databases, caches, or messaging channels.

## Service Profile

| Property                                  | Value                                                                                                                              |
| :---------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------- |
| **Bounded Context / Domain**              | [[domain\|conversational]]                                                                                                         |
| **Owner Team**                            | [[team\|contributor-team]]                                                                                                         |
| **Runtime Style**                         | Stateless Streamable HTTP MCP Server                                                                                               |
| **Public / Gateway Exposure**             | Internal Only (not routed via public API Gateway)                                                                                  |
| **Authentication & Authorization Policy** | Microsoft Entra ID JWT requiring `mcptools_read` scope with server-side authorization filters and default-deny governance policies |
| **Owned Data Store(s)**                   | None (Stateless)                                                                                                                   |
| **Key Resilience / Idempotency Pattern**  | Global rate limiting, RFC 9457 error handling, and explicit error propagation on upstream gRPC failures                            |

## Contracts & Data Ownership

MCP Server owns no persistent entities or data stores. It translates four read-only catalog tools (`search_catalog`, `get_book`, `list_categories`, `list_authors`) into gRPC queries against [[service|catalog-api]] and serves reusable prompt templates for book recommendations and review summarization.

:::note
MCP Server has no upstream dependency on [[service|rating-api]] and exposes no review-fetching tool. [[service|rating-api]] retrieves raw customer feedback in-process while using MCP Server only for book details and review-analysis prompts.
:::
