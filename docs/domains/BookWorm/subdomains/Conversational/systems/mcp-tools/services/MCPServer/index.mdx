MCP Tools (`mcptools`) is an internal, stateless Model Context Protocol (MCP) server in the Conversational bounded context that exposes four read-only Catalog tools and four reusable AI prompt templates over Streamable HTTP at `/mcp`. It owns no database, cache, or messaging infrastructure and delegates all catalog lookups to Catalog API over gRPC.

## Overview

| Property                        | Value                                                                                                                                                                      |
| :------------------------------ | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Owner**                       | Conversational bounded context (`BookWorm.McpTools`)                                                                                                                       |
| **Aspire resource ID**          | `mcptools`                                                                                                                                                                 |
| **Source**                      | `src/Services/McpTools/BookWorm.McpTools`                                                                                                                                  |
| **Endpoint & local ports**      | `/mcp` (Streamable HTTP, `HttpServerSessionMode.Stateless`); local HTTP `5243`, HTTPS `7193`; **not routed via API Gateway** (uses custom MCP CORS against gateway origin) |
| **Packages**                    | `ModelContextProtocol.AspNetCore` `2.4.0`, `Microsoft.AgentGovernance.Extensions.ModelContextProtocol` `5.0.0`                                                             |
| **Persistence & messaging**     | **Stateless** — no database, no Redis, no Kafka                                                                                                                            |
| **Authentication & governance** | Microsoft Entra ID JWT requiring `mcptools_read` scope; governance policies `AI/Governance/Policies/default.yaml` and `Policies/mcp-tools.yaml`                            |

## Runtime architecture

Chat API and Rating API call MCP Tools over Streamable HTTP using Entra ID token exchange; MCP Tools translates tool invocations into read-only gRPC queries against Catalog API.

## Registered MCP tools

All tools execute read-only gRPC queries against [[service|catalog-api]] (`Tools/CatalogTools.cs`) and serialize results as JSON. Upstream failures return an explicit error message without mutating data.

| Tool name         | Catalog gRPC method           | Purpose                                                    | Primary consumers                                                                 |
| :---------------- | :---------------------------- | :--------------------------------------------------------- | :-------------------------------------------------------------------------------- |
| `search_catalog`  | [[query\|ListBooksGrpc]]      | Searches books by description, keyword, or filter criteria | [[service\|chat-api]] (`book`, `catalog-researcher`, `recommendation-researcher`) |
| `get_book`        | [[query\|GetBookDetailsGrpc]] | Retrieves full details for a specific book ID              | [[service\|chat-api]], [[service\|rating-api]]                                    |
| `list_categories` | [[query\|ListCategoriesGrpc]] | Lists all available book categories                        | [[service\|chat-api]]                                                             |
| `list_authors`    | [[query\|ListAuthorsGrpc]]    | Lists all authors in the catalog                           | [[service\|chat-api]]                                                             |

:::note
MCP Tools has **no** Rating API upstream dependency, **no** `get_book_reviews` tool, and **no** registered MCP Resource URI handlers. [[service|rating-api]] reads raw customer feedback directly through its in-process `GetCustomerReviews` tool.
:::

## Registered MCP prompts

Prompts supply reusable instruction templates (`Prompts/*.cs`) without reading or writing business records.

| Prompt name               | Purpose                                                                                                  | Primary consumers       |
| :------------------------ | :------------------------------------------------------------------------------------------------------- | :---------------------- |
| `recommend_books`         | Converts reader preferences (genre, price range, author, profile) into a structured catalog-search task  | [[service\|chat-api]]   |
| `summarize_rating`        | Guides grounded summarization of supplied review text, themes, and data limitations                      | [[service\|rating-api]] |
| `reduce_rating_summaries` | Merges multiple partial review summaries into one consolidated summary                                   | [[service\|rating-api]] |
| `analyze_book_quality`    | Evaluates dominant negative review patterns; the calling service applies final classification thresholds | [[service\|rating-api]] |

## Security, governance, and observability

- **Authorization:** Default policy requires an authenticated Microsoft Entra ID caller with the `mcptools_read` scope, enforced via `.RequireAuthorization()` on `/mcp` and `.AddAuthorizationFilters()`.
- **Agent governance:** Applies `AI/Governance/Policies/default.yaml` and `Policies/mcp-tools.yaml` (`RequireAuthenticatedAgentId = false`, default agent ID `did:mesh:bookworm:{ServerInfoOptions.Name}`).
- **Rate limiting and errors:** Registers global rate limiting, global exception handling, and RFC 9457 `ProblemDetails`.
- **Observability:** Exports OpenTelemetry metrics and traces under the `Experimental.ModelContextProtocol` meter and activity source.
- **Local testing:** In Development run mode, AppHost starts **MCP Inspector** (`inspector`) pre-wired to `mcptools`; `/health` and `/alive` are mapped only in Development.

### Error responses

| Status                  | Condition                                                    | Recovery behavior                                               |
| :---------------------- | :----------------------------------------------------------- | :-------------------------------------------------------------- |
| `401 Unauthorized`      | Missing, expired, or invalid Entra ID JWT                    | Re-authenticate or refresh OBO token                            |
| `403 Forbidden`         | Token lacks `mcptools_read` scope or fails governance policy | Request `mcptools_read` scope; review `Policies/mcp-tools.yaml` |
| `429 Too Many Requests` | Global rate limit exceeded (`Retry-After` header returned)   | Wait for `Retry-After` interval and retry                       |
| `502 / 503`             | Upstream Catalog API gRPC unavailable                        | Check Catalog API health and retry with backoff                 |
