Conversational is BookWorm's Core domain for AI-assisted customer discovery and store-policy assistance. It orchestrates specialist agents inside `Chat API` using Microsoft Agent Framework, routes requests in a single pass with `Microsoft-Decision-1`, protects every prompt and reply with fail-closed Presidio PII middleware, and reads Catalog and Reviews data strictly through read-only MCP and A2A gRPC contracts.

## Scope and constraints

- **In scope:** Interactive AG-UI chat orchestration (`/ag-ui`), input validation, single-pass safety/language/scope/specialist routing, read-only Catalog MCP tools and prompts, delegated catalog and recommendation research, and fail-closed PII redaction.
- **Out of scope:** Mutating books (`Catalog`), modifying shopping baskets (`Shopping`), creating or canceling orders (`Ordering`), and persisting individual customer reviews (`Reviews`).
- **Key constraints:** Chat API has no PostgreSQL database, no Redis cache, and no Kafka broker integration. Privacy middleware failures stop requests rather than forwarding unfiltered text.

| **Chat API** (`chatting`)  | Conversational  | .NET 11 + Microsoft Agent Framework + AG-UI | `chat-workflow` orchestration (`DecisionRouterExecutor`, `Book Agent`, `QA Agent`, sub-researchers), session persistence in `chatting-blob`, Agent Governance (`Policies/chat-agents.yaml`) | `src/Services/Chat/BookWorm.Chat`         |

### Specialist agents and subagents

- **Decision Router (`DecisionRouterExecutor`):** Backed by `Microsoft-Decision-1`, evaluates `is_safe`, `is_english`, `is_in_scope`, and `route` in a single pass before invoking any conversational LLM, with human-in-the-loop disambiguation via `RequestPort`.
- **Book Agent (`book`):** Answers catalog discovery and recommendation requests using Catalog MCP tools and the `book-catalog` skill; delegates complex research concurrently to **Book Catalog Researcher** and **Book Recommendation Researcher**.
- **QA Agent (`qa`):** Answers shipping, returns, account, billing, and store-policy questions using the `store-policies` skill; holds no MCP tools and cannot access live customer accounts or orders.
- **Rating Agent (`rating`, remote A2A):** Hosted by [[domain|reviews]] (`Rating API`) and invoked over A2A gRPC when a specific book ID is identified for review summarization.

### Read-only Catalog MCP tools

| Tool              | Responsibility                              | Assigned agents                                                     |
| :---------------- | :------------------------------------------ | :------------------------------------------------------------------ |
| `search_catalog`  | Search books by keyword or description      | Book Agent, Book Catalog Researcher, Book Recommendation Researcher |
| `get_book`        | Retrieve full details for a known book UUID | Book Agent, Book Catalog Researcher, Book Recommendation Researcher |
| `list_categories` | List available catalog categories           | Book Agent, Book Catalog Researcher, Book Recommendation Researcher |
| `list_authors`    | List available catalog authors              | Book Agent, Book Catalog Researcher, Book Recommendation Researcher |

`MCP Tools` also publishes reusable AI prompts (`recommend_books`, `summarize_rating`, `reduce_rating_summaries`, `analyze_book_quality`).

## Runtime view

1. Storefront submits a customer message over AG-UI (`/chatting/ag-ui`), protected by the `customer` policy and `PerUserRateLimit`.
2. `InputValidationExecutor` rejects malformed or empty inputs immediately.
3. `DecisionRouterExecutor` screens safety, English language, BookWorm scope, and target specialist (`book`, `qa`, or remote A2A `rating`); ambiguous prompts pause on `RequestPort` for user clarification.
4. `DecisionToolSelectionMiddleware` filters optional tools per turn using a 6-message window and 50% confidence cutoff while preserving mandatory tools.
5. `PIIMiddleware` calls Presidio Analyzer and Anonymizer over HTTP on both incoming prompts and outgoing replies, buffering streaming output until redaction completes.
6. `ResponseFormatter` emits the final reply, and Chat API persists session state in Azure Blob Storage (`chatting-blob`, prefix `ag-ui/`).

## Deployment and cross-cutting concerns

- **Hosting and ingress:** `chatting` runs behind the YARP API Gateway (`/chatting/{**remainder}`). `mcptools` is **not** routed through YARP; it configures CORS directly against the gateway origin and serves `/mcp` internally.
- **Security and privacy:** Microsoft Entra ID JWT authentication enforces `customer` (`chatting_read`/`chatting_write`) and `admin` policies on Chat API and `mcptools_read` on MCP Tools. Entra Agent Identities (`chatAgentId`, `ratingAgentId`) perform On-Behalf-Of (OBO) token exchange with claims-based agent isolation. Agent Governance policies (`Policies/chat-agents.yaml`, `Policies/mcp-tools.yaml`) enforce runtime guardrails.
- **Observability and resilience:** OpenTelemetry records AG-UI, Foundry, Presidio, MCP, and A2A gRPC traces; `DecisionToolSelectionMiddleware` fails open on timeout while `PIIMiddleware` fails closed.

## Quality scenarios and known risks

| Quality attribute / risk | Scenario or exposure                                      | Current mitigation or gap                                                                                                  |
| :----------------------- | :-------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------- |
| **Privacy**              | Customer pastes personal email, phone, or address in chat | Fail-closed Presidio `PIIMiddleware` redacts both prompt and buffered output before LLM/client delivery                    |
| **Availability**         | Presidio sidecar outage blocks all chat responses         | Intentional fail-closed trade-off; monitor Presidio `/health` on port `3000`                                               |
| **Safety**               | Prompt injection or off-topic request                     | Layered deterministic `InputValidationExecutor`, `Microsoft-Decision-1` `is_safe`/`is_in_scope`, and `GuardrailMiddleware` |
