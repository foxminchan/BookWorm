## Role & Autonomy Boundary

Book Catalog Researcher is an internal delegated subagent hosted inside [[service|chat-api]] and invoked exclusively by [[agent|book-agent]]. It is triggered when a multi-part customer inquiry requires dedicated factual catalog verification in parallel with preference-based recommendation research.

It has **no external user-facing surface**: it cannot be routed to directly by the workflow orchestrator, cannot initiate handoffs to peer agents, cannot access planning or file memory, and must never fabricate titles, prices, availability, or ratings.

## Data, Messaging & Handoff Boundaries

- **Data Stores:** Book Catalog Researcher has no direct database, cache, or blob storage access. All catalog facts are retrieved exclusively through [[service|mcp-server]].
- **Messages:** Inherits [[agent|book-agent]]'s privacy pipeline, screening all inputs and outputs via [[service|presidio-api]] using [[command|AnalyzeText]] and [[command|AnonymizeText]].
- **Delegation & Handoffs:** Receives subagent tasks solely from [[agent|book-agent]] and returns concise findings with verified book identifiers. It has no handoff tools and never delegates further.

## Safety, Privacy & AI Governance

- **Inherited Fail-Closed PII Redaction:** Every model invocation runs through [[service|presidio-api]] (`AnalyzeText` and `AnonymizeText`, masking detected PII with `<PII>`); any failure aborts execution.
- **Strict Least-Privilege Policy:** Default-deny governance permits only agent execution and the four read-only catalog tools—no handoff, planning, file-memory, or storefront UI tools are granted.
- **Deterministic Grounding:** Configured with low temperature (`0.2`) and `1200` max output tokens to favor exact, concise catalog reporting over creative elaboration.
- **Prompt & Output Guardrails:** Inherits decision-based tool filtering, prompt/output safety guardrails, and full context compaction from [[agent|book-agent]].

<Admonition type="warning">
	Book Catalog Researcher must treat catalog tool outputs as its sole factual source. It must never
	extrapolate stock levels, prices, or bibliographic details beyond what [[service|mcp-server]]
	returns.
</Admonition>

<Accordion title="Fallback Behavior & Evaluation Criteria">

- **Empty or Partial Matches:** When catalog queries return no matching books, the subagent reports the exact gap to [[agent|book-agent]] rather than substituting unverified titles.
- **Evaluation:** Tested for strict tool-scope isolation (denying non-catalog tools), deterministic fact extraction, and inherited Presidio PII redaction.

</Accordion>
