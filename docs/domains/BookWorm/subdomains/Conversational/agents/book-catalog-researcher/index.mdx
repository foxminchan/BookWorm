Book Catalog Researcher (`book-catalog-researcher`) is an internal delegated subagent initialized by [[agent|book-agent]] inside [[service|chat-api]]. It performs focused, low-temperature catalog fact-finding via [[service|mcp-server]] and returns concise findings with verified book IDs so Book Agent can synthesize the final customer response.

## Overview

| Property             | Value                                                                                                                                                                                                                  |
| :------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Owner**            | Conversational bounded context — [[service\|chat-api]] (`chatting`)                                                                                                                                                    |
| **Parent agent**     | [[agent\|book-agent]] (initialized via `InitSubAgent`, invoked via `delegate_book_catalog_researcher`)                                                                                                                 |
| **Agent name / DID** | `book-catalog-researcher` (`did:mesh:bookworm:book-catalog-researcher`)                                                                                                                                                |
| **Source**           | `src/Services/Chat/BookWorm.Chat/Agents/BookSearch/catalog-researcher.yaml`, `src/Services/Chat/BookWorm.Chat/Agents/BookSearch/BookAgentRegistration.cs`, `src/Services/Chat/BookWorm.Chat/Policies/chat-agents.yaml` |
| **Model deployment** | Inherits Book Agent's middleware-wrapped Microsoft Foundry `chat` client (`FoundryModel.Microsoft.ModelRouter`)                                                                                                        |
| **Workflow role**    | Internal delegated tool only — not a top-level `chat-workflow` route or handoff target                                                                                                                                 |

## Architecture and delegation boundary

Book Agent invokes Book Catalog Researcher via `SubAgentFactory.Create(...)` when a multi-part customer prompt benefits from running factual catalog lookups in parallel with [[agent|book-recommendation-researcher]]. Simple single-step lookups run directly in Book Agent without delegating.

## Runtime settings

Settings are declared in `catalog-researcher.yaml`:

| Setting                  | Value    | Rationale                                                            |
| :----------------------- | :------- | :------------------------------------------------------------------- |
| `temperature`            | `0.2`    | Low creative variation favors exact, deterministic catalog reporting |
| `maxOutputTokens`        | `1200`   | Concise internal findings returned to Book Agent                     |
| `reasoningEffort`        | `medium` | Balanced reasoning for multi-tool catalog verification               |
| `allowMultipleToolCalls` | `true`   | Allows parallel catalog tool calls within one turn                   |
| `chatToolMode`           | `auto`   | Model selects required catalog tools                                 |

## Allowed tools and governance

`Policies/chat-agents.yaml` enforces `default_action: deny`. For `did:mesh:bookworm:book-catalog-researcher`, only agent execution (`agent_run`, `agent_run_streaming`) and four read-only MCP catalog tools are permitted:

| Tool name         | Parameters                         | Purpose                                        |
| :---------------- | :--------------------------------- | :--------------------------------------------- |
| `search_catalog`  | `description` (`string`, required) | Searches the catalog by keyword or description |
| `get_book`        | `id` (`string`, required)          | Retrieves full details for a known book UUID   |
| `list_categories` | None                               | Lists all available book categories            |
| `list_authors`    | None                               | Lists all authors available in the catalog     |

- **Explicit boundaries:** Book Catalog Researcher has no handoff tools, no planning/todo tools, no file-memory tools, and no storefront AG-UI tools. It uses catalog tool results as its sole factual source and never invents titles, availability, ratings, or prices.

## Inherited middleware pipeline

`InitSubAgent` passes Book Agent's already-wrapped `IChatClient` (`BookAgentRegistration.cs:38-48`), so every model call made by Book Catalog Researcher inherits:

- `UseAGUIClientContext()` — Propagates active AG-UI run context.
- `UseDecisionToolSelection()` — Filters candidate tools via Microsoft-Decision-1.
- `UsePIIMiddleware(sp)` — Screens input and output text via [[service|presidio-api]] (`AnalyzeText` and `AnonymizeText` replacing detected PII with `<PII>`); fails closed on error.
- `UseGuardrailMiddleware()` — Enforces prompt and output guardrails.
- `UseAIContextProviders(CompactionPipelineFactory.CreateFull(...))` — Applies context compaction.
