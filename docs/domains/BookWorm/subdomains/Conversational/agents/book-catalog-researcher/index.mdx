The Book Catalog Researcher is an internal subagent initialized by the
[[agent|book-agent]] and exposed as a delegated tool. It researches catalog
facts about books, authors, categories, and details, then returns concise
findings with book IDs for Book Agent to use in its response.

It uses catalog tool results as its only source for factual claims and does
not invent book details, availability, ratings, or prices. Its model provider
is inherited from the shared chat client; the agent definition does not specify
a provider or model.

## Privacy middleware

`InitSubAgent` receives the [[agent|book-agent]]'s chat client, already wrapped
with `UsePIIMiddleware(sp)`; this subagent does not register a separate PII
middleware. Its input and output text therefore passes through
[[service|PresidioAPI]] via [[command|AnalyzeText]] and, when PII is detected,
[[command|AnonymizeText]]. These are middleware HTTP calls, not model-selected
tools or brokered messages.
