The QA Agent handles customer-support questions about shipping and delivery,
returns and refunds, accounts and orders, store policies, and bookstore
services. It uses the supplied store-policy information, states when details
are unavailable, and does not change business records.

The agent receives the `store-policies` skill as context. Book-specific
requests are handed to the [[agent|book-agent]]. The runtime uses the shared
chat client; the agent definition does not specify a provider or model.

## Privacy middleware

The agent's chat client registers `UsePIIMiddleware(sp)`. It calls
[[service|PresidioAPI]] through [[command|AnalyzeText]] for non-empty text
and [[command|AnonymizeText]] when PII is detected, replacing detected values
with `<PII>`. The middleware filters input and output text, buffering streaming
responses before filtering and emitting them. Failures propagate rather than
bypassing privacy processing. These are middleware HTTP calls, not
model-selected tools or brokered messages.
