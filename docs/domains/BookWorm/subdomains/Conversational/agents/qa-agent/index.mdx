QA Agent (`qa`) is the read-only customer support and store-policy specialist hosted in [[service|chat-api]]. Built with Microsoft Agent Framework (`1.28.0`), it answers non-book-specific operational questions using the `store-policies` skill context, never mutates business records, and hands book-specific follow-ups to [[agent|book-agent]].

## Overview

| Property             | Value                                                                                                                                                                                                                |
| :------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Owner**            | Conversational bounded context — [[service\|chat-api]] (`chatting`)                                                                                                                                                  |
| **Agent name / DID** | `qa` (`did:mesh:bookworm:qa`)                                                                                                                                                                                        |
| **Source**           | `src/Services/Chat/BookWorm.Chat/Agents/CustomerSupport/qa-agent.yaml`, `src/Services/Chat/BookWorm.Chat/Agents/CustomerSupport/QAAgentRegistration.cs`, `src/Services/Chat/BookWorm.Chat/Policies/chat-agents.yaml` |
| **Model deployment** | Shared Microsoft Foundry `chat` deployment (`FoundryModel.Microsoft.ModelRouter`)                                                                                                                                    |
| **Skill context**    | `Skills/store-policies` (`AgentSkillsProvider`)                                                                                                                                                                      |
| **Workflow entry**   | Routed by Microsoft-Decision-1 (`RouteTarget.QA`) or handed off from Book Agent (`handoff_to_qa`)                                                                                                                    |

## Architecture and workflow boundaries

QA Agent executes inside `QAWorkflowExecutor` (`WorkflowRegistration.cs:80-86`), which allows handoffs from QA Agent to Book Agent (`handoff_to_book`) and from Book Agent to Rating Agent or back to QA Agent. QA Agent has no database access, no MCP catalog client, and no account or order mutation tools.

## Supported topics and grounding rules

Declared in `qa-agent.yaml`:

- **Shipping & delivery:** Methods, costs, timeframes, tracking, international shipping, and delays.
- **Returns & refunds:** Policy rules, procedures, processing times, exchanges, and damaged items.
- **Account & orders:** Account management, password resets, order tracking/cancellation guidance, billing, and payment rules (read-only guidance; cannot look up or modify live orders).
- **Store policies:** Privacy, terms, cookies, copyright, and accessibility.
- **Services & features:** Gift cards, loyalty programs, wishlists, pre-orders, and gift wrapping.
- **Missing-detail rule:** Never invents policies, prices, or account details; states explicitly when a detail is unavailable and directs the customer to the support channel. Never tailors policy answers based on inferred personal characteristics.

## Runtime settings

Settings are declared in `qa-agent.yaml`:

| Setting           | Value    | Rationale                                       |
| :---------------- | :------- | :---------------------------------------------- |
| `temperature`     | `0.5`    | Keeps policy explanations consistent and direct |
| `maxOutputTokens` | `1000`   | Enforces concise support responses              |
| `reasoningEffort` | `medium` | Balanced reasoning for policy interpretation    |

## Middleware and governance rules

`QAAgentRegistration.AddQAAgent()` wraps the shared `IChatClient` and applies `WithBookWormGovernance(sp, key)` using `Policies/chat-agents.yaml` (`default_action: deny`):

| Layer                                | Component / rule                                                 | Behavior                                                                                                                                     |
| :----------------------------------- | :--------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------- |
| **Middleware 1**                     | `UseAGUIClientContext()`                                         | Propagates active AG-UI client context                                                                                                       |
| **Middleware 2**                     | `UseDecisionToolSelection()`                                     | Filters candidate tools via Microsoft-Decision-1 (`CreateQAAgentToolSelectionOptions()`)                                                     |
| **Middleware 3**                     | `UsePIIMiddleware(sp)`                                           | Screens input and buffered streaming output via [[service\|presidio-api]] (`AnalyzeText` / `AnonymizeText` → `<PII>`); fails closed on error |
| **Middleware 4**                     | `UseGuardrailMiddleware()`                                       | Enforces prompt and output guardrails                                                                                                        |
| **Middleware 5**                     | `UseAIContextProviders(CompactionPipelineFactory.CreateLight())` | Applies lightweight history compaction                                                                                                       |
| **Allow rules (priority 60)**        | `qa-agent-run`, `qa-agent-skills-and-handoff`                    | Permits `agent_run`, `agent_run_streaming`, `load_skill`, `read_skill_resource`, and `handoff_to_book` for `did:mesh:bookworm:qa`            |
| **Explicit deny rule (priority 70)** | `qa-agent-deny-catalog-tools`                                    | Explicitly denies `search_catalog`, `get_book`, `list_categories`, and `list_authors` as defense-in-depth                                    |
| **Conversation Guardian**            | `conversation_guardian` & `multi_turn_injection_patterns`        | Detects escalating rhetoric, offensive patterns, handoff loops (`max_conversation_turns: 30`), and multi-turn prompt injection               |
