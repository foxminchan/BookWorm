Book Recommendation Researcher (`book-recommendation-researcher`) is an internal delegated subagent initialized by [[agent|book-agent]] inside [[service|chat-api]]. It curates concise, catalog-verified book shortlists matching stated customer preferences and constraints using [[service|mcp-server]], returning book IDs and supporting catalog facts for Book Agent to synthesize.

## Overview

| Property             | Value                                                                                                                                                                                                                         |
| :------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Owner**            | Conversational bounded context — [[service\|chat-api]] (`chatting`)                                                                                                                                                           |
| **Parent agent**     | [[agent\|book-agent]] (initialized via `InitSubAgent`, invoked via `delegate_book_recommendation_researcher`)                                                                                                                 |
| **Agent name / DID** | `book-recommendation-researcher` (`did:mesh:bookworm:book-recommendation-researcher`)                                                                                                                                         |
| **Source**           | `src/Services/Chat/BookWorm.Chat/Agents/BookSearch/recommendation-researcher.yaml`, `src/Services/Chat/BookWorm.Chat/Agents/BookSearch/BookAgentRegistration.cs`, `src/Services/Chat/BookWorm.Chat/Policies/chat-agents.yaml` |
| **Model deployment** | Inherits Book Agent's middleware-wrapped Microsoft Foundry `chat` client (`FoundryModel.Microsoft.ModelRouter`)                                                                                                               |
| **Workflow role**    | Internal delegated tool only — not a top-level `chat-workflow` route or handoff target                                                                                                                                        |

## Architecture and delegation boundary

Book Agent invokes Book Recommendation Researcher via `SubAgentFactory.Create(...)` in parallel with [[agent|book-catalog-researcher]] when a customer request combines open-ended preference matching with catalog fact-finding.

## Runtime settings

Settings are declared in `recommendation-researcher.yaml`:

| Setting                  | Value    | Rationale                                                                                                                         |
| :----------------------- | :------- | :-------------------------------------------------------------------------------------------------------------------------------- |
| `temperature`            | `0.4`    | Slightly higher flexibility than pure fact-finding (`0.2`) to match nuanced reader preferences while preserving catalog grounding |
| `maxOutputTokens`        | `1200`   | Concise shortlist with book IDs and supporting facts                                                                              |
| `reasoningEffort`        | `medium` | Balanced reasoning for preference-to-catalog matching                                                                             |
| `allowMultipleToolCalls` | `true`   | Allows parallel catalog exploration within one turn                                                                               |
| `chatToolMode`           | `auto`   | Model selects required catalog tools                                                                                              |

## Allowed tools, grounding rules, and governance

`Policies/chat-agents.yaml` enforces `default_action: deny`. For `did:mesh:bookworm:book-recommendation-researcher`, only agent execution (`agent_run`, `agent_run_streaming`) and four read-only MCP catalog tools are permitted:

| Tool name         | Parameters                         | Purpose                                                |
| :---------------- | :--------------------------------- | :----------------------------------------------------- |
| `search_catalog`  | `description` (`string`, required) | Searches the catalog by theme, keyword, or description |
| `get_book`        | `id` (`string`, required)          | Retrieves full details for a candidate book UUID       |
| `list_categories` | None                               | Lists all available book categories                    |
| `list_authors`    | None                               | Lists all authors available in the catalog             |

- **Grounding and fairness rules:** Uses catalog tool results as its sole factual source. Never infers customer demographics or invents availability, ratings, prices, popularity, or bibliographic details.
- **Explicit boundaries:** Has no handoff tools, no planning/todo tools, no file-memory tools, and no storefront AG-UI tools.

## Inherited middleware pipeline

`InitSubAgent` passes Book Agent's already-wrapped `IChatClient` (`BookAgentRegistration.cs:38-48`), so every model call inherits:

- `UseAGUIClientContext()` — Propagates active AG-UI run context.
- `UseDecisionToolSelection()` — Filters candidate tools via Microsoft-Decision-1.
- `UsePIIMiddleware(sp)` — Screens input and output text via [[service|presidio-api]] (`AnalyzeText` and `AnonymizeText` replacing detected PII with `<PII>`); fails closed on error.
- `UseGuardrailMiddleware()` — Enforces prompt and output guardrails.
- `UseAIContextProviders(CompactionPipelineFactory.CreateFull(...))` — Applies context compaction.
