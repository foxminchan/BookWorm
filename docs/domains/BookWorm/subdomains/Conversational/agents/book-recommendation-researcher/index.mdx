The Book Recommendation Researcher is an internal subagent initialized by
the [[agent|book-agent]] and exposed as a delegated tool. It searches for
catalog-backed recommendations matching customer preferences and returns a
concise shortlist with book IDs and supporting catalog facts.

It does not infer demographics or invent availability, ratings, popularity,
prices, or bibliographic details. Its model provider is inherited from the
shared chat client; the agent definition does not specify a provider or model.

## Privacy middleware

`InitSubAgent` receives the [[agent|book-agent]]'s chat client, already wrapped
with `UsePIIMiddleware(sp)`; this subagent does not register a separate PII
middleware. Its input and output text therefore passes through
[[service|PresidioAPI]] via [[command|AnalyzeText]] and, when PII is detected,
[[command|AnonymizeText]]. These are middleware HTTP calls, not model-selected
tools or brokered messages.
