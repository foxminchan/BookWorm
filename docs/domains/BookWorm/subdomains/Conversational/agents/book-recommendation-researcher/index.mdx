## Role & Autonomy Boundary

Book Recommendation Researcher is an internal delegated subagent hosted inside [[service|chat-api]] and invoked exclusively by [[agent|book-agent]]. It is triggered when an open-ended customer request benefits from curating a preference-matched shortlist in parallel with factual catalog lookups.

It has **no external user-facing surface**: it cannot be routed to directly by the workflow orchestrator, cannot initiate handoffs to peer agents, cannot access planning or file memory, and must never infer customer demographics or fabricate availability, popularity, ratings, or prices.

## Data, Messaging & Handoff Boundaries

- **Data Stores:** Book Recommendation Researcher has no direct database, cache, or blob storage access. Every candidate book in a shortlist must be verified through [[service|mcp-server]].
- **Messages:** Inherits [[agent|book-agent]]'s privacy pipeline, screening all inputs and outputs via [[service|presidio-api]] using [[command|AnalyzeText]] and [[command|AnonymizeText]].
- **Delegation & Handoffs:** Receives subagent tasks solely from [[agent|book-agent]] and returns an evidence-backed shortlist with verified book identifiers. It has no handoff tools and never delegates further.

## Safety, Privacy & AI Governance

- **Inherited Fail-Closed PII Redaction:** Every model invocation runs through [[service|presidio-api]] (`AnalyzeText` and `AnonymizeText`, masking detected PII with `<PII>`); any failure aborts execution.
- **Fairness & Grounding Invariants:** Prohibits demographic inference or stereotyping; every recommendation must cite explicit catalog attributes returned by [[service|mcp-server]].
- **Strict Least-Privilege Policy:** Default-deny governance permits only agent execution and the four read-only catalog tools—no handoff, planning, file-memory, or storefront UI tools are granted.
- **Prompt & Output Guardrails:** Inherits decision-based tool filtering, prompt/output safety guardrails, and full context compaction from [[agent|book-agent]].

<Admonition type="warning">
	Book Recommendation Researcher must never recommend titles that were not retrieved and verified
	through [[service|mcp-server]] during the current run, and must never infer protected or
	demographic attributes about the customer.
</Admonition>

<Accordion title="Fallback Behavior & Evaluation Criteria">

- **Insufficient Matches:** If few or no catalog titles match all stated constraints, the subagent returns only verified partial matches with explicit caveats to [[agent|book-agent]].
- **Evaluation:** Verified for catalog-grounding fidelity (zero hallucinated ISBNs/IDs), fairness constraints, tool-scope isolation, and Presidio PII redaction.

</Accordion>
