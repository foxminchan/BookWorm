The Book Agent handles book discovery, factual book questions, recommendations,
gift ideas, and book feedback. It uses catalog results as the source of truth
and does not invent book details, availability, ratings, or prices.

For complex requests with independent catalog and recommendation work, it can
invoke the internal [[agent|book-catalog-researcher]] and
[[agent|book-recommendation-researcher]] subagents concurrently, then
synthesize their findings. These subagents are registered as delegated tools
of Book Agent rather than as top-level handoff workflow participants. Simple
lookups use catalog tools directly. Non-book requests can be handed back to the
[[agent|router-agent]].

The agent also receives the `book-catalog` skill and planning, mode, todo, and
file-memory context providers. Its model provider is inherited from the shared
chat client; no provider or model is set in the agent definition.

## Privacy middleware

The agent's chat client registers `UsePIIMiddleware(sp)`. It calls
[[service|PresidioAPI]] through [[command|AnalyzeText]] for non-empty text
and [[command|AnonymizeText]] when PII is detected, replacing detected values
with `<PII>`. The middleware filters input and output text, buffering streaming
responses before filtering and emitting them. Failures propagate rather than
bypassing privacy processing. These are middleware HTTP calls, not
model-selected tools or brokered messages.

Both researchers are initialized through `InitSubAgent` using this same
middleware-wrapped chat client, so their model calls also use Presidio.
