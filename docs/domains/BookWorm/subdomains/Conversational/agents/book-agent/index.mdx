Book Agent (`book`) is the primary conversational book discovery and recommendation specialist hosted in [[service|chat-api]]. Built with Microsoft Agent Framework (`1.28.0`), it grounds every product claim in live [[service|mcp-server]] catalog queries, delegates complex multi-part lookups in parallel to [[agent|book-catalog-researcher]] and [[agent|book-recommendation-researcher]], and hands off review or policy requests to [[agent|rating-agent]] or [[agent|qa-agent]].

## Overview

| Property             | Value                                                                                                                                                                                                          |
| :------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Owner**            | Conversational bounded context — [[service\|chat-api]] (`chatting`)                                                                                                                                            |
| **Agent name / DID** | `book` (`did:mesh:bookworm:book`)                                                                                                                                                                              |
| **Source**           | `src/Services/Chat/BookWorm.Chat/Agents/BookSearch/book-agent.yaml`, `src/Services/Chat/BookWorm.Chat/Agents/BookSearch/BookAgentRegistration.cs`, `src/Services/Chat/BookWorm.Chat/Policies/chat-agents.yaml` |
| **Model deployment** | Shared Microsoft Foundry `chat` deployment (`FoundryModel.Microsoft.ModelRouter`)                                                                                                                              |
| **Identity**         | Microsoft Entra Agent Identity (`chatAgentId`); customer session isolation via Entra ID JWT (`customer` policy)                                                                                                |
| **Workflow entry**   | Routed by Microsoft-Decision-1 (`DecisionRouterExecutor`) inside `chat-workflow` (`WorkflowRegistration.cs`)                                                                                                   |

The generated Bicep snapshot pins the `model-router` deployment to version `2025-11-18`. `AppHost.cs` selects the `ModelRouter` model symbolically; the version pin is visible in the generated deployment template.

## Architecture and delegation flow

Book Agent runs as a top-level specialist inside `BookWorkflowExecutor` (`WorkflowRegistration.cs`). Its two researcher subagents are initialized via `InitSubAgent` with the same middleware-wrapped chat client and registered as internal delegated tools rather than top-level workflow participants.

## Runtime settings

Settings are declared in `book-agent.yaml` and `BookAgentRegistration.cs`:

| Setting                     | Value  | Notes                                                             |
| :-------------------------- | :----- | :---------------------------------------------------------------- |
| `temperature`               | `0.7`  | Balances conversational warmth with catalog grounding             |
| `maxOutputTokens`           | `2000` | Maximum response token budget                                     |
| `reasoningEffort`           | `high` | Deeper reasoning for multi-constraint recommendation synthesis    |
| `topP`                      | `0.95` | Nucleus sampling threshold                                        |
| `allowMultipleToolCalls`    | `true` | Enables parallel catalog queries and parallel subagent delegation |
| `chatToolMode`              | `auto` | Model chooses when to invoke tools                                |
| `AllowConcurrentInvocation` | `true` | Set in `BookAgentRegistration.cs` for concurrent tool execution   |

## Tools and capabilities

Book Agent is governed by `Policies/chat-agents.yaml` (`default_action: deny`). Only tools explicitly allow-listed for `did:mesh:bookworm:book` can execute.

### Catalog MCP tools (`mcptools`)

| Tool name         | Parameters                         | Purpose                                                 |
| :---------------- | :--------------------------------- | :------------------------------------------------------ |
| `search_catalog`  | `description` (`string`, required) | Searches the catalog by keyword or semantic description |
| `get_book`        | `id` (`string`, required)          | Retrieves full details for a specific book UUID         |
| `list_categories` | None                               | Lists all available book categories                     |
| `list_authors`    | None                               | Lists all authors available in the catalog              |

### Delegated subagents and workflow handoffs

| Tool name                                 | Target                                    | Trigger condition                                                                                                   |
| :---------------------------------------- | :---------------------------------------- | :------------------------------------------------------------------------------------------------------------------ |
| `delegate_book_catalog_researcher`        | [[agent\|book-catalog-researcher]]        | Complex multi-part queries needing dedicated catalog fact-finding (called in parallel with recommendation research) |
| `delegate_book_recommendation_researcher` | [[agent\|book-recommendation-researcher]] | Complex preference-based shortlist discovery (called in parallel with catalog fact-finding)                         |
| `handoff_to_rating`                       | [[agent\|rating-agent]] (remote A2A gRPC) | Review summaries or rating quality analysis **only after** resolving a single exact book ID and title               |
| `handoff_to_qa`                           | [[agent\|qa-agent]]                       | Store policies, shipping, returns, accounts, orders, or billing inquiries after resolving any active book task      |

### Harness, skills, and storefront AG-UI tools

- **Skills & planning harness:** `load_skill`, `read_skill_resource`, `mode_get`, `mode_set`, `todos_add`, `todos_complete`, `todos_get_remaining`, `todos_get_all`, `todos_remove`. In **Plan Mode**, Book Agent decomposes multi-step research into todos and waits for user approval before switching to **Execute Mode**; single-step lookups run directly without todos or approval cycles.
- **File memory:** `file_memory_write`, `file_memory_read`, `file_memory_delete`, `file_memory_ls`, `file_memory_grep`, `file_memory_replace`, `file_memory_replace_lines` backed by `Chat:Harness:FileMemory:Root` (default `agent-files`).
- **Interactive storefront AG-UI tools (when present in client tool list):** `showBookCard`, `showBookList`, `showBasketSummary`, `render_a2ui`, `addToBasket`, `viewBasket`, `searchBooks`, `getBookDetails`. Falls back to Markdown when client UI tools are absent.

## Middleware, context providers, and governance

`BookAgentRegistration.AddBookAgent()` wraps the shared `IChatClient` in a fixed middleware pipeline and attaches five context providers:

| Layer                 | Component                                                                                                                             | Behavior                                                                                                                                                                                                     |
| :-------------------- | :------------------------------------------------------------------------------------------------------------------------------------ | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Middleware 1**      | `UseAGUIClientContext()`                                                                                                              | Injects live storefront `<ag_ui_context>` and `<ag_ui_state>` into the run                                                                                                                                   |
| **Middleware 2**      | `UseDecisionToolSelection()`                                                                                                          | Uses Microsoft-Decision-1 (`IDecisionClient`) to filter candidate tools before model invocation                                                                                                              |
| **Middleware 3**      | `UsePIIMiddleware(sp)`                                                                                                                | Calls [[service\|PresidioAPI]] (`AnalyzeText`, then `AnonymizeText` replacing PII with `<PII>`) on input and buffered streaming output; fails closed on error                                                |
| **Middleware 4**      | `UseGuardrailMiddleware()`                                                                                                            | Enforces prompt and response safety guardrails                                                                                                                                                               |
| **Middleware 5**      | `UseAIContextProviders(CompactionPipelineFactory.CreateFull(...))`                                                                    | Compacts long conversation histories before hitting context limits                                                                                                                                           |
| **Context providers** | `AgentSkillsProvider` (`Skills/book-catalog`), `todoProvider`, `modeProvider`, `fileMemoryProvider`, optional `FoundryMemoryProvider` | Supplies domain skill guidance, planning state, local scratchpad files, and remembered customer reading preferences                                                                                          |
| **Governance**        | `WithBookWormGovernance(sp, key)` (`Policies/chat-agents.yaml`)                                                                       | Enforces `default_action: deny` tool allow-list, Conversation Guardian escalation/offensive/loop thresholds (`max_conversation_turns: 30`, `max_retry_cycles: 3`), and multi-turn prompt-injection detection |
