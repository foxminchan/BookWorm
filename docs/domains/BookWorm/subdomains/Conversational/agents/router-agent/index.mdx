The Router Agent is the first specialist in the Chat service's handoff workflow.
It routes bookstore policy, service, account, order, and billing questions to
the [[agent|qa-agent]], and book searches, recommendations, information, and
feedback to the [[agent|book-agent]]. It does not answer those requests itself.

The workflow validates customer input before routing and formats the selected
agent's response afterward. The Router Agent declines requests unrelated to
BookWorm and asks for English when a request is in another language.

The runtime uses the shared chat client; the agent definition does not specify
a provider or model.

## Privacy middleware

The agent's chat client registers `UsePIIMiddleware(sp)`. It calls
[[service|PresidioAPI]] through [[command|AnalyzeText]] for non-empty text
and [[command|AnonymizeText]] when PII is detected, replacing detected values
with `<PII>`. The middleware filters input and output text, buffering streaming
responses before filtering and emitting them. Failures propagate rather than
bypassing privacy processing. These are middleware HTTP calls, not
model-selected tools or brokered messages.
