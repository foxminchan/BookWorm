`Category` is the Catalog aggregate root that classifies books into a single-level taxonomy. Catalog API owns it and persists it in PostgreSQL (`catalogdb`).

## Overview

| Property                  | Value                                                                                                |
| :------------------------ | :--------------------------------------------------------------------------------------------------- |
| **Owner**                 | Catalog bounded context / **Catalog API** (`catalog`)                                                |
| **Source**                | `src/Services/Catalog/BookWorm.Catalog/Domain/AggregatesModel/CategoryAggregate/Category.cs`         |
| **EF Core configuration** | `src/Services/Catalog/BookWorm.Catalog/Infrastructure/EntityConfigurations/CategoryConfiguration.cs` |
| **Backing store**         | PostgreSQL database `catalogdb`, table `categories` (`snake_case`)                                   |
| **Base type**             | `Entity<CategoryId>`, `IAggregateRoot`                                                               |
| **Identifier**            | `CategoryId` (Vogen value object wrapping `Guid`)                                                    |

`Category` has no audit timestamps, row version, soft-delete flag, or `Books` navigation collection.

## Parameters and fields

| Name   | Type                  | Required | Default               | Constraints                                | Description                |
| :----- | :-------------------- | :------- | :-------------------- | :----------------------------------------- | :------------------------- |
| `id`   | `CategoryId` (`Guid`) | Yes      | `uuidv7()` (database) | Primary key                                | Unique category identifier |
| `name` | `string`              | Yes      | —                     | Non-whitespace; max 50 chars; unique index | Category display name      |

## Invariants and behavior

- **Name required:** Setting `Name` to null or whitespace throws `CatalogDomainException("Category name must be provided.")`.
- **Name unique:** PostgreSQL rejects a second category with the same `name`.
- **Hard delete:** Deleting a category removes the row. PostgreSQL sets `books.category_id` to `NULL` for affected books (`ON DELETE SET NULL`).
- **Domain events:** The constructor raises `CategoryCreatedEvent`, `UpdateName(...)` raises `CategoryUpdatedEvent`, and `Remove()` raises `CategoryDeletedEvent`.
