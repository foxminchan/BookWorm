`BookAuthor` is a child entity of the `Book` aggregate that records one book-to-author pairing. It implements the many-to-many relationship between books and authors in PostgreSQL (`catalogdb`).

## Overview

| Property                  | Value                                                                                                  |
| :------------------------ | :----------------------------------------------------------------------------------------------------- |
| **Owner**                 | Catalog bounded context / **Catalog API** (`catalog`)                                                  |
| **Parent aggregate**      | [[entity\|book]]                                                                                       |
| **Source**                | `src/Services/Catalog/BookWorm.Catalog/Domain/AggregatesModel/BookAggregate/BookAuthor.cs`             |
| **EF Core configuration** | `src/Services/Catalog/BookWorm.Catalog/Infrastructure/EntityConfigurations/BookAuthorConfiguration.cs` |
| **Backing store**         | PostgreSQL database `catalogdb`, table `book_authors` (`snake_case`)                                   |
| **Base type**             | `Entity` (`Guid Id`); not an aggregate root                                                            |

## Parameters and fields

| Name       | Type                | Required | Default               | Constraints                                                    | Description                               |
| :--------- | :------------------ | :------- | :-------------------- | :------------------------------------------------------------- | :---------------------------------------- |
| `id`       | `Guid`              | Yes      | `uuidv7()` (database) | Primary key                                                    | Unique link identifier                    |
| `authorId` | `AuthorId` (`Guid`) | Yes      | —                     | FK to `authors.id`; `ON DELETE RESTRICT`                       | Linked author                             |
| `bookId`   | `Guid`              | Yes      | —                     | EF Core shadow property; FK to `books.id`; `ON DELETE CASCADE` | Linked book; not exposed as a C# property |

## Invariants and behavior

- **Created through `Book`:** `Book` creates `BookAuthor` instances in its constructor, `SetMetadata(...)`, and `Update(...)`. `Update(...)` replaces the full set of links.
- **Cascade from book:** Deleting a `books` row deletes its `book_authors` rows.
- **Restrict from author:** PostgreSQL rejects deleting an `authors` row that still has `book_authors` rows.
- **Soft-delete filter:** A global query filter (`!x.Book.IsDeleted`) hides links whose parent book is soft-deleted.
- **No duplicate guard:** `BookAuthorConfiguration.cs` defines no unique index on `(book_id, author_id)`.
