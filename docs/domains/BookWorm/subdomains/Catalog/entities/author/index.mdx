`Author` is the Catalog aggregate root for a person credited on one or more books. Catalog API owns it and persists it in PostgreSQL (`catalogdb`).

## Overview

| Property                  | Value                                                                                              |
| :------------------------ | :------------------------------------------------------------------------------------------------- |
| **Owner**                 | Catalog bounded context / **Catalog API** (`catalog`)                                              |
| **Source**                | `src/Services/Catalog/BookWorm.Catalog/Domain/AggregatesModel/AuthorAggregate/Author.cs`           |
| **EF Core configuration** | `src/Services/Catalog/BookWorm.Catalog/Infrastructure/EntityConfigurations/AuthorConfiguration.cs` |
| **Backing store**         | PostgreSQL database `catalogdb`, table `authors` (`snake_case`)                                    |
| **Base type**             | `Entity<AuthorId>`, `IAggregateRoot`                                                               |
| **Identifier**            | `AuthorId` (Vogen value object wrapping `Guid`)                                                    |

`Author` has no audit timestamps, row version, or soft-delete flag.

## Parameters and fields

| Name          | Type                | Required | Default               | Constraints                   | Description                           |
| :------------ | :------------------ | :------- | :-------------------- | :---------------------------- | :------------------------------------ |
| `id`          | `AuthorId` (`Guid`) | Yes      | `uuidv7()` (database) | Primary key                   | Unique author identifier              |
| `name`        | `string`            | Yes      | —                     | Non-whitespace; max 100 chars | Author display name                   |
| `bookAuthors` | `BookAuthor[]`      | —        | `[]`                  | Inverse navigation            | Join links to `Book` (`book_authors`) |

## Invariants and behavior

- **Name required:** Setting `Name` to null or whitespace throws `CatalogDomainException("Author name must be provided.")`. The rule applies in the constructor and in `UpdateName(...)`.
- **Delete restriction:** `book_authors.author_id` uses `ON DELETE RESTRICT`. PostgreSQL rejects deleting an author that is still linked to a book.
- **Domain events:** The constructor raises `AuthorCreatedEvent`, `UpdateName(...)` raises `AuthorUpdatedEvent`, and `Remove()` raises `AuthorDeletedEvent`.
