`Book` is the Catalog aggregate root for a sellable title. Catalog API owns it and persists it in PostgreSQL (`catalogdb`) through EF Core with `snake_case` naming.

## Overview

| Property                  | Value                                                                                            |

The EF Core `ComplexProperty` stores the original and discount prices as `Price.OriginalPrice` and `Price.DiscountPrice` under the mapped `Price` complex property. Confirm exact generated column names from the current migration snapshot before writing database SQL.

The `Book` constructor accepts a nullable description, but `BookConfiguration` marks the mapped description as required. `SetMetadata` and `Update` reject empty or whitespace descriptions, so create/update behavior should treat a non-empty description as required even though the aggregate constructor parameter remains nullable.

## Invariants and behavior

- **Name required:** The constructor and `Update(...)` throw `CatalogDomainException("Book name is required.")` for null or whitespace names.
- **Price rules:** `Price` throws `CatalogDomainException` when `originalPrice < 0` or when `discountPrice` is negative or greater than `originalPrice`.
- **Initial status:** New books start as `InStock`.
- **Rating summary:** `AddRating(rating)` and `RemoveRating(rating)` recompute `averageRating` and `totalReviews`. When `totalReviews <= 1`, `RemoveRating` resets both to `0`.
- **Author replacement:** `Update(...)` clears and replaces all `BookAuthor` links. `SetMetadata(...)` appends links and requires a non-whitespace description.
- **Soft delete:** `Delete()` sets `isDeleted = true`. EF Core hides deleted books and their `BookAuthor` rows through global query filters.
- **Domain events:** The constructor raises `BookCreatedEvent`. `Update`, `AddRating`, `RemoveRating`, and `Delete` raise `BookChangedEvent(Id)`.
