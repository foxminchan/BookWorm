## Domain Role & Boundary

**Publisher** is an Aggregate Root in the [[domain|catalog]] bounded context representing the publishing house or imprint that issues a book. Owned by [[service|catalog-api]], it maintains canonical publisher names for catalog filtering and attribution. It explicitly does **not** own book inventory, author contracts, or royalty/order accounting.

## Domain Invariants & Lifecycle

- **Name required:** Creating or renaming a publisher with a null, empty, or whitespace-only name is rejected.
- **Global uniqueness:** Duplicate publisher names are rejected by the persistence layer.
- **Non-cascading hard delete:** Removing a publisher permanently deletes the publisher record and sets `publisherId` to null on any linked [[entity|book]] without deleting the books themselves.
- **Lifecycle events:** Creation, renaming, and deletion raise internal domain events within [[service|catalog-api]].

:::note
Publishers have no audit timestamps or soft-delete state; if a publisher is removed by mistake, a new record must be created and re-linked to affected books.
:::
