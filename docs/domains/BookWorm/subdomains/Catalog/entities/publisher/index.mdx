`Publisher` is the Catalog aggregate root for the publishing house or imprint of a book. Catalog API owns it and persists it in PostgreSQL (`catalogdb`).

## Overview

| Property                  | Value                                                                                                 |
| :------------------------ | :---------------------------------------------------------------------------------------------------- |
| **Owner**                 | Catalog bounded context / **Catalog API** (`catalog`)                                                 |
| **Source**                | `src/Services/Catalog/BookWorm.Catalog/Domain/AggregatesModel/PublisherAggregate/Publisher.cs`        |
| **EF Core configuration** | `src/Services/Catalog/BookWorm.Catalog/Infrastructure/EntityConfigurations/PublisherConfiguration.cs` |
| **Backing store**         | PostgreSQL database `catalogdb`, table `publishers` (`snake_case`)                                    |
| **Base type**             | `Entity<PublisherId>`, `IAggregateRoot`                                                               |
| **Identifier**            | `PublisherId` (Vogen value object wrapping `Guid`)                                                    |

`Publisher` has no audit timestamps, row version, soft-delete flag, or `Books` navigation collection.

## Parameters and fields

| Name   | Type                   | Required | Default               | Constraints                                 | Description                 |
| :----- | :--------------------- | :------- | :-------------------- | :------------------------------------------ | :-------------------------- |
| `id`   | `PublisherId` (`Guid`) | Yes      | `uuidv7()` (database) | Primary key                                 | Unique publisher identifier |
| `name` | `string`               | Yes      | —                     | Non-whitespace; max 100 chars; unique index | Publisher display name      |

## Invariants and behavior

- **Name required:** Setting `Name` to null or whitespace throws `CatalogDomainException("Publisher name must be provided.")`.
- **Name unique:** PostgreSQL rejects a second publisher with the same `name`.
- **Hard delete:** Deleting a publisher removes the row. PostgreSQL sets `books.publisher_id` to `NULL` for affected books (`ON DELETE SET NULL`).
- **Domain events:** The constructor raises `PublisherCreatedEvent`, `UpdateName(...)` raises `PublisherUpdatedEvent`, and `Remove()` raises `PublisherDeletedEvent`.
