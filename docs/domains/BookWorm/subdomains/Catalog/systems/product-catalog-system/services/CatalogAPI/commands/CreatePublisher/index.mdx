`CreatePublisher` creates a new publisher record in **Catalog API** (`POST /api/v1/publishers`) and returns its generated UUIDv7 identifier as a JSON string. Callers use the returned identifier when linking publishers in [[command|CreateBook]] and [[command|UpdateBook]].

## Overview

| Property              | Value                                                                                                                        |
| :-------------------- | :--------------------------------------------------------------------------------------------------------------------------- |
| **Owner**             | Catalog bounded context (**Catalog API**, Aspire resource `catalog`)                                                         |
| **Source**            | `src/Services/Catalog/BookWorm.Catalog/Features/Publishers/Create/`                                                          |
| **Protocol / format** | HTTP `POST`, JSON request (`application/json`), JSON string response                                                         |
| **Endpoint**          | Direct: `POST /api/v1/publishers` (local HTTP `5100`, HTTPS `7187`); API Gateway: `POST /catalog/api/v1/publishers`          |
| **Authentication**    | Microsoft Entra ID JWT — `business_user` policy (role `business_user` or `admin` and scopes `catalog_read`, `catalog_write`) |
| **Rate limiting**     | Global concurrency (`100`) and fixed-window (`30 req/min`) limiters plus `PerUserRateLimit` token bucket                     |
| **Idempotency**       | Not idempotent; duplicate names fail the PostgreSQL unique index, and no `x-request-id` header is enforced                   |
| **Contract version**  | `1.0.0` (`ApiVersions.V1`)                                                                                                   |

## Parameters and fields

### Request body (`application/json`)

`StringTrimmerJsonConverter` trims leading and trailing whitespace from string properties during deserialization.

| Name   | Type     | Required | Default | Constraints                                                                        | Description                   |
| :----- | :------- | :------- | :------ | :--------------------------------------------------------------------------------- | :---------------------------- |
| `name` | `string` | Yes      | —       | Non-empty, max `100` chars (`DataSchemaLength.Large`), unique in `publishers.name` | Display name of the publisher |

:::note
`CreatePublisherValidator` and `PublisherConfiguration` allow up to `100` characters (`DataSchemaLength.Large`), whereas `UpdatePublisherValidator` currently enforces a `50`-character limit (`DataSchemaLength.Medium`). See [[command|UpdatePublisher]].
:::

### Response body (`200 OK`)

`CreatePublisherEndpoint` returns `200 OK` (not `201 Created`) without a `Location` header.

| Name       | Type     | Required | Default | Constraints            | Description                                          |
| :--------- | :------- | :------- | :------ | :--------------------- | :--------------------------------------------------- |
| Root value | `string` | Yes      | —       | UUIDv7 (`PublisherId`) | Generated unique identifier of the created publisher |

## Behavior and side effects

- **Persistence and uniqueness:** Inserts a new row into the `publishers` table in PostgreSQL (`catalogdb`) with a database-generated UUIDv7 primary key. `PublisherConfiguration.cs` enforces a unique index on `publishers.name`; submitting a duplicate name raises an unhandled database exception mapped to `500 Internal Server Error` by `GlobalExceptionHandler`.
- **Cache invalidation:** Dispatches `PublisherCreatedEvent` on save; `PublisherChangedEventHandler` removes the FusionCache key `catalog:publishers:v1`.
- **Search vectors:** No vector-index trigger runs on `publishers` insert; `publishers_vector_update` fires only on `UPDATE` or `DELETE`.

## Error responses

| Code / status               | Condition                                                                                                                          | Recovery behavior                                                               |
| :-------------------------- | :--------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------ |
| `400 Bad Request`           | `name` is missing, empty, whitespace-only, exceeds `100` characters, or JSON payload is malformed (`HttpValidationProblemDetails`) | Fix the request body; do not retry unchanged input                              |
| `401 Unauthorized`          | Missing, expired, or invalid Entra ID JWT                                                                                          | Acquire a valid Entra ID access token and retry                                 |
| `403 Forbidden`             | Token lacks role `business_user` or `admin`, or lacks scopes `catalog_read` and `catalog_write`                                    | Request the required Entra ID app role and scopes                               |
| `429 Too Many Requests`     | Global or `PerUserRateLimit` quota exceeded (`ProblemDetails` with `Retry-After` header)                                           | Wait for the `Retry-After` interval before retrying                             |
| `500 Internal Server Error` | Duplicate `name` violating the `publishers.name` unique index or unhandled server error (`ProblemDetails` with `traceId`)          | Check existing publishers for a duplicate name and inspect logs using `traceId` |
