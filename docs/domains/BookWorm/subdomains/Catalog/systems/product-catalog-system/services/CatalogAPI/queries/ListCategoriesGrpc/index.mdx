`ListCategoriesGrpc` invokes the internal `book.v1.BookGrpcService/ListCategories` gRPC unary RPC on **Catalog API** to return all registered book categories (`CategoryItem`) without pagination. **MCP Tools** calls this RPC to power its `list_categories` tool.

## Overview

| Property                | Value                                                                                                                                         |
| :---------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------- |
| **Owner (gRPC server)** | Catalog bounded context (**Catalog API**, Aspire resource `catalog`)                                                                          |
| **Primary caller**      | **MCP Tools** (`mcptools`, `list_categories` tool)                                                                                            |
| **Source**              | `src/Services/Catalog/BookWorm.Catalog/Grpc/Protos/book/v1/book.proto`, `src/Services/Catalog/BookWorm.Catalog/Grpc/Services/BookService.cs`  |
| **Protocol / format**   | gRPC unary RPC (`book.v1.BookGrpcService/ListCategories`), Protobuf `edition = "2023"`, `csharp_namespace = "BookWorm.Catalog.Grpc.Services"` |
| **Authentication**      | `[AllowAnonymous]` (internal service-to-service public catalog read)                                                                          |
| **Caching**             | Dispatches `ListCategoriesQuery`, backed by PostgreSQL (`catalogdb`) and FusionCache (L1 + Redis L2, key `CatalogCacheKeys.Categories`)       |
| **Contract version**    | `1.0.0`                                                                                                                                       |

## Parameters and fields

### Request message (`ListCategoriesRequest`)

`ListCategoriesRequest` is an empty Protobuf message with no fields.

### Response message (`ListCategoriesResponse`)

| Field               | Protobuf type           | Tag | Description                                                               |
| :------------------ | :---------------------- | :-- | :------------------------------------------------------------------------ |
| `categories`        | `repeated CategoryItem` | `1` | All catalog categories (empty collection if none exist)                   |
| `categories[].id`   | `string`                | `1` | Category UUID                                                             |
| `categories[].name` | `string`                | `2` | Category display name (mapped to empty string `""` if null in source DTO) |

### Protobuf contract

<CodeGroup>

```protobuf
edition = "2023";

package book.v1;

service BookGrpcService {
  rpc ListCategories (ListCategoriesRequest) returns (ListCategoriesResponse);
}

message ListCategoriesRequest {}

message ListCategoriesResponse {
  repeated CategoryItem categories = 1;
}

message CategoryItem {
  string id = 1;
  string name = 2;
}
```

</CodeGroup>
