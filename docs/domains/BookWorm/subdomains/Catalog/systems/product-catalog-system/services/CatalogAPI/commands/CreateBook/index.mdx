## Overview

Creates a [[entity|book]] using a `multipart/form-data` request, including its catalog relationships and optional cover image.

<NodeGraph />

## Contract

Send the required title, description, price, [[entity|category]], [[entity|publisher]], and at least one [[entity|author]] as multipart fields. Use `image` for an optional binary cover upload.

The response body is a JSON string containing the new book UUID.

## Operational notes

`400` indicates validation failure, including malformed UUIDs, missing fields, invalid prices, or an invalid multipart payload.
