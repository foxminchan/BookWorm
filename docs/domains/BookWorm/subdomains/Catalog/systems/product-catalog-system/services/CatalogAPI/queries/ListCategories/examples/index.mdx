## List all categories with curl

<CodeGroup>

```bash
curl --request GET "<gateway-url>/catalog/api/v1/categories" \
  --header "Accept: application/json"
```

</CodeGroup>

Where:

- `<gateway-url>`: Base URL of the BookWorm API Gateway (or direct Catalog API URL `https://localhost:7187` without the `/catalog` prefix).

Expected response (`200 OK`):

<CodeGroup>

```json
[
	{
		"id": "11111111-1111-1111-1111-111111111111",
		"name": "Science Fiction"
	},
	{
		"id": "88888888-8888-8888-8888-888888888888",
		"name": "Technology"
	}
]
```

</CodeGroup>
