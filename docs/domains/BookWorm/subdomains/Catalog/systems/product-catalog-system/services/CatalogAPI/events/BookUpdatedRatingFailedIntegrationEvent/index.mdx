## Overview

The [[service|catalog-api]] publishes this event when a
[[event|FeedbackCreatedIntegrationEvent]] references a [[entity|book]] that
does not exist. The event contains the [[entity|feedback]] identifier so the
Rating service can
identify the failed update and apply its retry or reconciliation behavior.
