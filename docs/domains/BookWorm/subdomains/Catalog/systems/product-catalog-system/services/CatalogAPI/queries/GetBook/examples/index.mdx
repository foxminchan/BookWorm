## Retrieve a book with curl

<CodeGroup>

```bash
curl --request GET \
  "<gateway-url>/catalog/api/v1/books/44444444-4444-4444-4444-444444444444" \
  --header "Accept: application/json"
```

</CodeGroup>

Where:

- `<gateway-url>`: Base URL of the BookWorm API Gateway (or direct Catalog API URL `https://localhost:7187` without the `/catalog` prefix).

Expected response (`200 OK`):

<CodeGroup>

```json
{
	"id": "44444444-4444-4444-4444-444444444444",
	"name": "The Left Hand of Darkness",
	"description": "A science fiction classic exploring gender and diplomacy.",
	"imageUrl": "https://storage.example.com/catalog-blob/left-hand.jpg",
	"price": 18.99,
	"priceSale": null,
	"status": "InStock",
	"category": {
		"id": "11111111-1111-1111-1111-111111111111",
		"name": "Science Fiction"
	},
	"publisher": {
		"id": "22222222-2222-2222-2222-222222222222",
		"name": "Ace Books"
	},
	"authors": [
		{
			"id": "33333333-3333-3333-3333-333333333333",
			"name": "Ursula K. Le Guin"
		}
	],
	"averageRating": 4.8,
	"totalReviews": 12
}
```

</CodeGroup>

## Retrieve a book with TypeScript

<CodeGroup>

```typescript
type BookDto = {
	id: string;
	name: string | null;
	description: string | null;
	imageUrl: string | null;
	price: number;
	priceSale: number | null;
	status: "InStock" | "OutOfStock";
	category: { id: string; name: string | null } | null;
	publisher: { id: string; name: string | null } | null;
	authors: Array<{ id: string; name: string | null }>;
	averageRating: number;
	totalReviews: number;
};

const gatewayUrl = "<gateway-url>";
const bookId = "44444444-4444-4444-4444-444444444444";

const response = await fetch(`${gatewayUrl}/catalog/api/v1/books/${bookId}`, {
	headers: { Accept: "application/json" },
});

if (response.status === 404) {
	throw new Error("Book was not found");
}
if (!response.ok) {
	throw new Error(`GetBook failed with ${response.status}`);
}

const book = (await response.json()) as BookDto;
console.log(`${book.name} (${book.status}): ${book.price}`);
```

</CodeGroup>
