## Overview

Updates the [[entity|book]] identified by `id` using a `multipart/form-data` request. Only supplied fields are changed; `isRemoveImage` can remove the current cover.

<NodeGraph />

## Contract

Send `id` plus any fields to change. Use `image` to replace the cover, or `isRemoveImage=true` to remove it. Relationship fields accept UUIDs.

The successful response is `204 No Content` with an empty body.

## Operational notes

`400` indicates invalid form data. `404` indicates that the book identified by `id` does not exist.
