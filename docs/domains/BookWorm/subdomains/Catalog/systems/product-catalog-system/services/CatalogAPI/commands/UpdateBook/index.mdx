`UpdateBook` replaces the full metadata, pricing, relationships, and optional cover image of an existing book in **Catalog API** (`PUT /api/v1/books`) from a `multipart/form-data` payload and returns `204 No Content`. Callers can supply an `If-Match` header with the book's `ETag` to enforce optimistic concurrency control.

## Overview

| Property              | Value                                                                                                                        |
| :-------------------- | :--------------------------------------------------------------------------------------------------------------------------- |
| **Owner**             | Catalog bounded context (**Catalog API**, Aspire resource `catalog`)                                                         |
| **Source**            | `src/Services/Catalog/BookWorm.Catalog/Features/Books/Update/`                                                               |
| **Protocol / format** | HTTP `PUT`, `multipart/form-data` request (`[FromForm]`), empty response body (`204 No Content`)                             |
| **Endpoint**          | Direct: `PUT /api/v1/books` (local HTTP `5100`, HTTPS `7187`); API Gateway: `PUT /catalog/api/v1/books`                      |
| **Authentication**    | Microsoft Entra ID JWT — `business_user` policy (role `business_user` or `admin` and scopes `catalog_read`, `catalog_write`) |
| **Concurrency**       | Optional `If-Match` header (`ETagEndpointFilter` via `.WithETag()`); stale versions return `412 Precondition Failed`         |
| **Rate limiting**     | Global concurrency (`100`) and fixed-window (`30 req/min`) limiters plus `PerUserRateLimit` token bucket                     |
| **Idempotency**       | Idempotent when resubmitting identical fields without a new `image` upload; no `x-request-id` header is enforced             |
| **Contract version**  | `1.0.0` (`ApiVersions.V1`)                                                                                                   |

:::note
`PUT /api/v1/books` is a **full replacement**, not a partial patch. `UpdateBookValidator` inherits `BookValidatorBase` and requires `id`, `name`, `price`, `categoryId`, `publisherId`, and `authorIds` on every request; omitting optional fields (`description`, `priceSale`) overwrites them with their defaults (`""` and `null`).
:::

| :-------------- | :-------------- | :------- | :------ | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------ |

| `description`   | `string`        | No       | `""`    | Max `500` chars in `BookValidatorBase` (`DataSchemaLength.SuperLarge`; DB column max `1000`, `NOT NULL`)                                                                                               | Book summary text; omitting clears the stored description to `""`                           |

| `priceSale`     | `decimal`       | No       | `null`  | When provided: strictly `> 0` and `<= price`; stored as `numeric(18,2)`                                                                                                                                | Optional promotional sale price; omitting clears any existing sale price                    |

## Behavior and side effects

- **Optimistic concurrency:** When `If-Match` contains a valid integer ETag, `ETagEndpointFilter` populates `UpdateBookCommand.ExpectedVersion`. `UpdateBookHandler` compares `ExpectedVersion` against `book.RowVersion` and throws `DbUpdateConcurrencyException` on mismatch, which `GlobalExceptionHandler` maps to `412 Precondition Failed`.
- **Transactional persistence:** `UpdateBookCommand` is decorated with `[Transactional]`, wrapping entity updates and `book_authors` replacement inside `TransactionBehavior<CatalogDbContext>`.
- **Cover image handling:**
  - `UpdateBookPreProcessor` uploads `image` (when non-null) to Azure Blob Storage (`catalog-blob`) via `BlobService.UploadFileAsync` and stores the returned URN in `ImageUrn`.
  - `UpdateBookHandler` resolves the new column value as `isRemoveImage ? null : ImageUrn ?? book.Image`, preserving the existing cover URN when neither `image` nor `isRemoveImage=true` is sent.
  - `UpdateBookPostProcessor` calls `BlobService.DeleteFileAsync(ImageUrn)` only when both `IsRemoveImage == true` and `ImageUrn is not null` (deleting a file uploaded in the same request). Clearing a cover with `isRemoveImage=true` alone sets `book.Image = null` in PostgreSQL without deleting the previously stored blob from `catalog-blob`.
- **Cache invalidation:** `book.Update(...)` registers `BookChangedEvent(Id)`; `BookChangedEventHandler` removes FusionCache keys `book:{id}` and `book:summary:{id}` and invalidates tags `books:list` and `books:search`.
- **Vector index queueing:** PostgreSQL triggers `books_vector_update` and `book_authors_vector_update` enqueue `book_id` into `pending_vector_updates` for asynchronous Qdrant embedding refresh by **Catalog Ingestion**.

## Error responses

| Code / status               | Condition                                                                                                                                                                                                                                                           | Recovery behavior                                                                       |
| :-------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | :-------------------------------------------------------------------------------------- |
| `400 Bad Request`           | FluentValidation failure (missing/empty `id`, `name`, `categoryId`, `publisherId`, or `authorIds`; `price <= 0`; `priceSale <= 0` or `> price`; length exceeded; invalid image size/type/extension) or malformed multipart payload (`HttpValidationProblemDetails`) | Fix invalid form fields or file upload; do not retry unchanged input                    |
| `401 Unauthorized`          | Missing, expired, or invalid Entra ID JWT                                                                                                                                                                                                                           | Acquire a valid Entra ID access token and retry                                         |
| `403 Forbidden`             | Token lacks role `business_user` or `admin`, or lacks scopes `catalog_read` and `catalog_write`                                                                                                                                                                     | Request the required Entra ID app role and scopes                                       |
| `404 Not Found`             | No active book exists with the supplied `id` (`{ "detail": "The requested resource was not found." }`)                                                                                                                                                              | Verify the book UUID; do not treat `404` as a completed update                          |
| `412 Precondition Failed`   | `If-Match` version does not match the book's current `RowVersion` (`ProblemDetails`)                                                                                                                                                                                | Fetch the latest book and `ETag` via `GET /api/v1/books/{id}`, merge changes, and retry |
| `429 Too Many Requests`     | Global or `PerUserRateLimit` quota exceeded (`ProblemDetails` with `Retry-After` header)                                                                                                                                                                            | Wait for the `Retry-After` interval before retrying                                     |
| `500 Internal Server Error` | Foreign-key violation, Azure Blob Storage failure, or unhandled server error (`ProblemDetails` with `traceId`)                                                                                                                                                      | Verify referenced IDs exist and inspect Catalog API logs using `traceId`                |
