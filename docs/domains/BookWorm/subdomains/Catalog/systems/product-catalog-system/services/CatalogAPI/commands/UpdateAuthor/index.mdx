`UpdateAuthor` updates the display name of an existing author in [[service|catalog-api]] (`PUT /catalog/api/v1/authors`) and returns `204 No Content`. Callers pass both `id` and `name` in the JSON request body rather than as a path parameter.

## Overview

| Property                           | Value                                                                                                                              |
| :--------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------- |
| **Bounded Context**                | Catalog                                                                                                                            |
| **Owner Service**                  | [[service\|catalog-api]]                                                                                                           |
| **Protocol / Format**              | HTTP `PUT`, `application/json` request and empty response (`204 No Content`)                                                       |
| **Gateway Endpoint**               | `PUT /catalog/api/v1/authors` (service path `/api/v1/authors`)                                                                     |
| **Authentication & Authorization** | Microsoft Entra ID JWT — `business_user` policy (role `business_user` or `admin` and scopes `catalog_read`, `catalog_write`)       |
| **Idempotency / Concurrency**      | Naturally idempotent for repeated requests with the same `id` and `name`; no `x-request-id` header is enforced                     |
| **Rate Limit / Caching**           | Global concurrency (`100`) and fixed-window (`30 req/min`) limiters plus per-user token bucket; invalidates author and book caches |
| **Contract Version**               | `1.0.0` (`ApiVersions.V1`)                                                                                                         |

## Request & Response Contract

### Request Body (`application/json`)

Leading and trailing whitespace is trimmed from string properties during deserialization.

| Name   | Type              | Required | Constraints                     | Description                             |
| :----- | :---------------- | :------- | :------------------------------ | :-------------------------------------- |
| `id`   | `string` (`uuid`) | Yes      | Non-empty UUID                  | Identifier of the author to update      |
| `name` | `string`          | Yes      | Non-empty, max `100` characters | Replacement display name for the author |

## Behavior & Side Effects

- **Persistence:** Updates the [[entity|author]] display name; author names have no unique constraint.
- **Cache invalidation:** Clears `catalog:authors:v1` and invalidates `book` and `books:list` cache tags so cached book details reflect the renamed author.
- **Vector index queueing:** Database triggers enqueue all linked book IDs for asynchronous vector embedding refresh by [[service|catalog-ingestion]].

## Error Responses

| Status / Code               | Condition                                                                                                | Client Recovery Action                                    |
| :-------------------------- | :------------------------------------------------------------------------------------------------------- | :-------------------------------------------------------- |
| `400 Bad Request`           | `id` is empty or invalid UUID, or `name` is missing, empty, whitespace-only, or exceeds `100` characters | Fix the request body; do not retry unchanged input        |
| `401 Unauthorized`          | Missing, expired, or invalid Entra ID JWT                                                                | Acquire a valid Entra ID access token and retry           |
| `403 Forbidden`             | Token lacks role `business_user` or `admin`, or lacks scopes `catalog_read` and `catalog_write`          | Request the required Entra ID app role and scopes         |
| `404 Not Found`             | No author exists with the supplied `id`                                                                  | Verify the UUID; do not treat `404` as a completed update |
| `429 Too Many Requests`     | Rate limit quota exceeded (`Retry-After` header included)                                                | Wait for the `Retry-After` interval before retrying       |
| `500 Internal Server Error` | Unhandled server or database failure (`traceId` included)                                                | Inspect service logs using `traceId`                      |
