This reference defines the `FeedbackCreatedIntegrationEvent` Kafka integration contract consumed by **Catalog API** (`BookWorm.Catalog`) to update a book's derived `average_rating` and `total_reviews` projection in PostgreSQL (`catalogdb`) when **Rating API** (`BookWorm.Rating`) persists a new `Feedback` document in Azure Cosmos DB (`ratingdb`/`feedbacks`).

## Overview

| Property              | Value                                                                                                                                                          |
| :-------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Owner (producer)**  | Reviews bounded context — **Rating API** (`src/Services/Rating/BookWorm.Rating`)                                                                               |
| **Consumer**          | Catalog bounded context — **Catalog API** (`src/Services/Catalog/BookWorm.Catalog`)                                                                            |
| **Source**            | `src/Services/Catalog/BookWorm.Catalog/IntegrationEvents/Events/FeedbackCreatedIntegrationEvent.cs`, `EventHandlers/FeedbackCreatedIntegrationEventHandler.cs` |
| **Kafka topic**       | `bookworm.{env}.rating.feedback-create` (`AppendPrefix = true`)                                                                                                |
| **Message identity**  | `BookWorm.Contracts.FeedbackCreatedIntegrationEvent`                                                                                                           |
| **Protocol / format** | Kafka + CloudEvents JSON (`CloudEventsOnlyKafkaMapper`), partitioned by `BookId` / `FeedbackId`                                                                |
| **Idempotency**       | Redis-backed `IIntegrationEventIdempotencyGuard` (24-hour TTL keyed by `Id` + `FeedbackCreatedIntegrationEventHandler`)                                        |
| **Contract tests**    | Pact messaging tests in `BookWorm.Catalog.ContractTests` and `tests/pacts/` (`Catalog-Rating`, `Rating-Catalog`)                                               |

## Parameters and fields

| Name         | Type   | Required | Default   | Constraints                           | Description                                                                                                              |
| :----------- | :----- | :------- | :-------- | :------------------------------------ | :----------------------------------------------------------------------------------------------------------------------- |
| `Id`         | `Guid` | Yes      | Generated | Inherited from `IntegrationEvent`     | Unique event identifier used as the Redis idempotency key                                                                |
| `BookId`     | `Guid` | Yes      | —         | Non-empty UUID                        | Target Catalog book identifier to update                                                                                 |
| `Rating`     | `int`  | Yes      | —         | Validated by **Rating API** (`1`–`5`) | Star rating added to the book's running summary via `Book.AddRating`                                                     |
| `FeedbackId` | `Guid` | Yes      | —         | Non-empty UUID                        | Authoritative Cosmos DB feedback identifier returned in `BookUpdatedRatingFailedIntegrationEvent` if the book is missing |

## Processing and error behavior

| Condition                                | Handler behavior                                                                                                                                                                        | Recovery / downstream effect                                                                                                                 |
| :--------------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------- |
| **Book exists in `catalogdb`**           | Calls `book.AddRating(@event.Rating)` (`((AverageRating * TotalReviews) + rating) / (TotalReviews + 1)`, `TotalReviews++`) and saves via `UnitOfWork.SaveEntitiesAsync`; returns `null` | Commits updated summary and invalidates cached book entry                                                                                    |
| **Book missing (`book is null`)**        | Calls `UnitOfWork.SaveEntitiesAsync` and returns `BookUpdatedRatingFailedIntegrationEvent(@event.FeedbackId)` as a Wolverine cascading message                                          | Publishes compensation event to `bookworm.{env}.catalog.book-update-rating-failed` so **Rating API** deletes the orphaned Cosmos DB feedback |
| **Duplicate event within 24 hours**      | `IIntegrationEventIdempotencyGuard` skips re-execution for the same `@event.Id`                                                                                                         | Prevents double-counting `TotalReviews` on Kafka redelivery                                                                                  |
| **Transient DB or infrastructure error** | Exception propagates to Wolverine                                                                                                                                                       | Wolverine retries (`50ms / 250ms / 1s` with full jitter), then routes to `bookworm.{env}.catalog.dead-letter-queue`                          |

## Examples

### Contract record (`FeedbackCreatedIntegrationEvent.cs`)

<CodeGroup>

```csharp
using BookWorm.Constants.Aspire;
using Wolverine.Attributes;

namespace BookWorm.Contracts;

[IntegrationMessageOwner(ServiceName = Services.Rating, TopicName = "feedback-create")]
[MessageIdentity("BookWorm.Contracts.FeedbackCreatedIntegrationEvent")]
public sealed record FeedbackCreatedIntegrationEvent(Guid BookId, int Rating, Guid FeedbackId)
    : IntegrationEvent;
```

</CodeGroup>

### Catalog consumer handler (`FeedbackCreatedIntegrationEventHandler.cs`)

<CodeGroup>

```csharp
using BookWorm.Chassis.EventBus.Idempotency;
using BookWorm.Contracts;
using Wolverine.Attributes;

namespace BookWorm.Catalog.IntegrationEvents.EventHandlers;

internal sealed class FeedbackCreatedIntegrationEventHandler(
    IBookRepository repository,
    IIntegrationEventIdempotencyGuard? idempotencyGuard = null
)
{
    [WolverineHandler]
    public async Task<BookUpdatedRatingFailedIntegrationEvent?> Handle(
        FeedbackCreatedIntegrationEvent @event,
        CancellationToken cancellationToken
    )
    {
        return await idempotencyGuard.ExecuteAsync(
            @event.Id,
            nameof(FeedbackCreatedIntegrationEventHandler),
            async ct =>
            {
                var book = await repository.GetByIdAsync(@event.BookId, ct);

                if (book is null)
                {
                    await repository.UnitOfWork.SaveEntitiesAsync(ct);
                    return new BookUpdatedRatingFailedIntegrationEvent(@event.FeedbackId);
                }

                book.AddRating(@event.Rating);
                await repository.UnitOfWork.SaveEntitiesAsync(ct);
                return null;
            },
            cancellationToken: cancellationToken
        );
    }
}
```

</CodeGroup>
