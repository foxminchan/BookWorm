This reference defines the `FeedbackDeletedIntegrationEvent` Kafka integration contract consumed by **Catalog API** (`BookWorm.Catalog`) to remove a deleted review's score from a book's derived `average_rating` and `total_reviews` projection in PostgreSQL (`catalogdb`) when **Rating API** (`BookWorm.Rating`) deletes a `Feedback` document from Azure Cosmos DB (`ratingdb`/`feedbacks`).

## Overview

| Property              | Value                                                                                                                                                          |
| :-------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Owner (producer)**  | Reviews bounded context — **Rating API** (`src/Services/Rating/BookWorm.Rating`)                                                                               |
| **Consumer**          | Catalog bounded context — **Catalog API** (`src/Services/Catalog/BookWorm.Catalog`)                                                                            |
| **Source**            | `src/Services/Catalog/BookWorm.Catalog/IntegrationEvents/Events/FeedbackDeletedIntegrationEvent.cs`, `EventHandlers/FeedbackDeletedIntegrationEventHandler.cs` |
| **Kafka topic**       | `bookworm.{env}.rating.feedback-delete` (`AppendPrefix = true`)                                                                                                |
| **Message identity**  | `BookWorm.Contracts.FeedbackDeletedIntegrationEvent`                                                                                                           |
| **Protocol / format** | Kafka + CloudEvents JSON (`CloudEventsOnlyKafkaMapper`), partitioned by `BookId` / `FeedbackId`                                                                |
| **Idempotency**       | Redis-backed `IIntegrationEventIdempotencyGuard` (24-hour TTL keyed by `Id` + `FeedbackDeletedIntegrationEventHandler`)                                        |
| **Contract tests**    | Pact messaging tests in `BookWorm.Catalog.ContractTests` and `tests/pacts/` (`Catalog-Rating`, `Rating-Catalog`)                                               |

## Parameters and fields

| Name         | Type   | Required | Default   | Constraints                       | Description                                                                  |
| :----------- | :----- | :------- | :-------- | :-------------------------------- | :--------------------------------------------------------------------------- |
| `Id`         | `Guid` | Yes      | Generated | Inherited from `IntegrationEvent` | Unique event identifier used as the Redis idempotency key                    |
| `BookId`     | `Guid` | Yes      | —         | Non-empty UUID                    | Target Catalog book identifier to adjust                                     |
| `Rating`     | `int`  | Yes      | —         | `1`–`5`                           | Original star rating of the deleted feedback removed via `Book.RemoveRating` |
| `FeedbackId` | `Guid` | Yes      | —         | Non-empty UUID                    | Identifier of the deleted Cosmos DB feedback record for traceability         |

## Processing and error behavior

| Condition                                | Handler behavior                                                                                                                                                             | Recovery / downstream effect                                                                                        |
| :--------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------ |
| **Book exists (`TotalReviews > 1`)**     | Calls `book.RemoveRating(@event.Rating)` (`((AverageRating * TotalReviews) - rating) / (TotalReviews - 1)`, `TotalReviews--`) and commits via `UnitOfWork.SaveEntitiesAsync` | Updates `catalogdb` summary and invalidates cached book entry                                                       |
| **Book exists (`TotalReviews <= 1`)**    | `book.RemoveRating` resets `AverageRating = 0` and `TotalReviews = 0` and commits                                                                                            | Prevents divide-by-zero or negative review counts                                                                   |
| **Book missing (`book is null`)**        | Returns without writing or publishing any compensation event                                                                                                                 | Safe no-op; no local rating projection exists to adjust                                                             |
| **Duplicate event within 24 hours**      | `IIntegrationEventIdempotencyGuard` skips re-execution for the same `@event.Id`                                                                                              | Prevents double-decrementing `TotalReviews` on Kafka redelivery                                                     |
| **Transient DB or infrastructure error** | Exception propagates to Wolverine                                                                                                                                            | Wolverine retries (`50ms / 250ms / 1s` with full jitter), then routes to `bookworm.{env}.catalog.dead-letter-queue` |

## Examples

### Contract record (`FeedbackDeletedIntegrationEvent.cs`)

<CodeGroup>

```csharp
using BookWorm.Constants.Aspire;
using Wolverine.Attributes;

namespace BookWorm.Contracts;

[IntegrationMessageOwner(ServiceName = Services.Rating, TopicName = "feedback-delete")]
[MessageIdentity("BookWorm.Contracts.FeedbackDeletedIntegrationEvent")]
public sealed record FeedbackDeletedIntegrationEvent(Guid BookId, int Rating, Guid FeedbackId)
    : IntegrationEvent;
```

</CodeGroup>

### Catalog consumer handler (`FeedbackDeletedIntegrationEventHandler.cs`)

<CodeGroup>

```csharp
using BookWorm.Chassis.EventBus.Idempotency;
using BookWorm.Contracts;
using Wolverine.Attributes;

namespace BookWorm.Catalog.IntegrationEvents.EventHandlers;

internal sealed class FeedbackDeletedIntegrationEventHandler(
    IBookRepository repository,
    IIntegrationEventIdempotencyGuard? idempotencyGuard = null
)
{
    [WolverineHandler]
    public async Task Handle(
        FeedbackDeletedIntegrationEvent @event,
        CancellationToken cancellationToken
    )
    {
        await idempotencyGuard.ExecuteAsync(
            @event.Id,
            nameof(FeedbackDeletedIntegrationEventHandler),
            async ct =>
            {
                var book = await repository.GetByIdAsync(@event.BookId, ct);

                if (book is null)
                {
                    return;
                }

                book.RemoveRating(@event.Rating);

                await repository.UnitOfWork.SaveEntitiesAsync(ct);
            },
            cancellationToken: cancellationToken
        );
    }
}
```

</CodeGroup>
