## 1. Delete an existing author

Delete by UUID. A successful deletion returns `204 No Content` and has no response body.

### Operational notes

- Confirm that no remaining book relationship should reference the author.
- Treat `404` as a missing resource, not as a successful deletion.
- Retry only after checking that the UUID is correct.

### Example response

<CodeGroup dropdown>

```ts
const response = { status: 204, body: null };
```

</CodeGroup>

### Using this example

Remove the author from local state after receiving `204 No Content`.

</Column>

<Column>

<CodeGroup dropdown>

```ts delete-author.ts
const authorId = "5e4a1c9b-3f72-4b8d-a605-7c2e9f1d8430";
const response = await fetch(`https://api.example.com/api/v1/authors/${authorId}`, {
	method: "DELETE",
});

if (response.status === 404) {
	throw new Error("Author was not found");
}
if (!response.ok) {
	throw new Error(`DeleteAuthor failed with ${response.status}`);
}
```

## 2. Handle a missing author

An unknown UUID returns `404` with problem details. Confirm the identifier before retrying.
