## Overview

The `ListAuthors` RPC returns all available [[entity|author]] records in the
Catalog. It is an anonymous read operation exposed for internal
service-to-service clients.

[[service|mcp-server]] produces this query in its
`BookService.ListAuthorsAsync` client to power the `list_authors` MCP tool;
[[service|catalog-api]] consumes it by dispatching `ListAuthorsQuery`.

<NodeGraph />

## Contract

Send an empty `ListAuthorsRequest`. The response is `ListAuthorsResponse`,
containing a repeated collection of `AuthorItem` values (`id` and `name`).

## Examples

<CodeGroup dropdown>

```csharp title="ListAuthors gRPC example"
using Grpc.Net.Client;
using BookWorm.Catalog.Grpc.Services;

using var channel = GrpcChannel.ForAddress(Services.CatalogApi);
var client = new BookGrpcService.BookGrpcServiceClient(channel);

var response = await client.ListAuthorsAsync(new ListAuthorsRequest());

foreach (var author in response.Authors)
{
    Console.WriteLine($"{author.Id}: {author.Name}");
}
```
