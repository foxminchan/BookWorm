`ListAuthorsGrpc` invokes the internal `book.v1.BookGrpcService/ListAuthors` gRPC unary RPC on **Catalog API** to return all registered catalog authors (`AuthorItem`) without pagination. **MCP Tools** calls this RPC to power its `list_authors` tool.

## Overview

| Property                | Value                                                                                                                                        |
| :---------------------- | :------------------------------------------------------------------------------------------------------------------------------------------- |
| **Owner (gRPC server)** | Catalog bounded context (**Catalog API**, Aspire resource `catalog`)                                                                         |
| **Primary caller**      | **MCP Tools** (`mcptools`, `list_authors` tool)                                                                                              |
| **Source**              | `src/Services/Catalog/BookWorm.Catalog/Grpc/Protos/book/v1/book.proto`, `src/Services/Catalog/BookWorm.Catalog/Grpc/Services/BookService.cs` |
| **Protocol / format**   | gRPC unary RPC (`book.v1.BookGrpcService/ListAuthors`), Protobuf `edition = "2023"`, `csharp_namespace = "BookWorm.Catalog.Grpc.Services"`   |
| **Authentication**      | `[AllowAnonymous]` (internal service-to-service public catalog read)                                                                         |
| **Caching**             | Dispatches `ListAuthorsQuery`, backed by PostgreSQL (`catalogdb`) and FusionCache (L1 + Redis L2, key `CatalogCacheKeys.Authors`)            |
| **Contract version**    | `1.0.0`                                                                                                                                      |

## Parameters and fields

### Request message (`ListAuthorsRequest`)

`ListAuthorsRequest` is an empty Protobuf message with no fields.

### Response message (`ListAuthorsResponse`)

| Field            | Protobuf type         | Tag | Description                                                             |
| :--------------- | :-------------------- | :-- | :---------------------------------------------------------------------- |
| `authors`        | `repeated AuthorItem` | `1` | All catalog authors (empty collection if none exist)                    |
| `authors[].id`   | `string`              | `1` | Author UUID                                                             |
| `authors[].name` | `string`              | `2` | Author display name (mapped to empty string `""` if null in source DTO) |

### Protobuf contract

<CodeGroup>

```protobuf
edition = "2023";

package book.v1;

service BookGrpcService {
  rpc ListAuthors (ListAuthorsRequest) returns (ListAuthorsResponse);
}

message ListAuthorsRequest {}

message ListAuthorsResponse {
  repeated AuthorItem authors = 1;
}

message AuthorItem {
  string id = 1;
  string name = 2;
}
```

</CodeGroup>
