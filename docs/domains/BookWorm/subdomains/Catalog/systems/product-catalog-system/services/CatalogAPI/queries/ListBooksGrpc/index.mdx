`ListBooksGrpc` invokes the internal `book.v1.BookGrpcService/ListBooks` gRPC unary RPC on **Catalog API** to search and list books with full `BookItem` metadata (descriptions, images, pricing, stock status, relationships, and rating summaries). **MCP Tools** calls this RPC to power its `search_catalog` tool.

## Overview

| Property                         | Value                                                                                                                                                                                                                                                                               |
| :------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Owner (gRPC server)**          | Catalog bounded context (**Catalog API**, Aspire resource `catalog`)                                                                                                                                                                                                                |
| **Primary caller**               | **MCP Tools** (`mcptools`, `search_catalog` tool)                                                                                                                                                                                                                                   |
| **Source**                       | `src/Services/Catalog/BookWorm.Catalog/Grpc/Protos/book/v1/book.proto`, `src/Services/Catalog/BookWorm.Catalog/Grpc/Services/BookService.cs`                                                                                                                                        |
| **Protocol / format**            | gRPC unary RPC (`book.v1.BookGrpcService/ListBooks`), Protobuf `edition = "2023"`, `csharp_namespace = "BookWorm.Catalog.Grpc.Services"`                                                                                                                                            |
| **Authentication**               | `[AllowAnonymous]` (internal service-to-service public catalog read)                                                                                                                                                                                                                |
| **Delegation, search & caching** | Dispatches `ListBooksQuery(Search: search)` with fixed defaults (`PageIndex = 1`, `PageSize = 20`, `OrderBy = "Name"`, `IsDescending = false`); uses Qdrant (`vectordb`) hybrid search (5-minute FusionCache) when `search` is non-empty and caches filtered pages for `60 seconds` |
| **Contract version**             | `1.0.0`                                                                                                                                                                                                                                                                             |

:::note
Because `BookService.ListBooks` delegates to `ListBooksQuery` without exposing paging fields, responses are capped at the default first page of **20 books** sorted by `Name` ascending. Callers requiring multi-page traversal or price/relationship filters must use HTTP [[query|ListBooks]].
:::

## Parameters and fields

### Request message (`ListBooksRequest`)

| Field    | Protobuf type | Tag | Constraints                                  | Description                                                                         |
| :------- | :------------ | :-- | :------------------------------------------- | :---------------------------------------------------------------------------------- |
| `search` | `string`      | `1` | Optional; blank/whitespace treated as `null` | Free-text search term executed via hybrid vector search against Qdrant (`vectordb`) |

### Response message (`ListBooksResponse`)

| Field   | Protobuf type       | Tag | Description                                                                                                                                                                  |
| :------ | :------------------ | :-- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `books` | `repeated BookItem` | `1` | Up to 20 matching books with full metadata (empty collection if zero matches). See [[query\|GetBookDetailsGrpc]] for all `BookItem`, `DecimalValue`, and `BookStatus` fields |

### Protobuf contract

<CodeGroup>

```protobuf
edition = "2023";

package book.v1;

service BookGrpcService {
  rpc ListBooks (ListBooksRequest) returns (ListBooksResponse);
}

message ListBooksRequest {
  string search = 1;
}

message ListBooksResponse {
  repeated BookItem books = 1;
}
```

</CodeGroup>

## Error responses

| Code / status        | Condition                                                                                      | Recovery behavior                           |
| :------------------- | :--------------------------------------------------------------------------------------------- | :------------------------------------------ |
| `Unavailable` (`14`) | Catalog API (or backing Qdrant/PostgreSQL dependency during an uncached search) is unreachable | Retry within the budgeted resilience policy |
