## Overview

The `ListBooks` RPC returns matching [[entity|book]] records with their
descriptions, images, pricing, availability status, [[entity|category]],
[[entity|publisher]], [[entity|author]]s, and rating summary. It is an
anonymous read operation exposed for internal service-to-service clients.

[[service|mcp-server]] produces this query in its `BookService.ListBooksAsync`
client to power the `search_catalog` MCP tool; [[service|catalog-api]] consumes
it by dispatching `ListBooksQuery`.

<NodeGraph />

## Contract

Send a `ListBooksRequest` with an optional `search` string (empty or whitespace
returns the default list without a search filter). The response is
`ListBooksResponse`, containing a repeated collection of `BookItem` values.

## Examples

<CodeGroup dropdown>

```csharp title="ListBooks gRPC example"
using Grpc.Net.Client;
using BookWorm.Catalog.Grpc.Services;

using var channel = GrpcChannel.ForAddress(Services.CatalogApi);
var client = new BookGrpcService.BookGrpcServiceClient(channel);

var response = await client.ListBooksAsync(new ListBooksRequest
{
    Search = "microservices"
});

foreach (var book in response.Books)
{
    Console.WriteLine($"{book.Name} ({book.AverageRating}/5)");
}
```
