## Overview

Updates the [[entity|publisher]] identified by `id`. The operation is idempotent when the same name is submitted.

<NodeGraph />

## Contract

The request is JSON and requires both `id` and a non-empty `name`.

The successful response is `204 No Content` with an empty body.

## Operational notes

`400` indicates validation failure. `404` indicates that no publisher exists with the supplied UUID.
