`UpdatePublisher` updates the display name of an existing publisher in **Catalog API** (`PUT /api/v1/publishers`) and returns `204 No Content`. Callers pass both `id` and `name` in the JSON request body rather than using a path parameter.

## Overview

| Property              | Value                                                                                                                        |
| :-------------------- | :--------------------------------------------------------------------------------------------------------------------------- |
| **Owner**             | Catalog bounded context (**Catalog API**, Aspire resource `catalog`)                                                         |
| **Source**            | `src/Services/Catalog/BookWorm.Catalog/Features/Publishers/Update/`                                                          |
| **Protocol / format** | HTTP `PUT`, JSON request (`application/json`), empty response body (`204 No Content`)                                        |
| **Endpoint**          | Direct: `PUT /api/v1/publishers` (local HTTP `5100`, HTTPS `7187`); API Gateway: `PUT /catalog/api/v1/publishers`            |
| **Authentication**    | Microsoft Entra ID JWT — `business_user` policy (role `business_user` or `admin` and scopes `catalog_read`, `catalog_write`) |
| **Rate limiting**     | Global concurrency (`100`) and fixed-window (`30 req/min`) limiters plus `PerUserRateLimit` token bucket                     |
| **Idempotency**       | Naturally idempotent for repeated requests with the same `id` and `name`; no `x-request-id` header is enforced               |
| **Contract version**  | `1.0.0` (`ApiVersions.V1`)                                                                                                   |

## Parameters and fields

### Request body (`application/json`)

`StringTrimmerJsonConverter` trims leading and trailing whitespace from string properties during deserialization.

| Name   | Type     | Required | Default | Constraints                                                                        | Description                                |
| :----- | :------- | :------- | :------ | :--------------------------------------------------------------------------------- | :----------------------------------------- |
| `id`   | `uuid`   | Yes      | —       | Non-empty UUID (`Guid != Guid.Empty`, `PublisherId`)                               | Identifier of the publisher to update      |
| `name` | `string` | Yes      | —       | Non-empty, max `50` chars (`DataSchemaLength.Medium`), unique in `publishers.name` | Replacement display name for the publisher |

:::note
`UpdatePublisherValidator` enforces `DataSchemaLength.Medium` (`50` characters), which is narrower than the `100`-character limit (`DataSchemaLength.Large`) allowed by `CreatePublisherValidator` and `PublisherConfiguration`. Updating a publisher to a name between 51 and 100 characters returns `400 Bad Request`.
:::

## Behavior and side effects

- **Persistence and uniqueness:** Loads the publisher by `id`, updates `Publisher.Name` in PostgreSQL (`catalogdb`), and saves changes. `PublisherConfiguration.cs` enforces a unique index on `publishers.name`; renaming to another existing publisher's name raises an unhandled database exception mapped to `500 Internal Server Error` by `GlobalExceptionHandler`.
- **Cache invalidation:** Dispatches `PublisherUpdatedEvent` on save; `PublisherChangedEventHandler` removes `catalog:publishers:v1` and invalidates FusionCache tags `book` and `books:list`.
- **Vector index queueing:** PostgreSQL trigger `publishers_vector_update` (`BEFORE UPDATE OR DELETE ON publishers`) enqueues all `book_id` rows with matching `publisher_id` into `pending_vector_updates` for asynchronous Qdrant refresh by **Catalog Ingestion**.

## Error responses

| Code / status               | Condition                                                                                                                             | Recovery behavior                                                       |
| :-------------------------- | :------------------------------------------------------------------------------------------------------------------------------------ | :---------------------------------------------------------------------- |
| `400 Bad Request`           | `id` is empty or invalid UUID, `name` is missing, empty, whitespace-only, or exceeds `50` characters (`HttpValidationProblemDetails`) | Fix the request body; do not retry unchanged input                      |
| `401 Unauthorized`          | Missing, expired, or invalid Entra ID JWT                                                                                             | Acquire a valid Entra ID access token and retry                         |
| `403 Forbidden`             | Token lacks role `business_user` or `admin`, or lacks scopes `catalog_read` and `catalog_write`                                       | Request the required Entra ID app role and scopes                       |
| `404 Not Found`             | No publisher exists with the supplied `id` (`{ "detail": "The requested resource was not found." }`)                                  | Verify the UUID; do not treat `404` as a completed update               |
| `429 Too Many Requests`     | Global or `PerUserRateLimit` quota exceeded (`ProblemDetails` with `Retry-After` header)                                              | Wait for the `Retry-After` interval before retrying                     |
| `500 Internal Server Error` | Duplicate `name` violating the `publishers.name` unique index or unhandled server error (`ProblemDetails` with `traceId`)             | Check for a conflicting publisher name and inspect logs using `traceId` |
