`ListBooks` queries **Catalog API** (`QUERY /api/v1/books`) with an optional JSON request body to search, filter, sort, and paginate catalog books. The endpoint is publicly readable, uses hybrid vector search (Microsoft Foundry embeddings + Qdrant) when `search` is supplied, caches results in FusionCache, and emits total counts and navigation links in HTTP response headers.

## Overview

| Property                          | Value                                                                                                                                                                                                                       |
| :-------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Owner**                         | Catalog bounded context (**Catalog API**, Aspire resource `catalog`)                                                                                                                                                        |
| **Source**                        | `src/Services/Catalog/BookWorm.Catalog/Features/Books/List/ListBooksEndpoint.cs`, `ListBooksQuery.cs`, `ListBooksValidator.cs`                                                                                              |
| **Protocol / format**             | HTTP `QUERY /api/v1/books` (via API Gateway: `QUERY /catalog/api/v1/books`), `ApiVersions.V1`, JSON (`application/json`)                                                                                                    |
| **Authentication**                | None required (public read endpoint)                                                                                                                                                                                        |
| **Rate limiting**                 | `PerUserRateLimit` token bucket (30 token limit, 20 tokens per 10 seconds, queue limit 5) plus global IP/concurrency limiters                                                                                               |
| **Persistence, search & caching** | PostgreSQL (`catalogdb`, EF Core) + Qdrant (`vectordb`) hybrid search when `search` is non-empty; FusionCache L1/L2 caches search IDs for `5 minutes` (`BookSearchTag`) and filtered pages for `60 seconds` (`BookListTag`) |
| **Contract version**              | `1.0.0`                                                                                                                                                                                                                     |

## Parameters and fields

### Request body (`ListBooksQuery`, optional)

The JSON request body is optional; omitting it applies all defaults below.

| Name           | Type               | Required | Default  | Constraints                                 | Description                                                                                                                         |
| :------------- | :----------------- | :------- | :------- | :------------------------------------------ | :---------------------------------------------------------------------------------------------------------------------------------- |
| `pageIndex`    | `integer`          | No       | `1`      | `> 0` (`ListBooksValidator`)                | 1-based page number to retrieve                                                                                                     |
| `pageSize`     | `integer`          | No       | `20`     | `> 0` (`ListBooksValidator`)                | Maximum number of books per page (also caps vector search candidate count)                                                          |
| `orderBy`      | `string \| null`   | No       | `"Name"` | Property name supported by `BookFilterSpec` | Field used to sort results                                                                                                          |
| `isDescending` | `boolean`          | No       | `false`  | `true` or `false`                           | Sorts descending when `true` and ascending when `false`                                                                             |
| `search`       | `string \| null`   | No       | `null`   | Trimmed, lowercased for cache key           | Free-text query executed via hybrid search against Qdrant (`vectordb`); returns an empty page immediately if zero vector hits match |
| `minPrice`     | `number \| null`   | No       | `null`   | Decimal                                     | Inclusive minimum price filter                                                                                                      |
| `maxPrice`     | `number \| null`   | No       | `null`   | Decimal                                     | Inclusive maximum price filter                                                                                                      |
| `categoryId`   | `string[] \| null` | No       | `null`   | Array of UUIDs                              | Restricts results to books matching any supplied category ID                                                                        |
| `publisherId`  | `string[] \| null` | No       | `null`   | Array of UUIDs                              | Restricts results to books matching any supplied publisher ID                                                                       |
| `authorIds`    | `string[] \| null` | No       | `null`   | Array of UUIDs                              | Restricts results to books associated with any supplied author ID                                                                   |

`orderBy` recognizes `Name`, `Price.OriginalPrice`, `Price.DiscountPrice`, and `Status`. Any other value falls back to `Name`; ties are ordered by book ID.

### Response headers

`ListBooksEndpoint` applies `WithPaginationHeaders()` (`PaginationHeaderFilter`), which appends two headers on `200 OK` responses:

| Header             | Format                                    | Description                                                                                 |
| :----------------- | :---------------------------------------- | :------------------------------------------------------------------------------------------ |
| `Pagination-Count` | Integer string (for example, `84`)        | Total number of books matching the active filters across all pages                          |
| `Link`             | Comma-separated `<uri>;rel=<rel>` entries | Navigation URIs with `first`, `self`, `last`, and conditional `previous` / `next` relations |

### Response schema (`BookDto[]`)

A `200 OK` response body serializes `PagedResult<BookDto>` as a JSON array of `BookDto` objects (returns `[]` when no books match). See [[query|GetBook]] for the full field-by-field `BookDto` schema (`id`, `name`, `description`, `imageUrl`, `price`, `priceSale`, `status`, `category`, `publisher`, `authors`, `averageRating`, `totalReviews`).

## Error responses

| Code / status           | Condition                                                                                                                                               | Recovery behavior                                   |
| :---------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------ | :-------------------------------------------------- |
| `400 Bad Request`       | `pageIndex <= 0`, `pageSize <= 0`, malformed UUID in filter arrays, or invalid JSON payload (`application/problem+json` `HttpValidationProblemDetails`) | Fix request body values; do not retry unchanged     |
| `429 Too Many Requests` | Caller exceeded `PerUserRateLimit` or global rate limit (`application/problem+json` + `Retry-After` header)                                             | Wait for the `Retry-After` duration before retrying |
