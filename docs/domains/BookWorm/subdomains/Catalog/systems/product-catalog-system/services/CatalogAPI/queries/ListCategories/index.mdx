`ListCategories` queries **Catalog API** (`GET /api/v1/categories`) to return all registered book categories as an unpaginated JSON array (`CategoryDto[]`). The endpoint is publicly readable, returns `[]` with `200 OK` when no categories exist, and caches the taxonomy in FusionCache.

## Overview

| Property                  | Value                                                                                                                          |
| :------------------------ | :----------------------------------------------------------------------------------------------------------------------------- |
| **Owner**                 | Catalog bounded context (**Catalog API**, Aspire resource `catalog`)                                                           |
| **Source**                | `src/Services/Catalog/BookWorm.Catalog/Features/Categories/List/ListCategoriesEndpoint.cs`, `ListCategoriesQuery.cs`           |
| **Protocol / format**     | HTTP `GET /api/v1/categories` (via API Gateway: `GET /catalog/api/v1/categories`), `ApiVersions.V1`, JSON (`application/json`) |
| **Authentication**        | None required (public read endpoint)                                                                                           |
| **Rate limiting**         | `PerUserRateLimit` token bucket (30 token limit, 20 tokens per 10 seconds, queue limit 5) plus global IP/concurrency limiters  |
| **Persistence & caching** | PostgreSQL (`catalogdb`, EF Core) cached in FusionCache (L1 + Redis L2, key `CatalogCacheKeys.Categories`)                     |
| **Contract version**      | `1.0.0`                                                                                                                        |

## Parameters and fields

### Request parameters

`ListCategories` accepts no path parameters, query parameters, or request body.

### Response schema (`CategoryDto[]`)

A `200 OK` response returns a JSON array of `CategoryDto` objects (`additionalProperties: false`).

| Field     | Type             | Required | Constraints | Description                               |
| :-------- | :--------------- | :------- | :---------- | :---------------------------------------- |
| `[].id`   | `string`         | Yes      | UUID        | Unique identifier of the category         |
| `[].name` | `string \| null` | Yes      | Nullable    | Category display name (`null` when unset) |

## Error responses

| Code / status           | Condition                                                                                                   | Recovery behavior                                   |
| :---------------------- | :---------------------------------------------------------------------------------------------------------- | :-------------------------------------------------- |
| `429 Too Many Requests` | Caller exceeded `PerUserRateLimit` or global rate limit (`application/problem+json` + `Retry-After` header) | Wait for the `Retry-After` duration before retrying |
