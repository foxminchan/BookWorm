## List all authors with curl

<CodeGroup>

```bash
curl --request GET "<gateway-url>/catalog/api/v1/authors" \
  --header "Accept: application/json"
```

</CodeGroup>

Where:

- `<gateway-url>`: Base URL of the BookWorm API Gateway (or direct Catalog API URL `https://localhost:7187` without the `/catalog` prefix).

Expected response (`200 OK`):

<CodeGroup>

```json
[
	{
		"id": "33333333-3333-3333-3333-333333333333",
		"name": "Ursula K. Le Guin"
	},
	{
		"id": "77777777-7777-7777-7777-777777777777",
		"name": "Isaac Asimov"
	}
]
```

</CodeGroup>
