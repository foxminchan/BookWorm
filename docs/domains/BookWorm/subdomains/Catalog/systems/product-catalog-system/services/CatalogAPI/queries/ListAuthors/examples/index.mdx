## 1. List authors

The query returns `200` with an array of author summaries. Each item contains its UUID and display name.

### Response details

- An empty collection is represented by `200` and `[]`.
- The endpoint does not require a resource UUID.
- Use the returned identifiers when creating or updating books.

### Example response

<CodeGroup dropdown>

```ts
const authors: AuthorSummary[] = [
	{ id: "5e4a1c9b-3f72-4b8d-a605-7c2e9f1d8430", name: "Example Author" },
```

### Using this example

Render the returned summaries as selectable author options; an empty array is a valid catalog state.

<CodeGroup dropdown>

```ts list-authors.ts
type AuthorSummary = { id: string; name: string };

const response = await fetch("https://api.example.com/api/v1/authors");
if (!response.ok) {
	throw new Error(`ListAuthors failed with ${response.status}`);
}

const authors = (await response.json()) as AuthorSummary[];
for (const author of authors) {
	console.log(`${author.id}: ${author.name}`);
}
```
