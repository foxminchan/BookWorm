## 1. Delete an existing book

Delete by UUID. A successful deletion returns `204 No Content` and removes the catalog record.

### Operational notes

- The book's referenced cover image is also removed from blob storage.
- Confirm that downstream consumers no longer need the book before deleting it.
- Treat `404` as a missing resource, not as a successful deletion.

### Example response

<CodeGroup dropdown>

```ts
const response = { status: 204, body: null };
```

</CodeGroup>

### Using this example

Remove the book from local state after receiving `204 No Content`; its referenced cover is removed by the API.

```ts delete-book.ts
const bookId = "5e4a1c9b-3f72-4b8d-a605-7c2e9f1d8430";
const response = await fetch(`https://api.example.com/api/v1/books/${bookId}`, {
	method: "DELETE",
});

if (response.status === 404) {
	throw new Error("Book was not found");
}
if (!response.ok) {
	throw new Error(`DeleteBook failed with ${response.status}`);
}
```
