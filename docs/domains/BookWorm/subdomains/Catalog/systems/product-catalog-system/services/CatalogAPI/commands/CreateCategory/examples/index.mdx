## 1. Create a category

The command requires a non-empty category name. A successful request returns `200` and the generated category UUID.

### Payload details

- `name` is required and must contain at least one character.
- Store the returned UUID before assigning the category to a book.
- The endpoint accepts a JSON request body.

### Example response

<CodeGroup dropdown>

```ts
const categoryId = "5e4a1c9b-3f72-4b8d-a605-7c2e9f1d8430";
```

</CodeGroup>

### Using this example

Use the returned UUID when assigning this category to a book.

</Column>

<Column>

<CodeGroup dropdown>

```ts create-category.ts
const response = await fetch("https://api.example.com/api/v1/categories", {
	method: "POST",
	headers: { "Content-Type": "application/json" },
	body: JSON.stringify({ name: "Example Category" }),
});

if (!response.ok) {
	throw new Error(`CreateCategory failed with ${response.status}`);
}

const categoryId = (await response.json()) as string;
console.log(`Created category ${categoryId}`);
```

## 2. Reject an invalid request

Omitting `name` returns `400` with an RFC 7807 validation response. Display the field error and do not retry unchanged input.
