`CreateAuthor` creates a new author record in **Catalog API** (`POST /api/v1/authors`) and returns its generated UUIDv7 identifier as a JSON string. Callers use the returned identifier when linking authors to books in [[command|CreateBook]] and [[command|UpdateBook]].

## Overview

| Property              | Value                                                                                                                        |
| :-------------------- | :--------------------------------------------------------------------------------------------------------------------------- |
| **Owner**             | Catalog bounded context (**Catalog API**, Aspire resource `catalog`)                                                         |
| **Source**            | `src/Services/Catalog/BookWorm.Catalog/Features/Authors/Create/`                                                             |
| **Protocol / format** | HTTP `POST`, JSON request (`application/json`), JSON string response                                                         |
| **Endpoint**          | Direct: `POST /api/v1/authors` (local HTTP `5100`, HTTPS `7187`); API Gateway: `POST /catalog/api/v1/authors`                |
| **Authentication**    | Microsoft Entra ID JWT — `business_user` policy (role `business_user` or `admin` and scopes `catalog_read`, `catalog_write`) |
| **Rate limiting**     | Global concurrency (`100`) and fixed-window (`30 req/min`) limiters plus `PerUserRateLimit` token bucket                     |
| **Idempotency**       | Not idempotent; no `x-request-id` header is required or enforced                                                             |
| **Contract version**  | `1.0.0` (`ApiVersions.V1`)                                                                                                   |

## Parameters and fields

### Request body (`application/json`)

`StringTrimmerJsonConverter` trims leading and trailing whitespace from string properties during deserialization.

| Name   | Type     | Required | Default | Constraints                                           | Description                |
| :----- | :------- | :------- | :------ | :---------------------------------------------------- | :------------------------- |
| `name` | `string` | Yes      | —       | Non-empty, max `100` chars (`DataSchemaLength.Large`) | Display name of the author |

### Response body (`200 OK`)

`CreateAuthorEndpoint` returns `200 OK` (not `201 Created`) without a `Location` header.

| Name       | Type     | Required | Default | Constraints         | Description                                       |
| :--------- | :------- | :------- | :------ | :------------------ | :------------------------------------------------ |
| Root value | `string` | Yes      | —       | UUIDv7 (`AuthorId`) | Generated unique identifier of the created author |

## Behavior and side effects

- **Persistence:** Inserts a new row into the `authors` table in PostgreSQL (`catalogdb`) with a database-generated UUIDv7 primary key (`AuthorConfiguration.cs`). The `authors.name` column has no unique index, so duplicate author names are permitted.
- **Cache invalidation:** Dispatches `AuthorCreatedEvent` on save; `AuthorChangedEventHandler` removes the FusionCache key `catalog:authors:v1`.
- **Search vectors:** No vector-index trigger runs on `authors` insert; `authors_vector_update` fires only on `UPDATE` or `DELETE`.
- **Idempotency:** Sending the same `name` twice creates two distinct author records with different UUIDs.

## Error responses

| Code / status               | Condition                                                                                                                          | Recovery behavior                                        |
| :-------------------------- | :--------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------- |
| `400 Bad Request`           | `name` is missing, empty, whitespace-only, exceeds `100` characters, or JSON payload is malformed (`HttpValidationProblemDetails`) | Fix the request body; do not retry unchanged input       |
| `401 Unauthorized`          | Missing, expired, or invalid Entra ID JWT                                                                                          | Acquire a valid Entra ID access token and retry          |
| `403 Forbidden`             | Token lacks role `business_user` or `admin`, or lacks scopes `catalog_read` and `catalog_write`                                    | Request the required Entra ID app role and scopes        |
| `429 Too Many Requests`     | Global or `PerUserRateLimit` quota exceeded (`ProblemDetails` with `Retry-After` header)                                           | Wait for the `Retry-After` interval before retrying      |
| `500 Internal Server Error` | Unhandled server or PostgreSQL failure (`ProblemDetails` with `traceId`)                                                           | Inspect Catalog API logs using `traceId` before retrying |
