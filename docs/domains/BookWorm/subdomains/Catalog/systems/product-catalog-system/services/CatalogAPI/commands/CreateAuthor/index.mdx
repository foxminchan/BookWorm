`CreateAuthor` creates a new author record in [[service|catalog-api]] (`POST /catalog/api/v1/authors`) and returns its generated UUIDv7 identifier as a JSON string. Callers use the returned identifier when linking authors to books in [[command|CreateBook]] and [[command|UpdateBook]].

## Overview

| Property                           | Value                                                                                                                          |
| :--------------------------------- | :----------------------------------------------------------------------------------------------------------------------------- |
| **Bounded Context**                | Catalog                                                                                                                        |
| **Owner Service**                  | [[service\|catalog-api]]                                                                                                       |
| **Protocol / Format**              | HTTP `POST`, `application/json` request and JSON string response                                                               |
| **Gateway Endpoint**               | `POST /catalog/api/v1/authors` (service path `/api/v1/authors`)                                                                |
| **Authentication & Authorization** | Microsoft Entra ID JWT â€” `business_user` policy (role `business_user` or `admin` and scopes `catalog_read`, `catalog_write`) |
| **Idempotency / Concurrency**      | Not idempotent; no `x-request-id` header is required or enforced                                                               |
| **Rate Limit / Caching**           | Global concurrency (`100`) and fixed-window (`30 req/min`) limiters plus per-user token bucket; invalidates author list cache  |
| **Contract Version**               | `1.0.0` (`ApiVersions.V1`)                                                                                                     |

## Request & Response Contract

### Request Body (`application/json`)

Leading and trailing whitespace is trimmed from string properties during deserialization.

| Name   | Type     | Required | Constraints                     | Description                |
| :----- | :------- | :------- | :------------------------------ | :------------------------- |
| `name` | `string` | Yes      | Non-empty, max `100` characters | Display name of the author |

### Success Response (`200 OK`)

Returns `200 OK` without a `Location` header.

| Name       | Type     | Required | Constraints | Description                                       |
| :--------- | :------- | :------- | :---------- | :------------------------------------------------ |
| Root value | `string` | Yes      | UUIDv7      | Generated unique identifier of the created author |

## Behavior & Side Effects

- **Persistence:** Inserts a new [[entity|author]] record with a generated UUIDv7 primary key; duplicate author names are permitted and create distinct records.
- **Cache invalidation:** Clears the cached author list (`catalog:authors:v1`) upon successful creation.
- **Vector indexing:** No vector-index refresh is queued on author creation; vector updates are triggered only when an existing author is updated or deleted.
