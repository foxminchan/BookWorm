## Call `GetDashboard` from a .NET gRPC client

<CodeGroup>

```csharp
using BookWorm.Catalog.Grpc.Services;
using Grpc.Core;
using Grpc.Net.Client;

using var channel = GrpcChannel.ForAddress("<catalog-grpc-url>");
var client = new BookGrpcService.BookGrpcServiceClient(channel);

var headers = new Metadata
{
    { "Authorization", "Bearer <admin-access-token>" },
};

var response = await client.GetDashboardAsync(new GetDashboardRequest(), headers);

Console.WriteLine($"Books: {response.TotalBooks}");
foreach (var category in response.Categories)
{
    Console.WriteLine($"{category.Name}: {category.Value}");
}
```

</CodeGroup>

Where:

- `<catalog-grpc-url>`: Base URL of Catalog API (resolved via Aspire service discovery as `catalog`, or `https://localhost:7187` locally).
- `<admin-access-token>`: Entra ID bearer token satisfying the Catalog API `admin` policy.
