`GetBooksGrpc` invokes the internal `book.v1.BookGrpcService/GetBooks` gRPC unary RPC on **Catalog API** to fetch compact commercial summaries (ID, name, price, sale price, and stock status) for multiple books in a single round trip. **Basket API** calls this RPC to enrich basket items on read, and **Ordering API** calls it during checkout and order detail enrichment.

## Overview

| Property                | Value                                                                                                                                                                                                    |
| :---------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Owner (gRPC server)** | Catalog bounded context (**Catalog API**, Aspire resource `catalog`)                                                                                                                                     |
| **Primary callers**     | **Basket API** (`basket`) for basket enrichment; **Ordering API** (`ordering`) for checkout and order detail enrichment                                                                                  |
| **Source**              | `src/Services/Catalog/BookWorm.Catalog/Grpc/Protos/book/v1/book.proto`, `src/Services/Catalog/BookWorm.Catalog/Grpc/Services/BookService.cs`                                                             |
| **Protocol / format**   | gRPC unary RPC (`book.v1.BookGrpcService/GetBooks`), Protobuf `edition = "2023"`, `csharp_namespace = "BookWorm.Catalog.Grpc.Services"`                                                                  |
| **Authentication**      | `[AllowAnonymous]` (internal service-to-service public catalog read)                                                                                                                                     |
| **Caching & batching**  | Deduplicates `book_ids`, resolves hits per ID in FusionCache (`BookSummary`), batch-queries PostgreSQL (`catalogdb`) only for misses, populates cache, and returns matches in deduplicated request order |
| **Contract version**    | `1.0.0`                                                                                                                                                                                                  |

:::note
`GetBooks` silently omits unknown book IDs rather than throwing `StatusCode.NotFound`, and returns an empty `GetBooksResponse` when `book_ids` is empty. Callers must reconcile returned `books` against requested `book_ids`.
:::

## Parameters and fields

### Request message (`GetBooksRequest`)

| Field      | Protobuf type     | Tag | Constraints                | Description                                            |
| :--------- | :---------------- | :-- | :------------------------- | :----------------------------------------------------- |
| `book_ids` | `repeated string` | `1` | Valid UUIDs (`Guid.Parse`) | List of book UUIDs to fetch (deduplicated server-side) |

### Response message (`GetBooksResponse`)

| Field                | Protobuf type              | Tag | Description                                                      |
| :------------------- | :------------------------- | :-- | :--------------------------------------------------------------- |
| `books`              | `repeated GetBookResponse` | `1` | Matched book summaries in deduplicated request order             |
| `books[].id`         | `string`                   | `1` | Book UUID                                                        |
| `books[].name`       | `string`                   | `2` | Book title                                                       |
| `books[].price`      | `DecimalValue`             | `3` | Regular unit price (`int64 units`, `sfixed32 nanos`)             |
| `books[].price_sale` | `DecimalValue`             | `4` | Promotional sale price (omitted/null when no sale applies)       |
| `books[].status`     | `BookStatus`               | `5` | `BOOK_STATUS_IN_STOCK` (`1`) or `BOOK_STATUS_OUT_OF_STOCK` (`2`) |

### Protobuf contract

<CodeGroup>

```protobuf
edition = "2023";

package book.v1;

service BookGrpcService {
  rpc GetBooks (GetBooksRequest) returns (GetBooksResponse);
}

message GetBooksRequest {
  repeated string book_ids = 1;
}

message GetBooksResponse {
  repeated GetBookResponse books = 1;
}

message GetBookResponse {
  string id = 1;
  string name = 2;
  DecimalValue price = 3;
  DecimalValue price_sale = 4;
  BookStatus status = 5;
}
```

</CodeGroup>

## Error responses

| Code / status        | Condition                                                                                        | Recovery behavior                           |
| :------------------- | :----------------------------------------------------------------------------------------------- | :------------------------------------------ |
| `Unknown` (`2`)      | Any entry in `book_ids` is not a valid UUID (`BookService.GetBooks` calls `Guid.Parse` directly) | Validate all UUIDs before calling           |
| `Unavailable` (`14`) | Catalog API is unreachable                                                                       | Retry within the budgeted resilience policy |
