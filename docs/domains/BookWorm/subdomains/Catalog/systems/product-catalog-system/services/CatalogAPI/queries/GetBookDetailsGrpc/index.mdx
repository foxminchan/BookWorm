`GetBookDetailsGrpc` invokes the internal `book.v1.BookGrpcService/GetBookDetails` gRPC unary RPC on [[service|catalog-api]] to retrieve a single book's complete projection, including description, cover image URI, pricing, stock status, category, publisher, authors, and derived rating summary. [[service|mcp-server]] calls this RPC to power its `get_book` tool.

## Overview

| Property                           | Value                                                                                    |
| :--------------------------------- | :--------------------------------------------------------------------------------------- |
| **Bounded Context**                | Catalog                                                                                  |
| **Owner Service**                  | [[service\|catalog-api]]                                                                 |
| **Protocol / Format**              | gRPC unary RPC (`book.v1.BookGrpcService/GetBookDetails`), Protobuf `edition = "2023"`   |
| **Gateway Endpoint**               | Internal gRPC RPC `book.v1.BookGrpcService/GetBookDetails` (not exposed via API Gateway) |
| **Authentication & Authorization** | Internal service-to-service anonymous read                                               |
| **Idempotency / Concurrency**      | Read-only and naturally idempotent                                                       |
| **Rate Limit / Caching**           | Backed by PostgreSQL and cached in L1 + Redis L2                                         |
| **Contract Version**               | `1.0.0`                                                                                  |

## Request & Response Contract

### Request Message (`GetBookDetailsRequest`)

| Name      | Type              | Required | Constraints         | Description                               |
| :-------- | :---------------- | :------- | :------------------ | :---------------------------------------- |
| `book_id` | `string` (`uuid`) | Yes      | Tag `1`; valid UUID | Unique identifier of the book to retrieve |

### Success Response (`GetBookDetailsResponse` / `book.*`)

`GetBookDetailsResponse` wraps a single `book` (`BookItem`) field (tag `1`).

| Name             | Type              | Required | Constraints                                                          | Description                                         |
| :--------------- | :---------------- | :------- | :------------------------------------------------------------------- | :-------------------------------------------------- |
| `id`             | `string` (`uuid`) | Yes      | Tag `1`                                                              | Book UUID                                           |
| `name`           | `string`          | Yes      | Tag `2` (empty string if null)                                       | Book title                                          |
| `description`    | `string`          | Yes      | Tag `3` (empty string if null)                                       | Book description                                    |
| `image_url`      | `string`          | Yes      | Tag `4` (empty string if null)                                       | Cover image URI                                     |
| `price`          | `DecimalValue`    | Yes      | Tag `5` (`int64 units`, `sfixed32 nanos`)                            | Regular unit price                                  |
| `price_sale`     | `DecimalValue`    | No       | Tag `6` (omitted when no sale applies)                               | Promotional sale price                              |
| `status`         | `BookStatus`      | Yes      | Tag `7` (`BOOK_STATUS_IN_STOCK = 1`, `BOOK_STATUS_OUT_OF_STOCK = 2`) | Current stock availability status                   |
| `category`       | `CategoryItem`    | No       | Tag `8` (`id`, `name`)                                               | Optional category                                   |
| `publisher`      | `PublisherItem`   | No       | Tag `9` (`id`, `name`)                                               | Optional publisher                                  |
| `authors`        | `AuthorItem[]`    | Yes      | Tag `10` (`repeated`; `id`, `name`)                                  | Authors associated with the book                    |
| `average_rating` | `double`          | Yes      | Tag `11`; `>= 0`                                                     | Derived average rating projected from Reviews       |
| `total_reviews`  | `int32`           | Yes      | Tag `12`; `>= 0`                                                     | Derived total feedback count projected from Reviews |

## Behavior & Side Effects

- **Read-through caching:** Delegates to the same cached projection used by [[query|GetBook]] (L1 + Redis L2).
- **No state mutation:** Pure read RPC with no database writes or integration events.

## Error Responses

| Status / Code           | Condition                                         | Client Recovery Action                                   |
| :---------------------- | :------------------------------------------------ | :------------------------------------------------------- |
| `InvalidArgument` (`3`) | `book_id` is not a valid UUID                     | Validate the UUID before calling; do not retry unchanged |
| `NotFound` (`5`)        | No active book exists with the supplied `book_id` | Surface a not-found result to the caller                 |
| `Unavailable` (`14`)    | Catalog API is unreachable                        | Retry within the budgeted resilience policy              |
