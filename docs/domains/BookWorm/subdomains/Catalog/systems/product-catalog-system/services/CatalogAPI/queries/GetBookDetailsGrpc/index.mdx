`GetBookDetailsGrpc` invokes the internal `book.v1.BookGrpcService/GetBookDetails` gRPC unary RPC on **Catalog API** to retrieve a single book's complete `BookItem` projection, including description, cover image URI, pricing, stock status, category, publisher, authors, and derived rating summary. **MCP Tools** calls this RPC to power its `get_book` tool.

## Overview

| Property                | Value                                                                                                                                         |
| :---------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------- |
| **Owner (gRPC server)** | Catalog bounded context (**Catalog API**, Aspire resource `catalog`)                                                                          |
| **Primary caller**      | **MCP Tools** (`mcptools`, `get_book` tool)                                                                                                   |
| **Source**              | `src/Services/Catalog/BookWorm.Catalog/Grpc/Protos/book/v1/book.proto`, `src/Services/Catalog/BookWorm.Catalog/Grpc/Services/BookService.cs`  |
| **Protocol / format**   | gRPC unary RPC (`book.v1.BookGrpcService/GetBookDetails`), Protobuf `edition = "2023"`, `csharp_namespace = "BookWorm.Catalog.Grpc.Services"` |
| **Authentication**      | `[AllowAnonymous]` (internal service-to-service public catalog read)                                                                          |
| **Caching**             | Dispatches `GetBookQuery`, backed by PostgreSQL (`catalogdb`) and FusionCache (L1 + Redis L2)                                                 |
| **Contract version**    | `1.0.0`                                                                                                                                       |

## Parameters and fields

### Request message (`GetBookDetailsRequest`)

| Field     | Protobuf type | Tag | Constraints                  | Description                               |
| :-------- | :------------ | :-- | :--------------------------- | :---------------------------------------- |
| `book_id` | `string`      | `1` | Valid UUID (`Guid.TryParse`) | Unique identifier of the book to retrieve |

### Response message (`GetBookDetailsResponse` / `BookItem`)

`GetBookDetailsResponse` wraps a single `book` (`BookItem`) field (tag `1`).

| Field (`book.*`) | Protobuf type         | Tag  | Description                                                      |
| :--------------- | :-------------------- | :--- | :--------------------------------------------------------------- |
| `id`             | `string`              | `1`  | Book UUID                                                        |
| `name`           | `string`              | `2`  | Book title (empty string if null in DTO)                         |
| `description`    | `string`              | `3`  | Book description (empty string if null)                          |
| `image_url`      | `string`              | `4`  | Cover image URI (empty string if null)                           |
| `price`          | `DecimalValue`        | `5`  | Regular price (`int64 units`, `sfixed32 nanos`)                  |
| `price_sale`     | `DecimalValue`        | `6`  | Promotional sale price (omitted/null when no sale applies)       |
| `status`         | `BookStatus`          | `7`  | `BOOK_STATUS_IN_STOCK` (`1`) or `BOOK_STATUS_OUT_OF_STOCK` (`2`) |
| `category`       | `CategoryItem`        | `8`  | Optional category (`id`, `name`)                                 |
| `publisher`      | `PublisherItem`       | `9`  | Optional publisher (`id`, `name`)                                |
| `authors`        | `repeated AuthorItem` | `10` | Authors associated with the book (`id`, `name`)                  |
| `average_rating` | `double`              | `11` | Derived average rating projected from Reviews                    |
| `total_reviews`  | `int32`               | `12` | Derived total feedback count projected from Reviews              |

### Protobuf contract

<CodeGroup>

```protobuf
edition = "2023";

package book.v1;

service BookGrpcService {
  rpc GetBookDetails (GetBookDetailsRequest) returns (GetBookDetailsResponse);
}

message GetBookDetailsRequest {
  string book_id = 1;
}

message GetBookDetailsResponse {
  BookItem book = 1;
}

message BookItem {
  string id = 1;
  string name = 2;
  string description = 3;
  string image_url = 4;
  DecimalValue price = 5;
  DecimalValue price_sale = 6;
  BookStatus status = 7;
  CategoryItem category = 8;
  PublisherItem publisher = 9;
  repeated AuthorItem authors = 10;
  double average_rating = 11;
  int32 total_reviews = 12;
}

enum BookStatus {
  BOOK_STATUS_UNSPECIFIED = 0;
  BOOK_STATUS_IN_STOCK = 1;
  BOOK_STATUS_OUT_OF_STOCK = 2;
}

message DecimalValue {
  int64 units = 1;
  sfixed32 nanos = 2;
}
```

</CodeGroup>

## Error responses

| Code / status           | Condition                                                                        | Recovery behavior                                        |
| :---------------------- | :------------------------------------------------------------------------------- | :------------------------------------------------------- |
| `InvalidArgument` (`3`) | `book_id` is not a valid UUID (`"Invalid book id '<value>'."`)                   | Validate the UUID before calling; do not retry unchanged |
| `NotFound` (`5`)        | No book exists with the supplied `book_id` (`"Book with id <value> not found."`) | Surface a not-found result to the caller                 |
| `Unavailable` (`14`)    | Catalog API is unreachable                                                       | Retry within the budgeted resilience policy              |
