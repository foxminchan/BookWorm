## Update an author with curl

<CodeGroup>

```bash
curl --fail-with-body -i -X PUT "<gateway-url>/catalog/api/v1/authors" \
  -H "Authorization: Bearer <access-token>" \
  -H "Content-Type: application/json" \
  -d '{"id": "<author-id>", "name": "Ursula K. Le Guin"}'
```

</CodeGroup>

Where:

- `<gateway-url>`: Base URL of the BookWorm API Gateway.
- `<access-token>`: Entra ID JWT satisfying the `business_user` policy.
- `<author-id>`: UUID of the existing author to rename.

Expected response:

<CodeGroup>

```text
HTTP/1.1 204 No Content
```

</CodeGroup>

## Update an author with TypeScript

<CodeGroup>

```typescript
const response = await fetch("<gateway-url>/catalog/api/v1/authors", {
	method: "PUT",
	headers: {
		Authorization: "Bearer <access-token>",
		"Content-Type": "application/json",
	},
	body: JSON.stringify({
		id: "<author-id>",
		name: "Ursula K. Le Guin",
	}),
});

if (response.status === 404) {
	throw new Error("Author was not found");
}

if (!response.ok) {
	throw new Error(`UpdateAuthor failed with ${response.status}`);
}
```

</CodeGroup>

Where:

- `<gateway-url>`: Base URL of the BookWorm API Gateway.
- `<access-token>`: Entra ID JWT satisfying the `business_user` policy.
- `<author-id>`: UUID of the existing author to rename.

Expected response:

<CodeGroup>

```text
HTTP/1.1 204 No Content
```

</CodeGroup>
