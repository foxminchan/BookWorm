## Create a publisher with curl

<CodeGroup>

```bash
curl --fail-with-body -X POST "<gateway-url>/catalog/api/v1/publishers" \
  -H "Authorization: Bearer <access-token>" \
  -H "Content-Type: application/json" \
  -d '{"name": "Ace Books"}'
```

</CodeGroup>

Where:

- `<gateway-url>`: Base URL of the BookWorm API Gateway.
- `<access-token>`: Entra ID JWT satisfying the `business_user` policy.

Expected response (`200 OK`):

<CodeGroup>

```json
"0193f1a2-7b4c-7d8e-9f01-23456789abcd"
```

</CodeGroup>

## Create a publisher with TypeScript

<CodeGroup>

```typescript
const response = await fetch("<gateway-url>/catalog/api/v1/publishers", {
	method: "POST",
	headers: {
		Authorization: "Bearer <access-token>",
		"Content-Type": "application/json",
	},
	body: JSON.stringify({ name: "Ace Books" }),
});

if (!response.ok) {
	throw new Error(`CreatePublisher failed with ${response.status}`);
}

const publisherId = (await response.json()) as string;
```

</CodeGroup>

Where:

- `<gateway-url>`: Base URL of the BookWorm API Gateway.
- `<access-token>`: Entra ID JWT satisfying the `business_user` policy.

Expected response (`200 OK`):

<CodeGroup>

```json
"0193f1a2-7b4c-7d8e-9f01-23456789abcd"
```

</CodeGroup>
