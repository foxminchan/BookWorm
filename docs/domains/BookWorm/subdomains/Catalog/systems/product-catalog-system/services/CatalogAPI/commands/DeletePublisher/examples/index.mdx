## Delete a publisher with curl

<CodeGroup>

```bash
curl --fail-with-body -i -X DELETE "<gateway-url>/catalog/api/v1/publishers/<publisher-id>" \
  -H "Authorization: Bearer <access-token>"
```

</CodeGroup>

Where:

- `<gateway-url>`: Base URL of the BookWorm API Gateway.
- `<publisher-id>`: UUID of the publisher to delete.
- `<access-token>`: Entra ID JWT satisfying the `business_user` policy.

Expected response:

<CodeGroup>

```text
HTTP/1.1 204 No Content
```

</CodeGroup>

## Delete a publisher with TypeScript

<CodeGroup>

```typescript
const response = await fetch("<gateway-url>/catalog/api/v1/publishers/<publisher-id>", {
	method: "DELETE",
	headers: { Authorization: "Bearer <access-token>" },
});

if (response.status === 404) {
	throw new Error("Publisher was not found");
}

if (!response.ok) {
	throw new Error(`DeletePublisher failed with ${response.status}`);
}
```

</CodeGroup>

Where:

- `<gateway-url>`: Base URL of the BookWorm API Gateway.
- `<publisher-id>`: UUID of the publisher to delete.
- `<access-token>`: Entra ID JWT satisfying the `business_user` policy.

Expected response:

<CodeGroup>

```text
HTTP/1.1 204 No Content
```

</CodeGroup>
