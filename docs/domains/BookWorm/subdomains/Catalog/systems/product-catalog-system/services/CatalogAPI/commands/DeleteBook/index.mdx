## Overview

Deletes the [[entity|book]] identified by the UUID path parameter. This is a permanent catalog mutation.

<NodeGraph />

## Contract

Provide the resource UUID in the `{id}` path parameter. The operation has no request body.

The successful response is `204 No Content` with an empty body.

## Operational notes

`404` indicates that no book exists with the supplied UUID. A client can safely treat an already-absent resource as deleted only when that is explicitly acceptable for its workflow.
