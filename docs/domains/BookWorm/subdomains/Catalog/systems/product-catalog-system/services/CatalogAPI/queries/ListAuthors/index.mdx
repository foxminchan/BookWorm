`ListAuthors` queries **Catalog API** (`GET /api/v1/authors`) to return all registered catalog authors as an unpaginated JSON array (`AuthorDto[]`). The endpoint is publicly readable, returns `[]` with `200 OK` when no authors exist, and caches the directory in FusionCache.

## Overview

| Property                  | Value                                                                                                                         |
| :------------------------ | :---------------------------------------------------------------------------------------------------------------------------- |
| **Owner**                 | Catalog bounded context (**Catalog API**, Aspire resource `catalog`)                                                          |
| **Source**                | `src/Services/Catalog/BookWorm.Catalog/Features/Authors/List/ListAuthorsEndpoint.cs`, `ListAuthorsQuery.cs`                   |
| **Protocol / format**     | HTTP `GET /api/v1/authors` (via API Gateway: `GET /catalog/api/v1/authors`), `ApiVersions.V1`, JSON (`application/json`)      |
| **Authentication**        | None required (public read endpoint)                                                                                          |
| **Rate limiting**         | `PerUserRateLimit` token bucket (30 token limit, 20 tokens per 10 seconds, queue limit 5) plus global IP/concurrency limiters |
| **Persistence & caching** | PostgreSQL (`catalogdb`, EF Core) cached in FusionCache (L1 + Redis L2, key `CatalogCacheKeys.Authors`)                       |
| **Contract version**      | `1.0.0`                                                                                                                       |

## Parameters and fields

### Request parameters

`ListAuthors` accepts no path parameters, query parameters, or request body.

### Response schema (`AuthorDto[]`)

A `200 OK` response returns a JSON array of `AuthorDto` objects (`additionalProperties: false`).

| Field     | Type             | Required | Constraints | Description                             |
| :-------- | :--------------- | :------- | :---------- | :-------------------------------------- |
| `[].id`   | `string`         | Yes      | UUID        | Unique identifier of the author         |
| `[].name` | `string \| null` | Yes      | Nullable    | Author display name (`null` when unset) |

## Error responses
