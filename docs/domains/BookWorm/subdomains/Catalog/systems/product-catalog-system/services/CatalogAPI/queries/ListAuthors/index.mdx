`ListAuthors` queries [[service|catalog-api]] (`GET /catalog/api/v1/authors`) to return all registered catalog authors as an unpaginated JSON array. The endpoint is publicly readable, returns `[]` with `200 OK` when no authors exist, and caches the directory.

## Overview

| Property                           | Value                                                                                                                                                      |
| :--------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Bounded Context**                | Catalog                                                                                                                                                    |
| **Owner Service**                  | [[service\|catalog-api]]                                                                                                                                   |
| **Protocol / Format**              | HTTP `GET`, `application/json` response                                                                                                                    |
| **Gateway Endpoint**               | `GET /catalog/api/v1/authors` (service path `/api/v1/authors`)                                                                                             |
| **Authentication & Authorization** | None required (public read endpoint)                                                                                                                       |
| **Idempotency / Concurrency**      | Read-only and naturally idempotent                                                                                                                         |
| **Rate Limit / Caching**           | Global concurrency (`100`), per-IP fixed-window (`30 req/min`), and per-user token bucket (`30` limit, `20` per `10s`, queue `5`); cached in L1 + Redis L2 |
| **Contract Version**               | `1.0.0` (`ApiVersions.V1`)                                                                                                                                 |

## Request & Response Contract

### Request Parameters

Accepts no path parameters, query parameters, or request body.

### Success Response (`200 OK`)

Returns a JSON array of author objects (`additionalProperties: false`).

| Name      | Type              | Required | Constraints | Description                             |
| :-------- | :---------------- | :------- | :---------- | :-------------------------------------- |
| `[].id`   | `string` (`uuid`) | Yes      | Valid UUID  | Unique identifier of the author         |
| `[].name` | `string \| null`  | Yes      | Nullable    | Author display name (`null` when unset) |

## Behavior & Side Effects

- **Read-through caching:** Serves the author directory from L1/Redis L2 cache and invalidates when authors are created, updated, or deleted.
- **No state mutation:** Pure read query with no database writes or integration events.
