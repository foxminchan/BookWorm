`GetBookGrpc` invokes the internal `book.v1.BookGrpcService/GetBook` gRPC unary RPC on **Catalog API** to retrieve a compact commercial summary (ID, name, regular price, sale price, and stock status) for a single book. While **Basket API** and **Ordering API** wire client methods for this RPC, active checkout and enrichment flows use the batch [[query|GetBooksGrpc]] RPC instead.

## Overview

| Property                | Value                                                                                                                                        |
| :---------------------- | :------------------------------------------------------------------------------------------------------------------------------------------- |
| **Owner (gRPC server)** | Catalog bounded context (**Catalog API**, Aspire resource `catalog`)                                                                         |
| **Wired clients**       | **Basket API** (`basket`) and **Ordering API** (`ordering`) — currently superseded in active flows by `GetBooks`                             |
| **Source**              | `src/Services/Catalog/BookWorm.Catalog/Grpc/Protos/book/v1/book.proto`, `src/Services/Catalog/BookWorm.Catalog/Grpc/Services/BookService.cs` |
| **Protocol / format**   | gRPC unary RPC (`book.v1.BookGrpcService/GetBook`), Protobuf `edition = "2023"`, `csharp_namespace = "BookWorm.Catalog.Grpc.Services"`       |
| **Authentication**      | `[AllowAnonymous]` (internal service-to-service public catalog read)                                                                         |
| **Caching**             | Reads PostgreSQL (`catalogdb`) summaries cached in FusionCache (L1 + Redis L2, key `BookSummary(bookId)`, tagged with `BookTag`)             |
| **Contract version**    | `1.0.0`                                                                                                                                      |

## Parameters and fields

### Request message (`GetBookRequest`)

| Field     | Protobuf type | Tag | Constraints               | Description                               |
| :-------- | :------------ | :-- | :------------------------ | :---------------------------------------- |
| `book_id` | `string`      | `1` | Valid UUID (`Guid.Parse`) | Unique identifier of the book to retrieve |

### Response message (`GetBookResponse`)

| Field        | Protobuf type  | Tag | Description                                                      |
| :----------- | :------------- | :-- | :--------------------------------------------------------------- |
| `id`         | `string`       | `1` | Book UUID                                                        |
| `name`       | `string`       | `2` | Book title                                                       |
| `price`      | `DecimalValue` | `3` | Regular unit price (`int64 units`, `sfixed32 nanos`)             |
| `price_sale` | `DecimalValue` | `4` | Promotional sale price (omitted/null when no sale applies)       |
| `status`     | `BookStatus`   | `5` | `BOOK_STATUS_IN_STOCK` (`1`) or `BOOK_STATUS_OUT_OF_STOCK` (`2`) |

### Protobuf contract

<CodeGroup>

```protobuf
edition = "2023";

package book.v1;

service BookGrpcService {
  rpc GetBook (GetBookRequest) returns (GetBookResponse);
}

message GetBookRequest {
  string book_id = 1;
}

message GetBookResponse {
  string id = 1;
  string name = 2;
  DecimalValue price = 3;
  DecimalValue price_sale = 4;
  BookStatus status = 5;
}

enum BookStatus {
  BOOK_STATUS_UNSPECIFIED = 0;
  BOOK_STATUS_IN_STOCK = 1;
  BOOK_STATUS_OUT_OF_STOCK = 2;
}

message DecimalValue {
  int64 units = 1;
  sfixed32 nanos = 2;
}
```

</CodeGroup>

## Error responses

| Code / status        | Condition                                                                                                                                | Recovery behavior                                     |
| :------------------- | :--------------------------------------------------------------------------------------------------------------------------------------- | :---------------------------------------------------- |
| `NotFound` (`5`)     | No book exists with the supplied `book_id` (`"Book with id <value> not found."`)                                                         | Treat the book as unavailable; do not retry unchanged |
| `Unknown` (`2`)      | `book_id` is not a valid UUID (`BookService.GetBook` calls `Guid.Parse` directly without mapping `FormatException` to `InvalidArgument`) | Validate UUID format before calling                   |
| `Unavailable` (`14`) | Catalog API is unreachable                                                                                                               | Retry within the budgeted resilience policy           |
