`GetDashboardGrpc` invokes the admin-protected `book.v1.BookGrpcService/GetDashboard` gRPC unary RPC on **Catalog API** to retrieve total catalog book counts and per-category book counts. **Ordering API** calls this RPC using its `dashboard-catalog` gRPC client with an exchanged Microsoft Entra ID administrator token when refreshing the Backoffice dashboard.

## Overview

| Property                | Value                                                                                                                                                                                                                                |
| :---------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Owner (gRPC server)** | Catalog bounded context (**Catalog API**, Aspire resource `catalog`)                                                                                                                                                                 |
| **Primary caller**      | **Ordering API** (`ordering`, named `dashboard-catalog` gRPC client)                                                                                                                                                                 |
| **Source**              | `src/Services/Catalog/BookWorm.Catalog/Grpc/Protos/book/v1/book.proto`, `src/Services/Catalog/BookWorm.Catalog/Grpc/Services/BookService.cs`, `src/Services/Catalog/BookWorm.Catalog/Features/Dashboard/GetCatalogDashboardQuery.cs` |
| **Protocol / format**   | gRPC unary RPC (`book.v1.BookGrpcService/GetDashboard`), Protobuf `edition = "2023"`, `csharp_namespace = "BookWorm.Catalog.Grpc.Services"`                                                                                          |
| **Authentication**      | `[Authorize(Policy = Authorization.Policies.Admin)]` — Microsoft Entra ID JWT (`admin` role + `catalog_read`/`catalog_write` scopes) via `Authorization: Bearer <token>` metadata                                                    |
| **Caching**             | Dispatches `GetCatalogDashboardQuery`, querying PostgreSQL (`catalogdb`) and caching results in FusionCache (`CatalogCacheKeys.Dashboard`) for `15 seconds`                                                                          |
| **Contract version**    | `1.0.0`                                                                                                                                                                                                                              |

## Parameters and fields

### Request message (`GetDashboardRequest`)

`GetDashboardRequest` is an empty Protobuf message with no fields.

### Response message (`GetDashboardResponse`)

| Field                | Protobuf type                | Tag | Description                              |
| :------------------- | :--------------------------- | :-- | :--------------------------------------- |
| `total_books`        | `int64`                      | `1` | Sum of book counts across all categories |
| `categories`         | `repeated DashboardCategory` | `2` | Per-category book counts                 |
| `categories[].name`  | `string`                     | `1` | Category display name                    |
| `categories[].value` | `int64`                      | `2` | Number of books assigned to the category |

### Protobuf contract

<CodeGroup>

```protobuf
edition = "2023";

package book.v1;

service BookGrpcService {
  rpc GetDashboard (GetDashboardRequest) returns (GetDashboardResponse);
}

message GetDashboardRequest {}

message GetDashboardResponse {
  int64 total_books = 1;
  repeated DashboardCategory categories = 2;
}

message DashboardCategory {
  string name = 1;
  int64 value = 2;
}
```

</CodeGroup>

## Error responses

| Code / status            | Condition                                                            | Recovery behavior                                                     |
| :----------------------- | :------------------------------------------------------------------- | :-------------------------------------------------------------------- |
| `Unauthenticated` (`16`) | Missing, expired, or invalid Entra ID bearer token in gRPC metadata  | Exchange a valid administrator token scoped for Catalog API and retry |
| `PermissionDenied` (`7`) | Authenticated caller does not satisfy `Authorization.Policies.Admin` | Authenticate with an `admin` role principal                           |
| `Unavailable` (`14`)     | Catalog API is unreachable                                           | Retry within the budgeted resilience policy                           |
