## Update a book with curl and `If-Match`

<CodeGroup>

```bash
curl --fail-with-body -i -X PUT "<gateway-url>/catalog/api/v1/books" \
  -H "Authorization: Bearer <access-token>" \
  -H 'If-Match: "<row-version>"' \
  -F "id=<book-id>" \
  -F "name=The Left Hand of Darkness" \
  -F "description=Revised edition with updated foreword." \
  -F "price=19.99" \
  -F "priceSale=15.99" \
  -F "categoryId=<category-id>" \
  -F "publisherId=<publisher-id>" \
  -F "authorIds=<author-id>" \
  -F "isRemoveImage=false"
```

</CodeGroup>

Where:

- `<gateway-url>`: Base URL of the BookWorm API Gateway.
- `<access-token>`: Entra ID JWT satisfying the `business_user` policy.
- `<row-version>`: Current `ETag` version number returned by `GET /api/v1/books/<book-id>`.
- `<book-id>`, `<category-id>`, `<publisher-id>`, `<author-id>`: Existing catalog UUIDs.

Expected response:

<CodeGroup>

```text
HTTP/1.1 204 No Content
```

</CodeGroup>

## Remove an existing cover image with TypeScript

Send all required book fields together with `isRemoveImage=true`:

<CodeGroup>

```typescript
const form = new FormData();
form.set("id", "<book-id>");
form.set("name", "The Left Hand of Darkness");
form.set("description", "Revised edition with updated foreword.");
form.set("price", "19.99");
form.set("categoryId", "<category-id>");
form.set("publisherId", "<publisher-id>");
form.append("authorIds", "<author-id>");
form.set("isRemoveImage", "true");

const response = await fetch("<gateway-url>/catalog/api/v1/books", {
	method: "PUT",
	headers: {
		Authorization: "Bearer <access-token>",
		"If-Match": '"<row-version>"',
	},
	body: form,
});

if (response.status === 412) {
	throw new Error("Book was modified by another request; reload and retry");
}

if (!response.ok) {
	throw new Error(`UpdateBook failed with ${response.status}`);
}
```

</CodeGroup>

Where:

- `<gateway-url>`: Base URL of the BookWorm API Gateway.
- `<access-token>`: Entra ID JWT satisfying the `business_user` policy.
- `<row-version>`: Current `ETag` version number returned by `GET /api/v1/books/<book-id>`.
- `<book-id>`, `<category-id>`, `<publisher-id>`, `<author-id>`: Existing catalog UUIDs.

Expected response:

<CodeGroup>

```text
HTTP/1.1 204 No Content
```

</CodeGroup>
