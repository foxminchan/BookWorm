## 1. Update pricing and relationships

The command uses `multipart/form-data` so metadata and optional image changes can be submitted together. A successful update returns `204 No Content`.

### Payload details

- `id` is the only required field and identifies the book.
- `price`, `priceSale`, `categoryId`, and `authorIds` replace the supplied values.
- Omitted fields remain unchanged.
- `isRemoveImage=true` removes the existing cover.

### Example response

<CodeGroup dropdown>

```ts
const response = { status: 204, body: null };
```

</CodeGroup>

### Using this example

Refresh the book projection after `204 No Content`; do not attempt to parse a response body.

<CodeGroup dropdown>

```ts update-book.ts
const form = new FormData();
form.set("id", "44444444-4444-4444-4444-444444444444");
form.set("price", "19.99");
form.set("priceSale", "15.99");
form.set("categoryId", "11111111-1111-1111-1111-111111111111");
form.append("authorIds", "33333333-3333-3333-3333-333333333333");

const response = await fetch("https://api.example.com/api/v1/books", {
	method: "PUT",
	body: form,
});

if (response.status === 404) {
	throw new Error("Book was not found");
}
if (!response.ok) {
	throw new Error(`UpdateBook failed with ${response.status}`);
}
```

## 2. Remove a cover image

Send the book `id` with `isRemoveImage=true`. The API returns `204` after the cover is removed.

<CodeGroup dropdown>

```ts remove-cover.ts
const form = new FormData();
form.set("id", "44444444-4444-4444-4444-444444444444");
form.set("isRemoveImage", "true");

const response = await fetch("https://api.example.com/api/v1/books", {
	method: "PUT",
	body: form,
});

if (!response.ok) {
	throw new Error(`Remove cover failed with ${response.status}`);
}
```

</CodeGroup>
