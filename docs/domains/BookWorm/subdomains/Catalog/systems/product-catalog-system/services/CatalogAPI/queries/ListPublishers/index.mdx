`ListPublishers` queries **Catalog API** (`GET /api/v1/publishers`) to return all registered book publishers as an unpaginated JSON array (`PublisherDto[]`). The endpoint is publicly readable, returns `[]` with `200 OK` when no publishers exist, and caches the directory in FusionCache.

## Overview

| Property                  | Value                                                                                                                          |
| :------------------------ | :----------------------------------------------------------------------------------------------------------------------------- |
| **Owner**                 | Catalog bounded context (**Catalog API**, Aspire resource `catalog`)                                                           |
| **Source**                | `src/Services/Catalog/BookWorm.Catalog/Features/Publishers/List/ListPublishersEndpoint.cs`, `ListPublishersQuery.cs`           |
| **Protocol / format**     | HTTP `GET /api/v1/publishers` (via API Gateway: `GET /catalog/api/v1/publishers`), `ApiVersions.V1`, JSON (`application/json`) |
| **Authentication**        | None required (public read endpoint)                                                                                           |
| **Rate limiting**         | `PerUserRateLimit` token bucket (30 token limit, 20 tokens per 10 seconds, queue limit 5) plus global IP/concurrency limiters  |
| **Persistence & caching** | PostgreSQL (`catalogdb`, EF Core) cached in FusionCache (L1 + Redis L2, key `CatalogCacheKeys.Publishers`)                     |
| **Contract version**      | `1.0.0`                                                                                                                        |

## Parameters and fields

### Request parameters

`ListPublishers` accepts no path parameters, query parameters, or request body.

### Response schema (`PublisherDto[]`)

A `200 OK` response returns a JSON array of `PublisherDto` objects (`additionalProperties: false`).

| Field     | Type             | Required | Constraints | Description                                |
| :-------- | :--------------- | :------- | :---------- | :----------------------------------------- |
| `[].id`   | `string`         | Yes      | UUID        | Unique identifier of the publisher         |
| `[].name` | `string \| null` | Yes      | Nullable    | Publisher display name (`null` when unset) |

## Error responses

| :---------------------- | :---------------------------------------------------------------------------------------------------------- | :-------------------------------------------------- |
