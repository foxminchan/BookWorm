`ListPublishers` queries [[service|catalog-api]] (`GET /catalog/api/v1/publishers`) to return all registered book publishers as an unpaginated JSON array. The endpoint is publicly readable, returns `[]` with `200 OK` when no publishers exist, and caches the directory.

## Overview

| Property                           | Value                                                                                                                                                      |
| :--------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Bounded Context**                | Catalog                                                                                                                                                    |
| **Owner Service**                  | [[service\|catalog-api]]                                                                                                                                   |
| **Protocol / Format**              | HTTP `GET`, `application/json` response                                                                                                                    |
| **Gateway Endpoint**               | `GET /catalog/api/v1/publishers` (service path `/api/v1/publishers`)                                                                                       |
| **Authentication & Authorization** | None required (public read endpoint)                                                                                                                       |
| **Idempotency / Concurrency**      | Read-only and naturally idempotent                                                                                                                         |
| **Rate Limit / Caching**           | Global concurrency (`100`), per-IP fixed-window (`30 req/min`), and per-user token bucket (`30` limit, `20` per `10s`, queue `5`); cached in L1 + Redis L2 |
| **Contract Version**               | `1.0.0` (`ApiVersions.V1`)                                                                                                                                 |

## Request & Response Contract

### Request Parameters

Accepts no path parameters, query parameters, or request body.

### Success Response (`200 OK`)

Returns a JSON array of publisher objects (`additionalProperties: false`).

| Name      | Type              | Required | Constraints | Description                                |
| :-------- | :---------------- | :------- | :---------- | :----------------------------------------- |
| `[].id`   | `string` (`uuid`) | Yes      | Valid UUID  | Unique identifier of the publisher         |
| `[].name` | `string \| null`  | Yes      | Nullable    | Publisher display name (`null` when unset) |

## Behavior & Side Effects

- **Read-through caching:** Serves the publisher directory from L1/Redis L2 cache and invalidates when publishers are created, updated, or deleted.
- **No state mutation:** Pure read query with no database writes or integration events.

## Error Responses

| Status / Code           | Condition                                                 | Client Recovery Action                              |
| :---------------------- | :-------------------------------------------------------- | :-------------------------------------------------- |
| `429 Too Many Requests` | Rate limit quota exceeded (`Retry-After` header included) | Wait for the `Retry-After` duration before retrying |
