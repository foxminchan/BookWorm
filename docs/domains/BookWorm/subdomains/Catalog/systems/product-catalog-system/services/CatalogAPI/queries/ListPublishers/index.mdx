## Overview

Returns every catalog [[entity|publisher]] without pagination or request parameters.

## Contract

This query does not require a request body or query parameters.

The response is a JSON array of objects containing `id` and nullable `name`.

## Operational notes

The API returns `200` with an empty array when no resources are available.
