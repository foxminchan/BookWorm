`DeletePublisher` permanently deletes a publisher record from **Catalog API** (`DELETE /api/v1/publishers/{id}`) and returns `204 No Content`. The command rejects deletion with `400 Bad Request` when any active book references the publisher.

## Overview

| Property              | Value                                                                                                                             |
| :-------------------- | :-------------------------------------------------------------------------------------------------------------------------------- |
| **Owner**             | Catalog bounded context (**Catalog API**, Aspire resource `catalog`)                                                              |
| **Source**            | `src/Services/Catalog/BookWorm.Catalog/Features/Publishers/Delete/`                                                               |
| **Protocol / format** | HTTP `DELETE`, path parameter only, empty response body (`204 No Content`)                                                        |
| **Endpoint**          | Direct: `DELETE /api/v1/publishers/{id}` (local HTTP `5100`, HTTPS `7187`); API Gateway: `DELETE /catalog/api/v1/publishers/{id}` |
| **Authentication**    | Microsoft Entra ID JWT — `business_user` policy (role `business_user` or `admin` and scopes `catalog_read`, `catalog_write`)      |
| **Rate limiting**     | Global concurrency (`100`) and fixed-window (`30 req/min`) limiters plus `PerUserRateLimit` token bucket                          |
| **Idempotency**       | Not idempotent across retries; repeating a completed delete returns `404 Not Found`; no `x-request-id` header is enforced         |
| **Contract version**  | `1.0.0` (`ApiVersions.V1`)                                                                                                        |

## Parameters and fields

### Path parameters

`DELETE /api/v1/publishers/{id}` accepts no request body.

| Name | Type   | Required | Default | Constraints                                                           | Description                                  |
| :--- | :----- | :------- | :------ | :-------------------------------------------------------------------- | :------------------------------------------- |
| `id` | `uuid` | Yes      | —       | Valid UUID (`PublisherId`); must not be referenced by any active book | Unique identifier of the publisher to delete |

## Behavior and side effects

- **Referential integrity guard:** Before loading the publisher, `DeletePublisherValidator` runs `BookFilterSpec(null, [publisherId])` against active (non-soft-deleted) books. If any active book references the publisher, FluentValidation fails with `400 Bad Request` (`"Publisher has books and cannot be deleted"`).
- **Hard delete and foreign-key handling:** `Publisher` does not implement `ISoftDelete`; `DeletePublisherHandler` calls `repository.Delete(publisher)` to remove the row permanently from PostgreSQL (`publishers`). For any soft-deleted book rows still referencing the publisher, `BookConfiguration.cs` configures `OnDelete(DeleteBehavior.SetNull)`, setting their `publisher_id` to `NULL`.
- **Cache invalidation:** Dispatches `PublisherDeletedEvent` on save; `PublisherChangedEventHandler` removes `catalog:publishers:v1` and invalidates FusionCache tags `book` and `books:list`.
- **Vector index queueing:** PostgreSQL trigger `publishers_vector_update` (`BEFORE UPDATE OR DELETE ON publishers`) enqueues any linked `book_id` rows into `pending_vector_updates` for asynchronous Qdrant reconciliation by **Catalog Ingestion**.

## Error responses

| Code / status               | Condition                                                                                                                                                             | Recovery behavior                                                              |
| :-------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :----------------------------------------------------------------------------- |
| `400 Bad Request`           | Publisher is still linked to one or more active books (`"Publisher has books and cannot be deleted"`), or `{id}` is not a valid UUID (`HttpValidationProblemDetails`) | Reassign or delete linked books first, or fix the UUID; do not retry unchanged |
| `401 Unauthorized`          | Missing, expired, or invalid Entra ID JWT                                                                                                                             | Acquire a valid Entra ID access token and retry                                |
| `403 Forbidden`             | Token lacks role `business_user` or `admin`, or lacks scopes `catalog_read` and `catalog_write`                                                                       | Request the required Entra ID app role and scopes                              |
| `404 Not Found`             | No publisher exists with the supplied `{id}` (`{ "detail": "The requested resource was not found." }`)                                                                | Verify the UUID; treat as already absent only if your workflow allows it       |
| `429 Too Many Requests`     | Global or `PerUserRateLimit` quota exceeded (`ProblemDetails` with `Retry-After` header)                                                                              | Wait for the `Retry-After` interval before retrying                            |
| `500 Internal Server Error` | Unhandled server or PostgreSQL failure (`ProblemDetails` with `traceId`)                                                                                              | Inspect Catalog API logs using `traceId`                                       |
