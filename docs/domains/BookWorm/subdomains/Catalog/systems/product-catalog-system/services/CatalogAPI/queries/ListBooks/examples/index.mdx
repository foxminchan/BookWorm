## Search and filter books with curl

<CodeGroup>

```bash
curl --request QUERY "<gateway-url>/catalog/api/v1/books" \
  --header "Content-Type: application/json" \
  --header "Accept: application/json" \
  --data '{
    "pageIndex": 1,
    "pageSize": 20,
    "orderBy": "Name",
    "isDescending": false,
    "search": "foundation",
    "minPrice": 10,
    "maxPrice": 30,
    "categoryId": ["11111111-1111-1111-1111-111111111111"],
    "authorIds": ["33333333-3333-3333-3333-333333333333"]
  }'
```

</CodeGroup>

Where:

- `<gateway-url>`: Base URL of the BookWorm API Gateway (or direct Catalog API URL `https://localhost:7187` without the `/catalog` prefix).

Expected response (`200 OK` with `Pagination-Count` and `Link` headers):

## Search and filter books with TypeScript

<CodeGroup>

```typescript
type BookSummary = {
	id: string;
	name: string | null;
	price: number;
	priceSale: number | null;
	status: "InStock" | "OutOfStock";
};

const query = {
	pageIndex: 1,
	pageSize: 20,
	orderBy: "Name",
	isDescending: false,
	search: "foundation",
	minPrice: 10,
	maxPrice: 30,
	categoryId: ["11111111-1111-1111-1111-111111111111"],
	authorIds: ["33333333-3333-3333-3333-333333333333"],
};

const gatewayUrl = "<gateway-url>";
const response = await fetch(`${gatewayUrl}/catalog/api/v1/books`, {
	method: "QUERY",
	headers: {
		"Content-Type": "application/json",
		Accept: "application/json",
	},
	body: JSON.stringify(query),
});

if (!response.ok) {
	throw new Error(`ListBooks failed with ${response.status}`);
}

const totalBooks = Number(response.headers.get("Pagination-Count") ?? "0");
const books = (await response.json()) as BookSummary[];
console.log(`Found ${books.length} of ${totalBooks} book(s)`);
```

</CodeGroup>
