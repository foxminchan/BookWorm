## 1. List publishers

The query returns `200` with an array of publisher summaries. Each item contains its UUID and display name.

### Response details

- An empty collection is represented by `200` and `[]`.
- The endpoint does not require a resource UUID.
- Use the returned identifiers when creating or updating books.

### Example response

const publishers: PublisherSummary[] = [

### Using this example

Render the returned summaries as selectable publisher options; an empty array is a valid catalog state.

<CodeGroup dropdown>

```ts list-publishers.ts
type PublisherSummary = { id: string; name: string };

const response = await fetch("https://api.example.com/api/v1/publishers");
if (!response.ok) {
	throw new Error(`ListPublishers failed with ${response.status}`);
}

const publishers = (await response.json()) as PublisherSummary[];
for (const publisher of publishers) {
	console.log(`${publisher.id}: ${publisher.name}`);
}
```
