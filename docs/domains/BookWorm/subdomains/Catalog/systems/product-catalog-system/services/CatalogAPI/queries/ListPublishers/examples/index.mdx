## List all publishers with curl

<CodeGroup>

```bash
curl --request GET "<gateway-url>/catalog/api/v1/publishers" \
  --header "Accept: application/json"
```

</CodeGroup>

Where:

- `<gateway-url>`: Base URL of the BookWorm API Gateway (or direct Catalog API URL `https://localhost:7187` without the `/catalog` prefix).

Expected response (`200 OK`):

<CodeGroup>

```json
[
	{
		"id": "22222222-2222-2222-2222-222222222222",
		"name": "Ace Books"
	},
	{
		"id": "99999999-9999-9999-9999-999999999999",
		"name": "O'Reilly Media"
	}
]
```

</CodeGroup>
