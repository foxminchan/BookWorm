`GetBook` queries **Catalog API** (`GET /api/v1/books/{id}`) to retrieve a single book's full projection, including pricing, stock status, category, publisher, authors, and derived rating summary. The endpoint is publicly readable, supports HTTP `ETag` conditional requests, and caches book details in FusionCache.

## Overview

| Property                         | Value                                                                                                                                                                    |
| :------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Owner**                        | Catalog bounded context (**Catalog API**, Aspire resource `catalog`)                                                                                                     |
| **Source**                       | `src/Services/Catalog/BookWorm.Catalog/Features/Books/Get/GetBookEndpoint.cs`, `GetBookQuery.cs`, `src/Services/Catalog/BookWorm.Catalog/Features/Books/BookDto.cs`      |
| **Protocol / format**            | HTTP `GET /api/v1/books/{id}` (via API Gateway: `GET /catalog/api/v1/books/{id}`), `ApiVersions.V1`, JSON (`application/json`)                                           |
| **Authentication**               | None required (public read endpoint)                                                                                                                                     |
| **HTTP caching & rate limiting** | `.WithETag()` conditional requests (`ETag` / `If-None-Match` → `304 Not Modified`); `PerUserRateLimit` token bucket (30 limit, 20 per 10s, queue 5) plus global limiters |
| **Persistence & caching**        | PostgreSQL (`catalogdb`, EF Core) cached in FusionCache (L1 + Redis L2, tagged with `BookTag`)                                                                           |
| **Contract version**             | `1.0.0`                                                                                                                                                                  |

## Parameters and fields

### Path parameters

| Name | Type                | Required | Default | Constraints | Description                               |
| :--- | :------------------ | :------- | :------ | :---------- | :---------------------------------------- |
| `id` | `string` (`BookId`) | Yes      | —       | Valid UUID  | Unique identifier of the book to retrieve |

### Response schema (`BookDto`)

A `200 OK` response returns a `BookDto` JSON object.

| Field           | Type             | Required | Constraints                                    | Description                                              |
| :-------------- | :--------------- | :------- | :--------------------------------------------- | :------------------------------------------------------- |
| `id`            | `string`         | Yes      | UUID                                           | Unique identifier of the book                            |
| `name`          | `string \| null` | Yes      | Nullable                                       | Book title                                               |
| `description`   | `string \| null` | Yes      | Nullable                                       | Book description                                         |
| `imageUrl`      | `string \| null` | Yes      | URI or `null`                                  | Publicly accessible cover image URI                      |
| `price`         | `number`         | Yes      | Decimal                                        | Regular unit price                                       |
| `priceSale`     | `number \| null` | Yes      | Decimal or `null`                              | Promotional sale price (`null` when no discount applies) |
| `status`        | `string`         | Yes      | Enum: `InStock`, `OutOfStock`                  | Current stock availability status                        |
| `category`      | `object \| null` | Yes      | `{ id: uuid, name: string \| null }` or `null` | Assigned book category                                   |
| `publisher`     | `object \| null` | Yes      | `{ id: uuid, name: string \| null }` or `null` | Assigned publisher                                       |
| `authors`       | `object[]`       | Yes      | Array of `{ id: uuid, name: string \| null }`  | Authors associated with the book                         |
| `averageRating` | `number`         | Yes      | `>= 0`                                         | Derived average customer rating projected from Reviews   |
| `totalReviews`  | `integer`        | Yes      | `>= 0`                                         | Derived total feedback count projected from Reviews      |

## Error responses

| Code / status           | Condition                                                                                                   | Recovery behavior                                             |
| :---------------------- | :---------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------ |
| `304 Not Modified`      | Request included a matching `If-None-Match` ETag header                                                     | Reuse the client's cached `BookDto`                           |
| `404 Not Found`         | No book exists for the supplied UUID (`application/problem+json`)                                           | Render a not-found state; do not fabricate an empty `BookDto` |
| `429 Too Many Requests` | Caller exceeded `PerUserRateLimit` or global rate limit (`application/problem+json` + `Retry-After` header) | Wait for the `Retry-After` duration before retrying           |
