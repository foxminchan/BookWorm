## Overview

Returns the [[entity|book]] identity, description, pricing, availability status, [[entity|category]], [[entity|publisher]], [[entity|author]]s, and rating summary for one UUID.

<NodeGraph />

## Contract

Provide the book UUID as the required `id` path parameter. The query has no request body.

The response is a `BookDto` JSON object. Related category and publisher values may be `null`; authors is an array.

## Operational notes

`404` indicates that no book exists with the supplied UUID.
