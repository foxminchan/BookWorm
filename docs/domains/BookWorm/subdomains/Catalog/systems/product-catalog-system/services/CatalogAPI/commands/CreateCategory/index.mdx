`CreateCategory` creates a new book category in [[service|catalog-api]] (`POST /catalog/api/v1/categories`) and returns its generated UUIDv7 identifier as a JSON string. Callers use the returned identifier when assigning categories in [[command|CreateBook]] and [[command|UpdateBook]].

| Property                           | Value                                                                                                                           |
| :--------------------------------- | :------------------------------------------------------------------------------------------------------------------------------ |
| **Bounded Context**                | Catalog                                                                                                                         |
| **Owner Service**                  | [[service\|catalog-api]]                                                                                                        |
| **Protocol / Format**              | HTTP `POST`, `application/json` request and JSON string response                                                                |
| **Gateway Endpoint**               | `POST /catalog/api/v1/categories` (service path `/api/v1/categories`)                                                           |
| **Authentication & Authorization** | Microsoft Entra ID JWT â€” `business_user` policy (role `business_user` or `admin` and scopes `catalog_read`, `catalog_write`)  |
| **Idempotency / Concurrency**      | Not idempotent; duplicate names violate the unique name constraint, and no `x-request-id` header is enforced                    |
| **Rate Limit / Caching**           | Global concurrency (`100`) and fixed-window (`30 req/min`) limiters plus per-user token bucket; invalidates category list cache |
| **Contract Version**               | `1.0.0` (`ApiVersions.V1`)                                                                                                      |

## Request & Response Contract

### Request Body (`application/json`)

Leading and trailing whitespace is trimmed from string properties during deserialization.

| Name   | Type     | Required | Constraints                            | Description                  |
| :----- | :------- | :------- | :------------------------------------- | :--------------------------- |
| `name` | `string` | Yes      | Non-empty, max `50` characters, unique | Display name of the category |

### Success Response (`200 OK`)

Returns `200 OK` without a `Location` header.

| Name       | Type     | Required | Constraints | Description                                         |
| :--------- | :------- | :------- | :---------- | :-------------------------------------------------- |
| Root value | `string` | Yes      | UUIDv7      | Generated unique identifier of the created category |

## Behavior & Side Effects

- **Persistence & uniqueness:** Inserts a new [[entity|category]] record with a generated UUIDv7 primary key; category names are unique-indexed, so submitting an existing name fails with `500 Internal Server Error`.
- **Cache invalidation:** Clears the cached category list (`catalog:categories:v1`) upon successful creation.
- **Vector indexing:** No vector-index refresh is queued on category creation; vector updates are triggered only when an existing category is updated or deleted.

## Error Responses

| Status / Code               | Condition                                                                                       | Client Recovery Action                                                          |
| :-------------------------- | :---------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------ |
| `400 Bad Request`           | `name` is missing, empty, whitespace-only, exceeds `50` characters, or payload is malformed     | Fix the request body; do not retry unchanged input                              |
| `401 Unauthorized`          | Missing, expired, or invalid Entra ID JWT                                                       | Acquire a valid Entra ID access token and retry                                 |
| `403 Forbidden`             | Token lacks role `business_user` or `admin`, or lacks scopes `catalog_read` and `catalog_write` | Request the required Entra ID app role and scopes                               |
| `429 Too Many Requests`     | Rate limit quota exceeded (`Retry-After` header included)                                       | Wait for the `Retry-After` interval before retrying                             |
| `500 Internal Server Error` | Duplicate `name` violating the unique constraint or unhandled server error (`traceId` included) | Check existing categories for a duplicate name and inspect logs using `traceId` |
