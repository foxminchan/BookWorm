## Overview

Creates a [[entity|category]] and returns its generated UUID.

<NodeGraph />

## Contract

The request is JSON and requires a non-empty `name`.

The response body is a JSON string containing the new category UUID.

## Operational notes

A validation problem is returned with `400` when `name` is missing or empty.
