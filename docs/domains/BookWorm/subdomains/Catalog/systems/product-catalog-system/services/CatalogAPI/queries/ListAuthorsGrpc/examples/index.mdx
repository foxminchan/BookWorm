## Call `ListAuthors` from a .NET gRPC client

<CodeGroup>

```csharp
using BookWorm.Catalog.Grpc.Services;
using Grpc.Net.Client;

using var channel = GrpcChannel.ForAddress("<catalog-grpc-url>");
var client = new BookGrpcService.BookGrpcServiceClient(channel);

var response = await client.ListAuthorsAsync(new ListAuthorsRequest());

foreach (var author in response.Authors)
{
    Console.WriteLine($"{author.Id}: {author.Name}");
}
```

</CodeGroup>

Where:

- `<catalog-grpc-url>`: Base URL of Catalog API (resolved via Aspire service discovery as `catalog`, or `https://localhost:7187` locally).
