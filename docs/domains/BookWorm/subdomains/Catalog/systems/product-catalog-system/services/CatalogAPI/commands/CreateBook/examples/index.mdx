## Create a book with curl

<CodeGroup>

```bash
curl --fail-with-body -X POST "<gateway-url>/catalog/api/v1/books" \
  -H "Authorization: Bearer <access-token>" \
  -F "name=The Left Hand of Darkness" \
  -F "description=A science-fiction novel by Ursula K. Le Guin." \
  -F "price=18.99" \
  -F "priceSale=14.99" \
  -F "categoryId=<category-id>" \
  -F "publisherId=<publisher-id>" \
  -F "authorIds=<author-id>" \
  -F "image=@<cover-image-path>;type=image/jpeg"
```

</CodeGroup>

Where:

- `<gateway-url>`: Base URL of the BookWorm API Gateway.
- `<access-token>`: Entra ID JWT satisfying the `business_user` policy.
- `<category-id>`: Existing category UUID.
- `<publisher-id>`: Existing publisher UUID.
- `<author-id>`: Existing author UUID (repeat `-F "authorIds=..."` for multiple authors).
- `<cover-image-path>`: Local path to a JPEG, PNG, or WebP file up to 1 MB.

Expected response (`201 Created`, with `Location: /api/v1/books/0193f1a2-7b4c-7d8e-9f01-23456789abcd`):

<CodeGroup>

```json
"0193f1a2-7b4c-7d8e-9f01-23456789abcd"
```

</CodeGroup>
