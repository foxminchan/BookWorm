## 1. Create a book with relationships

The command uses `multipart/form-data` because the cover image is uploaded with the book metadata. A successful request returns `201 Created` with the generated book UUID.

### Payload details

- `name`, `description`, and `price` describe the listing.
- `priceSale` is optional and must not exceed the regular price.
- `categoryId`, `publisherId`, and `authorIds` link the book to catalog metadata.
- `image` is optional and is stored in blob storage.

### Example response

<CodeGroup dropdown>

```ts
const bookId = "44444444-4444-4444-4444-444444444444";
```

</CodeGroup>

### Using this example

Persist the returned UUID so the new book can be retrieved, updated, or linked to other catalog workflows.

<CodeGroup dropdown>

```ts create-book.ts
const form = new FormData();
form.set("name", "The Left Hand of Darkness");
form.set("description", "A science-fiction novel by Ursula K. Le Guin.");
form.set("price", "18.99");
form.set("priceSale", "14.99");
form.set("categoryId", "11111111-1111-1111-1111-111111111111");
form.set("publisherId", "22222222-2222-2222-2222-222222222222");
form.append("authorIds", "33333333-3333-3333-3333-333333333333");

const cover = new Blob(["binary cover contents"], { type: "image/jpeg" });
form.set("image", cover, "cover.jpg");

const response = await fetch("https://api.example.com/api/v1/books", {
	method: "POST",
	body: form,
});

if (!response.ok) {
	throw new Error(`CreateBook failed with ${response.status}`);
}

const bookId = (await response.json()) as string;
console.log(`Created book ${bookId}`);
```

## 2. Reject an invalid multipart request

Missing required fields or malformed relationship UUIDs return `400` with validation problem details. Correct the form before retrying.
