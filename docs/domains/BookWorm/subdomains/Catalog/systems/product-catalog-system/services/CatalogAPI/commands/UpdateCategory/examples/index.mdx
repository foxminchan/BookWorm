## Update a category with curl

<CodeGroup>

```bash
curl --fail-with-body -i -X PUT "<gateway-url>/catalog/api/v1/categories" \
  -H "Authorization: Bearer <access-token>" \
  -H "Content-Type: application/json" \
  -d '{"id": "<category-id>", "name": "Speculative Fiction"}'
```

</CodeGroup>

Where:

- `<gateway-url>`: Base URL of the BookWorm API Gateway.
- `<access-token>`: Entra ID JWT satisfying the `business_user` policy.
- `<category-id>`: UUID of the existing category to rename.

Expected response:

<CodeGroup>

```text
HTTP/1.1 204 No Content
```

</CodeGroup>

## Update a category with TypeScript

<CodeGroup>

```typescript
const response = await fetch("<gateway-url>/catalog/api/v1/categories", {
	method: "PUT",
	headers: {
		Authorization: "Bearer <access-token>",
		"Content-Type": "application/json",
	},
	body: JSON.stringify({
		id: "<category-id>",
		name: "Speculative Fiction",
	}),
});

if (response.status === 404) {
	throw new Error("Category was not found");
}

if (!response.ok) {
	throw new Error(`UpdateCategory failed with ${response.status}`);
}
```

</CodeGroup>

Where:

- `<gateway-url>`: Base URL of the BookWorm API Gateway.
- `<access-token>`: Entra ID JWT satisfying the `business_user` policy.
- `<category-id>`: UUID of the existing category to rename.

Expected response:

<CodeGroup>

```text
HTTP/1.1 204 No Content
```

</CodeGroup>
