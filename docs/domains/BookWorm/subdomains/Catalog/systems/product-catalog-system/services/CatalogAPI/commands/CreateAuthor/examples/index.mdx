## 1. Create an author

The command requires a non-empty display name. A successful request returns `200` and the generated author UUID.

### Payload details

- `name` is required and must contain at least one character.
- The returned UUID should be persisted by the caller when creating related books.
- The request uses the Catalog API's JSON endpoint.

### Example response

<CodeGroup dropdown>

```ts
const authorId = "5e4a1c9b-3f72-4b8d-a605-7c2e9f1d8430";
```

</CodeGroup>

### Using this example

Use the returned UUID when assigning this author to a book.

</Column>

<Column>

<CodeGroup dropdown>

```ts create-author.ts
const response = await fetch("https://api.example.com/api/v1/authors", {
	method: "POST",
	headers: { "Content-Type": "application/json" },
	body: JSON.stringify({ name: "Example Author" }),
});

if (!response.ok) {
	throw new Error(`CreateAuthor failed with ${response.status}`);
}

const authorId = (await response.json()) as string;
console.log(`Created author ${authorId}`);
```

## 2. Reject an invalid request

Omitting `name` returns `400` with an RFC 7807 validation response. Display the field error and do not retry unchanged input.
