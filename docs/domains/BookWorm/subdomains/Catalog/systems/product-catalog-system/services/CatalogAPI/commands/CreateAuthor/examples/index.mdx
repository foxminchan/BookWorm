## Create an author with curl

<CodeGroup>

```bash
curl --fail-with-body -X POST "<gateway-url>/catalog/api/v1/authors" \
  -H "Authorization: Bearer <access-token>" \
  -H "Content-Type: application/json" \
  -d '{"name": "Ursula K. Le Guin"}'
```

</CodeGroup>

Where:

- `<gateway-url>`: Base URL of the BookWorm API Gateway (or direct Catalog API URL without the `/catalog` prefix).
- `<access-token>`: Entra ID JWT with role `business_user` or `admin` and scopes `catalog_read` and `catalog_write`.

Expected response (`200 OK`):

<CodeGroup>

```json
"0193f1a2-7b4c-7d8e-9f01-23456789abcd"
```

</CodeGroup>

## Create an author with TypeScript

<CodeGroup>

```typescript
const response = await fetch("<gateway-url>/catalog/api/v1/authors", {
	method: "POST",
	headers: {
		Authorization: "Bearer <access-token>",
		"Content-Type": "application/json",
	},
	body: JSON.stringify({ name: "Ursula K. Le Guin" }),
});

if (!response.ok) {
	throw new Error(`CreateAuthor failed with ${response.status}`);
}

const authorId = (await response.json()) as string;
```

</CodeGroup>

Where:

- `<gateway-url>`: Base URL of the BookWorm API Gateway.
- `<access-token>`: Entra ID JWT satisfying the `business_user` policy.

Expected response (`200 OK`):

<CodeGroup>

```json
"0193f1a2-7b4c-7d8e-9f01-23456789abcd"
```

</CodeGroup>
