## Update a publisher with curl

<CodeGroup>

```bash
curl --fail-with-body -i -X PUT "<gateway-url>/catalog/api/v1/publishers" \
  -H "Authorization: Bearer <access-token>" \
  -H "Content-Type: application/json" \
  -d '{"id": "<publisher-id>", "name": "Ace Science Fiction"}'
```

</CodeGroup>

Where:

- `<gateway-url>`: Base URL of the BookWorm API Gateway.
- `<access-token>`: Entra ID JWT satisfying the `business_user` policy.
- `<publisher-id>`: UUID of the existing publisher to rename.

Expected response:

<CodeGroup>

```text
HTTP/1.1 204 No Content
```

</CodeGroup>

## Update a publisher with TypeScript

<CodeGroup>

```typescript
const response = await fetch("<gateway-url>/catalog/api/v1/publishers", {
	method: "PUT",
	headers: {
		Authorization: "Bearer <access-token>",
		"Content-Type": "application/json",
	},
	body: JSON.stringify({
		id: "<publisher-id>",
		name: "Ace Science Fiction",
	}),
});

if (response.status === 404) {
	throw new Error("Publisher was not found");
}

if (!response.ok) {
	throw new Error(`UpdatePublisher failed with ${response.status}`);
}
```

</CodeGroup>

Where:

- `<gateway-url>`: Base URL of the BookWorm API Gateway.
- `<access-token>`: Entra ID JWT satisfying the `business_user` policy.
- `<publisher-id>`: UUID of the existing publisher to rename.

Expected response:

<CodeGroup>

```text
HTTP/1.1 204 No Content
```

</CodeGroup>
