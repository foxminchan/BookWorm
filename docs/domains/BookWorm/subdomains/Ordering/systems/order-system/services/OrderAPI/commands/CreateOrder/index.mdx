## Overview

Creates an [[entity|order]] for the authenticated Buyer. Order API obtains the
Buyer's current basket and resolves its book details and prices through
Shopping and Catalog.

<NodeGraph />

## Contract

Send the required `x-request-id` header as the idempotency key. The operation
has no request body. A successful `201 Created` response returns the Order ID
as a JSON UUID.
