## Create a buyer profile through API Gateway

<CodeGroup>

```bash
curl --request POST "https://<gateway-host>/ordering/api/v1/buyers" \
  --header "Authorization: Bearer <access-token>" \
  --header "Content-Type: application/json" \
  --header "x-request-id: <request-id>" \
  --data '{
    "street": "123 Book Street",
    "city": "District 1",
    "province": "Ho Chi Minh City"
  }'
```

</CodeGroup>

Where:

- `<gateway-host>`: API Gateway hostname (or `localhost:7203` with `/api/v1/buyers` when calling Ordering API directly).
- `<access-token>`: Entra ID JWT with role `customer` or `admin` and scopes `ordering_read` and `ordering_write`.
- `<request-id>`: Unique client-generated idempotency key (for example, a UUID v7).

Expected response (`201 Created`, with header `Location: /api/v1/buyers/0193f1a2-6666-7d8e-9f01-23456789abcd`):

<CodeGroup>

```json
"0193f1a2-6666-7d8e-9f01-23456789abcd"
```

</CodeGroup>
