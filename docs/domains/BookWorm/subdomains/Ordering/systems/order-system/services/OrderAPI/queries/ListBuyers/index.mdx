`ListBuyers` queries [[service|order-api]] (`GET /ordering/api/v1/buyers`) to return a paginated slice of registered buyer profiles for store administrators. The endpoint requires the Microsoft Entra ID `admin` policy and emits total item counts and navigation URIs in HTTP response headers.

## Request & Response Contract

### Query Parameters

| Name        | Type      | Required | Constraints                 | Description                               |
| :---------- | :-------- | :------- | :-------------------------- | :---------------------------------------- |
| `PageIndex` | `integer` | No       | Default `1`; must be `> 0`  | 1-based page number to retrieve           |
| `PageSize`  | `integer` | No       | Default `20`; must be `> 0` | Maximum number of buyer profiles per page |

### Response Headers (`200 OK`)

| Name               | Type     | Required | Constraints                               | Description                                                                                 |
| :----------------- | :------- | :------- | :---------------------------------------- | :------------------------------------------------------------------------------------------ |
| `Pagination-Count` | `string` | Yes      | Integer string (e.g., `128`)              | Total number of buyer profiles across all pages                                             |
| `Link`             | `string` | Yes      | Comma-separated `<uri>;rel=<rel>` entries | Navigation URIs with `first`, `self`, `last`, and conditional `previous` / `next` relations |

### Success Response (`200 OK`)

Returns a JSON array of buyer summary objects.

| Name         | Type              | Required | Constraints | Description                                    |
| :----------- | :---------------- | :------- | :---------- | :--------------------------------------------- |
| `[].id`      | `string` (`uuid`) | Yes      | Valid UUID  | Unique identifier of the buyer profile         |
| `[].name`    | `string \| null`  | Yes      | Nullable    | Buyer display name (`null` when unset)         |
| `[].address` | `string \| null`  | Yes      | Nullable    | Formatted shipping address (`null` when unset) |

## Behavior & Side Effects

- **Admin-scoped listing:** Returns paginated buyer profiles from PostgreSQL with `Pagination-Count` and `Link` headers.
- **No state mutation:** Pure read query with no database writes or integration events.

## Error Responses

| Status / Code           | Condition                                                      | Client Recovery Action                                             |
| :---------------------- | :------------------------------------------------------------- | :----------------------------------------------------------------- |
| `400 Bad Request`       | `PageIndex <= 0`, `PageSize <= 0`, or non-integer paging value | Fix paging parameters to positive integers; do not retry unchanged |
| `401 Unauthorized`      | Missing, expired, or invalid Entra ID bearer token             | Re-authenticate and retry                                          |
| `403 Forbidden`         | Caller does not satisfy the `admin` authorization policy       | Authenticate with an administrator account                         |
| `429 Too Many Requests` | Rate limit quota exceeded (`Retry-After` header included)      | Wait for the `Retry-After` duration before retrying                |
