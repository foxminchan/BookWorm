`ListBuyers` queries **Ordering API** (`GET /api/v1/buyers`) to return a paginated slice of registered buyer profiles (`BuyerDto[]`) for store administrators. The endpoint requires the Microsoft Entra ID `admin` authorization policy and emits total item counts and navigation URIs in HTTP response headers.

## Overview

| Property              | Value                                                                                                                                |
| :-------------------- | :----------------------------------------------------------------------------------------------------------------------------------- |
| **Owner**             | Ordering bounded context (**Ordering API**, Aspire resource `ordering`)                                                              |
| **Source**            | `src/Services/Ordering/BookWorm.Ordering/Features/Buyers/List/ListBuyersEndpoint.cs`, `ListBuyersQuery.cs`, `ListBuyersValidator.cs` |
| **Protocol / format** | HTTP `GET /api/v1/buyers` (via API Gateway: `GET /ordering/api/v1/buyers`), `ApiVersions.V1`, JSON (`application/json`)              |
| **Authentication**    | Microsoft Entra ID JWT required — `admin` policy (`admin` role; scopes `ordering_read`, `ordering_write`)                            |
| **Rate limiting**     | `PerUserRateLimit` token bucket (30 token limit, 20 tokens per 10 seconds, queue limit 5) plus global IP/concurrency limiters        |
| **Backing store**     | PostgreSQL (`orderingdb`, EF Core)                                                                                                   |
| **Contract version**  | `1.0.0`                                                                                                                              |

## Parameters and fields

### Query parameters

| Name        | Type      | Required | Default | Constraints                   | Description                               |
| :---------- | :-------- | :------- | :------ | :---------------------------- | :---------------------------------------- |
| `PageIndex` | `integer` | No       | `1`     | `> 0` (`ListBuyersValidator`) | 1-based page number to retrieve           |
| `PageSize`  | `integer` | No       | `20`    | `> 0` (`ListBuyersValidator`) | Maximum number of buyer profiles per page |

### Response headers

`ListBuyersEndpoint` applies `WithPaginationHeaders()` (`PaginationHeaderFilter`), which appends two headers on `200 OK` responses:

| Header             | Format                                    | Description                                                                                 |
| :----------------- | :---------------------------------------- | :------------------------------------------------------------------------------------------ |
| `Pagination-Count` | Integer string (for example, `128`)       | Total number of buyer profiles across all pages                                             |
| `Link`             | Comma-separated `<uri>;rel=<rel>` entries | Navigation URIs with `first`, `self`, `last`, and conditional `previous` / `next` relations |

### Response schema (`BuyerDto[]`)

A `200 OK` response body serializes `PagedResult<BuyerDto>` as a JSON array of `BuyerDto` objects.

| Field        | Type             | Required | Constraints | Description                                    |
| :----------- | :--------------- | :------- | :---------- | :--------------------------------------------- |
| `[].id`      | `string`         | Yes      | UUID        | Unique identifier of the buyer profile         |
| `[].name`    | `string \| null` | Yes      | Nullable    | Buyer display name (`null` when unset)         |
| `[].address` | `string \| null` | Yes      | Nullable    | Formatted shipping address (`null` when unset) |

## Error responses

| Code / status           | Condition                                                                                                                    | Recovery behavior                                                  |
| :---------------------- | :--------------------------------------------------------------------------------------------------------------------------- | :----------------------------------------------------------------- |
| `400 Bad Request`       | `PageIndex <= 0` or `PageSize <= 0`, or non-integer paging value (`application/problem+json` `HttpValidationProblemDetails`) | Fix paging parameters to positive integers; do not retry unchanged |
| `401 Unauthorized`      | Missing, expired, or invalid Entra ID bearer token                                                                           | Re-authenticate and retry                                          |
| `403 Forbidden`         | Authenticated caller does not satisfy the `admin` authorization policy                                                       | Authenticate with an administrator account                         |
| `429 Too Many Requests` | Caller exceeded `PerUserRateLimit` or global rate limit (`application/problem+json` + `Retry-After` header)                  | Wait for the `Retry-After` duration before retrying                |
