## List buyer profiles with curl

<CodeGroup>

```bash
curl --request GET \
  "<gateway-url>/ordering/api/v1/buyers?PageIndex=1&PageSize=20" \
  --header "Authorization: Bearer <admin-access-token>" \
  --header "Accept: application/json"
```

</CodeGroup>

Where:

- `<gateway-url>`: Base URL of the BookWorm API Gateway (or direct Ordering API URL `https://localhost:7203` without the `/ordering` prefix).
- `<admin-access-token>`: Entra ID bearer token with the `admin` role and Ordering API scopes.

Expected response (`200 OK` with `Pagination-Count` and `Link` headers):

<CodeGroup>

```json
[
	{
		"id": "66666666-6666-6666-6666-666666666666",
		"name": "Avery Nguyen",
		"address": "10 Example Street, Ben Thanh, Ho Chi Minh City"
	}
]
```

</CodeGroup>

## List buyer profiles with TypeScript

<CodeGroup>

```typescript
type BuyerDto = {
	id: string;
	name: string | null;
	address: string | null;
};

const gatewayUrl = "<gateway-url>";
const accessToken = "<admin-access-token>";
const params = new URLSearchParams({ PageIndex: "1", PageSize: "20" });

const response = await fetch(`${gatewayUrl}/ordering/api/v1/buyers?${params.toString()}`, {
	headers: {
		Authorization: `Bearer ${accessToken}`,
		Accept: "application/json",
	},
});

if (!response.ok) {
	throw new Error(`ListBuyers failed with ${response.status}`);
}

const totalBuyers = Number(response.headers.get("Pagination-Count") ?? "0");
const buyers = (await response.json()) as BuyerDto[];
console.log(`Received ${buyers.length} of ${totalBuyers} buyer(s)`);
```

</CodeGroup>
