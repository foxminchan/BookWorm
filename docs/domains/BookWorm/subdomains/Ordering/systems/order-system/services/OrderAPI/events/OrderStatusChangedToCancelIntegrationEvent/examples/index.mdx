## Publish Order cancellation

[[service|order-api]] publishes this event after an Order transitions from
New to Cancelled, through
[[channel|bookworm.&#123;env&#125;.ordering.order-status-change-to-cancel]].

- `id` identifies this integration event; `creationDate` is its UTC timestamp.
- `orderId` identifies the cancelled Order.
- `basketId` currently contains the Order's Buyer ID, supplied by EventMapper.
- `fullName` and `email` are included as null when unavailable, not omitted.
- `totalMoney` preserves the accepted purchase amount.

</Column>

```csharp OrderStatusChangedToCancelIntegrationEvent.cs
[IntegrationMessageOwner(
    ServiceName = Services.Ordering,
    TopicName = "order-status-change-to-cancel"
)]
[MessageIdentity("BookWorm.Contracts.OrderStatusChangedToCancelIntegrationEvent")]
public sealed record OrderStatusChangedToCancelIntegrationEvent(
    Guid OrderId,
    Guid BasketId,
    string? FullName,
    string? Email,
    decimal TotalMoney
) : IntegrationEvent;
```

```csharp EventMapper.cs
OrderCancelledEvent orderCancelledEvent =>
    new OrderStatusChangedToCancelIntegrationEvent(
        (Guid)orderCancelledEvent.Order.Id,
        (Guid)orderCancelledEvent.Order.BuyerId,
        fullName,
        email,
        orderCancelledEvent.Order.TotalPrice
    )
```

## Distinguish cancellation from recovery

The example shows the camelCase JSON data inside the BookWorm
CloudEvents-compatible envelope. This event reports a business-status
transition, not a soft deletion or a request to cancel. Finance's
[[command|CancelOrderCommand]] and basket-cleanup failure recovery are separate
messages and behaviors.

Finance's saga copies the event details, sets its state to Cancelled, and
finalizes. Notification requires both email and full name to be nonblank,
so the null values above produce no cancellation notification command.
This excerpt shows the outgoing-message selection after the state update:

<CodeGroup dropdown>

```csharp OrderSaga.cs
MarkCompleted();

var messages = new OutgoingMessages();

if (CanSendNotification)
{
    messages.Add(new CancelOrderCommand(OrderId, FullName!, Email!, EffectiveTotalMoney));
}

return messages;
```
