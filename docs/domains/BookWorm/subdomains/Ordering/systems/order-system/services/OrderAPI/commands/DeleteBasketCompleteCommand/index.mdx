## Overview

Finance publishes this command after successful basket cleanup.
[[service|order-api]] logs the outcome without changing the
[[entity|order]]'s business status. Finance saga progress and Order status
are separate lifecycles.

This command is distinct from
[[event|BasketDeletedCompleteIntegrationEvent]], which Basket publishes as
its own deletion result.

## Channel

[[channel|bookworm.&#123;env&#125;.finance.delete-basket-complete]]

## Schema

The payload contains `id`, `creationDate`, `orderId`, and `totalMoney`.
The schema describes camelCase JSON data inside the BookWorm
CloudEvents-compatible envelope, not the complete transport envelope.
