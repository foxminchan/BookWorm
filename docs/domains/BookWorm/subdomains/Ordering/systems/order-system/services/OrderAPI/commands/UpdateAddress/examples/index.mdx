## Update the authenticated buyer's address through API Gateway

<CodeGroup>

```bash
curl --request PATCH "https://<gateway-host>/ordering/api/v1/buyers/address" \
  --header "Authorization: Bearer <customer-access-token>" \
  --header "Content-Type: application/json" \
  --data '{
    "street": "20 New Street",
    "city": "Ben Thanh",
    "province": "Ho Chi Minh City"
  }'
```

</CodeGroup>

Where:

- `<gateway-host>`: API Gateway hostname (or `localhost:7203` with `/api/v1/buyers/address` when calling Ordering API directly).
- `<customer-access-token>`: Entra ID JWT with role `customer` and scopes `ordering_read` and `ordering_write`.

Expected response (`200 OK`):

<CodeGroup>

```json
{
	"id": "0193f1a2-6666-7d8e-9f01-23456789abcd",
	"name": "Avery Nguyen",
	"address": "20 New Street, Ben Thanh, Ho Chi Minh City"
}
```

</CodeGroup>

## Validation failure response (`400 Bad Request`)

<CodeGroup>

```json
{
	"title": "One or more validation errors occurred.",
	"status": 400,
	"errors": {
		"City": ["'City' must not be empty."]
	}
}
```

</CodeGroup>
