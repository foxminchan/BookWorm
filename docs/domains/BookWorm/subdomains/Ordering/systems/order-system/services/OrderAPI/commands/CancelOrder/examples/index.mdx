## 1. Cancel an Order

Provide the Order UUID and an idempotency key. The operation has no request
body.

<CodeGroup dropdown>

```sh
curl --request PATCH "$BASE_URL/api/v1/orders/44444444-4444-4444-4444-444444444444/cancel" \
  --header "Authorization: Bearer <access-token>" \
  --header "x-request-id: cancel-order-2026-001"
```

</CodeGroup>

The same request from TypeScript:

<CodeGroup dropdown>

```ts cancel-order.ts
const baseUrl = "https://api.example.com";
const accessToken = "<access-token>";
const orderId = "44444444-4444-4444-4444-444444444444";
const response = await fetch(`${baseUrl}/api/v1/orders/${orderId}/cancel`, {
	method: "PATCH",
	headers: {
		Authorization: `Bearer ${accessToken}`,
		"x-request-id": "cancel-order-2026-001",
	},
});

if (response.status === 404) {
	throw new Error("Order was not found or is not accessible");
}
if (!response.ok) {
	throw new Error(`CancelOrder failed with ${response.status}`);
}

const order = await response.json();
console.log(order);
```

</CodeGroup>
