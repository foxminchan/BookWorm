## Overview

[[service|order-api]] publishes this event after placing an
[[entity|order]]. It carries the accepted Order's ID, total purchase amount,
and customer details for Finance. It does not confirm payment settlement,
basket cleanup, or Order completion.

## Channel

[[channel|bookworm.&#123;env&#125;.ordering.user-checked-out]]

## Payload

The payload contains `id`, `creationDate`, `orderId`, `basketId`, nullable
`fullName` and `email`, and `totalMoney`. All fields are required by the
AsyncAPI schema, including the nullable fields.

The current EventMapper supplies the Order's Buyer ID as `basketId`.
Consumers must not assume this field is independently resolved basket data.
