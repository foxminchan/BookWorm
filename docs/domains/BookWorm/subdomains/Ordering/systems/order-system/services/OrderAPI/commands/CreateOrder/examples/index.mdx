## Create an order through API Gateway

<CodeGroup>

```bash
curl --request POST "https://<gateway-host>/ordering/api/v1/orders" \
  --header "Authorization: Bearer <access-token>" \
  --header "x-request-id: <request-id>"
```

</CodeGroup>

Where:

- `<gateway-host>`: API Gateway hostname (or `localhost:7203` with `/api/v1/orders` when calling Ordering API directly).
- `<access-token>`: Entra ID JWT with role `customer` or `admin` and scopes `ordering_read` and `ordering_write`.
- `<request-id>`: Unique client-generated idempotency key (for example, a UUID v7).

Expected response (`201 Created`, with header `Location: /api/v1/orders/0193f1a2-1111-7d8e-9f01-23456789abcd`):

<CodeGroup>

```json
"0193f1a2-1111-7d8e-9f01-23456789abcd"
```

</CodeGroup>
