## Retrieve an order with curl

<CodeGroup>

```bash
curl --request GET \
  "<gateway-url>/ordering/api/v1/orders/44444444-4444-4444-4444-444444444444" \
  --header "Authorization: Bearer <access-token>" \
  --header "Accept: application/json"
```

</CodeGroup>

Where:

- `<gateway-url>`: Base URL of the BookWorm API Gateway (or direct Ordering API URL `https://localhost:7203` without the `/ordering` prefix).
- `<access-token>`: Entra ID bearer token for the owning customer or an administrator.

Expected response (`200 OK`):

<CodeGroup>

```json
{
	"id": "44444444-4444-4444-4444-444444444444",
	"date": "2026-11-03T10:00:00Z",
	"total": 33.98,
	"status": "New",
	"items": [
		{
			"id": "55555555-5555-5555-5555-555555555555",
			"quantity": 2,
			"price": 16.99,
			"name": "Example book"
		}
	]
}
```

</CodeGroup>

Expected response when unavailable (`404 Not Found`):

<CodeGroup>

```json
{
	"title": "Not Found",
	"status": 404
}
```

</CodeGroup>

## Retrieve an order with TypeScript

<CodeGroup>

```typescript
type OrderDetailDto = {
	id: string;
	date: string;
	total: number;
	status: "New" | "Cancelled" | "Completed";
	items: Array<{
		id: string;
		quantity: number;
		price: number;
		name: string | null;
	}>;
};

const gatewayUrl = "<gateway-url>";
const accessToken = "<access-token>";
const orderId = "44444444-4444-4444-4444-444444444444";

const response = await fetch(`${gatewayUrl}/ordering/api/v1/orders/${orderId}`, {
	headers: {
		Authorization: `Bearer ${accessToken}`,
		Accept: "application/json",
	},
});

if (response.status === 404) {
	throw new Error("Order was not found or is not accessible");
}
if (!response.ok) {
	throw new Error(`GetOrder failed with ${response.status}`);
}

const order = (await response.json()) as OrderDetailDto;
console.log(`${order.status}: ${order.total}`);
```

</CodeGroup>
