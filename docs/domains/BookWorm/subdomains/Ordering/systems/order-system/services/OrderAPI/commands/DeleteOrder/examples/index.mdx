## Soft-delete an order through API Gateway

<CodeGroup>

```bash
curl --request DELETE "https://<gateway-host>/ordering/api/v1/orders/<order-id>" \
  --header "Authorization: Bearer <admin-access-token>"
```

</CodeGroup>

Where:

- `<gateway-host>`: API Gateway hostname (or `localhost:7203` with `/api/v1/orders/<order-id>` when calling Ordering API directly).
- `<order-id>`: UUID of the order to soft-delete.
- `<admin-access-token>`: Entra ID JWT with role `admin` and scopes `ordering_read` and `ordering_write`.

Expected response:

<CodeGroup>

```text
HTTP/1.1 204 No Content
```

</CodeGroup>
