## Overview

Cancels an [[entity|order]] through the Order API. The transition is available
only while the Order is **New**; cancellation raises the corresponding Order
lifecycle event for downstream coordination.

<NodeGraph />

## Contract

Provide the Order UUID in the `{orderId}` path parameter and a required
`x-request-id` idempotency header. The operation has no request body.

`200 OK` returns the updated `OrderDetailDto`. `404 Not Found` is returned
when the Order cannot be found within the caller's permitted scope.
