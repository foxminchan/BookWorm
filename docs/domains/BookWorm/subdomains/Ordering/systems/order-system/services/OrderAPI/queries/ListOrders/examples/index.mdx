## List new orders with curl

<CodeGroup>

```bash
curl --request GET \
  "<gateway-url>/ordering/api/v1/orders?PageIndex=1&PageSize=20&Status=New" \
  --header "Authorization: Bearer <access-token>" \
  --header "Accept: application/json"
```

</CodeGroup>

Where:

- `<gateway-url>`: Base URL of the BookWorm API Gateway (or direct Ordering API URL `https://localhost:7203` without the `/ordering` prefix).
- `<access-token>`: Entra ID bearer token for a signed-in customer or administrator.

Expected response (`200 OK` with `Pagination-Count` and `Link` headers):

<CodeGroup>

```json
[
	{
		"id": "44444444-4444-4444-4444-444444444444",
		"date": "2026-11-03T10:00:00Z",
		"total": 33.98,
		"status": "New"
	}
]
```

</CodeGroup>

Expected validation error (`400 Bad Request`):

<CodeGroup>

```json
{
	"title": "One or more validation errors occurred.",
	"status": 400,
	"errors": {
		"Status": ["The value is not valid."]
	}
}
```

</CodeGroup>

## List new orders with TypeScript

<CodeGroup>

```typescript
type OrderDto = {
	id: string;
	date: string;
	total: number;
	status: "New" | "Cancelled" | "Completed";
};

const gatewayUrl = "<gateway-url>";
const accessToken = "<access-token>";
const params = new URLSearchParams({
	PageIndex: "1",
	PageSize: "20",
	Status: "New",
});

const response = await fetch(`${gatewayUrl}/ordering/api/v1/orders?${params.toString()}`, {
	headers: {
		Authorization: `Bearer ${accessToken}`,
		Accept: "application/json",
	},
});

if (response.status === 400) {
	throw new Error("ListOrders validation failed");
}
if (!response.ok) {
	throw new Error(`ListOrders failed with ${response.status}`);
}

const totalOrders = Number(response.headers.get("Pagination-Count") ?? "0");
const orders = (await response.json()) as OrderDto[];
console.log(`Received ${orders.length} of ${totalOrders} order(s)`);
```

</CodeGroup>
