The `CreateBuyer` command (`POST /api/v1/buyers`) creates a `Buyer` profile in **Ordering API** (v1.0.0) using the supplied shipping address while deriving the buyer's identifier and name from the authenticated Microsoft Entra ID token. External callers reach this endpoint through the YARP **API Gateway** at `/ordering/api/v1/buyers`.

## Behavior and side effects

- **Identity derivation:** `CreateBuyerHandler` extracts `BuyerId` from `ClaimTypes.NameIdentifier` (must be a valid GUID) and `Name` from `ClaimConstants.Name` (`"name"` claim), falling back to `"anonymous"` if the name claim is absent. `BuyerConfiguration` constrains the `name` column to 20 characters (`DataSchemaLength.Small`).
- **Persistence:** Persists the `Buyer` aggregate and its owned `Address` value object to PostgreSQL (`orderingdb`) inside a `[Transactional]` unit of work. Emits no domain events or Kafka integration events.
- **PII redaction:** `Street`, `City`, and `Province` carry `[property: PIIData]` so structured logging redacts address fields automatically.
- **Idempotency key lifecycle:** `IdempotencyEndpointFilter` claims `POST:{path}:{x-request-id}` in Redis for 3600 seconds. Reusing the same `x-request-id` returns `409 Conflict`. On HTTP `5xx` or an unhandled exception, the filter deletes the key so retries can proceed.

`CreateBuyerHandler` derives the buyer ID from the authenticated user's ID, so a second request for that user can collide with the existing primary key even when its `x-request-id` is new. `GlobalExceptionHandler` does not map PostgreSQL/EF persistence exceptions specially; an unhandled database exception falls through to HTTP `500` with the generic problem title. This is inferred from the source exception mapping, not a live database test.

## Error responses

| Code / status               | Condition                                                                                                                                                                           | Recovery behavior                                                                                    |
| :-------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------- |
| `400 Bad Request`           | Missing `x-request-id` header, empty/whitespace address field, field exceeding 50 characters (`ValidationProblemDetails`), or non-GUID `NameIdentifier` claim (`ArgumentException`) | Fix headers, payload fields, or token claims; do not retry unchanged.                                |
| `401 Unauthorized`          | Missing, expired, or invalid Entra ID bearer token                                                                                                                                  | Acquire a fresh Entra ID access token and retry.                                                     |
| `403 Forbidden`             | Authenticated caller lacks `customer`/`admin` role or `ordering_read`/`ordering_write` scopes                                                                                       | Request the required Entra ID role and scopes before retrying.                                       |
| `409 Conflict`              | `x-request-id` was already processed for this path within the 3600-second Redis TTL (`ProblemDetails`)                                                                              | Treat as a duplicate submission and fetch the buyer profile with `GET /ordering/api/v1/buyers/{id}`. |
| `429 Too Many Requests`     | Caller exceeded `PerUserRateLimit` or global rate limits                                                                                                                            | Wait for the `Retry-After` header interval before retrying.                                          |
| `500 Internal Server Error` | Unhandled persistence error (such as duplicate `BuyerId` primary key or `Name` exceeding 20 characters)                                                                             | Inspect Ordering API logs and verify whether the buyer profile already exists.                       |
