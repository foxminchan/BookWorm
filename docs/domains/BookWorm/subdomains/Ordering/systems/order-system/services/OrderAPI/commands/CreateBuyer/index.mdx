## Overview

Creates a [[entity|buyer]] profile associated with the authenticated
customer's identity. The request supplies the Buyer's address; the service
derives the Buyer ID and name from the authenticated identity.

<NodeGraph />

## Contract

Send an `application/json` body containing the required `street`, `city`, and
`province` fields. `201 Created` returns the Buyer ID as a JSON UUID.
`400 Bad Request` returns validation problem details.
