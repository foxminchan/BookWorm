## Overview

Updates the address on the authenticated customer's [[entity|buyer]] profile.
The operation does not accept a Buyer ID; the service identifies the Buyer
from the authenticated request.

<NodeGraph />

## Contract

Send an `application/json` body containing the required `street`, `city`, and
`province` fields. `200 OK` returns the updated `BuyerDto`. `400 Bad Request`
indicates validation failure, and `404 Not Found` indicates that the Buyer
profile does not exist.
