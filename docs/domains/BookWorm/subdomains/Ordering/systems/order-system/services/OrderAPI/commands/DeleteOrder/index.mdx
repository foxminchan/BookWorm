## Overview

Soft-deletes an [[entity|order]] by setting its deletion flag. This operation
is restricted to administrators and does not transition the Order's business
status.

<NodeGraph />

## Contract

Provide the Order identifier in the `{id}` path parameter. The operation has
no request body. `204 No Content` confirms the deletion; `404 Not Found`
indicates that no matching Order exists.
