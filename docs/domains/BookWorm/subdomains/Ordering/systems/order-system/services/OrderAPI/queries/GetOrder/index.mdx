## Overview

Retrieves an [[entity|order]] by identifier. Customers can retrieve their own
Orders, while administrators can retrieve Orders across Buyers.

<NodeGraph />

## Query parameters and response

Provide the Order identifier in the `{id}` path parameter. A `200 OK` response
returns an `OrderDetailDto` with the Order ID, date, total, status, and item
details. `404 Not Found` returns `ProblemDetails` when the Order does not exist
or is outside the caller's permitted scope.

## Query using CURL

<CodeGroup dropdown>

```sh get-order.sh
curl -H "Authorization: Bearer <access-token>" \
  "https://api.example.com/api/v1/orders/<order-id>"
```

</CodeGroup>
