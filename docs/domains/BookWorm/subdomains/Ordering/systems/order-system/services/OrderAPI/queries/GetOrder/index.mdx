`GetOrder` queries **Ordering API** (`GET /api/v1/orders/{id}`) to retrieve a single order's header metadata, purchase-time unit prices, quantities, and book display names. Standard customers can retrieve only their own orders, while administrators (`admin` role) can retrieve any order; nonexistent and out-of-scope orders both return `404 Not Found`.

## Overview

| Property                     | Value                                                                                                                                                                              |
| :--------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Owner**                    | Ordering bounded context (**Ordering API**, Aspire resource `ordering`)                                                                                                            |
| **Source**                   | `src/Services/Ordering/BookWorm.Ordering/Features/Orders/Get/GetOrderEndpoint.cs`, `GetOrderQuery.cs`                                                                              |
| **Protocol / format**        | HTTP `GET /api/v1/orders/{id}` (via API Gateway: `GET /ordering/api/v1/orders/{id}`), `ApiVersions.V1`, JSON (`application/json`)                                                  |
| **Authentication**           | Microsoft Entra ID JWT required (`customer` or `admin` role; scopes `ordering_read`, `ordering_write`)                                                                             |
| **Rate limiting**            | `PerUserRateLimit` token bucket (30 token limit, 20 tokens per 10 seconds, queue limit 5) plus global IP/concurrency limiters                                                      |
| **Persistence & enrichment** | Reads order and purchase-time prices from PostgreSQL (`orderingdb`, EF Core); enriches `items[].name` via **Catalog API** gRPC `book.v1.BookGrpcService/GetBooks` when items exist |
| **Contract version**         | `1.0.0`                                                                                                                                                                            |

## Parameters and fields

### Path parameters

| Name | Type                 | Required | Default | Constraints | Description                                |
| :--- | :------------------- | :------- | :------ | :---------- | :----------------------------------------- |
| `id` | `string` (`OrderId`) | Yes      | —       | Valid UUID  | Unique identifier of the order to retrieve |

### Response schema (`OrderDetailDto`)

A `200 OK` response returns an `OrderDetailDto` JSON object.

| Field              | Type             | Required | Constraints                           | Description                                                                    |
| :----------------- | :--------------- | :------- | :------------------------------------ | :----------------------------------------------------------------------------- |
| `id`               | `string`         | Yes      | UUID                                  | Unique identifier of the order                                                 |
| `date`             | `string`         | Yes      | ISO 8601 `date-time`                  | UTC timestamp when the order was placed                                        |
| `total`            | `number`         | Yes      | Decimal currency amount               | Total order amount computed from recorded item prices and quantities           |
| `status`           | `string`         | Yes      | Enum: `New`, `Cancelled`, `Completed` | Current lifecycle status of the order                                          |
| `items`            | `OrderItemDto[]` | Yes      | Array                                 | Line items recorded at checkout                                                |
| `items[].id`       | `string`         | Yes      | UUID                                  | Catalog book identifier                                                        |
| `items[].quantity` | `integer`        | Yes      | `int32`                               | Purchased unit quantity                                                        |
| `items[].price`    | `number`         | Yes      | Decimal currency amount               | Unit price locked at checkout (does not change if Catalog prices update later) |
| `items[].name`     | `string \| null` | No       | Nullable                              | Book title enriched via Catalog API gRPC `GetBooks` (`null` if unavailable)    |

## Error responses

| Code / status           | Condition                                                                                                     | Recovery behavior                                                                   |
| :---------------------- | :------------------------------------------------------------------------------------------------------------ | :---------------------------------------------------------------------------------- |
| `401 Unauthorized`      | Missing, expired, or invalid Entra ID bearer token                                                            | Re-authenticate and retry                                                           |
| `403 Forbidden`         | Authenticated principal lacks Ordering API roles or scopes                                                    | Request a token with `customer` or `admin` role and Ordering scopes                 |
| `404 Not Found`         | Order does not exist or belongs to another buyer outside the caller's role scope (`application/problem+json`) | Display a not-found state; do not assume whether the ID belongs to another customer |
| `429 Too Many Requests` | Caller exceeded `PerUserRateLimit` or global rate limit (`application/problem+json` + `Retry-After` header)   | Wait for the `Retry-After` duration before retrying                                 |
