## Overview

Deletes a [[entity|buyer]] profile by its identifier. The endpoint requires
the administrator authorization policy.

<NodeGraph />

## Contract

Provide the Buyer identifier in the `{id}` path parameter. The operation has
no request body. `204 No Content` confirms deletion; `404 Not Found` indicates
that no matching Buyer exists.
