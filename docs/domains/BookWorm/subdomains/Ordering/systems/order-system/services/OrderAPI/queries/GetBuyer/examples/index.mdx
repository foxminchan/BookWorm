## Retrieve a buyer profile with curl

<CodeGroup>

```bash
curl --request GET \
  "<gateway-url>/ordering/api/v1/buyers/me?Id=<buyer-id>" \
  --header "Authorization: Bearer <access-token>" \
  --header "Accept: application/json"
```

</CodeGroup>

Where:

- `<gateway-url>`: Base URL of the BookWorm API Gateway (or direct Ordering API URL `https://localhost:7203` without the `/ordering` prefix).
- `<buyer-id>`: Valid UUID (used directly for `admin` callers; required for parameter binding on customer calls).
- `<access-token>`: Entra ID bearer token authorized for Ordering API.

Expected response (`200 OK`):

<CodeGroup>

```json
{
	"id": "66666666-6666-6666-6666-666666666666",
	"name": "Avery Nguyen",
	"address": "10 Example Street, Ben Thanh, Ho Chi Minh City"
}
```

</CodeGroup>

## Retrieve a buyer profile with TypeScript

<CodeGroup>

```typescript
type BuyerDto = {
	id: string;
	name: string | null;
	address: string | null;
};

const gatewayUrl = "<gateway-url>";
const accessToken = "<access-token>";
const buyerId = "66666666-6666-6666-6666-666666666666";

const params = new URLSearchParams({ Id: buyerId });
const response = await fetch(`${gatewayUrl}/ordering/api/v1/buyers/me?${params.toString()}`, {
	headers: {
		Authorization: `Bearer ${accessToken}`,
		Accept: "application/json",
	},
});

if (response.status === 404) {
	throw new Error("Buyer profile was not found");
}
if (!response.ok) {
	throw new Error(`GetBuyer failed with ${response.status}`);
}

const buyer = (await response.json()) as BuyerDto;
console.log(buyer.name);
```

</CodeGroup>
