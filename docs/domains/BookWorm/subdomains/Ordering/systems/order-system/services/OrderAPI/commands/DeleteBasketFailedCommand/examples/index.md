## 1. Compensate Order When Basket Cleanup Fails

When **Basket API** emits `BasketDeletedFailedIntegrationEvent` (or checkout saga compensation runs), **Finance** publishes `DeleteBasketFailedCommand` so **Ordering API** soft-deletes the order.

### Payload details

- `id`: UUIDv7 generated by `IntegrationEvent` (`Guid.CreateVersion7()`).
- `creationDate`: UTC ISO 8601 timestamp (`DateTime.UtcNow`).
- `basketId`: UUID of the basket whose cleanup failed.
- `email`: Customer email (`string | null`).
- `orderId`: UUID of the affected order (Kafka partition key).
- `totalMoney`: Order total (`decimal`).

### Example payload

```json
{
	"id": "01960a1b-8a02-7b00-8a9b-0c1d2e3f4f02",
	"creationDate": "2026-11-25T16:15:03Z",
	"basketId": "01960a1b-2c3d-7e4f-8a9b-0c1d2e3f4a01",
	"email": "minh.nguyen@bookworm.dev",
	"orderId": "01960a1b-3c4d-7e00-8a9b-0c1d2e3f4a99",
	"totalMoney": 59.98
}
```

### Using this example

**Ordering API** idempotently soft-deletes the order in PostgreSQL so the failed checkout does not leave a dangling active order.

```csharp EventBus.cs
using BookWorm.Chassis.EventBus;
using BookWorm.Chassis.EventBus.Idempotency;
using BookWorm.Contracts;
using Wolverine;
using Wolverine.Attributes;

// Integration command contract (BookWorm.Contracts)
[IntegrationMessageOwner(ServiceName = Services.Finance, TopicName = "delete-basket-failed")]
[MessageIdentity("BookWorm.Contracts.DeleteBasketFailedCommand")]
public sealed record DeleteBasketFailedCommand(
    Guid BasketId,
    string? Email,
    Guid OrderId,
    decimal TotalMoney
) : IntegrationEvent;

// 1. Publishing from Finance Durable Functions compensation activity via Wolverine IMessageBus
await bus.PublishAsync(
    new DeleteBasketFailedCommand(
        Guid.Parse("01960a1b-2c3d-7e4f-8a9b-0c1d2e3f4a01"),
        "minh.nguyen@bookworm.dev",
        Guid.Parse("01960a1b-3c4d-7e00-8a9b-0c1d2e3f4a99"),
        59.98m
    )
);

// 2. Consuming in Ordering API with Wolverine + IIntegrationEventIdempotencyGuard
internal sealed class DeleteBasketFailedCommandHandler(
    IOrderRepository repository,
    IIntegrationEventIdempotencyGuard idempotencyGuard
)
{
    [WolverineHandler]
    public async Task Handle(DeleteBasketFailedCommand command, CancellationToken cancellationToken)
    {
        await idempotencyGuard.ExecuteAsync(
            command.Id,
            nameof(DeleteBasketFailedCommandHandler),
            async ct =>
            {
                var order = await repository.GetByIdAsync(command.OrderId, ct);
                if (order is not null)
                {
                    order.Delete();
                    await repository.UnitOfWork.SaveEntitiesAsync(ct);
                }
            },
            cancellationToken: cancellationToken
        );
    }
}
```
