## Delete a buyer profile through API Gateway

<CodeGroup>

```bash
curl --request DELETE "https://<gateway-host>/ordering/api/v1/buyers/<buyer-id>" \
  --header "Authorization: Bearer <admin-access-token>"
```

</CodeGroup>

Where:

- `<gateway-host>`: API Gateway hostname (or `localhost:7203` with `/api/v1/buyers/<buyer-id>` when calling Ordering API directly).
- `<buyer-id>`: UUID of the buyer profile to delete.
- `<admin-access-token>`: Entra ID JWT with role `admin` and scopes `ordering_read` and `ordering_write`.

Expected response:

<CodeGroup>

```text
HTTP/1.1 204 No Content
```

</CodeGroup>
