## Complete an order through API Gateway

<CodeGroup>

```bash
curl --request PATCH "https://<gateway-host>/ordering/api/v1/orders/<order-id>/complete" \
  --header "Authorization: Bearer <access-token>" \
  --header "x-request-id: <request-id>"
```

</CodeGroup>

Where:

- `<gateway-host>`: API Gateway hostname (or `localhost:7203` with `/api/v1/orders/<order-id>/complete` when calling Ordering API directly).
- `<order-id>`: UUID of the order in `New` status.
- `<access-token>`: Entra ID JWT with role `customer` or `admin` and scopes `ordering_read` and `ordering_write`.
- `<request-id>`: Unique client-generated idempotency key (for example, a UUID v7).

Expected response (`200 OK`):

<CodeGroup>

```json
{
	"id": "0193f1a2-1111-7d8e-9f01-23456789abcd",
	"date": "2026-11-25T10:00:00Z",
	"total": 33.98,
	"status": "Completed",
	"items": [
		{
			"id": "0193f1a2-5555-7d8e-9f01-23456789abcd",
			"quantity": 2,
			"price": 16.99,
			"name": null
		}
	]
}
```

</CodeGroup>
