## 1. Record Successful Post-Checkout Basket Cleanup

After **Basket API** emits `BasketDeletedCompleteIntegrationEvent`, **Finance**'s `OrderOrchestrator` publishes `DeleteBasketCompleteCommand` to **Ordering API** to log cleanup completion.

### Payload details

- `id`: UUIDv7 generated by `IntegrationEvent` (`Guid.CreateVersion7()`).
- `creationDate`: UTC ISO 8601 timestamp (`DateTime.UtcNow`).
- `orderId`: UUID of the order whose basket cleanup succeeded (Kafka partition key).
- `totalMoney`: Non-negative order total (`decimal`).

### Example payload

```json
{
	"id": "01960a1b-8a01-7b00-8a9b-0c1d2e3f4f01",
	"creationDate": "2026-11-25T16:15:01Z",
	"orderId": "01960a1b-3c4d-7e00-8a9b-0c1d2e3f4a99",
	"totalMoney": 59.98
}
```

### Using this example

**Ordering API** logs the completion event for operational visibility and leaves `Order.Status` unchanged.

```csharp EventBus.cs
using BookWorm.Chassis.EventBus;
using BookWorm.Contracts;
using Wolverine;
using Wolverine.Attributes;

// Integration command contract (BookWorm.Contracts)
[IntegrationMessageOwner(ServiceName = Services.Finance, TopicName = "delete-basket-complete")]
[MessageIdentity("BookWorm.Contracts.DeleteBasketCompleteCommand")]
public sealed record DeleteBasketCompleteCommand(Guid OrderId, decimal TotalMoney)
    : IntegrationEvent;

// 1. Publishing from Finance Durable Functions activity via Wolverine IMessageBus
await bus.PublishAsync(
    new DeleteBasketCompleteCommand(
        Guid.Parse("01960a1b-3c4d-7e00-8a9b-0c1d2e3f4a99"),
        59.98m
    )
);

// 2. Consuming in Ordering API via Wolverine
internal sealed class DeleteBasketCompleteCommandHandler(
    ILogger<DeleteBasketCompleteCommandHandler> logger
)
{
    [WolverineHandler]
    public Task Handle(DeleteBasketCompleteCommand command, CancellationToken cancellationToken)
    {
        logger.LogInformation(
            "Basket deletion completed for Order {OrderId}, Amount: {TotalMoney}",
            command.OrderId,
            command.TotalMoney
        );
        return Task.CompletedTask;
    }
}
```
