`GetBuyer` queries **Ordering API** (`GET /api/v1/buyers/me`) to retrieve a buyer's profile (`id`, `name`, and `address`). Callers with the `admin` role retrieve the profile specified by the `Id` query parameter; all other authenticated callers are resolved to the buyer linked to their Microsoft Entra ID `NameIdentifier` claim.

## Overview

| Property              | Value                                                                                                                         |
| :-------------------- | :---------------------------------------------------------------------------------------------------------------------------- |
| **Owner**             | Ordering bounded context (**Ordering API**, Aspire resource `ordering`)                                                       |
| **Source**            | `src/Services/Ordering/BookWorm.Ordering/Features/Buyers/Get/GetBuyerEndpoint.cs`, `GetBuyerQuery.cs`                         |
| **Protocol / format** | HTTP `GET /api/v1/buyers/me` (via API Gateway: `GET /ordering/api/v1/buyers/me`), `ApiVersions.V1`, JSON (`application/json`) |
| **Authentication**    | Microsoft Entra ID JWT required (`customer` or `admin` role; scopes `ordering_read`, `ordering_write`)                        |
| **Rate limiting**     | `PerUserRateLimit` token bucket (30 token limit, 20 tokens per 10 seconds, queue limit 5) plus global IP/concurrency limiters |
| **Backing store**     | PostgreSQL (`orderingdb`, EF Core)                                                                                            |
| **Contract version**  | `1.0.0`                                                                                                                       |

## Parameters and fields

### Query parameters

| Name | Type            | Required | Default | Constraints         | Description                                                                                                                              |
| :--- | :-------------- | :------- | :------ | :------------------ | :--------------------------------------------------------------------------------------------------------------------------------------- |
| `Id` | `string` (UUID) | Yes      | —       | Valid UUID (`Guid`) | Buyer identifier requested by `admin` callers; ignored for non-admin callers whose buyer ID is resolved from `ClaimTypes.NameIdentifier` |

:::note
Because `GetBuyerQuery` binds `Id` as a non-nullable `Guid`, non-admin clients must still supply a valid UUID query parameter even though Ordering API resolves their own authenticated buyer ID.
:::

### Response schema (`BuyerDto`)

A `200 OK` response returns a `BuyerDto` JSON object.

| Field     | Type             | Required | Constraints | Description                                    |
| :-------- | :--------------- | :------- | :---------- | :--------------------------------------------- |
| `id`      | `string`         | Yes      | UUID        | Unique identifier of the buyer profile         |
| `name`    | `string \| null` | Yes      | Nullable    | Buyer display name (`null` when unset)         |
| `address` | `string \| null` | Yes      | Nullable    | Formatted shipping address (`null` when unset) |

## Error responses

| Code / status           | Condition                                                                                                   | Recovery behavior                                                       |
| :---------------------- | :---------------------------------------------------------------------------------------------------------- | :---------------------------------------------------------------------- |
| `400 Bad Request`       | Missing or malformed `Id` UUID query parameter (`application/problem+json`)                                 | Supply a valid UUID in the `Id` query parameter; do not retry unchanged |
| `401 Unauthorized`      | Missing, expired, or invalid Entra ID bearer token                                                          | Re-authenticate and retry                                               |
| `403 Forbidden`         | Authenticated principal lacks Ordering API roles or scopes                                                  | Request a token with `customer` or `admin` role and Ordering scopes     |
| `404 Not Found`         | No buyer profile exists for the resolved buyer ID (`application/problem+json`)                              | Prompt the user to create a buyer profile via `CreateBuyer`             |
| `429 Too Many Requests` | Caller exceeded `PerUserRateLimit` or global rate limit (`application/problem+json` + `Retry-After` header) | Wait for the `Retry-After` duration before retrying                     |
