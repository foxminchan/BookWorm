## Overview

Retrieves a [[entity|buyer]] profile from the `/buyers/me` endpoint.
Administrators may retrieve another user's profile; other callers are resolved
to the Buyer associated with their authenticated identity.

<NodeGraph />

## Query parameters and response

The OpenAPI contract requires an `Id` UUID query parameter. A `200 OK`
response returns a `BuyerDto` with the Buyer ID, name, and address.
`404 Not Found` returns `ProblemDetails` when the resolved Buyer profile does
not exist.

## Query using CURL

<CodeGroup dropdown>

```sh get-buyer.sh
curl -H "Authorization: Bearer <access-token>" \
  "https://api.example.com/api/v1/buyers/me?Id=<buyer-id>"
```
