## 1. Initiate Checkout Saga After Order Creation

When `CreateOrder` persists a new order in PostgreSQL, **Ordering API** dispatches `UserCheckedOutIntegrationEvent` via `IEventDispatcher` to start **Finance**'s `OrderOrchestrator` Durable Functions saga.

### Payload details

- `id`: UUIDv7 generated by `IntegrationEvent` (`Guid.CreateVersion7()`).
- `creationDate`: UTC ISO 8601 timestamp (`DateTime.UtcNow`).
- `orderId`: UUID of the newly created order (Kafka partition key).
- `basketId`: UUID serialized as `basketId` (supplied from `Order.BuyerId` by `OrderEventMapper`).
- `fullName`: Customer name (`string | null`).
- `email`: Customer email (`string | null`).
- `totalMoney`: Order total (`decimal`).

### Example payload

```json
{
	"id": "01960a1b-9003-7c00-8a9b-0c1d2e3f4g03",
	"creationDate": "2026-11-25T16:14:57Z",
	"orderId": "01960a1b-3c4d-7e00-8a9b-0c1d2e3f4a99",
	"basketId": "01960a1b-2c3d-7e4f-8a9b-0c1d2e3f4a01",
	"fullName": "Minh Nguyen",
	"email": "minh.nguyen@bookworm.dev",
	"totalMoney": 59.98
}
```

### Using this example

**Ordering API** publishes `UserCheckedOutIntegrationEvent` to `bookworm.{env}.ordering.user-checkout`; **Finance** starts a new `OrderOrchestrator` instance keyed by `orderId` and dispatches `PlaceOrderCommand`.
