## Overview

The Order aggregate records the authenticated Buyer's purchase from the basket
and Catalog data available at checkout. It starts as **New** and can transition
to **Completed** or **Cancelled**; both outcomes are terminal.

Each [[entity|order-item]] retains the referenced book ID, selected purchase-time
price, and quantity. The Order total is calculated from those item values, so
later Catalog price changes do not rewrite the accepted purchase.

The `isDeleted` flag represents a soft deletion and does not change `status`.
Finance's saga states, basket-deletion outcomes, and notification delivery are
separate from this aggregate's lifecycle.
