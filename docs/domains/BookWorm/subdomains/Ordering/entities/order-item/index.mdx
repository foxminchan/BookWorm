`OrderItem` is a child entity of the `Order` aggregate that records one book, its quantity, and its purchase-time unit price. Ordering API persists it in PostgreSQL (`orderingdb`).

## Invariants and behavior

- **Positive quantity:** The constructor throws `OrderingDomainException("Quantity must be greater than zero")` when `quantity <= 0`.
- **Non-negative price:** The constructor throws `OrderingDomainException("Price must be greater than or equal to zero")` when `price < 0`.
- **One line per book:** A unique index on `(book_id, order_id)` prevents two lines for the same book in one order.
- **Line total:** `GetTotalPrice()` returns `price * quantity`. `Order.totalPrice` sums these values.
- **Parent visibility:** A global query filter (`!e.Order!.IsDeleted`) hides items of soft-deleted orders.
- **Price snapshot:** `price` does not change when Catalog prices change.
