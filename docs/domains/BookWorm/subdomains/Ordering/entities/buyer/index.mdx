`Buyer` is the Ordering aggregate root for a customer's ordering profile and delivery address. Ordering API owns it and persists it in PostgreSQL (`orderingdb`).

## Overview

| Property                  | Value                                                                                                    |
| :------------------------ | :------------------------------------------------------------------------------------------------------- |
| **Owner**                 | Ordering bounded context / **Ordering API** (`ordering`)                                                 |
| **Source**                | `src/Services/Ordering/BookWorm.Ordering/Domain/AggregatesModel/BuyerAggregate/Buyer.cs`                 |
| **EF Core configuration** | `src/Services/Ordering/BookWorm.Ordering/Infrastructure/EntityConfigurations/BuyerConfiguration.cs`      |
| **Backing store**         | PostgreSQL database `orderingdb`, table `buyers` (`snake_case`)                                          |
| **Base type**             | `Entity<BuyerId>`, `IAggregateRoot`                                                                      |
| **Identifier**            | `BuyerId` (Vogen value object wrapping `Guid`); the constructor receives the authenticated customer's ID |

`Buyer` has no audit timestamps, row version, or soft-delete flag.

## Invariants and behavior

- **Name required:** The constructor throws `OrderingDomainException("Name is required")` for null or whitespace names.
- **Address required:** `Address` throws `OrderingDomainException` with `"Street is required"`, `"City is required"`, or `"Province is required"`.
- **Address replacement:** `UpdateAddress(street, city, province)` replaces the whole `Address` value object.
- **PII:** `name` and `address` contain personal data. Keep them out of logs, events, and incident reports.
