## Overview

`ProcessVectorBatchIntegrationEvent` is published by
[[service|sheduler-dashboard]]'s `ProcessVectorBatchJob` to notify
[[service|catalog-ingestion]] that pending book embedding updates should be
processed.

It inherits only `id` and `creationDate` from `IntegrationEvent`; batch size
and selection order remain owned by [[service|catalog-ingestion]].
