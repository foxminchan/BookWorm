## 1. Scheduled Five-Minute Vector Index Refresh

Every five minutes (`0 0/5 * * * ?` UTC), **Scheduler**'s Quartz `ProcessVectorBatchJob` publishes `ProcessVectorBatchIntegrationEvent` to the unprefixed `scheduler.process-vector-batch` Kafka topic so **Catalog Ingestion** embeds pending book updates into Qdrant.

### Payload details

- `id`: UUIDv7 generated by `IntegrationEvent` (`Guid.CreateVersion7()`).
- `creationDate`: UTC ISO 8601 timestamp (`DateTime.UtcNow`).

### Example payload

```json
{
	"id": "01960a1b-7b01-7c00-8a9b-0c1d2e3f4e01",
	"creationDate": "2026-11-25T16:30:00Z"
}
```

### Using this example

**Scheduler** enqueues `ProcessVectorBatchIntegrationEvent` in its Wolverine PostgreSQL outbox and publishes it to `scheduler.process-vector-batch`; **Catalog Ingestion** consumes the event and upserts embeddings for any rows in `pending_vector_updates`.

```csharp EventBus.cs
using BookWorm.Chassis.EventBus;
using BookWorm.Chassis.EventBus.Kafka;
using BookWorm.Contracts;
using Wolverine;
using Wolverine.Attributes;

// Integration event contract (BookWorm.Contracts)
[IntegrationMessageOwner(
    ServiceName = Services.Scheduler,
    TopicName = "scheduler.process-vector-batch",
    AppendPrefix = false
)]
[MessageIdentity("BookWorm.Contracts.ProcessVectorBatchIntegrationEvent")]
public sealed record ProcessVectorBatchIntegrationEvent : IntegrationEvent;

// 1. Publishing from Scheduler Quartz job via Wolverine IMessageBus
await bus.PublishAsync(new ProcessVectorBatchIntegrationEvent());

// 2. Deserializing CloudEvents payload in Catalog Ingestion Azure Function
var @event = CloudEventsMessageParser.Deserialize<ProcessVectorBatchIntegrationEvent>(
    kafkaEventJson
);
```
