`GetMailBatch` queries the external SendGrid Web API v3 (`GET /v3/mail/batch/{batch_id}`) to verify whether a previously created mail batch identifier exists. A `200 OK` response confirms only that SendGrid recognizes the identifier; it does not confirm that messages were attached, submitted, or delivered.

:::warning
**Not invoked by current BookWorm runtime code:** BookWorm's **Notification** service (`src/Services/Notification/BookWorm.Notification`) sends transactional order emails over **SMTP using MailKit** (**Mailpit** locally and `smtp://smtp.sendgrid.net:587` in Azure publish mode). No service in the current repository calls SendGrid's HTTP v3 Mail Batch API.
:::

## Parameters and fields

### Path parameters

| Name       | Type     | Required | Default | Constraints                                    | Description                                |
| :--------- | :------- | :------- | :------ | :--------------------------------------------- | :----------------------------------------- |
| `batch_id` | `string` | Yes      | —       | Non-empty string returned by `CreateMailBatch` | SendGrid mail batch identifier to validate |

### Response schema (`GetMailBatchResponse`)

A `200 OK` response returns a `GetMailBatchResponse` JSON object (`additionalProperties: false`).

| Field      | Type     | Required | Constraints    | Description                              |
| :--------- | :------- | :------- | :------------- | :--------------------------------------- |
| `batch_id` | `string` | Yes      | `minLength: 1` | Validated SendGrid mail batch identifier |

## Error responses

The [SendGrid OpenAPI contract](https://raw.githubusercontent.com/twilio/sendgrid-oai/refs/heads/main/spec/yaml/tsg_mail_v3.yaml) defines `ErrorResponse` with an `errors` array and optional `id`. For `GET /v3/mail/batch/{batch_id}`, it documents `400`, `401`, `403`, `405`, and `500` responses; its description says an invalid batch ID returns `400`. It does not list `404` for this operation. This documents the published contract, not every possible live-service response.

| Code / status               | Condition                                     | Recovery behavior                                                          |
| :-------------------------- | :-------------------------------------------- | :------------------------------------------------------------------------- |
| `400 Bad Request`           | Invalid or unrecognized `batch_id`            | Treat as a workflow state error; create a new batch before submitting mail |
| `401 Unauthorized`          | Missing or invalid SendGrid API key           | Verify the bearer token credential and retry                               |
| `403 Forbidden`             | API key lacks permission to read mail batches | Grant Mail Batch read permissions on the SendGrid API key                  |
| `405 Method Not Allowed`    | Unsupported HTTP verb used on the batch path  | Send an HTTP `GET` request                                                 |
| `500 Internal Server Error` | SendGrid server-side failure                  | Retry with exponential backoff                                             |
