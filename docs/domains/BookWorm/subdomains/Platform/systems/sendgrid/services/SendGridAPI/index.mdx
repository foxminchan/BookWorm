## Integration Purpose & Boundary

SendGrid is BookWorm's external email delivery provider in publish environments, offloading internet mail routing, sender reputation, and downstream delivery. At runtime, only [[service|notification-api]] integrates with SendGrid to transmit rendered order lifecycle emails.

:::note
Although SendGrid's platform exposes a REST v3 HTTP API, BookWorm does **not** invoke SendGrid HTTP endpoints at runtimeâ€”[[service|notification-api]] submits rendered MIME messages exclusively over **authenticated SMTP** (using a local test inbox during development).
:::

## Integration Profile

| Property                         | Value                                                                                                                                                                                    |
| :------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Provider / Sidecar**           | Twilio SendGrid (SMTP relay in publish environments; local test inbox in development)                                                                                                    |
| **BookWorm Consumers**           | [[service\|notification-api]] only                                                                                                                                                       |
| **Runtime Transport & Protocol** | SMTP over TLS (port 587)                                                                                                                                                                 |
| **Auth / Credential Boundary**   | API key injected via runtime secret configuration (`apikey` username); domain-authenticated sender identity recommended for production                                                   |
| **Data / PII Sensitivity**       | High â€” carries customer recipient email addresses and order notification content; redact recipient metadata in logs and never log rendered email bodies                                |
| **Failure / Fallback Behavior**  | Bounded client retries followed by Kafka listener backoff and dead-letter routing on [[channel\|bookworm.&#123;env&#125;.notification.dead-letter-queue]]; no delivery webhooks ingested |
