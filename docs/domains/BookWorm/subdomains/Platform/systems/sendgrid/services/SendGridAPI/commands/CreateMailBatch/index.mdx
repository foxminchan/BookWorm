## Overview

The `CreateMailBatch` command requests a new batch identifier from
[[system|sendgrid]].
BookWorm can associate the returned identifier with a later
[[command|SendMail]] request to group related mail submissions.

Creating a batch does not send an email and does not indicate that a
notification has been delivered. The [[system|notification-system]] should persist the
identifier with the workflow that will use it and retain ownership of the
delivery state.

## Request

This operation does not define a request body. SendGrid authentication and
optional subuser context are supplied through the API request headers.

## Response and failures

- `201 Created` returns the new batch identifier.
- `400 Bad Request` indicates an invalid request.
- `401 Unauthorized` indicates missing or invalid authentication.
- `403 Forbidden` indicates that the caller is not allowed to perform the
  operation.
- `404 Not Found` indicates that the requested provider resource is unavailable.
- `405 Method Not Allowed` indicates an unsupported HTTP method.
- `500 Internal Server Error` indicates a provider-side failure.
