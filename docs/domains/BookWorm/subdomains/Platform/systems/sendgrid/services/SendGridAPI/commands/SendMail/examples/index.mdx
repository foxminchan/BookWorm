## Send an email via SendGrid SMTP with MailKit (matches BookWorm runtime)

<CodeGroup>

```csharp
using MailKit.Net.Smtp;
using MailKit.Security;
using MimeKit;

var password = Environment.GetEnvironmentVariable("Email__Password")
    ?? throw new InvalidOperationException("Set Email__Password to your SendGrid API key.");

var message = new MimeMessage();
message.From.Add(new MailboxAddress("BookWorm", "<sender-email>"));
message.To.Add(new MailboxAddress("BookWorm reader", "<recipient-email>"));
message.Subject = "BookWorm: Your Order Has Been Received Successfully";
message.Body = new TextPart("html") { Text = "<p>Your order has been received.</p>" };

using var client = new SmtpClient { Timeout = 10_000 };
await client.ConnectAsync("smtp.sendgrid.net", 587, SecureSocketOptions.StartTls);
await client.AuthenticateAsync("apikey", password);
await client.SendAsync(message);
await client.DisconnectAsync(true);
```

</CodeGroup>

Where:

- `<sender-email>`: Sender address verified in SendGrid (matches `Email__From`).
- `<recipient-email>`: Destination customer email address.

## Send an email via SendGrid REST v3 with curl (external contract only)

<CodeGroup>

```bash
curl --request POST "https://api.sendgrid.com/v3/mail/send" \
  --header "Authorization: Bearer <sendgrid-api-key>" \
  --header "Content-Type: application/json" \
  --data '{
    "personalizations": [
      {
        "to": [
          { "email": "<recipient-email>", "name": "BookWorm reader" }
        ]
      }
    ],
    "from": { "email": "<sender-email>", "name": "BookWorm" },
    "subject": "Your notification",
    "content": [
      { "type": "text/plain", "value": "Your requested notification is ready." }
    ]
  }'
```

</CodeGroup>

Where:

- `<sendgrid-api-key>`: SendGrid API key with Mail Send permissions.
- `<sender-email>`: Sender address verified in SendGrid.
- `<recipient-email>`: Destination email address.

Expected response (`202 Accepted`):

<CodeGroup>

```text
HTTP/1.1 202 Accepted
```

</CodeGroup>
