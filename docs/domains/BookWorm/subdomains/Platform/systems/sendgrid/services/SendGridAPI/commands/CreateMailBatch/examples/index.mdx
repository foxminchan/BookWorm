## Create a mail batch with curl

<CodeGroup>

```bash
curl --request POST "https://api.sendgrid.com/v3/mail/batch" \
  --header "Authorization: Bearer <sendgrid-api-key>"
```

</CodeGroup>

Where:

- `<sendgrid-api-key>`: A restricted SendGrid API key with the minimum permissions allowed for mail batch creation (external to BookWorm's current SMTP runtime). Supply it through a secret manager in real deployments.

Expected response (`201 Created`):

<CodeGroup>

```json
{
	"batch_id": "YWJjZDEyMzQtZWY1Ni03ODkwLWFiY2QtZWYxMjM0NTY3ODkw"
}
```

</CodeGroup>

## Create a mail batch with C# `HttpClient`

<CodeGroup>

```csharp
using System.Net.Http.Headers;
using System.Net.Http.Json;
using System.Text.Json.Serialization;

var apiKey = Environment.GetEnvironmentVariable("SENDGRID_API_KEY")
    ?? throw new InvalidOperationException("Set SENDGRID_API_KEY before calling SendGrid REST v3.");

using var client = new HttpClient { BaseAddress = new Uri("https://api.sendgrid.com") };
client.DefaultRequestHeaders.Authorization = new AuthenticationHeaderValue("Bearer", apiKey);

using var response = await client.PostAsync("/v3/mail/batch", content: null);
response.EnsureSuccessStatusCode();

var result = await response.Content.ReadFromJsonAsync<CreateMailBatchResponse>()
    ?? throw new InvalidOperationException("SendGrid returned an empty response.");

Console.WriteLine(result.BatchId);

internal sealed record CreateMailBatchResponse(
    [property: JsonPropertyName("batch_id")] string BatchId
);
```

</CodeGroup>
