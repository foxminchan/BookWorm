## 1. Send an Order Completion Email

After **Ordering API** marks an order as `Completed` and emits `OrderStatusChangedToCompleteIntegrationEvent`, **Notification** consumes `CompleteOrderCommand` to send an order completion email.

### Payload details

- `id`: UUIDv7 generated by `IntegrationEvent` (`Guid.CreateVersion7()`).
- `creationDate`: UTC ISO 8601 timestamp (`DateTime.UtcNow`).
- `orderId`: UUID of the completed order (used as the Kafka partition key).
- `fullName`: Optional customer display name (`null` defaults to `"Customer"` in Notification).
- `email`: Optional recipient email address (`null` or whitespace skips SMTP delivery).
- `totalMoney`: Order total (`decimal`).

### Example payload

```json
{
	"id": "01960a1b-6a02-7b00-8a9b-0c1d2e3f4d02",
	"creationDate": "2026-11-25T16:25:00Z",
	"orderId": "01960a1b-3c4d-7e00-8a9b-0c1d2e3f4a99",
	"fullName": "Minh Nguyen",
	"email": "minh.nguyen@bookworm.dev",
	"totalMoney": 59.98
}
```

### Using this example

**Notification** deduplicates by `command.Id` for 24 hours, renders the completion MJML email template, and submits it to SMTP without mutating order state.

```csharp EventBus.cs
using BookWorm.Chassis.EventBus;
using BookWorm.Chassis.EventBus.Idempotency;
using BookWorm.Contracts;
using Wolverine;
using Wolverine.Attributes;

// Integration command contract (BookWorm.Contracts)
public sealed record CompleteOrderCommand(
    Guid OrderId,
    string? FullName,
    string? Email,
    decimal TotalMoney
) : IntegrationEvent;

// 1. Publishing via Wolverine IMessageBus
await bus.PublishAsync(
    new CompleteOrderCommand(
        Guid.Parse("01960a1b-3c4d-7e00-8a9b-0c1d2e3f4a99"),
        "Minh Nguyen",
        "minh.nguyen@bookworm.dev",
        59.98m
    )
);

// 2. Consuming in Notification with Wolverine + IIntegrationEventIdempotencyGuard
internal sealed class CompleteOrderCommandHandler(
    ISender sender,
    IIntegrationEventIdempotencyGuard idempotencyGuard
)
{
    [WolverineHandler]
    public async Task Handle(CompleteOrderCommand command, CancellationToken cancellationToken)
    {
        await idempotencyGuard.ExecuteAsync(
            command.Id,
            nameof(CompleteOrderCommandHandler),
            async ct =>
            {
                if (!string.IsNullOrWhiteSpace(command.Email))
                {
                    await sender.SendEmailAsync(command, ct);
                }
            },
            cancellationToken: cancellationToken
        );
    }
}
```
