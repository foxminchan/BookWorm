## 1. Trigger Post-Checkout Basket Cleanup and Order Confirmation Email

After **Ordering API** emits `UserCheckedOutIntegrationEvent`, **Finance**'s Durable Functions `OrderOrchestrator` publishes `PlaceOrderCommand` to `bookworm.{env}.finance.place-order` so **Basket API** deletes the customer's basket and **Notification** sends an order confirmation email.

### Payload details

- `id`: UUIDv7 generated by `IntegrationEvent` (`Guid.CreateVersion7()`).
- `creationDate`: UTC ISO 8601 timestamp (`DateTime.UtcNow`).
- `basketId`: UUID of the shopper's Redis basket to delete.
- `orderId`: UUID of the placed order (Kafka partition key and Basket deduplication key).
- `fullName`: Optional customer display name (`null` defaults to `"Customer"` in Notification).
- `email`: Optional recipient email address (`null` or whitespace skips email delivery).
- `totalMoney`: Order total (`decimal`).

### Example payload

```json
{
	"id": "01960a1b-6a03-7b00-8a9b-0c1d2e3f4d03",
	"creationDate": "2026-11-25T16:14:58Z",
	"basketId": "01960a1b-2c3d-7e4f-8a9b-0c1d2e3f4a01",
	"orderId": "01960a1b-3c4d-7e00-8a9b-0c1d2e3f4a99",
	"fullName": "Minh Nguyen",
	"email": "minh.nguyen@bookworm.dev",
	"totalMoney": 59.98
}
```

### Using this example

**Basket API** deletes the Redis basket and publishes `BasketDeletedCompleteIntegrationEvent` (or `BasketDeletedFailedIntegrationEvent`), while **Notification** independently renders and dispatches the new-order confirmation email.

```csharp EventBus.cs
using BookWorm.Chassis.EventBus;
using BookWorm.Chassis.EventBus.Idempotency;
using BookWorm.Contracts;
using Wolverine;
using Wolverine.Attributes;

// Integration command contract (BookWorm.Contracts)
[IntegrationMessageOwner(ServiceName = Services.Finance, TopicName = "place-order")]
[MessageIdentity("BookWorm.Contracts.PlaceOrderCommand")]
public sealed record PlaceOrderCommand(
    Guid BasketId,
    Guid OrderId,
    string? FullName,
    string? Email,
    decimal TotalMoney
) : IntegrationEvent;

// 1. Publishing from Finance Durable Functions activity via Wolverine IMessageBus
await bus.PublishAsync(
    new PlaceOrderCommand(
        Guid.Parse("01960a1b-2c3d-7e4f-8a9b-0c1d2e3f4a01"),
        Guid.Parse("01960a1b-3c4d-7e00-8a9b-0c1d2e3f4a99"),
        "Minh Nguyen",
        "minh.nguyen@bookworm.dev",
        59.98m
    )
);

// 2. Consuming in Notification with Wolverine + IIntegrationEventIdempotencyGuard
internal sealed class PlaceOrderCommandHandler(
    ISender sender,
    IIntegrationEventIdempotencyGuard idempotencyGuard
)
{
    [WolverineHandler]
    public async Task Handle(PlaceOrderCommand command, CancellationToken cancellationToken)
    {
        await idempotencyGuard.ExecuteAsync(
            command.Id,
            nameof(PlaceOrderCommandHandler),
            async ct =>
            {
                if (!string.IsNullOrWhiteSpace(command.Email))
                {
                    await sender.SendEmailAsync(command, ct);
                }
            },
            cancellationToken: cancellationToken
        );
    }
}
```
