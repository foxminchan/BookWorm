## 1. Context & Problem

In a distributed platform where multiple scheduler replicas can run concurrently, the system needs a reliable way to track which instances are active, how often they report health, and whether an instance has stopped unexpectedly. Without shared liveness tracking, clustered nodes cannot detect failed peers or safely take over orphaned scheduled work.

## 2. Business Value

- **High Availability & Failover:** Allows healthy scheduler instances to detect when a peer stops checking in so missed or interrupted work can be recovered automatically.
- **Operational Visibility:** Shows which scheduler instances are participating, when each last reported in, and which scheduler version each node is running.
- **Coordinated Cluster Execution:** Maintains a shared node registry under a common scheduler name so distributed instances coordinate safely.

## 3. How It Works

Each running scheduler instance registers itself under the shared scheduler name with a unique instance name, its configured check-in interval, and optionally its scheduler software version.

On a recurring cadence matching its check-in interval, each active instance updates its last check-in timestamp in shared storage. Other nodes sharing the same scheduler name monitor these timestamps to distinguish healthy peers from unresponsive instances that require failover recovery for the jobs and triggers they manage.

## 4. Trade-offs & Lessons Learned

- **Check-In Interval Tuning:** A shorter interval detects node failures faster but increases background storage writes; a longer interval reduces overhead but delays failover detection.
- **Clock Synchronization Dependency:** Because clustered nodes compare check-in timestamps across instances, clock drift between application hosts or database servers can cause false failure detection.
- **Rolling Upgrade Visibility:** Tracking the scheduler version per instance helps operators spot mixed-version nodes during deployments, though backward-compatible cluster coordination must still be maintained.
