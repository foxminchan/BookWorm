## 1. Context & Problem

Many platform jobs—such as running hourly email maintenance or refreshing search indexes every five minutes—follow recurring calendar-style schedules rather than fixed one-off delays. The scheduler needs a durable, human-readable way to persist each job's recurring schedule rule and its governing time zone so jobs fire predictably across restarts and server deployments.

## 2. Business Value

- **Transparent Scheduling:** Keeps recurring schedule rules and time zones readable and inspectable for operators troubleshooting when a job is supposed to run.
- **Time Zone Accuracy:** Prevents confusion across regions or daylight-saving transitions by explicitly pairing a schedule rule with a time zone (standardizing on UTC across BookWorm Platform jobs).
- **Reliable Persistence:** Stores recurring schedules in shared storage so clustered scheduler nodes stay synchronized on when each job fires next.

## 3. How It Works

Each recurring schedule record extends a parent trigger in the core trigger registry. While the parent trigger tracks execution state, priority, and the next calculated fire time, this extension stores the recurring schedule expression and an optional time zone identifier.

When the scheduler calculates when a job should run next, it evaluates the recurring schedule expression against the specified time zone (defaulting to the scheduler's standard time zone if omitted) and updates the parent trigger accordingly.

## 4. Trade-offs & Lessons Learned

- **Explicit Time Zones Prevent Drift:** Because an omitted time zone falls back to host or scheduler defaults, explicitly storing UTC avoids unexpected shifts during server moves or daylight-saving changes.
- **Readable Text vs. Validation:** Unlike binary-stored triggers, schedule rules here are stored as plain text, making diagnostics easier—though editing them directly in the database bypasses validation and risks breaking schedule parsing.
- **Parent-Child Coupling:** This entity cannot stand alone; its existence and lifecycle depend entirely on its corresponding parent trigger.
