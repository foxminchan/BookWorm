`CustomerBasket` is the Shopping aggregate for a customer's pre-order selection of books. Basket API owns it and stores it in Redis; Basket API has no SQL database.

## Invariants and behavior

- **Customer ID required:** The constructor throws `BasketDomainException("Customer ID cannot be null.")` for a null ID.
- **Non-empty on create:** The constructor throws `BasketDomainException("Basket must contain at least one item.")` for an empty item list.
- **Whole-set update:** `Update(items)` clears and replaces every item. The domain method accepts an empty list; `UpdateBasketValidator` rejects it at the API boundary.
- **API validation:** `CreateBasketValidator` and `UpdateBasketValidator` apply `BasketItemRules`: `items` not empty, each `id` not empty, each `quantity > 0`.
- **Checkout handoff:** Basket API deletes the basket when it handles `PlaceOrderCommand` from Finance, then publishes `BasketDeletedCompleteIntegrationEvent` or `BasketDeletedFailedIntegrationEvent`.
