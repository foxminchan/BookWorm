`BasketItem` is a child object of `CustomerBasket` that records one requested book and its quantity. Basket API stores it inside the parent basket's Redis JSON value and enriches it with Catalog data at read time.

## Overview

| Property             | Value                                                                 |
| :------------------- | :-------------------------------------------------------------------- |
| **Owner**            | Shopping bounded context / **Basket API** (`basket`)                  |
| **Parent aggregate** | [[entity\|basket]] (`CustomerBasket`)                                 |
| **Source**           | `src/Services/Basket/BookWorm.Basket/Domain/BasketItem.cs`            |
| **Backing store**    | Embedded in the Redis value at key `basket:{userId}`                  |
| **Base type**        | Plain class implementing `IValidatableObject`; no identity of its own |

## Parameters and fields

### Persisted fields

| Name (JSON) | Type     | Required | Default | Constraints            | Description                             |
| :---------- | :------- | :------- | :------ | :--------------------- | :-------------------------------------- |
| `id`        | `string` | Yes      | —       | GUID format; not empty | Catalog `Book.id` of the requested book |
| `quantity`  | `int`    | Yes      | —       | `> 0`                  | Number of copies requested              |

### Enriched response fields (`BasketItemDto`)

Basket API adds these fields when it returns a basket. They are not stored in Redis.

| Name (JSON) | Type      | Required | Default | Constraints | Description                             |
| :---------- | :-------- | :------- | :------ | :---------- | :-------------------------------------- |
| `name`      | `string`  | No       | `null`  | —           | Book title from Catalog API             |
| `price`     | `decimal` | No       | `0`     | —           | Current original price from Catalog API |
| `priceSale` | `decimal` | No       | `null`  | —           | Current sale price from Catalog API     |

The basket post-processor resolves missing display fields through Catalog API's `book.v1.BookGrpcService` read path and fills `Name`, `Price`, and `PriceSale` into the returned basket item.

## Invariants and behavior

- **Positive quantity:** `Validate(...)` returns `"Quantity must be greater than zero."` when `quantity <= 0`. `BasketItemRules` also enforces `quantity > 0` and a non-empty `id`.
- **Removal:** To remove a book, send the full basket without that item. Zero-quantity items are rejected.
- **No price snapshot:** The item stores no price. Ordering captures purchase-time prices in [[entity|order-item]].

## Relationships

| Related entity     | Cardinality              | Mapping                           |
| :----------------- | :----------------------- | :-------------------------------- |
| [[entity\|basket]] | Many items to one basket | Embedded in the parent JSON value |
| [[entity\|book]]   | Many items to one book   | `id` holds the Catalog book ID    |
