## Overview

Deletes a [[entity|basket]]. This command has no documented parameters or request body.

<NodeGraph />

## Request and response

Send the `DELETE` request without a request body. `204` confirms deletion and
does not include a response payload. `404` returns
`application/problem+json` with `ProblemDetails`.
