## 1. Post-Checkout Basket Cleanup Succeeded

After **Finance** dispatches `PlaceOrderCommand`, **Basket API** deletes the shopper's Redis basket and publishes `BasketDeletedCompleteIntegrationEvent` so `OrderOrchestrator` can advance the checkout saga.

### Payload details

- `id`: UUIDv7 generated by `IntegrationEvent` (`Guid.CreateVersion7()`).
- `creationDate`: UTC ISO 8601 timestamp (`DateTime.UtcNow`).
- `orderId`: UUID of the placed order (also used as the Kafka partition key).
- `basketId`: UUID of the deleted Redis basket.
- `totalMoney`: Non-negative order total (`decimal`).

### Example payload

```json
{
	"id": "01960a1b-4d5e-7f01-8a9b-0c1d2e3f4b01",
	"creationDate": "2026-11-25T16:15:00Z",
	"orderId": "01960a1b-3c4d-7e00-8a9b-0c1d2e3f4a99",
	"basketId": "01960a1b-2c3d-7e4f-8a9b-0c1d2e3f4a01",
	"totalMoney": 59.98
}
```

### Using this example

**Basket API** publishes `BasketDeletedCompleteIntegrationEvent` to `bookworm.{env}.basket.delete-complete` partitioned by `OrderId`, and **Finance** resumes `OrderOrchestrator` to emit `DeleteBasketCompleteCommand`.

```csharp EventBus.cs
using BookWorm.Chassis.EventBus;
using BookWorm.Chassis.EventBus.Idempotency;
using BookWorm.Contracts;
using Wolverine.Attributes;

// Integration event contract (BookWorm.Contracts)
[IntegrationMessageOwner(ServiceName = Services.Basket, TopicName = "delete-complete")]
[MessageIdentity("BookWorm.Contracts.BasketDeletedCompleteIntegrationEvent")]
public sealed record BasketDeletedCompleteIntegrationEvent(
    Guid OrderId,
    Guid BasketId,
    decimal TotalMoney
) : IntegrationEvent;

// Publishing from Basket API's PlaceOrderCommandHandler via Wolverine
[WolverineHandler]
public async Task<IntegrationEvent> Handle(
    PlaceOrderCommand command,
    CancellationToken cancellationToken
)
{
    var deleted = await repository.DeleteBasketAsync(command.BasketId.ToString());

    return deleted
        ? new BasketDeletedCompleteIntegrationEvent(
            command.OrderId,
            command.BasketId,
            command.TotalMoney
        )
        : new BasketDeletedFailedIntegrationEvent(
            command.OrderId,
            command.BasketId,
            command.Email,
            command.TotalMoney
        );
}
```
