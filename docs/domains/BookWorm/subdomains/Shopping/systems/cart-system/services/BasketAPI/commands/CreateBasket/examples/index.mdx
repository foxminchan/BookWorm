## Create a basket with curl

<CodeGroup>

```bash
curl --request POST "<gateway-url>/basket/api/v1/baskets" \
  --header "Authorization: Bearer <access-token>" \
  --header "Content-Type: application/json" \
  --data '{
    "items": [
      { "id": "0193f1a2-7b4c-7d8e-9f01-23456789abcd", "quantity": 2 },
      { "id": "0193f1a2-7b4c-7d8e-9f01-23456789abce", "quantity": 1 }
    ]
  }'
```

</CodeGroup>

Where:

- `<gateway-url>`: Base URL of the BookWorm API Gateway (or use the direct Basket API URL without the `/basket` prefix).
- `<access-token>`: Entra ID JWT bearer token with role `customer` and scopes `basket_read` and `basket_write`.

Expected response (`201 Created`):

<CodeGroup>

```json
"a1b2c3d4-e5f6-7890-abcd-ef1234567890"
```

</CodeGroup>

## Validation error response (`400 Bad Request`)

<CodeGroup>

```json
{
	"title": "One or more validation errors occurred.",
	"status": 400,
	"errors": {
		"Items": ["'Items' must not be empty."]
	}
}
```

</CodeGroup>
