## 1. Post-Checkout Basket Cleanup Failed

When `IBasketRepository.DeleteBasketAsync` returns `false` (for example, the Redis key expired or was already removed), **Basket API** publishes `BasketDeletedFailedIntegrationEvent` so **Finance** triggers saga compensation.

### Payload details

- `id`: UUIDv7 generated by `IntegrationEvent` (`Guid.CreateVersion7()`).
- `creationDate`: UTC ISO 8601 timestamp (`DateTime.UtcNow`).
- `orderId`: UUID of the placed order (also used as the Kafka partition key).
- `basketId`: UUID of the Redis basket that could not be deleted.
- `email`: Optional customer email (`string | null`) forwarded for recovery or notification workflows.
- `totalMoney`: Non-negative order total (`decimal`).

### Example payload

```json
{
	"id": "01960a1b-4d5e-7f02-8a9b-0c1d2e3f4b02",
	"creationDate": "2026-11-25T16:15:02Z",
	"orderId": "01960a1b-3c4d-7e00-8a9b-0c1d2e3f4a99",
	"basketId": "01960a1b-2c3d-7e4f-8a9b-0c1d2e3f4a01",
	"email": "minh.nguyen@bookworm.dev",
	"totalMoney": 59.98
}
```

### Using this example

**Basket API** publishes `BasketDeletedFailedIntegrationEvent` to `bookworm.{env}.basket.delete-failed` partitioned by `OrderId`, and **Finance** executes `PublishDeleteBasketFailedActivity` to compensate the order in **Ordering API**.

```csharp EventBus.cs
using BookWorm.Chassis.EventBus;
using BookWorm.Contracts;
using Wolverine.Attributes;

// Integration event contract (BookWorm.Contracts)
[IntegrationMessageOwner(ServiceName = Services.Basket, TopicName = "delete-failed")]
[MessageIdentity("BookWorm.Contracts.BasketDeletedFailedIntegrationEvent")]
public sealed record BasketDeletedFailedIntegrationEvent(
    Guid OrderId,
    Guid BasketId,
    string? Email,
    decimal TotalMoney
) : IntegrationEvent;

// Publishing from Basket API's PlaceOrderCommandHandler via Wolverine
[WolverineHandler]
public async Task<IntegrationEvent> Handle(
    PlaceOrderCommand command,
    CancellationToken cancellationToken
)
{
    var deleted = await repository.DeleteBasketAsync(command.BasketId.ToString());

    if (!deleted)
    {
        return new BasketDeletedFailedIntegrationEvent(
            command.OrderId,
            command.BasketId,
            command.Email,
            command.TotalMoney
        );
    }

    return new BasketDeletedCompleteIntegrationEvent(
        command.OrderId,
        command.BasketId,
        command.TotalMoney
    );
}
```
