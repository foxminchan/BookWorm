## Replace the basket item collection with curl

<CodeGroup>

```bash
curl --request PUT "<gateway-url>/basket/api/v1/baskets" \
  --header "Authorization: Bearer <access-token>" \
  --header "Content-Type: application/json" \
  --data '{
    "items": [
      { "id": "0193f1a2-7b4c-7d8e-9f01-23456789abcd", "quantity": 1 },
      { "id": "0193f1a2-7b4c-7d8e-9f01-23456789abce", "quantity": 3 }
    ]
  }'
```

</CodeGroup>

Where:

- `<gateway-url>`: Base URL of the BookWorm API Gateway (or use the direct Basket API URL without the `/basket` prefix).
- `<access-token>`: Entra ID JWT bearer token with role `customer` and scopes `basket_read` and `basket_write`.

Expected response (`204 No Content`):

<CodeGroup>

```text
HTTP/1.1 204 No Content
```

</CodeGroup>

## Validation error response (`400 Bad Request`)

<CodeGroup>

```json
{
	"title": "One or more validation errors occurred.",
	"status": 400,
	"errors": {
		"Items[0].Quantity": ["'Quantity' must be greater than '0'."]
	}
}
```

</CodeGroup>

## Missing basket response (`404 Not Found`)

<CodeGroup>

```json
{
	"detail": "The requested resource was not found."
}
```

</CodeGroup>
