`BasketDeletedFailedIntegrationEvent` (v1.0.0) signals that [[service|basket-api]] could not delete a submitted customer basket during post-checkout cleanup. [[service|order-orchestration]] consumes this event to trigger compensating failure handling instead of stalling the checkout orchestration.

## Overview

| Property                             | Value                                                                                                             |
| :----------------------------------- | :---------------------------------------------------------------------------------------------------------------- |
| **Bounded Context**                  | Shopping                                                                                                          |
| **Producer**                         | [[service\|basket-api]]                                                                                           |
| **Consumer(s)**                      | [[service\|order-orchestration]]                                                                                  |
| **Protocol / Format**                | Kafka + CloudEvents JSON (camelCase payload)                                                                      |
| **Channel / Topic**                  | [[channel\|bookworm.&#123;env&#125;.basket.delete-failed]]                                                        |
| **Dead-Letter Channel**              | [[channel\|bookworm.&#123;env&#125;.basket.dead-letter-queue]]                                                    |
| **Partition Key**                    | `OrderId`                                                                                                         |
| **Delivery / Idempotency Guarantee** | At-least-once delivery; emitted when Redis deletion returns `false` while handling [[command\|PlaceOrderCommand]] |

## Payload Fields & Envelope

### Event Payload

| Name           | Type                   | Required | Constraints                          | Description                                                           |
| :------------- | :--------------------- | :------- | :----------------------------------- | :-------------------------------------------------------------------- |
| `id`           | `string` (`uuid`)      | Yes      | UUIDv7                               | Unique identifier for this integration event instance                 |
| `creationDate` | `string` (`date-time`) | Yes      | ISO 8601 UTC timestamp               | UTC timestamp when the event was created                              |
| `orderId`      | `string` (`uuid`)      | Yes      | Valid UUID; Kafka partition key      | Identifier of the order whose submitted basket could not be deleted   |
| `basketId`     | `string` (`uuid`)      | Yes      | Valid UUID                           | Identifier of the basket that could not be removed                    |
| `email`        | `string \| null`       | No       | Email format when non-null; nullable | Customer email used by downstream recovery notifications when present |
| `totalMoney`   | `number`               | Yes      | Non-negative monetary amount         | Total purchase amount associated with the order                       |

:::note
Consumers must handle `email` when it is `null` or omitted and must never interpret `BasketDeletedFailedIntegrationEvent` as a successful cleanup milestone.
:::

### CloudEvents Envelope Headers

| Header        | Value / Source                                           | Purpose                                                     |
| :------------ | :------------------------------------------------------- | :---------------------------------------------------------- |
| `messagetype` | `BookWorm.Contracts.BasketDeletedFailedIntegrationEvent` | Explicit message identity for cross-service deserialization |
| `source`      | `urn:bookworm:bookworm-basket`                           | Identifies the producing service                            |
| `requestid`   | Propagated from incoming [[command\|PlaceOrderCommand]]  | Correlates checkout and recovery logs across services       |

## Delivery Guarantees & Error Handling

| Condition                                                   | System Behavior                                                                          | Recovery / Compensation                                                                                      |
| :---------------------------------------------------------- | :--------------------------------------------------------------------------------------- | :----------------------------------------------------------------------------------------------------------- |
| Redis deletion returns `false` (key missing or not deleted) | Emits `BasketDeletedFailedIntegrationEvent`                                              | [[service\|order-orchestration]] dispatches [[command\|DeleteBasketFailedCommand]] to [[service\|order-api]] |
| Unhandled exception during Redis deletion                   | Releases the `OrderId` idempotency lock and retries (`50ms`, `250ms`, `1s`, full jitter) | Exhausted messages route to [[channel\|bookworm.&#123;env&#125;.basket.dead-letter-queue]]                   |
| Deserialization failure                                     | Routed immediately to the dead-letter queue without retries                              | Inspect dead-letter payload against contract schema                                                          |
