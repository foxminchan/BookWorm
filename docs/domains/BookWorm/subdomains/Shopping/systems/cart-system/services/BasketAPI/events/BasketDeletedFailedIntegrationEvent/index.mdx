`BasketDeletedFailedIntegrationEvent` (v1.0.0) signals that Basket API could not delete a submitted customer basket during post-checkout cleanup (`IBasketRepository.DeleteBasketAsync` returned `false`). Finance consumes this event to trigger compensating failure handling instead of stalling the checkout orchestration.

## Overview

| Property              | Value                                                                                                 |
| :-------------------- | :---------------------------------------------------------------------------------------------------- |
| **Owner**             | Shopping bounded context (`Basket API`)                                                               |
| **Producer**          | [[service\|basket-api]] (`PlaceOrderCommandHandler`)                                                  |
| **Consumer**          | [[service\|order-orchestration]] (`OrderOrchestrator`)                                                |
| **Source**            | `src/Services/Basket/BookWorm.Basket/IntegrationEvents/Events/BasketDeletedFailedIntegrationEvent.cs` |
| **Protocol / format** | Kafka + CloudEvents JSON (Wolverine)                                                                  |
| **Kafka topic**       | `bookworm.{env}.basket.delete-failed` (where `{env}` is the kebab-case environment name)              |
| **Message identity**  | `BookWorm.Contracts.BasketDeletedFailedIntegrationEvent`                                              |
| **Partition key**     | `OrderId` (preserves per-order saga ordering on Kafka)                                                |
| **Trigger condition** | `IBasketRepository.DeleteBasketAsync` returns `false` while handling `PlaceOrderCommand`              |

:::

## Error handling and delivery guarantees

| Condition                                                     | Behavior                                                                                      | Recovery behavior                                                                                                                                |
| :------------------------------------------------------------ | :-------------------------------------------------------------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------- |
| Redis returns `false` (key missing or not deleted)            | `PlaceOrderCommandHandler` emits `BasketDeletedFailedIntegrationEvent`.                       | Finance advances its compensation branch and dispatches `DeleteBasketFailedCommand` to Ordering API.                                             |
| Unhandled exception during Redis deletion                     | `PlaceOrderCommandHandler` releases the Redis idempotency lock (`ReleaseAsync`) and rethrows. | Wolverine retries with cooldown (`50ms`, `250ms`, `1s`, full jitter) and routes exhausted messages to `bookworm.{env}.basket.dead-letter-queue`. |
| Deserialization failure (`JsonException` / `FormatException`) | Routed immediately to the consumer native Kafka DLQ without retries.                          | Validate payloads against `tests/pacts/Finance-Basket.json` before replaying.                                                                    |
