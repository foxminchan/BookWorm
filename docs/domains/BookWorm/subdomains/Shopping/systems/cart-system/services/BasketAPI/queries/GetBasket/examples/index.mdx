## Retrieve the current basket with curl

<CodeGroup>

```bash
curl --request GET "<gateway-url>/basket/api/v1/baskets" \
  --header "Authorization: Bearer <access-token>" \
  --header "Accept: application/json"
```

</CodeGroup>

Where:

- `<gateway-url>`: Base URL of the BookWorm API Gateway (or direct Basket API URL `https://localhost:7155` without the `/basket` prefix).
- `<access-token>`: Entra ID bearer token for a signed-in customer.

Expected response (`200 OK`):

<CodeGroup>

```json
{
	"id": "customer-123",
	"items": [
		{
			"id": "0193f1a2-7b4c-7d8e-9f01-23456789abcd",
			"quantity": 2,
			"name": "The Great Gatsby",
			"price": 12.99,
			"priceSale": null
		}
	]
}
```

</CodeGroup>

Expected response when no basket exists (`404 Not Found`):

<CodeGroup>

```json
{
	"title": "Not Found",
	"status": 404
}
```

</CodeGroup>

## Retrieve the current basket with TypeScript

<CodeGroup>

```typescript
type BasketItem = {
	id: string | null;
	quantity: number | string;
	name?: string | null;
	price?: number | string;
	priceSale?: number | string | null;
};

type CustomerBasketDto = {
	id: string | null;
	items: BasketItem[];
};

const gatewayUrl = "<gateway-url>";
const accessToken = "<access-token>";

const response = await fetch(`${gatewayUrl}/basket/api/v1/baskets`, {
	headers: {
		Authorization: `Bearer ${accessToken}`,
		Accept: "application/json",
	},
});

if (response.status === 404) {
	throw new Error("Basket was not found");
}
if (!response.ok) {
	throw new Error(`GetBasket failed with ${response.status}`);
}

const basket = (await response.json()) as CustomerBasketDto;
console.log(`${basket.items.length} item(s) in basket ${basket.id}`);
```

</CodeGroup>
