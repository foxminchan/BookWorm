## Overview

The `BasketGrpcService.GetBasket` RPC retrieves the current customer's [[entity|basket]]
for internal service-to-service clients. It accepts an empty request and
returns the basket identifier and its item quantities.

[[service|order-api]] produces this query during Order creation, using a
token exchanged for Basket. [[service|basket-api]] consumes it over a
synchronous service-to-service gRPC call; it does not use an
integration-event channel.

<NodeGraph />

## Contract

Send `google.protobuf.Empty`. The response is `GetBasketResponse`, containing
the basket `id` and a repeated `items` collection. Each item contains an
identifier and an `int32` quantity.

## Example

<CodeGroup dropdown>

```csharp title="GetBasket gRPC example"
using Grpc.Net.Client;
using Google.Protobuf.WellKnownTypes;
using BookWorm.Basket.Grpc.Services;

using var channel = GrpcChannel.ForAddress(Services.BasketApi);
var client = new BasketGrpcService.BasketGrpcServiceClient(channel);

var response = await client.GetBasketAsync(new Empty());

Console.WriteLine($"Basket {response.Id} contains {response.Items.Count} item(s)");
```
