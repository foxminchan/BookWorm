## Delete the active basket with curl

<CodeGroup>

```bash
curl --request DELETE "<gateway-url>/basket/api/v1/baskets" \
  --header "Authorization: Bearer <access-token>"
```

</CodeGroup>

Where:

- `<gateway-url>`: Base URL of the BookWorm API Gateway (or use the direct Basket API URL without the `/basket` prefix).
- `<access-token>`: Entra ID JWT bearer token with role `customer` and scopes `basket_read` and `basket_write`.

Expected response (`204 No Content`):

<CodeGroup>

```text
HTTP/1.1 204 No Content
```

</CodeGroup>

## Missing basket response (`404 Not Found`)

<CodeGroup>

```json
{
	"detail": "The requested resource was not found."
}
```

</CodeGroup>
