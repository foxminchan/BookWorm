## Overview

Retrieves a [[entity|basket]]. The operation defines no query or path parameters.

<NodeGraph />

## Query parameters and response

This query has no documented request body or parameters. A `200` response
returns an `application/json` `CustomerBasketDto`, containing an `id` and
`items`. `404` returns `application/problem+json` with `ProblemDetails`.

When the basket has items, BasketAPI enriches them by sending the
[[query|GetBooksGrpc]] gRPC query to Catalog with the distinct item IDs.
