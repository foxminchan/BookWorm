`GetBasket` retrieves the authenticated customer's active basket from **Basket API** (`GET /api/v1/baskets`) and enriches non-empty basket items with live titles and pricing from **Catalog API** over gRPC. The caller's customer identity is resolved from the Microsoft Entra ID access token; no basket identifier parameter is accepted.

## Overview

| Property                       | Value                                                                                                                                                      |
| :----------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Owner**                      | Shopping bounded context (**Basket API**, Aspire resource `basket`)                                                                                        |
| **Source**                     | `src/Services/Basket/BookWorm.Basket/Features/Get/GetBasketEndpoint.cs`, `GetBasketQuery.cs`, `GetBasketQuery.PostProcessor.cs`                            |
| **Protocol / format**          | HTTP `GET /api/v1/baskets` (via API Gateway: `GET /basket/api/v1/baskets`), `ApiVersions.V1`, JSON (`application/json`)                                    |
| **Authentication**             | Microsoft Entra ID JWT required (`customer` role; scopes `basket_read`, `basket_write`)                                                                    |
| **Rate limiting**              | `PerUserRateLimit` token bucket (30 token limit, 20 tokens per 10 seconds, queue limit 5) plus global IP/concurrency limiters                              |
| **Backing store & enrichment** | Reads basket state from Redis; when `items` is non-empty, deduplicates book IDs and enriches items via Catalog API gRPC `book.v1.BookGrpcService/GetBooks` |
| **Contract version**           | `1.0.0`                                                                                                                                                    |

## Parameters and fields

### Request parameters

`GetBasket` accepts no path parameters, query parameters, or request body. Basket API resolves the customer ID from the authenticated Entra ID claims principal.

### Response schema (`CustomerBasketDto`)

A `200 OK` response returns a `CustomerBasketDto` JSON object.

| Field               | Type                       | Required | Constraints                     | Description                                                                    |
| :------------------ | :------------------------- | :------- | :------------------------------ | :----------------------------------------------------------------------------- |
| `id`                | `string \| null`           | Yes      | —                               | Identifier of the customer's basket                                            |
| `items`             | `BasketItem[]`             | Yes      | Array (may be empty)            | Line items currently stored in the basket                                      |
| `items[].id`        | `string \| null`           | Yes      | —                               | Catalog book identifier                                                        |
| `items[].quantity`  | `integer \| string`        | Yes      | `int32` (`^-?(?:0\|[1-9]\d*)$`) | Requested unit quantity                                                        |
| `items[].name`      | `string \| null`           | No       | —                               | Book title enriched from Catalog API (`null` when unavailable)                 |
| `items[].price`     | `number \| string`         | No       | `double`, default `0`           | Regular unit price enriched from Catalog API                                   |
| `items[].priceSale` | `number \| string \| null` | No       | `double` or `null`              | Promotional sale price enriched from Catalog API (`null` when no sale applies) |

## Error responses

| Code / status           | Condition                                                                                                   | Recovery behavior                                                     |
| :---------------------- | :---------------------------------------------------------------------------------------------------------- | :-------------------------------------------------------------------- |
| `401 Unauthorized`      | Missing, expired, or invalid Entra ID bearer token                                                          | Re-authenticate the customer and retry                                |
| `403 Forbidden`         | Authenticated principal lacks the `customer` role or required `basket_read` / `basket_write` scope          | Request a token with the required customer scopes                     |
| `404 Not Found`         | No active basket exists in Redis for the authenticated customer (`application/problem+json`)                | Treat as an empty/uninitialized basket until the customer creates one |
| `429 Too Many Requests` | Caller exceeded `PerUserRateLimit` or global rate limit (`application/problem+json` + `Retry-After` header) | Wait for the `Retry-After` duration before retrying                   |
