`UpdateBasket` (`PUT /api/v1/baskets`) replaces the entire item collection of the authenticated customer's existing **Basket** in Redis and returns `204 No Content`. It requires an active basket to exist and rejects requests targeting a missing basket with `404 Not Found`.

## Overview

| Property                 | Value                                                                                                                                                                                               |
| :----------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Owner**                | Shopping bounded context (**Basket API**, Aspire resource `basket`)                                                                                                                                 |
| **Source**               | `src/Services/Basket/BookWorm.Basket/Features/Update/UpdateBasketEndpoint.cs`, `UpdateBasketCommand.cs`, `UpdateBasketValidator.cs`, `src/Services/Basket/BookWorm.Basket/Domain/CustomerBasket.cs` |
| **Protocol / format**    | HTTP `PUT`, `application/json` request body, empty `204` response                                                                                                                                   |
| **Direct endpoint**      | `PUT /api/v1/baskets` (local ports: HTTP `5052`, HTTPS `7155`)                                                                                                                                      |
| **API Gateway endpoint** | `PUT /basket/api/v1/baskets` (YARP strips `/basket`)                                                                                                                                                |
| **Authentication**       | Microsoft Entra ID JWT bearer token; default policy requires role `customer` and scopes `basket_read` and `basket_write`                                                                            |
| **Rate limit**           | `PerUserRateLimit` token bucket (30 tokens, +20 per 10 s, queue 5) plus global concurrency (100) and per-IP fixed-window (30 req/min) limiters                                                      |
| **Contract version**     | `1.0.0` (`ApiVersions.V1`)                                                                                                                                                                          |

### Success response (`204 No Content`)

Returns HTTP `204 No Content` with an empty response body.

## Behavior and side effects

- **Full-list replacement (last write wins):** `UpdateBasketHandler` resolves `userId` from `ClaimTypes.NameIdentifier`, loads `basket:{userId}` from Redis via `GetBasketAsync`, and calls `Guard.Against.NotFound(basket, userId)`. It then invokes `CustomerBasket.Update(...)`, which clears the existing item list and inserts the submitted items, writing the serialized JSON back to Redis via `StringSetAsync` with no TTL.
- **No implicit creation:** Updating a customer who has no active basket returns `404 Not Found`. Call `POST /api/v1/baskets` to create a basket first, or call `DELETE /api/v1/baskets` to remove all items.
- **No synchronous Catalog lookup:** `UpdateBasket` stores only book IDs and quantities; titles and prices are resolved on read in `GetBasket`.
- **No Kafka integration events:** HTTP basket updates do not publish any Kafka or Wolverine integration events.

:::note
OpenAPI metadata (`ProducesPut()`) declares `404 Not Found` as `application/problem+json` (`ProblemDetails`), but at runtime `NotFoundExceptionHandler` (`src/BuildingBlocks/BookWorm.Chassis/Exceptions/NotFoundExceptionHandler.cs`) returns `application/json` with `{ "detail": "The requested resource was not found." }`.
:::

## Error responses

| Code / status               | Condition                                                                                                                                                                                      | Recovery behavior                                                                 |
| :-------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :-------------------------------------------------------------------------------- |
| `400 Bad Request`           | Missing `items`, empty `items` array, empty `items[].id`, `items[].quantity <= 0`, or malformed JSON (`ValidationExceptionHandler`, `application/problem+json` `HttpValidationProblemDetails`) | Fix the failing fields reported in `errors` and resubmit                          |
| `401 Unauthorized`          | Missing, expired, or invalid Entra ID bearer token                                                                                                                                             | Acquire a valid Entra ID access token and retry                                   |
| `403 Forbidden`             | Valid token missing the `customer` role or the `basket_read`/`basket_write` scopes                                                                                                             | Request a token with the required role and scopes                                 |
| `404 Not Found`             | No active basket exists in Redis for the authenticated customer (`NotFoundExceptionHandler` returns `application/json` `{ "detail": "The requested resource was not found." }`)                | Create a basket via `POST /api/v1/baskets` before updating                        |
| `429 Too Many Requests`     | `PerUserRateLimit` or global rate limiter exceeded (`ProblemDetails` with `Retry-After` header in seconds)                                                                                     | Wait for the `Retry-After` interval before retrying                               |
| `500 Internal Server Error` | Unexpected Redis or server failure (`GlobalExceptionHandler`, `ProblemDetails` with `traceId`)                                                                                                 | Retry with exponential backoff; inspect Basket API and Redis logs using `traceId` |
