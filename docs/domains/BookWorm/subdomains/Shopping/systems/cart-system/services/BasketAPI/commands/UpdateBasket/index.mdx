## Overview

Updates a [[entity|basket]] using an `UpdateBasketCommand`. The request contains the
complete `items` collection to apply to the basket.

<NodeGraph />

## Request and response

Send `application/json` with the required `items` array. Each item requires an
`id` and `quantity`. `204` has no response body.

`400` returns `application/problem+json` with
`HttpValidationProblemDetails`; `404` returns `application/problem+json` with
`ProblemDetails`.
