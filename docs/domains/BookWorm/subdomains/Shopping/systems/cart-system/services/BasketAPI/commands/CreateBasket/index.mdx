## Overview

Creates a new [[entity|basket]] from an item collection. The request body is a
`CreateBasketCommand`; each item identifies a [[entity|basket-item]] and its requested
quantity.

<NodeGraph />

## Request and response

Send `application/json` with the required `items` array. Each item requires an
`id` and `quantity`. A successful `201` response returns a JSON customer ID,
which may be `null` according to the OpenAPI contract.

`400` returns `application/problem+json` with
`HttpValidationProblemDetails`.
