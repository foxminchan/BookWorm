`CreateBasket` (`POST /api/v1/baskets`) creates a customer-scoped **Basket** in **Basket API** with an initial non-empty list of book items and quantities, returning the authenticated customer's identifier. It persists the basket directly in Redis and overwrites any existing basket for the same customer.

## Behavior and side effects

- **Customer scoping:** `CreateBasketHandler` resolves the basket owner exclusively from the JWT `ClaimTypes.NameIdentifier` claim via `claimsPrincipal.GetAuthenticatedUserId()`. Callers cannot supply a customer ID in the request body or route.
- **Redis storage and overwrite semantics:** `BasketRepository.CreateOrUpdateBasketAsync` serializes `CustomerBasket` as camelCase JSON and writes it to Redis under key `basket:{userId}` with `StringSetAsync`. No expiration (TTL) is configured, and calling `POST /api/v1/baskets` when a basket already exists overwrites the stored basket.
- **No synchronous Catalog lookup:** Basket creation stores only book IDs and quantities. Book titles and prices are resolved later when reading the basket via `GetBasket`.
- **No Kafka integration events:** HTTP basket creation does not publish any Kafka or Wolverine integration events.

## Error responses

| Code / status               | Condition                                                                                                                                                                                      | Recovery behavior                                                                 |
| :-------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :-------------------------------------------------------------------------------- |
| `400 Bad Request`           | Missing `items`, empty `items` array, empty `items[].id`, `items[].quantity <= 0`, or malformed JSON (`ValidationExceptionHandler`, `application/problem+json` `HttpValidationProblemDetails`) | Fix the failing fields reported in `errors` and resubmit                          |
| `401 Unauthorized`          | Missing, expired, or invalid Entra ID bearer token                                                                                                                                             | Acquire a valid Entra ID access token and retry                                   |
| `403 Forbidden`             | Valid token missing the `customer` role or the `basket_read`/`basket_write` scopes                                                                                                             | Request a token with the required role and scopes                                 |
| `429 Too Many Requests`     | `PerUserRateLimit` or global rate limiter exceeded (`ProblemDetails` with `Retry-After` header in seconds)                                                                                     | Wait for the `Retry-After` interval before retrying                               |
| `500 Internal Server Error` | Redis write failed (`BasketCreatedException`) or unexpected unhandled server error (`GlobalExceptionHandler`, `ProblemDetails` with `traceId`)                                                 | Retry with exponential backoff; inspect Basket API and Redis logs using `traceId` |
