# EventCatalog: ALWAYS read docs before coding

Before any EventCatalog work, find and read the relevant doc in `node_modules/@eventcatalog/core/dist/docs/`. Your training data may be outdated. The bundled docs are the source of truth.

## Architecture diagrams

Use the repository's native architecture models and named-view embeds for system diagrams, not Mermaid. Keep architecture sources and views together in the dedicated modeling directory. Mermaid remains appropriate for sequence, process, and runtime diagrams.
