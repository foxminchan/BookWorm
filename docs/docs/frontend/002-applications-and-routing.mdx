## Explanation: Thin Routes & Feature Slices

Both `@bookworm/storefront` and `@bookworm/backoffice` are Next.js App Router applications served behind the YARP API gateway. When page files mix routing, data fetching, form state, and layout logic together, server and client boundaries blur and routes become difficult to test.

BookWorm keeps route files thin and delegates domain logic to focused feature slices:

- **Thin route entrypoints:** Route files handle page metadata, loading boundaries, and server-side prefetching, then render a single view component from `features/`.
- **Domain-aligned feature slices:** UI components, filters, tables, and forms are grouped under `features/` by business capability ([[domain|catalog]], [[domain|shopping]], [[domain|ordering]], [[domain|reviews]]), mirroring the backend service boundaries.
- **Centralized navigation and constants:** Application titles, pagination defaults, and navigation trees live in `config/` rather than being duplicated across components.
- **Separate authentication scopes:** Each application configures its own Microsoft Entra ID scopes through `@workspace/auth` so customer sessions never request staff-only write permissions. Backend APIs still enforce authorization independently.

## Reference

### Application Comparison

| Attribute               | `@bookworm/storefront`                             | `@bookworm/backoffice`                      |
| :---------------------- | :------------------------------------------------- | :------------------------------------------ |
| **Audience**            | Online bookstore customers                         | Store administrators and staff              |
| **Gateway Path Prefix** | `/` (root)                                         | `/backoffice`                               |
| **Default Local Port**  | `3000` (`http://localhost:3000`)                   | `3001` (`http://localhost:3001/backoffice`) |
| **Rendering Features**  | App Router, Partial Prerendering, Turbopack        | App Router, `basePath`, Turbopack           |
| **Conversational UI**   | CopilotKit + AG-UI (`/api/copilotkit/[[...slug]]`) | None                                        |
