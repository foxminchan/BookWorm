This reference documents BookWorm's three Next.js 16 App Router applications (**Storefront**, **Commerce**, and **Backoffice**), including API Gateway zone ownership, development ports, Next.js configuration flags, standard folder layout, authentication scopes, SEO ownership, and complete route maps. For architectural rationale, see [[doc|frontend/007-architecture-and-state-design]] and [[doc|frontend/006-microfrontend-architecture]].

## Overview

| Property               | Value                                                                                                                                                                           |
| :--------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Owner**              | BookWorm Frontend (`src/Clients/apps/`)                                                                                                                                         |
| **Source**             | `src/Clients/apps/{storefront,commerce,backoffice}`, `src/Clients/apps/storefront/microfrontends.json`, `src/Aspire/BookWorm.AppHost/Extensions/Frontend/FrontendExtensions.cs` |
| **Protocol / ingress** | HTTPS via YARP API Gateway (`gateway`) with `X-Mfe-Zone` response header                                                                                                        |
| **Authentication**     | Better Auth (`^1.7.28`) + Microsoft Entra ID (callback: `/api/auth/oauth2/callback/microsoft-entra-id`)                                                                         |

## Application and zone ownership matrix

Combines application runtime attributes (`FrontendExtensions.cs`, `next.config.mjs`) with microfrontend (MFE) zone routing (`microfrontends.json`):

| Attribute                | Storefront (`@bookworm/storefront`)                                                    | Commerce (`@bookworm/commerce`)                                                                      | Backoffice (`@bookworm/backoffice`)                              |
| :----------------------- | :------------------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------- | :--------------------------------------------------------------- |
| **Aspire resource ID**   | `storefront`                                                                           | `commerce`                                                                                           | `backoffice`                                                     |
| **Audience**             | Public and authenticated bookstore customers                                           | Authenticated bookstore customers (basket, checkout, orders)                                         | Store administrators and staff                                   |
| **Dev port**             | `3000` (`microfrontends.json`)                                                         | `3001` (`microfrontends.json`)                                                                       | Dynamic `PORT` under Aspire (Playwright E2E `defaultPort: 3001`) |
| **Gateway mount**        | `/{**remainder}` (lowest priority fallback, `int.MaxValue`)                            | `/basket`, `/checkout`, `/checkout/:path*`, `/account`, `/account/:path*`, `/commerce-assets/:path*` | `/backoffice/{**remainder}`                                      |
| **`X-Mfe-Zone` header**  | `storefront`                                                                           | `commerce`                                                                                           | `backoffice`                                                     |
| **Next.js config flags** | `cacheComponents: true`, `withMicrofrontends`                                          | `cacheComponents: false`, `withMicrofrontends`, `assetPrefix: "commerce-assets"`                     | `basePath: "/backoffice"`                                        |
| **Cached & public**      | Yes (public pages indexed via `@workspace/seo`)                                        | No (private, dynamic, non-indexed)                                                                   | No (staff-only, non-indexed)                                     |
| **Auth ownership**       | Owns `/api/auth/[...all]` (Better Auth + Entra ID)                                     | Shares Storefront session (`.WithoutEntraId()` in AppHost); `proxy.ts` enforces login                | Owns `/backoffice/api/auth/[...all]` (separate Entra ID scopes)  |
| **Health check path**    | `/`                                                                                    | `/api/health`                                                                                        | `/backoffice`                                                    |
| **Conversational UI**    | CopilotKit + AG-UI (`/api/copilotkit/[[...slug]]`, `NEXT_PUBLIC_COPILOT_ENABLED=true`) | —                                                                                                    | —                                                                |
| **E2E BDD suites**       | 9 Playwright BDD feature files                                                         | None (unit/component tests only; covered via Storefront E2E)                                         | 6 Playwright BDD feature files                                   |

## Route maps

### Storefront (`@bookworm/storefront`)

Served at the root origin (`/`) via the API Gateway fallback zone (`X-Mfe-Zone: storefront`).

| Route group / path                                           | Feature area                                 | Primary backing domain and service                  |
| :----------------------------------------------------------- | :------------------------------------------- | :-------------------------------------------------- |
| `(main)/`                                                    | Landing showcase and book discovery          | Catalog (**Catalog API**)                           |
| `(catalog)/shop`                                             | Filterable catalog listing                   | Catalog (**Catalog API**)                           |
| `(catalog)/shop/[id]`                                        | Book detail view and customer reviews        | Catalog (**Catalog API**), Reviews (**Rating API**) |
| `(catalog)/categories`                                       | Category directory                           | Catalog (**Catalog API**)                           |
| `(catalog)/publishers`                                       | Publisher directory                          | Catalog (**Catalog API**)                           |
| `(auth)/login`, `(auth)/register`                            | Customer sign-in and registration redirects  | Microsoft Entra ID (via Better Auth)                |
| `(content)/about`, `(content)/shipping`, `(content)/returns` | Static informational pages                   | —                                                   |
| `/api/auth/[...all]`                                         | Better Auth OAuth2 and session route handler | Better Auth + Microsoft Entra ID                    |
| `/api/copilotkit/[[...slug]]`                                | Streaming AI assistant runtime (AG-UI)       | Conversational (**Chat API**)                       |

### Commerce (`@bookworm/commerce`)

Served behind the API Gateway under explicit zone patterns from `microfrontends.json` (`X-Mfe-Zone: commerce`). `apps/commerce/proxy.ts` enforces session cookies on `["/basket", "/checkout", "/account"]` and redirects unauthenticated requests to `/login?callbackUrl=<path>`.

| Route group / path                 | Feature area                                                    | Primary backing domain and service |
| :--------------------------------- | :-------------------------------------------------------------- | :--------------------------------- |
| `(basket)/basket`                  | Customer shopping basket                                        | Shopping (**Basket API**)          |
| `(ordering)/checkout/confirmation` | Post-checkout order confirmation                                | Ordering (**Ordering API**)        |
| `(ordering)/account`               | Customer account profile and address                            | Ordering (**Ordering API**)        |
| `(ordering)/account/orders`        | Customer order history list                                     | Ordering (**Ordering API**)        |
| `(ordering)/account/orders/[id]`   | Individual order detail and status                              | Ordering (**Ordering API**)        |
| `/api/health`                      | Aspire health check endpoint (excluded from `proxy.ts` matcher) | —                                  |

### Backoffice (`@bookworm/backoffice`)

Mounted at `basePath: "/backoffice"` (`X-Mfe-Zone: backoffice`). Every route below is externally accessed with the `/backoffice` prefix (for example, `/backoffice/books` and `/backoffice/api/auth/[...all]`).

| Route group / internal path      | External gateway path           | Feature area                                        | Primary backing domain and service                     |
| :------------------------------- | :------------------------------ | :-------------------------------------------------- | :----------------------------------------------------- |
| `(admin)/`                       | `/backoffice`                   | Admin overview dashboard (KPIs, charts, SSE stream) | Ordering (**Ordering API**), Catalog (**Catalog API**) |
| `(admin)/(catalog)/books`        | `/backoffice/books`             | Book inventory list                                 | Catalog (**Catalog API**)                              |
| `(admin)/(catalog)/books/new`    | `/backoffice/books/new`         | Create book form                                    | Catalog (**Catalog API**)                              |
| `(admin)/(catalog)/books/[id]`   | `/backoffice/books/[id]`        | Edit book detail (ETag concurrency)                 | Catalog (**Catalog API**)                              |
| `(admin)/(catalog)/authors`      | `/backoffice/authors`           | Author taxonomy management                          | Catalog (**Catalog API**)                              |
| `(admin)/(catalog)/categories`   | `/backoffice/categories`        | Category taxonomy management                        | Catalog (**Catalog API**)                              |
| `(admin)/(catalog)/publishers`   | `/backoffice/publishers`        | Publisher taxonomy management                       | Catalog (**Catalog API**)                              |
| `(admin)/(ordering)/customers`   | `/backoffice/customers`         | Buyer directory management                          | Ordering (**Ordering API**)                            |
| `(admin)/(ordering)/orders`      | `/backoffice/orders`            | Order management list                               | Ordering (**Ordering API**)                            |
| `(admin)/(ordering)/orders/[id]` | `/backoffice/orders/[id]`       | Order detail, cancel/complete actions               | Ordering (**Ordering API**)                            |
| `(admin)/(rating)/reviews`       | `/backoffice/reviews`           | Customer feedback moderation                        | Reviews (**Rating API**)                               |
| `/api/auth/[...all]`             | `/backoffice/api/auth/[...all]` | Staff Better Auth route handler                     | Better Auth + Microsoft Entra ID                       |

## SEO and metadata scope

- **Storefront:** Uses `@workspace/seo` to generate Open Graph metadata, canonical URLs, and Schema.org JSON-LD structured data for public catalog and content pages.
- **Commerce and Backoffice:** Serve authenticated workflows that are excluded from public search indexing.

Commerce sets `robots: { index: false, follow: false }` in its root layout. Backoffice's root layout does not declare `robots` metadata; its admin layout enforces an `AuthGuard`, but that is not equivalent to a `noindex, nofollow` directive.
