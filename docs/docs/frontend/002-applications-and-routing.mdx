## Explanation: Thin Routes & Feature Slices

BookWorm runs three Next.js App Router applications served behind the YARP API gateway: `@bookworm/storefront` and `@bookworm/commerce` (which together form the customer-facing microfrontend experience) and `@bookworm/backoffice` (for store staff). When page files mix routing, data fetching, form state, and layout logic together, server and client boundaries blur and routes become difficult to test.

BookWorm keeps route files thin and delegates domain logic to focused feature slices:

- **Thin route entrypoints:** Route files handle page metadata, loading boundaries, and server-side prefetching, then render a single view component from `features/`.
- **Domain-aligned feature slices:** UI components, filters, tables, and forms are grouped under `features/` by business capability ([[domain|catalog]], [[domain|shopping]], [[domain|ordering]], [[domain|reviews]]), mirroring the backend service boundaries.
- **Centralized navigation and constants:** Application titles, pagination defaults, and navigation trees live in `config/` (or `@workspace/storefront-shell` for customer zones) rather than being duplicated across components.
- **Separate authentication scopes:** Customer zones (`storefront` and `commerce`) share a single Better Auth session owned by `storefront` (`/api/auth/[...all]`), while `backoffice` configures its own Microsoft Entra ID scopes through `@workspace/auth` so customer sessions never request staff-only write permissions. Backend APIs still enforce authorization independently.

## Reference

### Application Comparison

| Attribute               | `@bookworm/storefront`                             | `@bookworm/commerce`                                         | `@bookworm/backoffice`               |
| :---------------------- | :------------------------------------------------- | :----------------------------------------------------------- | :----------------------------------- |
| **Audience**            | Online bookstore customers (public & discovery)    | Authenticated bookstore customers (cart & orders)            | Store administrators and staff       |
| **Gateway Path Prefix** | `/` (fallback zone)                                | `/basket`, `/checkout/*`, `/account/*`, `/commerce-assets/*` | `/backoffice`                        |
| **Rendering Features**  | App Router, `cacheComponents`, MFE, Turbopack      | App Router, MFE (`assetPrefix`), Turbopack                   | App Router, `basePath`, Turbopack    |
| **Auth Ownership**      | Owns `/api/auth/[...all]` (Better Auth + Entra ID) | Consumes shared session; `proxy.ts` enforces login           | Owns `/backoffice/api/auth/[...all]` |
| **Conversational UI**   | CopilotKit + AG-UI (`/api/copilotkit/[[...slug]]`) | None                                                         | None                                 |
