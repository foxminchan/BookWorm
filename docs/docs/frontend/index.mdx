BookWorm's frontend is a multi-zone web platform composed of three independent web applications—**Storefront**, **Commerce**, and **Backoffice**—served behind a single reverse-proxy **API Gateway** origin. Each surface is organized into domain-aligned vertical feature slices backed by layered shared foundations that enforce one-way dependencies, strict server-versus-client rendering boundaries, centralized authentication handoffs, and measurable accessibility and performance standards.
