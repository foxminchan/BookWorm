This reference catalogs the Bun and Turborepo workspace under `src/Clients/`, covering toolchain versions, root scripts, Turborepo dependency boundary tiers, and all 19 workspace members (3 Next.js applications and 16 `@workspace/*` packages). For the architectural rationale behind these boundaries, see [[doc|frontend/007-architecture-and-state-design]].

## Overview

| Property                  | Value                                                                      |
| :------------------------ | :------------------------------------------------------------------------- |
| **Owner**                 | BookWorm Frontend (`@bookworm/clients`)                                    |
| **Source**                | `src/Clients/`                                                             |
| **Package manager**       | `bun@1.4.4` (lockfile: `src/Clients/bun.lock`; do not use `npm` or `pnpm`) |
| **Monorepo orchestrator** | Turborepo `^2.11.13` (`src/Clients/turbo.json`)                            |
| **Workspace members**     | 19 total: 3 applications (`apps/*`) and 16 shared packages (`packages/*`)  |

## Dependency boundary tiers

`turbo boundaries` enforces one-way dependencies across all 19 packages using `tags` defined in each package's `turbo.json` and deny rules in `src/Clients/turbo.json`:

| Tier tag     | Allowed workspace imports               | Denied workspace imports      | Responsibility                                                                                |
| :----------- | :-------------------------------------- | :---------------------------- | :-------------------------------------------------------------------------------------------- |
| `config`     | None within workspace                   | `app`, `domain`, `foundation` | Shared ESLint, TypeScript, Next.js, Vitest, Playwright, and Allure presets                    |
| `foundation` | `config`, `foundation`                  | `app`, `domain`               | Pure DTO types, helper utilities, environment schemas, and OpenTelemetry startup              |
| `domain`     | `config`, `foundation`, `domain`        | `app`                         | Design system, shared customer shell, API clients, query hooks, auth, SEO, validations, mocks |
| `app`        | `config`, `foundation`, `domain`, `app` | —                             | Deployable Next.js 16 applications (`storefront`, `commerce`, `backoffice`)                   |

## Root workspace scripts and Turborepo environment

### Root scripts (`src/Clients/package.json`)

Run from `src/Clients/`:

| Script                    | Underlying command                            | Purpose                                                                               |
| :------------------------ | :-------------------------------------------- | :------------------------------------------------------------------------------------ |
| `bun run dev`             | `turbo run dev`                               | Starts Next.js development servers with Turbopack                                     |
| `bun run build`           | `turbo run build`                             | Builds production Next.js bundles (tracks `microfrontends.json` as input)             |
| `bun run boundaries`      | `turbo boundaries`                            | Validates tier import rules across all 19 packages                                    |
| `bun run check-types`     | `turbo run check-types`                       | Runs `@typescript/native` `tsc --noEmit` across packages                              |
| `bun run lint`            | `turbo run lint`                              | Runs ESLint (`--max-warnings 0`) across packages                                      |
| `bun run test`            | `turbo run test`                              | Runs Vitest unit/component tests with Allure output                                   |
| `bun run e2e`             | `turbo run test:e2e`                          | Compiles Gherkin specs (`bddgen`) and runs Playwright E2E suites                      |
| `bun run format`          | `prettier --write "**/*.{ts,tsx,md,feature}"` | Formats workspace source, Markdown, and Gherkin files (also via `mise run format:fe`) |
| `bun run allure:generate` | `turbo run allure:generate`                   | Generates per-app Allure reports (depends on `test`)                                  |
| `bun run allure:report`   | `allure generate --clean ...`                 | Aggregates Backoffice, Storefront, and Commerce results into `allure-report/`         |

### Turborepo environment variables (`src/Clients/turbo.json`)

| Scope                     | Variables                                                                                                                                                                              | Notes                                |
| :------------------------ | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :----------------------------------- |
| `globalEnv`               | `NODE_ENV`, `NEXT_PUBLIC_GATEWAY_HTTPS`, `NEXT_PUBLIC_GATEWAY_HTTP`, `NEXT_PUBLIC_COPILOT_ENABLED`, `NEXT_PUBLIC_COPILOT_AGENT_NAME`, `NEXT_PUBLIC_MAX_RETRIES`, `NEXT_PUBLIC_APP_URL` | Included in every task cache hash    |
| `build.env`               | `ENTRA_INSTANCE`, `ENTRA_TENANT_ID`, `ENTRA_CLIENT_ID`, `BETTER_AUTH_SECRET`, `SKIP_ENV_VALIDATION`, `NEXT_RUNTIME`, `OTEL_EXPORTER_OTLP_ENDPOINT`, `OTEL_EXPORTER_OTLP_HEADERS`       | Scoped to Next.js build tasks        |
| `test.passThroughEnv`     | `FAKER_SEED`, `MSW_COOKIE_STORE_PATH`                                                                                                                                                  | Passed through without busting cache |
| `test:e2e.passThroughEnv` | `PLAYWRIGHT_*`, `BASE_URL`, `HEADLESS`, `CI`, `SLOW_MO`, `VIDEO`, `TEST_ADMIN_EMAIL`, `TEST_ADMIN_PASSWORD`                                                                            | Passed through to Playwright runs    |

:::note
`lint` and `check-types` depend on the Turborepo `transit` virtual node (`"dependsOn": ["transit"]`) so dependency changes invalidate downstream lint/type caches without requiring intermediate package build artifacts.
:::
