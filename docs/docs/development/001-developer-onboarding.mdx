# Welcome to BookWorm development

[[domain|BookWorm]] is a cloud-native microservices application built with .NET Aspire, Domain-Driven Design, and AI integration. This guide helps you set up your environment, understand the development workflow, and contribute changes confidently.

## Onboarding path

1. [[doc|development/002-getting-started]]: Fork and clone BookWorm, configure Git, and review the project guide.
2. [[doc|development/003-development-workflow]]: Create branches, make changes, and use the repository's agent skills.
3. [[doc|development/004-engineering-standards]]: Follow conventions for C#, integration events, and Protocol Buffers.
4. [[doc|development/005-testing]]: Choose the right test approach and run the relevant checks.
5. [[doc|development/006-pull-request-process]]: Prepare your changes for review and get help when needed.

For detailed project prerequisites, setup instructions, and architecture context, start with the [repository's AGENTS.md](https://github.com/foxminchan/BookWorm/blob/main/AGENTS.md) and [README](https://github.com/foxminchan/BookWorm/blob/main/README.md).

## Before making a change

- Find the owning service or domain and understand its boundaries.
- Read the relevant repository instructions and load the skills for your task.
- Keep changes focused, and update related tests and documentation.
- Run the checks that cover your changes before opening a pull request.
