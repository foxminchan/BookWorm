This reference catalogs every automated test layer, framework version, project inventory, coverage target, and verification command across BookWorm's backend (`src/Services/`, `tests/`), frontend (`src/Clients/`), and documentation (`docs/`) workspaces. For step-by-step execution instructions, see [[doc|development/005-testing]] and [[doc|frontend/004-testing-and-quality-gates]].

## Overview

| Layer                            | Framework / Runner                                                                 | Workspace     | Primary Command                                             | Requires Docker?  |
| :------------------------------- | :--------------------------------------------------------------------------------- | :------------ | :---------------------------------------------------------- | :---------------: |
| **Backend unit tests**           | TUnit `1.87.12` on Microsoft.Testing.Platform (MTP)                                | Repo root     | `mise run test:unit`                                        |        No         |
| **Architecture tests**           | `TngTech.ArchUnitNET.TUnit` `0.13.5`                                               | Repo root     | `mise run test:unit`                                        |        No         |
| **Async message contract tests** | `PactNet` `5.0.1` (consumer → provider)                                            | Repo root     | `mise run test:contracts`                                   |        No         |
| **Backend code coverage**        | `Microsoft.Testing.Extensions.CodeCoverage` (XML)                                  | Repo root     | `mise run test:coverage`                                    |        No         |
| **Frontend static checks**       | Turborepo `boundaries`, `@typescript/native` `7.0.2`, ESLint `10.15.0`             | `src/Clients` | `bun run boundaries && bun run check-types && bun run lint` |        No         |
| **Frontend unit & component**    | Vitest `5.1.2`, Testing Library, Happy DOM, MSW v2                                 | `src/Clients` | `bun run test`                                              |        No         |
| **Frontend BDD E2E & a11y**      | Playwright `1.65.1`, `playwright-bdd` `9.2.1`, `@axe-core/playwright` `4.14.1`     | `src/Clients` | `bun run e2e`                                               | Depends on target |
| **Documentation checks**         | `@eventcatalog/linter` `1.4.0`, Prettier `3.10.1`, `@eventcatalog/fitness` `0.1.4` | `docs`        | `bun run check && bun run fitness`                          |        No         |

## Backend testing stack and conventions

| Concern                    | Verified Package / Standard                                                                                                  | Source                           |
| :------------------------- | :--------------------------------------------------------------------------------------------------------------------------- | :------------------------------- |
| **Test framework**         | TUnit `1.87.12` (never xUnit, NUnit, or MSTest)                                                                              | `Directory.Packages.props`       |
| **Test runner**            | `Microsoft.Testing.Platform` (use `--treenode-filter`, not VSTest `--filter`)                                                | `global.json`, `mise.toml`       |
| **Assertions & mocking**   | `Shouldly` `4.3.0`, `Moq` `4.21.0`, `Bogus` `35.6.5`                                                                         | `tests/BookWorm.Testing/`        |
| **Reporting**              | `Allure.TestingPlatform` `3.0.0-preview.1` (auto-attached to all `*Tests` projects)                                          | `Directory.Build.props`          |
| **Naming convention**      | `Given<Condition>_When<Action>_Then<ExpectedResult>` (for example, `GivenValidBook_WhenAddingToLibrary_ThenSuccessReturned`) | Engineering convention           |
| **Domain coverage target** | >=80% on core domain logic; coverage exclusions configured in `coverage.settings`                                            | `coverage.settings`, `sonar.yml` |
| **Class modifiers**        | All test classes must be `sealed`                                                                                            | `tests/BookWorm.ArchTests/`      |

### Backend test project inventory

BookWorm's `BookWorm.slnx` contains **9 unit test projects**, **7 Pact contract test projects**, **1 architecture test project**, and **1 shared test helper library (`tests/BookWorm.Testing`)**.

:::note
**Backend `.IntegrationTests` status:** No `.IntegrationTests` projects currently exist in `BookWorm.slnx`. If added in the future, follow the `BookWorm.<Service>.IntegrationTests` naming convention defined in `AGENTS.md`.
:::

- `Catalog-Rating` · `Rating-Catalog`
- `Catalog-Scheduler`
- `Finance-Ordering` · `Ordering-Finance`
- `Notification-Finance`

## Frontend testing matrix (`src/Clients`)

Frontend test configuration is centralized in `@workspace/app-config` (deterministic Faker seeds, isolated MSW v2 mock handlers, router stubs). Declarative files (`page.tsx`, `layout.tsx`, `env.mjs`, `instrumentation.ts`, `proxy.ts`, `config/`) are excluded from V8 coverage metrics so percentages measure executable logic in `features/`, `components/`, and `hooks/`.

### Frontend verification commands

| Check              | Working Directory | Command                        | Tooling / Scope                                                  |
| :----------------- | :---------------- | :----------------------------- | :--------------------------------------------------------------- |
| Format frontend    | Repo root         | `mise run format:fe`           | Prettier `3.10.1` (`*.{ts,tsx,md,feature}`)                      |
| Check boundaries   | `src/Clients`     | `bun run boundaries`           | Turborepo `config` → `foundation` → `domain` → `app` rules       |
| Type check         | `src/Clients`     | `bun run check-types`          | `@typescript/native` (`tsgo`) across all apps and 16 packages    |
| Lint & a11y static | `src/Clients`     | `bun run lint`                 | ESLint `10.15.0` (`--max-warnings 0`) + `eslint-plugin-jsx-a11y` |
| Unit & component   | `src/Clients`     | `bun run test`                 | Vitest `5.1.2` + Happy DOM + MSW v2 (`fast-check` in Storefront) |
| Coverage           | `src/Clients`     | `bunx turbo run test:coverage` | `@vitest/coverage-v8` (`lcov`, `json-summary`, `html`)           |
| Production build   | `src/Clients`     | `bun run build`                | Next.js `16.4.6` production build with Turbopack                 |
| BDD E2E & a11y     | `src/Clients`     | `bun run e2e`                  | `bddgen` + Playwright `1.65.1` + `@axe-core/playwright` `4.14.1` |
| Allure report      | `src/Clients`     | `bun run allure:report`        | Merges Vitest and Playwright results across all 3 apps           |
