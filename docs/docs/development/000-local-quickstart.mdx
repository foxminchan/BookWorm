---
title: Run BookWorm locally
summary: The shortest path from a prepared machine to a responding local BookWorm application.
owners:
  - architecture-enabling-team
---

Follow these five steps to start the application. With Docker ready and images cached, this path is designed to take under 10 minutes; first-time image downloads can take longer.

<Admonition type="info" title="Before you begin">
	Have Git, mise, and Docker Desktop (or a compatible container runtime) installed. Keep Docker
	running while the application starts.
</Admonition>

<Steps>
<Step title="Clone the repository">

Replace the placeholders with your repository URL and preferred local directory:

```bash
git clone <repository-url>
cd <repository-directory>
```

</Step>
<Step title="Install the pinned toolchain">

From the repository root, install the versions selected for the project:

```bash
mise install
```

</Step>
<Step title="Prepare dependencies and Git hooks">

```bash
mise run prepare
```

</Step>
<Step title="Start the application">

```bash
mise run run
```

Wait for Aspire to finish starting the resources. The dashboard address is printed in the terminal.

</Step>
<Step title="Verify the dashboard and application">

Open the printed dashboard address, confirm the required resources report **Running**, then open the public application endpoint shown for the gateway. Confirm that the application responds.

</Step>
</Steps>

If a step fails, start with [[doc|development/007-troubleshoot-local-dev]]. For tool choices, secrets, and workspace-specific setup, see [[doc|development/002-getting-started]].
