Use this guide to run BookWorm's automated backend unit tests, architecture tests, Pact asynchronous-message contract tests, code coverage collection, and documentation quality gates. For frontend quality gates, see [[doc|frontend/004-testing-and-quality-gates]]; for framework versions and the full project inventory, see [[doc|development/008-testing-matrix]].

## Prerequisites

- Local workspace restored via `mise run prepare` (see [[doc|development/002-getting-started]])
- Docker is **not** required for unit, architecture, contract, or documentation checks

## Steps

<Steps>
<Step title="Run a single backend unit test project during rapid iteration">

Target only the service you changed (using the Microsoft.Testing.Platform runner configured in `global.json`):

<CodeGroup>

```bash
dotnet test src/Services/<ServiceName>/BookWorm.<ServiceName>.UnitTests/BookWorm.<ServiceName>.UnitTests.csproj
```

</CodeGroup>

Where:

- `<ServiceName>`: One of `Basket`, `Catalog`, `Chat`, `Finance`, `McpTools`, `Notification`, `Ordering`, `Rating`, or `Scheduler`.

</Step>
<Step title="Run all backend unit and architecture tests">

From the repository root, run all 9 service `.UnitTests` projects plus `tests/BookWorm.ArchTests`:

<CodeGroup>

```bash
mise run test:unit
```

</CodeGroup>

</Step>
<Step title="Run Pact consumer-driven contract tests">

Run consumer pact generation followed by provider message verification in the required order:

<CodeGroup>

```bash
mise run test:contracts
```

</CodeGroup>

`mise run test:contracts` executes `test:contracts:consumer` first (generating JSON pact files in `tests/pacts/`) and then `test:contracts:provider` (verifying producers against those files).

To run a single contract project manually, pass the Microsoft.Testing.Platform `--treenode-filter` used in `mise.toml`:

<CodeGroup>

```bash
# Consumer stage first
dotnet test src/Services/Finance/BookWorm.Finance.ContractTests/BookWorm.Finance.ContractTests.csproj \
  --treenode-filter '/*/*/*/*[Category=PactConsumer]'

# Provider stage second
dotnet test src/Services/Ordering/BookWorm.Ordering.ContractTests/BookWorm.Ordering.ContractTests.csproj \
  --treenode-filter '/*/*/*/*[Category=PactProvider]'
```

</CodeGroup>

</Step>
<Step title="Run the full backend test suite or collect SonarCloud-matching coverage">

Run unit, architecture, and contract suites together:

<CodeGroup>

```bash
mise run test
```

</CodeGroup>

To generate XML coverage files under `./test-results` matching SonarCloud (`coverage.settings`):

<CodeGroup>

```bash
mise run test:coverage
```

</CodeGroup>

<Admonition type="note">
	BookWorm currently has **no** backend `.IntegrationTests` projects in `BookWorm.slnx`. Backend
	verification relies on `.UnitTests`, `.ContractTests`, and `BookWorm.ArchTests`.
</Admonition>

</Step>
<Step title="Run EventCatalog documentation checks">

When you modify files under `docs/`, validate EventCatalog linting, Prettier formatting, and architecture fitness rules from `docs/`:

<CodeGroup>

```bash
cd docs
bun run check
bun run fitness
```

</CodeGroup>

</Step>
</Steps>

## Verification

Confirm your targeted or full suite exits with zero failures:

<CodeGroup>

```bash
mise run test
```

</CodeGroup>

Expected output (summary per test project):

<CodeGroup>

```text
Test run summary: Passed!
  total: <count>
  failed: 0
  succeeded: <count>
  skipped: 0
```

</CodeGroup>

## Troubleshooting

| Symptom                                                                | Cause                                                                                                        | Fix                                                                                                                                          |
| :--------------------------------------------------------------------- | :----------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------- |
| Provider contract test fails with missing pact file or outdated schema | `test:contracts:provider` ran before `test:contracts:consumer` regenerated `tests/pacts/*.json`              | Run `mise run test:contracts` (never run provider verification before consumer generation)                                                   |
| `dotnet test --filter` fails or is ignored                             | BookWorm uses Microsoft.Testing.Platform (MTP) + TUnit, not VSTest                                           | Use `--treenode-filter '/*/*/*/*[Category=<Category>]'` instead of VSTest `--filter`                                                         |
| `BookWorm.ArchTests` fails on a new class                              | New endpoint, handler, DbContext, or test class is not `sealed` or violates bounded-context dependency rules | Mark the class `sealed`, remove direct cross-service references, and re-run `dotnet test tests/BookWorm.ArchTests/BookWorm.ArchTests.csproj` |
| `bun run check` fails in `docs/`                                       | EventCatalog frontmatter lint violation or Prettier formatting drift                                         | Run `mise run format:docs` and re-run `bun run check` from `docs/`                                                                           |
