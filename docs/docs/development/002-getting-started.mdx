Use this guide to prepare a local fork of BookWorm for contributing backend, frontend, or documentation changes. If you want a guided first-time run of the full application stack instead, follow [[doc|development/000-local-quickstart]].

## Prerequisites

- A GitHub account with SSH or HTTPS Git access configured
- [mise](https://mise.jdx.dev/) installed and activated in your shell
- [Docker Desktop](https://www.docker.com/get-started/) installed (required only when running the Aspire AppHost; not required for unit tests, architecture tests, frontend-only work, or documentation edits)

## Steps

<Steps>
<Step title="Fork and clone the repository">

Fork [foxminchan/BookWorm](https://github.com/foxminchan/BookWorm) on GitHub, then clone your fork and add `upstream`:

<CodeGroup>

```bash
git clone https://github.com/<github-username>/BookWorm.git
cd BookWorm
git remote add upstream https://github.com/foxminchan/BookWorm.git
```

</CodeGroup>

Where:

- `<github-username>`: Your GitHub handle that owns the fork.

</Step>
<Step title="Install the pinned toolchain">

Install the repository tools managed in `mise.toml` (Node `26`, Aspire `17`, `uv`, Azure CLI `2`, GitHub CLI `2`), plus idiomatic tool versions from `global.json` (.NET `11.0.100`) and `.bun-version` (Bun `1.4.4`):

<CodeGroup>

```bash
mise install
```

</CodeGroup>

</Step>
<Step title="Install optional tools when your task requires them">

Run these tasks only if you edit `.proto` files (`BookWorm.Catalog` or `BookWorm.Basket`) or use the GitHub Copilot CLI extension:

<CodeGroup>

```bash
mise run setup:buf
mise run setup:copilot
```

</CodeGroup>

</Step>
<Step title="Restore .NET dependencies and configure Git hooks">

Restore NuGet packages, local .NET tools (`husky`, `csharpier`, `dotnet-ef`, `dotnet-outdated-tool`), and register `.husky` as `core.hooksPath`:

<CodeGroup>

```bash
mise run prepare
```

</CodeGroup>

</Step>
<Step title="Install frontend or documentation Bun dependencies">

Install dependencies only for the JavaScript workspaces you plan to touch:

<CodeGroup>

```bash
# Frontend monorepo (Storefront, Commerce, Backoffice, 16 @workspace/* packages)
bun install --cwd src/Clients

# EventCatalog documentation site
bun install --cwd docs
```

</CodeGroup>

> [!IMPORTANT]
> Never run `npm install`, `pnpm install`, or `yarn` in `src/Clients` or `docs`. Both workspaces use Bun-managed `bun.lock` lockfiles.

</Step>
<Step title="Inspect available `mise` tasks and optionally preview docs">

List all workspace tasks defined in `mise.toml`:

<CodeGroup>

```bash
mise tasks ls
```

</CodeGroup>

To preview the EventCatalog documentation site locally without Docker, run from `docs/`:

<CodeGroup>

```bash
bun run dev
```

</CodeGroup>

Open `http://localhost:3000` in your browser.

</Step>
</Steps>

## Verification

Confirm your Git remotes, toolchain versions, and build health:

<CodeGroup>

```bash
git remote -v
git config core.hooksPath
mise run build
```

</CodeGroup>

Expected output:

<CodeGroup>

```text
origin    https://github.com/<github-username>/BookWorm.git (fetch)
origin    https://github.com/<github-username>/BookWorm.git (push)
upstream  https://github.com/foxminchan/BookWorm.git (fetch)
upstream  https://github.com/foxminchan/BookWorm.git (push)
.husky
Build succeeded.
    0 Warning(s)
    0 Error(s)
```

</CodeGroup>

## Troubleshooting

| Symptom                                                               | Cause                                                            | Fix                                                                                                       |
| :-------------------------------------------------------------------- | :--------------------------------------------------------------- | :-------------------------------------------------------------------------------------------------------- |
| `dotnet: command not found` or wrong SDK version after `mise install` | `mise` shims are not activated in the current shell              | Run `eval "$(mise activate bash)"` (or add `mise activate` to your shell profile) and open a new terminal |
| `mise run prepare` succeeds but pre-commit hook does not trigger      | Local Git hook path was overridden or `.husky` is not executable | Run `mise run hook` and confirm `git config core.hooksPath` returns `.husky`                              |
| `bun install` fails with version mismatch in `src/Clients`            | Global Bun version differs from `.bun-version` (`1.4.4`)         | Run `mise install` from repo root and confirm `bun --version` prints `1.4.4`                              |
| `mise run build` fails with warnings treated as errors                | `Directory.Build.props` sets `TreatWarningsAsErrors: true`       | Resolve compiler or analyzer warnings before building; do not suppress warnings globally                  |
