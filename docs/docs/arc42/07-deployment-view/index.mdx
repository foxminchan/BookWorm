BookWorm is cloud-hosted in Azure, with external managed providers for messaging, vector search, and email; local development uses containerized services and emulators instead of most cloud dependencies. Development, Staging, and Production retain the same logical workload placement while varying capacity and resilience settings. This model supports independent application scaling, managed stateful services, identity-based access, and a lower-cost local workflow; it is not an on-premises or hybrid deployment.
