BookWorm is an online bookstore built on .NET 11, Aspire 17, Next.js 16, Wolverine, and Kafka across six bounded contexts. This page provides a single-page C4 System Context (Level 1) and Container (Level 2) overview showing every user actor, frontend microfrontend (MFE), backend service, AI platform dependency, and backing store.

## Scope and constraints

- **Scope:** Covers the entire BookWorm platform—three Next.js 16 frontends (`Storefront`, `Commerce`, `Backoffice`), the YARP `API Gateway`, ten .NET 11 backend services and Azure Functions workers, two Presidio privacy containers, managed Azure stores, and external cloud providers.
- **Key constraints:** Each bounded context owns its authoritative persistence; cross-service writes never share databases; only the `API Gateway` (and the Entra-protected Quartz Dashboard) expose external HTTP ingress; AI workflows remain strictly read-only with respect to commerce transactions.

| **Rating API** (`rating`)                                 | Reviews         | .NET 11 Minimal API + Agent-to-Agent (A2A) gRPC   | Azure Cosmos DB (`ratingdb`/`feedbacks`), Redis, Foundry, Presidio                       | `src/Services/Rating/BookWorm.Rating/`             |

## Key runtime and deployment boundaries

- **Synchronous vs. asynchronous communication:** Interactive reads use REST (`/api/v1/*`) behind YARP and internal gRPC (`book.v1`, `basket.v1`, A2A gRPC). Cross-context workflows use Kafka CloudEvents via Wolverine with per-service dead-letter queues (`bookworm.{env}.{service}.dead-letter-queue`).
- **Identity and authorization:** Microsoft Entra ID issues OAuth2/JWT tokens for three app roles (`admin`, `business_user`, `customer`), per-service managed identities authenticate passwordlessly to Azure resources, and Entra Agent Identities (`chatAgentId`, `ratingAgentId`) isolate AI On-Behalf-Of (OBO) calls.
- **Deployment:** Aspire 17 (`aspire deploy`) publishes all 16 core Container Apps plus `quartz-dashboard` into one Azure Container Apps environment (`Consumption` workload profile). See [[doc|arc42/07-deployment-view]] for environment SKUs and open production hardening items.
