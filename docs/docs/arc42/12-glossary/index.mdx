This glossary is the single authoritative vocabulary for BookWorm's business domains, bounded contexts, and platform architecture. It consolidates the platform glossary and all domain ubiquitous languages so product, engineering, and operations teams use consistent terms with explicit ownership boundaries.

## Overview

| Property             | Value                                                                                               |
| :------------------- | :-------------------------------------------------------------------------------------------------- |
| **Owner**            | BookWorm platform and domain maintainers                                                            |
| **Scope**            | Whole platform (`BookWorm` root domain, 6 bounded contexts, edge apps, and shared infrastructure)   |
| **Canonical status** | Single source of truth replacing `arc42/12-glossary` and per-domain `ubiquitous-language.mdx` files |

:::note
In prose, BookWorm uses US English (`canceled`, `fulfillment`, `behavior`). Code identifiers and C# enum literals remain verbatim in backticks (for example, `Status.Cancelled`).
:::

## Core architecture and platform terms

| Term                             | Owner / Layer                       | Definition                                                                                                                                                              | Boundary notes                                                                                                                            |
| :------------------------------- | :---------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------- |
| **A2A (Agent-to-Agent)**         | Conversational / Reviews            | Protocol over gRPC (`A2A.Grpc.AspNetCore`) used by Chat API to invoke Rating API's remote `Rating Agent`.                                                               | Authenticated with Microsoft Entra ID Agent Identities; read-only analysis.                                                               |
| **AG-UI**                        | Conversational / Storefront         | Interactive streaming protocol exposed by Chat API at `/ag-ui` and consumed by Storefront's CopilotKit chat runtime.                                                    | Requires authenticated `customer` policy and per-user rate limiting; session state lives in Azure Blob Storage (`chatting-blob`).         |
| **Anti-corruption layer**        | Cross-cutting                       | Adapter translating another bounded context's contract into the consumer's local model.                                                                                 | Prevents upstream schema changes from leaking into downstream domain logic.                                                               |
| **Aspire**                       | AppHost (`src/Aspire`)              | Distributed application orchestrator (Aspire 17) governing local containers, service discovery, telemetry, and `aspire deploy` Azure provisioning.                      | Replaces ad-hoc compose files and manual `azd` workflows; there is no `azure.yaml` in this repository.                                    |
| **Backoffice**                   | Edge (`@bookworm/backoffice`)       | Next.js 16 staff web application mounted at `/backoffice` behind the API Gateway.                                                                                       | Used by store administrators to manage catalog listings, orders, customers, and reviews.                                                  |
| **Bounded context**              | Whole platform                      | Explicit domain boundary within which a model and vocabulary have unambiguous meaning and a single owning service or system.                                            | Contexts exchange data through versioned HTTP, gRPC, or Kafka contracts—never shared databases.                                           |
| **Commerce**                     | Edge (`@bookworm/commerce`)         | Next.js 16 customer microfrontend (MFE) serving `/basket`, `/checkout/*`, and `/account/*` behind the API Gateway.                                                      | Shares the authenticated customer session owned by Storefront; not indexed by search engines.                                             |
| **Dead-letter queue (DLQ)**      | Messaging (Kafka)                   | Per-service native Kafka topic (`bookworm.{env}.{service}.dead-letter-queue`) where Wolverine routes messages that exhaust retry policies or fail JSON deserialization. | Requires operational inspection and controlled replay; never silently discarded.                                                          |
| **Eventual consistency**         | Cross-cutting                       | State in which an asynchronously updated projection or index trails its authoritative source before converging.                                                         | Applies to Catalog rating summaries and Qdrant search vectors; implies no fixed convergence SLA.                                          |
| **Finance orchestration**        | Ordering (`finance`)                | Azure Functions and Azure Durable Task Scheduler (`finance-taskhub`) saga coordinating post-checkout basket cleanup and order notification commands.                    | Not payment processing and not the owner of `Order` business status; has no PostgreSQL database.                                          |
| **FusionCache**                  | BuildingBlocks (`BookWorm.Chassis`) | Multi-layer caching library combining L1 in-memory cache, L2 Redis cache, Redis backplane, fail-safe protection, and distributed locking.                               | Used across Catalog API, Basket API, Ordering API, Rating API, and Notification.                                                          |
| **Idempotency**                  | Cross-cutting                       | Property ensuring repeated HTTP requests or Kafka messages do not duplicate business side effects.                                                                      | Ordering enforces HTTP idempotency keys; Notification and Basket enforce 24-hour Redis idempotency (`IIntegrationEventIdempotencyGuard`). |
| **Integration event**            | Messaging (Kafka)                   | Immutable fact in `BookWorm.Contracts` serialized as CloudEvents JSON over Kafka describing a committed state change.                                                   | Does not transfer data ownership to subscribers.                                                                                          |
| **Mailpit**                      | Platform (local dev)                | Local SMTP test server container (port `587`) used by Notification in local Aspire runs.                                                                                | Replaced by parameterized SMTP (SendGrid) in cloud deployments.                                                                           |
| **MCP (Model Context Protocol)** | Conversational (`mcptools`)         | Stateless Streamable HTTP protocol (`/mcp`) exposing read-only Catalog tools and reusable AI prompts.                                                                   | Tool access does not transfer book ownership from Catalog; protected by `mcptools_read` scope.                                            |
| **Microsoft Foundry**            | AI Platform                         | Managed AI hosting service providing BookWorm's `chat` (`ModelRouter`), `decision` (`Microsoft-Decision-1`), and `embedding` (`embed-v-4-0`) model deployments.         | Accessed passwordlessly via Entra ID RBAC (`Cognitive Services User`).                                                                    |
| **Presidio**                     | Privacy (`src/Integrations`)        | Microsoft Presidio analyzer and anonymizer HTTP sidecars (port `3000`) detecting and redacting PII in Chat API and Rating API traffic.                                  | Runs fail-closed: privacy middleware errors halt the request rather than bypassing redaction.                                             |
| **Projection**                   | Cross-cutting                       | Derived read or search model built from authoritative data (for example, Catalog's rating summary, Qdrant vectors, or Marten's `OrderSummary`).                         | Disposable and rebuildable from its source of truth.                                                                                      |
| **Saga**                         | Ordering (`finance`)                | Durable multi-step coordination workflow with bounded retries and compensation commands.                                                                                | Not a single atomic transaction; saga timeout does not change an `Order`'s business status.                                               |
| **Source of truth**              | Cross-cutting                       | Authoritative persistence store owned by a bounded context for a specific business record.                                                                              | Caches, search indexes, and projections never replace the source of truth.                                                                |
| **Storefront**                   | Edge (`@bookworm/storefront`)       | Next.js 16 public customer microfrontend (MFE) serving catalog browsing, book details, AI chat, and Better Auth sign-in (`/api/auth/[...all]`).                         | Fallback zone (`/`) behind the YARP API Gateway.                                                                                          |
| **Wolverine**                    | Messaging (`BookWorm.Chassis`)      | Messaging runtime routing CloudEvents integration events and commands over Kafka with PostgreSQL or Cosmos DB transactional outbox/inbox where configured.              | Replaces MassTransit/RabbitMQ (neither is used in BookWorm).                                                                              |

## Catalog domain terms

Owned by [[domain|catalog]] (`BookWorm.Catalog`, PostgreSQL `catalogdb`, Qdrant `vectordb`, Azure Blob Storage `catalog-blob`).

| Term               | Definition                                                                                                                        | Invariants and boundary notes                                                                                    |
| :----------------- | :-------------------------------------------------------------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------- |
| **Author**         | Named contributor associated with one or more books.                                                                              | Many-to-many relationship with `Book` via `BookAuthor`.                                                          |
| **Availability**   | Listing state indicating whether a book is currently in stock or out of stock.                                                    | Describes the Catalog listing only; does not reserve stock for a `Basket` or guarantee fulfillment.              |
| **Book**           | Listed title available for discovery, pricing, and purchase.                                                                      | Owned by Catalog; other bounded contexts reference it strictly by UUID (`BookId`). Soft-deleted via `isDeleted`. |
| **Category**       | Classification grouping books for browsing and filtering.                                                                         | Each book belongs to one category.                                                                               |
| **Price**          | Book's regular (original) price and optional discounted sale price.                                                               | Discount price cannot be negative or exceed the original price; modeled on `Book`, not as a separate product.    |
| **Publisher**      | Publishing organization associated with a book.                                                                                   | Each book belongs to one publisher.                                                                              |
| **Rating summary** | Aggregate average rating (`averageRating`) and review count (`totalReviews`) displayed on a book listing.                         | Eventually consistent projection updated from Reviews events; never replaces individual `Feedback` records.      |
| **Vector index**   | Qdrant collection (`vectordb`) storing book text embeddings generated by `Catalog Ingestion` via Microsoft Foundry `embed-v-4-0`. | Derived hybrid-search index; rebuildable from PostgreSQL `catalogdb`.                                            |

## Shopping domain terms

Owned by [[domain|shopping]] (`BookWorm.Basket`, authoritative Redis store).

| Term                    | Definition                                                                                      | Invariants and boundary notes                                                                                    |
| :---------------------- | :---------------------------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------- |
| **Basket**              | Authenticated customer's mutable collection of book identifiers and quantities before purchase. | Stored authoritatively in Redis (no SQL database); not an `Order` and not an inventory reservation.              |
| **Basket item**         | Book identifier (`BookId`) paired with a positive requested quantity inside a basket.           | Does not store Catalog metadata or locked Order prices; enriched from Catalog API over gRPC at read time.        |
| **Checked-out event**   | Integration event (`UserCheckedOutIntegrationEvent`) initiating post-checkout coordination.     | Published by Ordering API to Kafka topic `bookworm.{env}.ordering.user-checked-out` after an order is persisted. |
| **Checkout**            | Cross-context transition that validates a customer's basket and creates a durable `Order`.      | Initiates Finance coordination; does not prove payment settlement, basket cleanup, or order completion.          |
| **Customer identifier** | Authenticated subject identifier scoping a customer's basket in Shopping.                       | Treated independently from Ordering's `Buyer` aggregate boundary.                                                |

## Ordering domain terms

Owned by [[domain|ordering]] (`BookWorm.Ordering`, PostgreSQL `orderingdb` with EF Core + Marten; `BookWorm.Finance`, Azure Durable Task Scheduler `finance-taskhub`).

| Term              | Definition                                                                                                | Invariants and boundary notes                                                                              |
| :---------------- | :-------------------------------------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------- |
| **Address**       | Delivery location containing street, city, and province details.                                          | Value object owned by a `Buyer`.                                                                           |
| **Buyer**         | Named customer profile associated with one or more orders in Ordering.                                    | Owned by Ordering; manages delivery address and order history.                                             |
| **`Cancelled`**   | Terminal `Order` status (`Status.Cancelled`) for an order that will not complete.                         | Reached only from `New` via an explicit Ordering command; a Finance saga timeout does not set this status. |
| **`Completed`**   | Terminal `Order` status (`Status.Completed`) for a finished order.                                        | Reached only from `New` via an explicit Ordering command.                                                  |
| **`New`**         | Initial status of a newly created `Order`.                                                                | Transitions exclusively to `Completed` or `Cancelled`.                                                     |
| **Order**         | Durable purchase record containing one or more `Order Item` lines and a lifecycle status.                 | Owned by Ordering after checkout acceptance; independent from mutable `Basket` state.                      |
| **Order item**    | Child line on an `Order` capturing a book ID, positive quantity, and purchase-time unit price.            | Captures active sale price or regular price at checkout; never mutated by later Catalog price edits.       |
| **Order summary** | Marten event-sourced live aggregation and async projection summarizing order state for dashboard queries. | Derived read view inside `orderingdb`.                                                                     |
| **Order total**   | Sum of all `Order Item` line totals (`price * quantity`) on an order.                                     | Computed strictly from recorded items.                                                                     |

## Reviews domain terms

Owned by [[domain|reviews]] (`BookWorm.Rating`, Azure Cosmos DB `ratingdb` / `feedbacks` container partitioned by `/bookId`).

| Term                 | Definition                                                                                                                                                         | Invariants and boundary notes                                                                                        |
| :------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------- |
| **Book reference**   | Catalog `BookId` UUID linked to a customer feedback record.                                                                                                        | Reviews never duplicates or owns Catalog book metadata.                                                              |
| **Comment**          | Optional written review text supplied with a `Feedback` submission.                                                                                                | Screened by Presidio PII middleware before AI summarization.                                                         |
| **Feedback**         | Individual customer rating and optional comment for a book.                                                                                                        | Authoritative record stored in Cosmos DB `ratingdb`/`feedbacks`; at most one record per book and reviewer-name pair. |
| **Feedback summary** | Read-only AI classification (`Best Seller`, `Good`, `Bad`, `No Data`) with metrics and confidence generated by `Rating Agent` and cached in Redis via FusionCache. | Distinct from Catalog's numeric `Rating Summary`; never alters stored `Feedback` records.                            |
| **Rating**           | Integer score from `0` through `5` on a `Feedback` submission.                                                                                                     | Validated by Rating API before persistence.                                                                          |
| **Review**           | Customer-facing Storefront label for an individual `Feedback` submission.                                                                                          | Synonym for `Feedback`; internal code and contracts use `Feedback`.                                                  |

## Conversational domain terms

Owned by [[domain|conversational]] (`BookWorm.Chat`, Azure Blob Storage `chatting-blob` with prefix `ag-ui/`; `BookWorm.McpTools`, stateless `/mcp`).

| Term                               | Definition                                                                                                                                                                                                | Invariants and boundary notes                                                                                             |
| :--------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------ |
| **Book Agent**                     | Primary specialist agent helping customers search books, inspect details, and receive catalog-backed recommendations.                                                                                     | Reads Catalog via MCP tools; delegates complex queries to `Book Catalog Researcher` and `Book Recommendation Researcher`. |
| **Book Catalog Researcher**        | Subagent delegated by `Book Agent` to gather detailed book, author, and category evidence from Catalog MCP tools.                                                                                         | Inherits `Book Agent`'s fail-closed Presidio PII middleware.                                                              |
| **Book Recommendation Researcher** | Subagent delegated by `Book Agent` to assemble a catalog-backed shortlist matching customer preferences.                                                                                                  | Inherits `Book Agent`'s fail-closed Presidio PII middleware.                                                              |
| **Customer request**               | Interactive customer message submitted over AG-UI (`/ag-ui`) to Chat API.                                                                                                                                 | Referencing books or orders in a request never transfers ownership of those records to Conversational.                    |
| **Decision Router**                | Single-pass classifier (`DecisionRouterExecutor` backed by `Microsoft-Decision-1`) evaluating safety (`is_safe`), language (`is_english`), domain scope (`is_in_scope`), and target specialist (`route`). | Runs before invoking any conversational LLM; supports human-in-the-loop disambiguation via `RequestPort`.                 |
| **Handoff**                        | Transfer of conversational control between specialist agents (`QA Agent` → `Book Agent`, or `Book Agent` → remote A2A `Rating Agent`).                                                                    | Moves dialogue control only; never executes transactional actions such as order placement.                                |
| **QA Agent**                       | Specialist agent answering BookWorm policy, delivery, returns, account, order, and billing questions from supplied store-policy context.                                                                  | Has no MCP tools and cannot read or modify live customer baskets, orders, or accounts.                                    |
| **Rating Agent**                   | Remote specialist agent hosted by Rating API and invoked over A2A gRPC to classify and summarize a known book's feedback.                                                                                 | Read-only analysis governed by `Policies/rating-agent.yaml` and Presidio PII middleware.                                  |

## Platform domain terms

Owned by [[domain|platform]] (`BookWorm.Scheduler`, PostgreSQL `schedulerdb`; `BookWorm.Notification`, stateless Kafka + MailKit/Mjml.Net + Redis idempotency worker).

| Term                                    | Definition                                                                                                                                                                                                | Invariants and boundary notes                                                                |
| :-------------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------- |
| **Heartbeat job**                       | Recurring Quartz.NET liveness job (`HeartbeatJob`, cron `0/30 * * * * ?` UTC, every 30 seconds) verifying Scheduler health.                                                                               | Operational monitoring only; carries no business payload.                                    |
| **Integration event idempotency guard** | Redis/FusionCache-backed guard (`IIntegrationEventIdempotencyGuard`, 24-hour window) preventing duplicate handling of redelivered Kafka commands in Notification and Basket.                              | Replaces any legacy relational email-outbox table; Notification uses no PostgreSQL database. |
| **Quartz Dashboard**                    | Operator-facing web UI (`/quartz`) inspecting Scheduler jobs, triggers, and 30-day execution history.                                                                                                     | Protected by Microsoft Entra ID OIDC (`admin` role).                                         |
| **Vector batch job**                    | Recurring Quartz.NET job (`ProcessVectorBatchJob`, cron `0 0/5 * * * ?` UTC, every 5 minutes) publishing `ProcessVectorBatchIntegrationEvent` to unprefixed Kafka topic `scheduler.process-vector-batch`. | Triggers `Catalog Ingestion`; Scheduler does not own book records or embeddings.             |
