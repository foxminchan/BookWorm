This glossary defines the shared ubiquitous language used across all arc42 sections, including domain concepts, acronyms, and BookWorm-specific technical terms. Each definition identifies important ownership or meaning differences so the same word does not imply different business and engineering behavior.

## Domain Terms

| Term                | Definition                                                                                                                                                                 | Synonyms / Acronyms                              |
| :------------------ | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :----------------------------------------------- |

| Basket              | A customer's mutable selection of books and quantities before checkout; it is not an Order, price lock, or inventory reservation.                                          | Shopping basket                                  |
| Basket item         | A book reference and positive requested quantity in a Basket; it contains no purchase-price snapshot.                                                                      | â€”                                              |
| Book                | A Catalog listing that supplies the title and purchase facts used for discovery and checkout.                                                                              | Catalog book                                     |
| Book reference      | A link from a Reviews record to a Catalog book without transferring ownership of the book's details.                                                                       | Catalog book reference                           |
| Buyer               | An Ordering-owned customer profile used for delivery details and order history; it is distinct from the authenticated Customer identity.                                   | â€”                                              |
| Canceled            | Terminal Order state meaning the purchase will not complete; it is reached by an explicit order decision, not inferred from a failed downstream workflow.                  | Order status; implementation spelling: Cancelled |
| Category            | Catalog classification used to group books for browsing and filtering.                                                                                                     | â€”                                              |

| Rating summary      | Catalog's average score and review count, updated asynchronously from Reviews data.                                                                                        | Catalog rating aggregate                         |
| Review              | Customer-facing term for an individual Feedback record; it is not a second record or a rating summary.                                                                     | Feedback                                         |
