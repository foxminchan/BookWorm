This chapter is the navigation index for BookWorm's Architecture Decision Records (ADRs). It links to each decision's canonical record so readers can review its context, alternatives, outcome, consequences, and current status without duplicating that rationale here.

<Admonition type="info">
	The status and rationale in each linked ADR are authoritative. Treat a decision marked
	**Superseded** as historical and follow its replacement when one is identified by the record.
</Admonition>

## Governance

- **Whole-system decisions** establish principles that apply across multiple capabilities.
- **Capability-specific decisions** describe choices owned by a particular system or integration.
- **Preserve decision history.** When a material decision changes, record the new context and outcome and link it to the decision it replaces; do not silently rewrite the earlier rationale.
- **Keep rationale canonical.** This index provides navigation and scope, while each ADR remains the source of its own details and lifecycle status.
- **Review compatibility.** Before applying a decision, check its scope, status, related decisions, and stated consequences.
