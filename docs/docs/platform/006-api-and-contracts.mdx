This index consolidates every HTTP `v1`, gRPC, AG-UI, Model Context Protocol (MCP), Agent-to-Agent (A2A), and Kafka/Wolverine contract across BookWorm's 10 backend services and 3 external integrations. Use it as your starting point to locate gateway routes, local ports, Microsoft Entra ID scopes, RFC 9457 error semantics, and detailed per-service specifications.

## Global API conventions

- **Single public ingress:** All external browser and API traffic enters through the YARP **API Gateway** (`gateway`). Backend services strip their `/{service}` gateway prefix (`X-Powered-By: BookWorm Gateway`) and are not exposed publicly in Azure.
- **API versioning:** All REST services use explicit URL-segment and `api-version` header versioning via `ApiVersions.V1` (`/api/v1/...`). `V2` and `V3` constants exist in `BookWorm.Constants` but are not yet mapped.
- **OpenAPI & Scalar (Development only):** Each HTTP API maps `/openapi/v1.json` only in Development; Aspire AppHost hosts **Scalar** (`scalar`) with Microsoft Entra ID OAuth2 Authorization Code + PKCE for interactive local testing.
- **Health endpoints (Development only):** `MapDefaultEndpoints()` maps `/health` (readiness) and `/alive` (liveness) only when `Environment.IsDevelopment()`.
- **Rate limiting (`AddRateLimiting`):**
  - **Global chained limiter:** Concurrency load-shedding (`PermitLimit = 100`, `QueueLimit = 0`) + Fixed Window per IP/Host (`30` requests / `1` minute, `QueueLimit = 0`).
  - **Named `PerUserRateLimit`:** Token Bucket per `NameIdentifier` (`TokenLimit = 30`, `TokensPerPeriod = 20`, `ReplenishmentPeriod = 10s`, `QueueLimit = 5`).
- **Standard error format:** All HTTP services return RFC 9457 `ProblemDetails` JSON responses with `Content-Type: application/problem+json`.

### Shared HTTP error contract

| Status                  | Meaning                           | Typical cause                                                                                   | Client recovery                                      |
| :---------------------- | :-------------------------------- | :---------------------------------------------------------------------------------------------- | :--------------------------------------------------- |
| `400 Bad Request`       | Validation or domain-rule failure | `FluentValidation` error, missing `x-request-id`, or invalid Order transition                   | Fix payload or preconditions; do not retry unchanged |
| `401 Unauthorized`      | Authentication failed             | Missing, expired, or invalid Microsoft Entra ID JWT                                             | Re-authenticate and retry                            |
| `403 Forbidden`         | Authorization denied              | Token lacks required Entra ID role (`admin`, `business_user`, `customer`) or scope              | Request token with required role and scopes          |
| `404 Not Found`         | Missing or out-of-scope resource  | Entity does not exist or belongs to another customer                                            | Verify resource ID and ownership                     |
| `409 Conflict`          | Concurrency or duplicate request  | Duplicate `x-request-id` (1-hour Redis window), lock contention, or duplicate reviewer feedback | Query current state before issuing a new request     |
| `429 Too Many Requests` | Rate limit exceeded               | Global or `PerUserRateLimit` threshold hit (`Retry-After` header included)                      | Back off for `Retry-After` seconds and retry         |
| `500 / 502 / 503`       | Server or upstream failure        | Unhandled error or unavailable downstream dependency (e.g., fail-closed Presidio)               | Retry idempotent requests with exponential backoff   |

## Protocol interaction overview

External requests enter via the YARP API Gateway, synchronous internal reads run over gRPC/MCP/A2A, and asynchronous cross-domain workflows run over Kafka with CloudEvents JSON.
