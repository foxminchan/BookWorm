All BookWorm workloads run as **15 Azure Container Apps** inside the shared `cae-<token>` Consumption environment. Every container app is configured with `activeRevisionsMode: 'Single'` and `minReplicas: 1`.

## Stateful Function Workers & Orchestration

Two compute workloads run on Azure Functions containers (port `8080`) with `Storage Blob Data Owner` access for Azure Functions host state:

1. **[[service|order-orchestration]] (`finance`):** Coordinates order checkout sagas via Azure Durable Task Scheduler (`finance-taskhub`) and Kafka integration events.
2. **[[service|catalog-ingestion]] (`catalog-ingestion`):** Processes vector embedding batches triggered by [[event|ProcessVectorBatchIntegrationEvent]] from [[service|sheduler-dashboard]], reading from [[container|catalog-database]] and writing embeddings to [[container|catalog-vector]] (Qdrant Cloud).

## PII Redaction Sidecars

[[service|chat-api]] and [[service|rating-api]] route user-generated prompts and feedback through `presidio-analyzer` and `presidio-anonymizer` ([[service|PresidioAPI]]) on internal port `3000` before persisting or forwarding content to Microsoft Foundry models. Neither Presidio container requires a managed identity or external database.
