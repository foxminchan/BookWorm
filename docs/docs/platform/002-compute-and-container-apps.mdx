This reference lists every compute workload that `src/Aspire/BookWorm.AppHost/AppHost.cs` assigns to the Azure Container Apps environment (`aca`) in publish mode. BookWorm runs 16 application Container Apps plus the `quartz-dashboard` operational tooling container.

## Overview

| Property                       | Value                                                                                                                               |
| :----------------------------- | :---------------------------------------------------------------------------------------------------------------------------------- |
| **Owner**                      | BookWorm platform (AppHost)                                                                                                         |
| **Source**                     | `src/Aspire/BookWorm.AppHost/AppHost.cs`, `src/BuildingBlocks/BookWorm.Constants/Aspire/Services.cs`, `Clients.cs`, `Components.cs` |
| **Environment**                | `aca` (`cae-<token>`), `Consumption` workload profile                                                                               |
| **Application Container Apps** | 16                                                                                                                                  |
| **Operational tooling**        | `quartz-dashboard`                                                                                                                  |
| **Assignment**                 | `containerAppEnvironment.AssignComputeResources()` in publish mode                                                                  |

The generated Bicep snapshot declares `activeRevisionsMode: 'Single'` and `minReplicas: 1` on all 17 Container Apps (16 application workloads plus `quartz-dashboard`). No `maxReplicas` value or scale rule is emitted, so do not document a specific upper bound from this artifact.

## Runtime notes

- **Azure Functions workers:** `finance` and `catalog-ingestion` use `.WithHostStorage(storage)` and receive `BrokerList` set to the Kafka connection string.
- **Finance orchestration:** `finance` receives `DTS_CONNECTION_STRING` and `TASKHUB_NAME` from `Infra/durable-task-scheduler.bicep` (`AzureExtensions.DurableTask.cs`). It has no PostgreSQL database.
- **Notification:** `notification` has no REST or gRPC API and no PostgreSQL database. It uses Redis for FusionCache and integration-event idempotency.
- **Scheduler:** `scheduler` uses `.WithExplicitStart()`, so it does not start automatically in local run mode. Quartz.NET runs `ProcessVectorBatchJob` every 5 minutes and `HeartbeatJob` every 30 seconds.
- **Presidio:** Run mode uses HTTPS with the developer certificate; publish mode uses HTTP on port `3000`. Both modes use the `/health` check.
- **Frontend images:** `FrontendAppBuilder.cs` builds a multi-stage `oven/bun:1-alpine` Dockerfile and runs the Next.js standalone server on port `3000`.
