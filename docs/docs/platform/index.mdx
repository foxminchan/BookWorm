The Platform Reference documents BookWorm's shared infrastructure, runtime hosting model, stateful backing stores, identity and access boundaries, job persistence schema, and cross-service contract surface. It is designed as a fast-lookup reference for application engineers integrating with platform capabilities, platform engineers managing infrastructure, and operators diagnosing production workloads.
