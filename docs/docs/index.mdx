BookWorm is an open-source, cloud-native bookstore reference application built with .NET 11, Aspire 17, Domain-Driven Design, Vertical Slice Architecture, Wolverine over Kafka, Next.js 16 microfrontends, and Microsoft Foundry AI agents. Use this home page to jump directly to the guide that matches your role and task.

:::warning
BookWorm is a reference and demonstration application. It is not hardened for production use out of the box—see [[doc|operational/004-security-hardening-checklist]] before deploying to a live environment.
:::
