# Book Catalog Guide

## Genre Descriptions

| Genre                | Description                    |
|----------------------|--------------------------------|
| Fiction              | Narrative prose stories        |
| Science Fiction      | Speculative future/technology  |
| Fantasy              | Magic and mythical worlds      |
| Mystery / Thriller   | Crime, suspense, investigation |
| Non-Fiction          | Factual accounts and analysis  |
| Self-Help            | Personal development           |
| Biography            | Life stories of real people    |
| Children's           | Age-appropriate stories        |
| Young Adult (YA)     | Coming-of-age narratives       |
| Software Engineering | Programming and architecture  |
| Business             | Strategy, management, finance  |

These descriptions are browsing aids, not assumptions about who reads a category. Base
recommendations on the customer's stated interests and the current catalog results.

## Search Tips

- **Broad first**: Start with genre or theme, then narrow by author or rating.
- **Author variations**: Try both full name and last name only (e.g., "Fowler" vs "Martin Fowler").
- **Series**: Mention the series name if asking about a sequence (e.g., "Dune series").
- **Gift searches**: Ask about the recipient's age, interests, and budget.
- **Current details**: Use catalog results for prices, ratings, availability, and other book
  details; do not rely on category-level popularity or approximate price assumptions.
